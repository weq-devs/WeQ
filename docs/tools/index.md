# 工具箱

这里放一组**纯前端**的小工具：打开页面就能算，不上传文件、不联网、不依赖本机 QQ。
所有计算都在你的浏览器里完成，关掉页面就什么都不剩。

它们的用途很具体 —— QQ 的本地数据全是「一串派生出来的名字」（头像文件名、账号目录名、
数据库口令），公式公开但翻起来麻烦。填几个已知值就能一步跳到结果。

## 路径与设备

| 工具 | 解决什么问题 |
| --- | --- |
| [头像缓存路径预测](avatar.md) | 有 uid，想知道头像文件到底落在哪一层目录 |
| [QQ 数据目录速查](paths.md) | 有 QQ 号 / uid，想知道账号目录、各库、各类媒体在哪 |
| [设备 guid 预测](paths.md#设备-guid-预测) | 想知道本机 guid 由哪两个值算出来，或反查机器标识对应的 guid |

## 密钥

| 工具 | 解决什么问题 |
| --- | --- |
| [手机数据库密钥](db-key.md) | 手上是 Android / iOS 拷出来的 `nt_msg.db`，要离线算口令 |
| [gpro 频道库密钥](db-key.md#gpro-频道库) | QQ 频道库的密钥和消息库不是一套 |
| [商城表情密钥](marketface.md) | 消息里缺 `encryptKey`，要找回生成时间戳 |
| [login.db 在线检查](login-db.md) | 想先确认这份 `login.db` 是什么布局、密钥该从哪来 |

## 图片

| 工具 | 解决什么问题 |
| --- | --- |
| [商城表情本地图片解密](marketface.md#本地缓存图片解密) | 缓存目录里那个无扩展名的文件打不开 |

::: tip

这些工具只做「算得出来、验得了」的部分。**解密数据库本体**仍然要交给 WeQ 或原生模块 ——
文档不提供未经验证的解密实现，也不内置任何密钥。

:::

## 为什么不做成 App 里的功能

能算的东西其实 App 里都有对应入口（头像路径、密钥扫描、其它设备密钥），这里的页面是给
「只想看公式、手上没有 WeQ 环境」的人准备的：比如在一台没装 QQ 的机器上核对别人发来的
hexdump，或者写解析脚本前先确认一个派生结果对不对。
