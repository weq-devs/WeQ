# Remote 页面就绪通知

手机壳的导航完成回调只代表主文档加载结束，不能作为 React 业务就绪信号。
共享 renderer 的备份检查在 `BackupStartupGate` 中完成，账号探测和首屏查询仍在其后运行。

## 当前流程

- 备份启动检查及浏览器恢复锁共用 15 秒等待上限，超时取消请求并释放串行队列。
- 读取失败后补充恢复回执最多等待 3 秒，随后展示可重试错误，不无限停在检查页。
- `RemoteStartupReporter` 只等待账号启动探测及挂载所需的账号配置；昵称、在线状态、
  会话列表、好友列表及消息等业务查询在 WeQ 界面内异步加载，不作为启动等待条件。
- 查询完成不等于界面完成：还须确认真实工作区或账号选择页已挂载、没有可见的启动
  加载占位，并经过两次绘制回调。`lazyPanel` 及工作区整体 Suspense 的占位带专用标记，
  不按「正在加载」文案猜测，也不把列表内的状态提示误算为启动占位；成功后停止 DOM 观察。
- `window.weqRemoteStartup` 保存 `{state, message?}`，状态更新发送本地
  `weq-remote-startup` 事件。原生壳加载后补读当前值，覆盖通知先于导航完成的情况。
- `loading` 留在手机首页，`error` 回到首页重试；`action-required` 允许展示需要用户确认的
  恢复回执、恢复处理或组件诊断页面。不会把这些操作挡在首页后面。
- iOS / Android 最多等待 45 秒，然后在首页报告超时；没有按 DOM 文案猜测状态、定时轮询
  或新增网络探测。此变化需同时更新电脑网页和手机安装包；旧手机仍按原来的导航完成条件切页。
- 手机首页依次显示实际发生的网页连接、资源下载、网页初始化、恢复检查、账号工作区恢复
  和界面绘制阶段，不虚构百分比。后续业务查询不会重新拉回首页。

## 最新业务数据

- 账号和配置确认后即请求最新 50 条会话，与 IndexedDB 缓存恢复并行，不等待好友、群和
  资料目录批次。已有目录先显示，最新页返回即合并；失败保留旧数据。
- 最新页和冷启动目录首屏共用查询缓存及在途请求，下一页从实际返回游标继续，每页 500 条。
  完整目录仍在首屏之后让出绘制并后台补齐，置顶会话保持独立读取。
- 列表可见行回调决定 Web 预览身份的补全范围，包括私聊对方、发送者及灰条身份；复用已有
  批量资料和群名片解析器。缺失群名仅对可见群按需读取本地资料，全量目录继续后台刷新。
- 会话及上述按需资料读取走独立 HTTP 请求，不等待同一 HTTP 批次的慢目录或在线接口。
- 本次无需修改手机壳协议或升级安装包，电脑提供的 Web 页面更新后生效。

## 回归入口

`backup_startup_gate.test.ts` 覆盖启动与补充状态均不返回、超时后同页重试、恢复错误及回执；
`startup_deadline.test.ts` 覆盖取消及定时器清理；`remote_startup.test.ts` 覆盖代码分包未完成、
真实界面绘制、隐藏旧界面、取消过期绘制帧及业务列表不阻塞启动；
`test/browser/run-remote-startup.mjs` 使用浏览器执行真实观察器，验证加载占位消失后才放行。
手机仓库的 `WebContainerTests` 补充 HTML 完成不放行、进度通知、
重复通知、错误及恢复操作状态检查，需 iOS 测试环境执行。

跨仓库的合成 Web 夹具在订阅收到数据后发出就绪通知，继续用于原生容器协议联调。
这些合成测试不能代替真实手机网络和具体卡顿现场的验收。
