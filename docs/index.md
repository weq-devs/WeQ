features:
  - title: 自主取密钥
    details: 本地保存凭据解密发包、离线计算等多条路径，按凭据有效期动态选择方案，期间无需重启 QQ 或预先登录。
  - title: 高仿 QQ 阅读界面
    details: 私聊、群聊、官方账号、频道私聊全覆盖，连气泡、字体、挂件都能按原样还原。
  - title: 完整导出
    details: JSON / TXT / XLSX 等多种格式，聊天记录之外还能带走联系人、收藏、QQ 空间与配套媒体资源。
  - title: 分析与年度报告
    details: 单聊会话分析、群聊分析、成员画像与年度报告，统计口径写进文档，不靠感觉。
  - title: 防撤回与消息编辑
    details: 撤回触发与保护范围可配置，撤回内容可离线回看；消息还能新增、修改、删除与恢复。
  - title: 完整协议功能
    details: 实现了QQNT的大部分在线操作功能，包含发消息，群管理，传文件等等等功能。
