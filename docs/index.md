features:
  - title: 自主取密钥
    details: 纯协议快登 / 扫码换票据、零注入内存扫描、离线计算，多条路径按凭据有效期动态选择，期间不必重启 QQ 或预先登录。
  - title: 高仿 QQ 阅读界面
    details: 私聊、群聊、官方账号、频道私聊全覆盖，气泡、字体、挂件都按原样还原，并支持只看某一类消息。
  - title: 完整导出
    details: JSON / TXT / XLSX 等多种格式，聊天记录之外还能带走联系人、收藏、QQ 空间与配套媒体资源。
  - title: 分析与年度报告
    details: 单聊会话分析、群聊分析、成员画像与年度报告，统计口径写进文档，不靠感觉。
  - title: 防撤回与消息编辑
    details: 撤回触发与保护范围可配置，撤回内容可离线回看；消息还能新增、修改、删除与恢复。
  - title: 在线与协议能力
    details: 发消息、群管理、传文件、QQ 空间、QQ 邮箱、空间相册、抓包与协议调试，覆盖 QQNT 的大部分在线操作。
  - title: 可维护的数据底座
    details: 坏页体检、数据库重建、布局迁移与回滚，长导出走安全解密，不拿残缺结果当完整结果。
  - title: 文档即工具
    details: 头像路径、数据库密钥、商城表情解密、设备 guid 预测都能在文档站里直接算，纯前端、不上传。
