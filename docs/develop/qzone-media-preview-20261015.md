# 空间媒体预览

空间说说、转发原文、好友动态及相册使用共用的空间照片/视频预览；聊天灯箱不受影响。

- 图片缩放、复位、滚轮锚定缩放和拖动平移复用 `useZoomPan`；切换媒体重置变换，关闭移除拖动监听。
- 左右空白区及箭头在当前已加载集合内导航，不循环、不自动翻相册页；原生视频控制优先接收输入，Escape/关闭恢复入口焦点。
- 相册按精确 picKey 读取详情。已有图片先显示，详情升级失败保留原图并提供重试；晚到结果不能替换新选项。
- 单次打开期间按媒体键和 loader 复用详情 promise，失败淘汰以便重试，关闭后释放。这是元数据缓存，不是另一份媒体下载缓存。
- 当前预览**没有相册名称页脚或相册归属查询**，不发 R15/R25 探测；相册导航只在原相册上下文提供。旧 `postAlbum` RPC 已移除。
- 空白区命中使用 CSS 按钮，不在每次 mousemove 中读取布局或写内联光标。

实现入口：`components/QzoneMediaPreview.tsx`、`QzoneAlbumDialog.tsx`、`views/QzoneView.tsx`、`components/useZoomPan.ts`。验证需覆盖图片立即显示、详情失败回退、重试与迟到响应、原生视频控制和焦点恢复。
