## 针对性校验

```bash
pnpm test:export-schema
pnpm exec biome check package.json schemas/export/v1
git diff --check
```

规范测试采用 Node 内置 test runner + Ajv 2020-12，使用合成字段、固定字节和假地址，
不读取真实 QQ 数据、不访问业务网络。全部 schema 先做 meta-schema 校验、引用注册和
预编译，再分别校验正例与预期失败反例。

| 项目 | 验证内容 |
| --- | --- |
| 格式覆盖 | 17 个 schema，七领域各 basic/full；每档 43 个 Record，覆盖子类型 |
| 正反例 | 必填、闭合对象、整数精度、时间精度、null/0/false/空串、原始字节/base64 |
| 内容 | 双层转发、内部资源、引用关系、CID 邮件正文、相册/成员父子关系及范围外引用 |
| 不重复保存 | native 属性不覆盖规范字段，已消费来源路径不重复作为残余，残余字节区间不重叠 |
| 档位投影 | full 删除 native 后重算摘要、合并相同 basic 版本并重连观察，不伪造缺失信息 |
| JSON/JSONL | 相同领域数据等价、正式提交链、计数/hash/前链、重复键及档位混写拒绝 |
| 增量模型 | 重试幂等、晚到历史、正文变化、来源冲突、明确删除、字段/附件补齐及成功资源保留 |
| 恢复模型 | 无索引从正式数据重建；未换行尾段、无 commit 尾批不计成功；坏提交不当作可丢尾部 |
| 真实合成文件 | 4 字节示例文件回读，其 SHA-256、大小与 Resource 回执一致 |

本轮初次投影测试发现空 mappings 与属性缺席的差异，已修正投影输出；未放宽断言或
schema。字段意义、重复信息是否真等价、来源是否穷尽，不能仅凭目标 schema 判定，
仍按覆盖矩阵逐来源对账。

本轮实际结果：**150 项规范测试全部通过**；23 个代码/schema/配置文件的定向 Biome
检查通过；13 份新文档内 20 个本地链接存在；`git diff --check` 通过。未以这些结果
替代下列业务实现验收。
