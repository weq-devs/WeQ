# 后台操作接入统一任务列表

## 状态来源

`shared/background_task.ts` 提供主进程与渲染窗口共用的轻量回执注册表。沿用现有
导出、漫游、克隆、闪传队列，不迁移其执行或持久化方式，也不新增通用重试引擎。

| 操作 | 回执来源 | 停止能力 |
| --- | --- | --- |
| OCR、语音、本地意图模型下载 | 原下载器事件及真实返回结果 | 原下载器不提供取消 |
| WeQ 更新包 | 原更新器进度及下载 Promise | 原更新器不提供取消 |
| 数据库体检、坏页扫描、修复、备份、回滚 | 原数据库服务及修复阶段回调 | 体检复用原子进程取消并等待退出 |
| 配置备份与恢复 | 宿主读取、校验、生成、暂存；浏览器分片传输另由发起窗口记录 | 浏览器传输可停止后续分片 |
| 收藏表情导入 | 原账号导入 session 主动发布快照 | 复用原 session.cancel，等待在途请求收尾 |
| 逐条转发 | 发起窗口，每个目标一项 | 复用该目标 AbortController |
| 群相册视频上传 | 发起窗口，覆盖分片传输、提交与原读回核对 | 仅提交 QQ 前可停止宿主传输 |
| 资源扫描、清理 | 窗口按目录扫描；宿主清理服务返回逐目录结果 | 扫描停止后续目录，清理不伪造取消 |

## 展示与清除

- 主进程 `backgroundTasks` 顶层 RPC 不依赖活动账号，因此数据库维护关闭账号后仍能保留回执。
- 账号操作附带 uin 和已知 configId；模型、应用更新、配置备份属于全局。界面按当前来源过滤，
  不把同号不同配置的导入、转发或资源操作混在一起。回执不包含模型输入、图片字节或备份正文。
- `CurrentTaskList` 与 `WorkspaceTools` 共用查询和窗口注册表；新增任务参与现有红蓝角标、排序、
  详情与清除操作。待核对状态不计入成功任务，也不贡献已完成提醒。
- 清除确认固定记录身份；宿主再核对 updatedAt，窗口核对快照身份。记录变化或仍在运行时拒绝移除。
  只移除回执，不删除任何业务文件或已上传内容。
- 记录是进程内状态，不承诺重启恢复或跨窗口续作。各注册表最多保留 100 项已结束历史，不淘汰在途任务。
- 宿主轮询每秒一次，隐藏窗口按现有活动策略停读；收藏导入终态由业务 session 主动通知，不依赖页面轮询。
- 列表查询不重复传逐项明细，仅选中的宿主任务按回执版本读取详情；详情查询不长期缓存。

## 验证

离线合成数据覆盖注册表生命周期、去重、来源隔离、真实下载器返回失败、部分导入结果、
停止收尾、确认期间记录变化、任务列表与角标。浏览器夹具覆盖八类任务、深浅主题、自定义主题色、
背景、窄屏及减少动态效果。不触发真实 QQ 写入、数据库修复、模型下载或应用更新。

本轮验证：桌面端 138 项、服务层 11 项定向测试通过；桌面主进程、渲染层及 Web 服务端
类型检查通过，改动文件 Biome 检查通过。`test/browser/run-background-tasks.mjs` 使用独立
无头浏览器完成四组主题与布局检查，并验证任务内停止、移除；浏览器与测试服务器均已关闭。
