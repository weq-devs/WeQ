# 空间媒体网格

说说、转发原文和好友动态复用照片/视频混排，不把视频封面再次算成照片。

- 单项保留自然比例，只限制最大尺寸，不强行放大；多项使用响应式方格并裁切预览，不裁切原件。
- 两项两列、三项三列、四项 2×2，五项以上三列；具体像素尺寸以样式为准。
- 好友动态 HTML 只接受已知的视频元数据、原生 video/source 和真实 lazy-image 目标。排除加载器、控制图和跟踪像素，不把 SWF/播放器页面当视频本体。
- 真正的内容图片加载失败仍占位并提示不可用，不能按“失败图片”统一隐藏。
- `pic[].is_video/video_info` 表示携带视频，不能据此标成 Live Photo；已知混合帖中普通视频也使用这一结构，详见[分类证据](qzone-live-photo-investigation-20261015.md)。

源码：`renderer/src/lib/qzone.ts`、`views/QzoneView.tsx` 及空间样式；大图行为见[空间媒体预览](qzone-media-preview-20261015.md)。验证应使用实际好友流和说说组件，覆盖单项比例、混合数量、失败占位、视频播放及窄屏边界，不能仅检查空外框。
