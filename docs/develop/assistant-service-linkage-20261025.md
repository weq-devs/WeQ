# 助手退出与服务依赖提醒

本次只补交互提醒，不恢复独立 daemon，也不把助手／登录自启或 Remote／Web 变成强制绑定。

## 退出顺序

`registerAppQuitConfirmation` 通过 `prependListener('before-quit')` 先于退出准备和清理运行。
后二者尊重 `defaultPrevented`，取消或只关窗口时不设置 `isQuitting`、不销毁托盘、不停止资源服务。
窗口关闭偏好为退出时，先拦截原始窗口关闭，再统一请求应用退出，避免问题尚未确认窗口就已销毁。

同一时刻只保留一个询问。确认退出后放行后续清理触发的普通退出，不重复询问。
更新安装及已确认的重启／存储清除走既有流程；原生更新或其它已放行退出使旧询问结果失效，
防止迟到的「只关闭窗口」隐藏后续窗口。

## 设置联动

- 开启助手先提交原请求，再读取自启状态并推荐开启自启；拒绝推荐不回滚助手。
- 自启不支持时不下发设置；待批准时只提醒，不假报已生效或重复注册。
- 助手仍启用时关闭自启，确认前不改变自启，可保留或仍关闭；不擅自停用助手。
- Remote 启用后，Web 当前关闭或未记住自动启动均会推荐；反向关闭 Web 可选择同时关闭 Remote。
- Remote 启用时取消 Web 自动启动可选择保留；只改偏好不会停止本轮服务，停用 Remote 不会停止独立 Web。
- 每组操作跨确认等待持有锁，防止重复点击覆盖未完成的全局确认框；失败后回读实际状态。

验证使用离线组件用例、更新退出回归及隔离 Electron 真实退出事件，不操作真实 QQ 数据或系统登录项。
