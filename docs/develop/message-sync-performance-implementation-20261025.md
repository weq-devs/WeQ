# 消息链路性能优化实施记录（2026-10-25）

## 范围与状态

依据[修复方案](./message-sync-performance-plan-20261025.md)落地可独立验证的消息调度、未读、持久化、首屏读取及媒体优化。此记录不宣称 S0 至 S5 全部完成；动态高度时间线虚拟化、真实 QQ 端到端采样和长时间运行验收仍待完成。

仅源码与离线回归；不重启日常实例、不操作真实 QQ 消息、不推送、不发布。主进程与 preload 是否已被运行实例加载须另行核实，不能由 renderer 热更新推断。

## 已实施

| 路径 | 变更与边界 |
| --- | --- |
| 实时窗口 | 单个在途读取，通知合并为下一轮；当前轮可以持续交付，仍保留来源、账号、会话身份、窗口身份和已提交版本检查。历史／搜索窗口不拉回尾页。 |
| 数据库通知 | 明确消息目标立即校准对应聊天和最近页；未知文件变化每秒合并校准当前窗口，辅助目录五秒合并。不虚构文件事件携带表名。未知变化仍使缓存失效，但不逐个重新查询缓存。 |
| 正文差分 | 每会话每轮一页，每轮最多八页；补齐边界同 seq 灰条后交付，积压会话排队续作。失败或正文迟到按目标退避，独立于文件签名变化；卸载取消续作。 |
| QQ 已读校准 | `getUnreadInfos` 新增可选 `watermarksOnly`。可信水位已覆盖最新位置的结果先交付；仍需排除自己发送时返回 `countPending`，不能按零未读应用，转入精确队列。继续保留手动未读、实时入站及范围外高亮。 |
| 未读队列 | 失败和遗漏仅重试对应目标；每批最多 256，健康目标不等待失败目标退避。前台有提醒目标每 1.5 秒兜底校准；后台全目录每 15 秒检查是否存在未校准版本，无变化不重复扫描。失焦隐藏不发周期查询，恢复前台立即校准。队列溢出显式补扫。 |
| 本地状态 | 异步原子写仍包含文件 fsync、rename 和尽力而为的目录 fsync。单写者、版本化等待；同轮修改可合并，失败不清除未保存版本。通知、阅读及手动操作等待自身状态实际发布。正常关闭、切号与退出接入等待，强制释放失败显式记录。JSON 序列化仍在 JS 线程，尚未量化其耗时。 |
| 首屏缓存 | 普通模式可立即恢复最新窗口并校准，不再由未读阅读偏好控制。普通模式不把历史缓存当最新页，也不恢复旧历史锚点；未读阅读模式保留原有锚点与分页契约。缓存容量不扩大。 |
| 查询关键路径 | 40900 引用缓存按 ID 批量读取，坏缓存隔离；消息页撤回只读当前页 ID，保留 64 位精度、会话和表隔离，不随每页关闭共享 native 连接。本地页与漫游缓存读取重叠启动，合并规则不变。 |
| 最近会话 | 首次由完整目录的首批读取提供，不再同时自动发第二份最近页请求。仍逐页取得完整目录；实时和前台恢复使用单独最近页，避免焦点恢复重取整个分页目录。 |
| 渲染计算 | 缺失引用按窗口建索引，保留发送者／时间消歧和多匹配不猜测。刷新按消息身份复用未变行及未变窗口引用；普通消息模板按对象与成员／会话上下文复用，引用继续重新解析以响应原消息变化。尚未声称行级 memo 或 DOM 虚拟化已完成。 |
| 媒体定位 | 异步目录 I/O、在途合并、按 inode／mtime／ctime 校验目录快照。目录数、条目数及单目录缓存均有界，缺图不缓存最终结论，新下载和删除可使快照失效。月末相邻月份计算不再溢出。 |
| 气泡缩图 | 普通聊天图片复用既有 sharp 预览器，最长边 512，静态输入受既有字节／像素与队列预算约束；灯箱独立读取原图。GIF／APNG 等多帧内容不静默转为首帧，超限或转换失败仍沿用原图回退，所以不能宣称动画与坏图场景的像素峰值已受同样限制。 |

## 验证口径

- 单测仅使用合成对象、临时媒体和明文 SQLite，不读真实 QQ 库，不联网。
- 调度回归覆盖持续通知、慢查询、健康／失败目标、5000 目标分页、队列溢出、无后续文件事件的补齐与卸载取消。
- SQL 回归覆盖单页引用的分批查询、坏 BLOB、跨表隔离、64 位 ID、当前页撤回标记与空 ID 列表。
- 未读回归继续覆盖手动标记／撤销、设备回声、自己发送、旧快照、缺水位和已读上报开关。
- 异步保存回归覆盖单写者、交错版本、等待关闭、失败重试、突发合并和真实原子文件发布。
- 媒体回归检查输出真实像素尺寸、原文件不改写、多帧保留、来源切换拒收，以及目录缓存新下载／删除失效。
- 数字反映结构性预算：连续通知峰值在途为一；2000 条唯一序号引用只需线性建索引；不能将其称为日常速度倍数或真实 QQ P95。

本轮定向回归 32 文件、247 项通过（desktop 125、service 78、db 44），37 个本次涉及的 TS／TSX 文件通过 Biome 检查。desktop 的主进程／渲染进程以及 service、db 类型检查通过。检查对象是保留其他任务改动的当前工作区，不能将结果外推成对所有未提交改动的验收。

未运行全仓 CI、桌面打包、真实 QQ 联调或一小时长测。测试日志中的刻意缺少 AppContext 和无应答协议夹具属于对应反例，不是运行实例报错。
