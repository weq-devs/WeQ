# 会话总日历

当前源码实现说明；不代表安装版已更新、所有平台原生产物已发布，或真实 UI 性能已经验收。

## 读取与接口

会话列表目录完成分页后提供稳定对象描述，日历复用显示范围、关键词和聚合归属，先展开再按来源及会话身份去重。目录失败时保留部分结果提示。日期统一采用北京时间半开区间。

`account.calendarOverview` 提供 `start`、`poll`、`task`、`control`、`background`、`stop`、`locate`。同一账号、数据源、月份及统计范围复用原任务，所有调用绑定账号及 configId；客户端不传文件路径、SQL 或数据库游标。当天会话列表连续滚动，每次接近底部将返回窗口增加 50 行，界面虚拟化渲染可视区域附近的行；扩大窗口仅读取已有统计结果，不重扫消息。接口默认窗口仍为 50，最多覆盖已筛选的 12000 个会话。切换账号后原任务不得继续提交读取，定位前后均验证当前来源。

前端任务句柄同时绑定创建请求的月份、账号、筛选、修订和活动状态。请求改变的当次渲染即停用旧句柄，不等待 effect 清空 ID，避免将新日期发送给旧任务；迟到的创建结果立即停止，旧请求响应和错误不更新新视图。后端日期所属月份校验不放宽。

统计范围签名只取排序去重的来源及会话身份，不含活跃顺序、头像和名称；收消息导致会话排序改变时不重启统计，显示信息单独更新。创建时即传入选中日期，先统计当天，再优先向前、随后向后补齐其他已发生日期；最晚到北京时间今天，未来日期不执行读取、不计入分母，在月历中置灰且不可选择。任务每次推进时重新核对日期，跨北京时间午夜可在原任务中继续新的一天。同日固定按私聊、群聊、我的设备、公众号、服务号、频道私聊、好友克隆、克隆群聊顺序读取。

## 进度与日志

进度条按已完成来源统计：当月分母是日期数乘已选来源数，当日进度跟随任务实际正在获取的日期，并非日历选中的列表日期。顶部“统计进度”集中展示这两条进度、当前扫描阶段及任务日志；列表日期紧邻会话列表，列表计数单独展示，不混作当前扫描进度。未完成的正计数显示 `数量+`，未知零值仍显示待统计。不为进度额外执行全量 COUNT。

每条进度条右侧提供图标控制：进行中暂停、暂停后继续、成功或失败后重试。空选择及当前范围无已选来源属于独立空态，不将 `0/0` 或空集合 `every()` 冒称完成；真正执行查询得到零条仍是有效完成结果，月/日重试均可用。两层暂停独立：月暂停只停止扩展到其他日期，当前日仍可完成、继续或重试；日暂停只跳过该日，月扫描未暂停时按原顺序继续其他日期。月状态按月份保存，日状态按日期保存，月继续和重试不清除各日暂停标记。暂停今天后会从昨天向月初推进，暂停日期在日历中标注。

重试使用来源级双缓冲：原计数、完成进度和会话列表继续展示，重新读取的行与游标进入临时结果；该日期来源完整读完后替换，允许消息数减少、会话移除及最早锚点变化，不将新旧结果相加。中断和失败不覆盖旧结果；检查点包含临时结果，可从成功游标继续。重复重试通过批次代次隔离迟到响应。

日历对话框和任务详情复用同一个“任务日志”折叠栏，使用聊天导出的日志组件与北京时间时间戳，不在顶部工具栏另设日志图标。动态更新当前日期/来源、阶段、已处理元数据量及已计消息数；等待空闲、超预算缩批、暂停和完成分别留记录。连续同阶段进度原位更新，最多保存 200 条、每条 512 字符，不含消息正文或联系人身份。只有展开日志时日历 `poll` 或任务详情才读取日志；公共任务列表不携带日志正文。

打开日历本身不注册公共任务。点击原刷新按钮位置的“后台进行”，才将已有统计加入任务列表并关闭日历，不重建、不重扫；后台批次事件最多每 500 ms 更新一次回执，完成时补最终状态，不依赖渲染进程轮询或新增统计定时器。任务列表可停止后台统计，切账号/数据源前通过账号关闭事件立即取消。

原生可选能力 `executeSqlBudgeted(dbPath, sql, params, budgetMs, key?, algo?)` 支持 1–50 ms 查询预算，日历固定使用 10 ms。它复用严格只读连接缓存和 SQLite progress handler，等待或执行超时分别返回 `database_query_wait_timeout` / `database_query_execution_timeout`；中断后清理 handler，不返回部分 SQL 行。原有接口仍使用原来的 120 秒上限。旧组件缺少此方法时日历提示更新，不能回退普通长查询。

## 调度与一致性

- 同一账号与数据源下，月份、外部会话范围和隐藏消息集合一致时复用原统计句柄。普通关闭仍停止后续读取，但保留计数、成功游标和日志；再次打开恢复原任务，后台任务不重复注册。统计检查点在实际缓存根目录的 `conversation-calendar/` 持久保存，以账号、配置、数据库路径及统计范围的 SHA-256 区分；重启后按需恢复，不登录预热或自动开启后台扫描。
- 统计内容采用全局搜索同款多选控件，分为私聊、群聊、我的设备、公众号/服务号、频道私聊、克隆会话六组。选择记忆在本机；组合项同时控制对应来源。关闭某组后不再提交其后续批次，已在途批次不并发抢占；快照的每日总数、会话列表及进度分母均排除未选来源，内部保留该来源计数、游标和结果，重新选择继续，不建立新任务。
- 任务详情复用日历右侧组件，包含日期选择、统计内容、月/日来源进度、当前扫描阶段与已计消息数、按需日志、连续滚动会话列表和原消息定位，不重复渲染月历网格。定位复用同一账号绑定和后端锚点验证。
- 短预算读取显式回传空闲让路、JS 队列等待、原生读取和结束状态。界面不再把零次原生读取或历史等待日志当作当前等待状态；原生等待包含线程池和 SQLite 等待，不冒称纯 SQL 执行。

- 默认只在弹窗活动且页面可见时读取；明确点击“后台进行”后允许关闭日历继续当月任务。每批最多 256 条，批次间至少 20 ms，优先等待数据库连续 500 ms 空闲，每条短预算读取在队列外最多等待 1 秒，之后进入既有后台公平队列；不抢占在途查询，保持 10 ms 原生预算。该上限只限制队列外让路时间，不保证实际 SQL 在 1 秒内开始，也不改变建索引等操作的持续空闲条件。
- 复用已存在的时间覆盖索引，优先使用按日 COUNT；没有合适索引、需要验证 ARK 卡片或混入漫游缓存时使用稳定游标的元数据页。无时间索引的表按 rowid 续查，不执行整表分组，不建索引。
- 时间索引游标包含时间、source 和 rowid，显式处理 NULL source 及负消息 ID。超时后缩小批量、保留成功游标；连续三次无法推进暂停来源。超时页与超出缓存预算的页整批不提交。
- 频道仅枚举消息目录中的私聊节点，克隆枚举既有子会话和旧桶，不创建新会话。服务号/公众号为 ARK-only：仅此适配器需要逐批校验原卡片可展示性，其他来源不解码正文。
- 漫游缓存使用已有组合和时间线去重规则，计数路径只投影身份/时间，不复制元素及原始载荷，不触发缓存建表或联网请求。与 QQ 本地记录按来源身份校验，避免把已同步副本再次计数。
- 日历总数和详情来自同一任务；详情扫描完成后才视为完整。未完成、失败、缓存满均不能冒称 0。加载中行位置稳定，完成后按条数、名称及稳定身份排序。
- 普通任务每 5 秒续租，客户端丢失后在下一批结束时停止；关闭/隐藏/换月主动取消，只有明确转入后台的任务免续租。账号内 LRU 最多 12 个任务，元数据按保守估算共享 8 MiB 上限，超额先淘汰较旧任务，单个任务无法容纳时暂停。
- 仅在统计、选择、暂停等状态改变时合并保存，普通轮询不反复写盘。异步原子写、文件 fsync 与目录发布复用已有工具；普通关闭、换账号及正常退出前补最终检查点。读取上限 16 MiB，完整校验月份、来源、行、游标和内存预算后恢复；坏文件保留，不静默覆盖，保存失败在界面提示。检查点不含消息正文或附件，包含已提交结果、正在重试的临时结果、暂停状态、扫描顺序及有界日志。
- 目录修订比较实际内容，不比较请求刷新时间。扫描期间的数据通知不遮住已完成数字、不取消进度；已完成后的刷新同样保留旧结果。任务快照只附加有界匿名计数、超时/暂停次数及耗时峰值，不输出正文或联系人诊断日志。

## 验证

数据库黄金夹具覆盖有/无时间索引、同时间戳、NULL source、负 ID、隐藏记录与半开日期；服务测试覆盖范围去重、克隆子会话、整批提交、超时降级、三次暂停及取消。漫游回归继续运行既有缓存分页与删除再拉取测试。

真实大库应交错采集无统计、月份统计、当天详情统计，各前台路径至少 100 个样本。验收条件为前台 p95 增幅不超过 `max(10 ms, 基线的 10%)`、共享连接占用样本不超过 50 ms、无新增 50 ms 主线程长任务、未打开时没有该功能周期查询。

原生 await 包含 N-API/线程等待，不能冒称纯 SQL 执行或锁持有时间；SQL 代理基准、合成 UI 浏览器测试与真实用户 UI 端到端验收必须分开记录。短预算无法硬性中断操作系统 I/O。
