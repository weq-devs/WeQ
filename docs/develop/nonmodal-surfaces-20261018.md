# 非模态内容与工具

日期：2026-10-18（北京时间）。本轮范围来自用户确认的弹窗分类调整，不替代其它 UX 重构任务。

## 交互契约

- `Modal`、`OverlayLayer` 默认仍为模态；调用方显式选择 `page`、`sidecar`、`panel` 或 `popover`。不能用透明遮罩冒充非模态。
- `WorkspacePages` 将内容页 portal 到主区域，用标签切换；关闭返回原内容，原聊天草稿及阅读组件不因打开页面卸载。导航离开关闭临时内容页，正在执行且不能安全关闭的清理界面保留原保护，不强制销毁。
- 页面内的 `TabActivity` 隔离隐藏页的后代浮层。窄屏即使没有打开聊天会话，也能进入内容页；页面避让标题栏和底部导航。
- 非模态面板外壳不命中鼠标，只有内容区域接收输入，无背景模糊、遮罩、全局焦点锁或 `aria-modal`。初始焦点进入内容，但用户可返回背景；Escape 仅处理自身焦点所在层。
- 真正模态层按实际 z-index 判断最上层；Escape 不连关后层。多选快捷键按焦点所在内容页或对话框隔离，不再以「有无遮罩」决定归属。
