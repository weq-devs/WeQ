# 页面卸载与现场恢复

2026-10-28 起，`RetainedTabs` 保留既有调用名称，但不再缓存访问过的 ReactNode、DOM 或隐藏页面。切换标签、祖先页面失活时卸载子树，重新进入再挂载。主导航、设置分类、工具页、频道网页/私聊和空间内容使用此生命周期。

## 保存的数据

`PageSnapshots` 以当前账号与配置 ID 隔离，`PageSnapshotScope` 按页面进一步分组。`usePageState` 只保存显式登记的选择、搜索条件、导出配置及表单字段，使用既有 superjson 编解码并通过 Zod 核对恢复类型；不序列化 React 内部状态、组件树或媒体对象。账号配置暂不可读时仍展示原工作区，但不恢复未核实来源的快照。

- 页面缓存写入本机 localStorage 的 `weq:page-snapshot:v1:`，按 UTF-16 估算每项最多 256 KiB、合计 2 MiB、256 项，超出淘汰最早更新的可重建现场。
- 已登记的未提交表单使用 `weq:page-draft:v1:`，不参与页面缓存淘汰。正文草稿与缓存不同，不因释放页面而删除；保存失败明确提示，本次工作区暂存输入数据，不继续保留旧 DOM。
- 消息、联系人选择与分区，收藏筛选，频道私聊选择，空间导航，导出对象及参数、模型服务商等设置表单均按需恢复。凭据的揭示状态、一次性验证流程、忙碌标记和提交动作不持久化。
- 聊天图文草稿继续复用已有正文快照和 IndexedDB 素材存储，不把图片字节写到页面快照。邮件正文单独作为草稿保存，记录未保存状态；恢复不发送邮件。

## 卸载与重建

`PageScrollSnapshot` 仅保存至多 64 个滚动坐标和 64 个展开项的路径，不保留节点引用；消息列表另外保存稳定消息锚点与相对偏移。重新挂载后等待内容就绪，恢复观察最多运行五秒；用户滚动、触摸、键盘或指针操作以及新的设置搜索会停止旧恢复，卸载时清理观察器、定时器及监听。新搜索定位与普通返回分别处理，不反复抢焦点。

快照容器内的真实页面根节点继续继承工作区的满幅尺寸规则，保持设置页等内容的原有分栏与滚动，不退回旧弹窗的固定宽高。

工作区覆盖页与右栏失活时卸载可见内容；页面拥有者保留必要的轻量控制状态。邮件的通知/连接控制器独立于邮件 DOM，发送或附件操作在途时先完成既有操作再释放界面。助手保留当前会话的无界面控制器接收在途输出与完成提醒，隐藏时移除聊天 DOM、布局观察与搜索定位；重新显示时恢复界面。导出、漫游和其它已经提交的服务端任务不因对应页面卸载而取消。

远程频道网页关闭后重新进入会重新载入，沿用既有持久会话分区。普通消息的数据窗口仍由已有聊天读取与有界窗口缓存管理；未保存在页面快照中的远程列表数据重新读取。释放量随 Chromium/GPU 的缓存回收节奏变化，现有后台采样继续跟踪长时间运行。

源码：`components/RetainedTabs.tsx`、`PageSnapshots.tsx`、`PageScrollSnapshot.tsx`、`WorkspacePages.tsx`、`lib/pageSnapshots.ts`。回归入口：`page_unloading.test.ts`、`workspace_activity.test.ts`、`workspace_surfaces.test.ts`、`settings_retention.test.ts`、`channel_workspace.test.ts`、`qqmail_folders.test.ts`。
