# 群文件管理器（2026-10-21）

## 实现范围

- `GroupFileManager` 取代独立操作表单和重复的文件列表；旧 `GroupFileActions` 导出保留为组件入口。
- 复用 `useMultiSelection`、`ConversationActionsMenu`、`useQQAction` 和 `useQQAutoRefresh`，
  工具栏、表格选择、F2 编辑、行菜单与内部拖拽共用稳定文件／目录身份。
- `groupFileManager` 提供名称、排序、权限与拖拽载荷校验。来源包括账号、配置、群与原目录；
  显示名称不参与定位。权限仍由既有主进程路由重新核对，未新增协议或依赖。
- 本机拖入只取得路径并排队，不读取整个文件，不复制原件。上传复用 `account.sendFile` 的目录与名称参数，
  真正发送前再次核对账号服务、配置、QQ PID 和在线状态。群内拖拽只准备文件移动，不自动提交。

## 读取与结果

目录查询增加可选来源绑定，并在返回后检查服务实例、配置和运行时，错误目录不写入已浏览索引。
进入、必要前台恢复与操作后读取走现有自动刷新；没有新增常驻轮询或写请求重试。

重命名、新建、移动与上传先读取相关目录检查同名。检查不构成跨设备原子事务，服务端业务错误
仍需如实显示。批次串行，未知回执立即停止；已受理项不因列表回读失败被重新提交。
停止不取消正在进行的写请求，未执行项与未知项保持区别。再次手动提交关联项目会额外确认
上次可能已生效的风险，不自动重放，也不把目录的其他操作永久禁用。

文件夹选择与导出确认窗复用 `collectGroupFileSubtree`，按目录 ID 防环、来源变化时停止，
遍历有目录数和文件数上限。文件夹保存复用现有资源导出任务、保存位置和结果报告。
搜索深层定位时不捏造未知祖先名称或路径。日期格式固定北京时间，异常时间留空。

## 验证边界

合成测试覆盖权限、范围选择、取消、来源变化、逐项结果、上传目录、同名冲突、拖拽身份与子树边界。
浏览器用独立本地数据替身核对真实组件交互、剪裁和菜单位置，资源图标来自仓库文件。
这些验证不冒充实际 QQ 写入或接收端验收；真实测试群的操作、恢复和跨端同步另见本机测试清单。
