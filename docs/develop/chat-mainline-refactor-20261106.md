# 聊天主链路重构：阶段收尾

日期：2026-11-06（北京时间）。本记录是阶段交付，不代表完整拆分方案已经实施。

## 已实施

- 恢复消息模型、ChatPane、ChatMainContent、输入框、引用、草稿元素、消息行、消息气泡和渲染注册表的类型检查，共移除 9 处文件级抑制。
- 导出具名 `ChatPaneProps`，宿主通过 `Pick` 复用回调契约；补齐实际消息删除来源和撤回显示字段，收窄会话类型，区分 React 与原生 DOM 事件，处理空值及二进制缓冲区类型。
- `useChatTimelineNavigation` 负责阅读位置、新消息提示、未读跳转、已读手势、定位反馈及相关 effect/清理；继续复用 `useVirtualTimeline`，上层分页和消息窗口归属不变。
- 时间线对外暴露导航命令和视口引用；不向宿主暴露内部已读上下文、未读状态 setter 或贴底状态 ref。
- `chatTimelineModel` 承载追加消息计数；`composerSubmission` 捕获提交正文、独立附件、引用及额外 token，保留原有顺序和草稿清理规则。
- 增加迟到发送成功/失败不覆盖新会话草稿的组件回归，以及提交快照、追加计数和核心文件不得重新关闭类型检查的测试。

## 验证

- 修改前：桌面渲染层类型检查通过。第一阶段恢复检查后，定向 5 个测试文件、87 个用例通过。
- 收尾版本：`pnpm --filter @weq/desktop typecheck:web` 通过；定向 Biome 检查（告警视为失败）通过。
- 最终定向 Vitest：10 个文件、83 个用例通过，覆盖草稿恢复、发送迟到结果、提及身份、已读手势、消息定位、跨页选择、消息行 memo 和纯逻辑。
- `pnpm --filter @weq/web build` 通过，Electron 隔离和构建产物检查通过。
- 离线浏览器 `run-conversation-entry.mjs` 通过；`run-timeline.mjs` 的长列表、阅读锚点、选择、发送定位和滚动打断断言通过，但浏览器记录了 ResizeObserver 循环警告，不能记为零告警。
- `run-composer-actions.mjs` 停在文件菜单文案断言 `File menu mismatch`。将同一夹具切到类型修复前的 `592a9747^` 原组件后，同位置复现相同失败，确认不是本轮重构新增；本轮未修改断言或菜单来绕过失败。
- 测试使用合成数据与离线 tRPC 替身，不连接真实 QQ。浏览器复用本机 Playwright 和 Edge，脚本退出时关闭自身实例及测试服务。
- 工作区同时存在其他任务改动。曾因 `unicodeFaceMap.ts` 迁移期间短暂缺失导致检查无法加载，文件恢复后已重跑；本任务未修改该迁移。
