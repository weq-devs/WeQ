# 闪传下载任务归并

闪传浏览改为紧凑文件列表，顶部任务入口和下载成功后的跳转均打开常规任务面板，不再提供独立闪传任务弹窗。

每次下载操作为解析后的文件保存同一个 `batchId`，文件传输仍复用原有四路并发池。
任务查询按明确的 `batchId` 聚合文件数量、字节进度、状态与错误，详情展示逐文件结果。
同一分享的不同下载操作不会混合；旧记录没有操作标识时各自保留，不按时间猜测归属。

整批有待处理文件时保持活动状态；全部结束后，解析或下载失败优先标记失败，其次为取消，全部成功才算完成。
取消会中止该操作下所有未完成文件；清除已完成只移除整批成功的任务记录，不删除下载文件。
失败、取消或尚未结束的操作不会被「清除已完成」移除。重启后按保存的操作标识重新归并。

验证使用离线合成数据，不读取真实 QQ 数据或请求下载服务。覆盖操作隔离、旧记录、混合状态、取消、清除与重载。

浏览器验证：`node apps/desktop/test/browser/run-flash-transfer.mjs`，可通过
`WEQ_PLAYWRIGHT_IMPORT`、`WEQ_BROWSER_EXECUTABLE` 指定已有 Playwright 与浏览器，
`WEQ_STYLE_ARTIFACTS` 指定截图目录。覆盖六组主题、背景和窗口组合，复用真实文件图标并阻止外部请求。
