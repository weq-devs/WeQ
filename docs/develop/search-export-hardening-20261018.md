# 选择、搜索与导出契约

用法见[统一导出](../guide/export.md)，来源覆盖见[搜索来源](content-search-sources-20261018.md)。

## 选择与确认

- 内容多选复制为工具草稿，不反向修改内容页；新一轮选择进入工具时更新草稿，相同选择重开保留工具内调整。
- 按内容身份分别保存范围；真实/虚拟会话、聊天/空间不能互套。精确空集合不能扩大为全部，不连续 ID 不能转换为时间区间。
- 等待目录选择之前复制目标与格式；切号或同号切换配置后拒绝旧请求。关闭工具不取消已创建任务。
- 大列表窗口化；范围编辑器按需单实例挂载。全选会话不能逐一查询所有消息或成员。
- 三种保存模式分别保留本次目录，切回预设恢复预设草稿或全局默认；Web 相对子目录不能冒充桌面绝对路径。明确“设为默认”才写全局配置。
- 目录选择合并重复请求，准备期间禁用提交；卸载或切号后的迟到结果不更新草稿。

## 来源与恢复

- 普通聊天按原消息/过滤契约读取；频道私聊不支持漫游补全。
- [联系人](contacts-exact-export-20261018.md)固定 UID 目标，重新执行时重读资料；[空间](qzone-exact-export-20261018.md)固定 tid，重新执行时重读服务器；[生成对话](generated-content-export-20261018.md)固定持久正文快照。三者不能统称不可变正文或字节断点。
- 同一任务多格式共用一次收集，内容数与格式副本数分开。任务身份隔离输出，同名任务不能覆盖。
- 暂停停止新阶段，已开始的写入先收尾；恢复或删除须遵守对应来源的快照与资源约束。
- 定时是普通聊天的执行方式，不是内容种类；精确消息集合不能悄悄变成定时整会话范围。

## 搜索边界

- 关键词、范围、清空、重试和账号变化使旧请求失效；分页失败保留已有结果并从原游标重试。
- 来源并行且独立失败，单一慢来源不清空其它命中。文件按来源、会话和消息身份去重，不按文件名合并。
- 有限候选池明确显示覆盖限制。下一页偏移按服务端原始返回数量推进，不按渲染去重后的数量计算。
- 搜索返回只恢复当前账号、词和类别绑定的内存现场；条件变化丢弃。不是事务快照，也不替代内容页完整导航历史。
