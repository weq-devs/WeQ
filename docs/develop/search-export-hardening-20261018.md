# 全局搜索与统一导出完善

日期：2026-10-18（北京时间）。在现有 `refactor/content-tools-ux` 工作区继续开发，未切换分支、推送或发布；不包含工作区中其它重构的交付声明。

## 本轮范围

- 搜索更多页在关键词变化、清空、卸载时立即使旧请求失效；同步请求锁避免滚动事件重复提交同一页。首次失败可重试，分页失败保留已有内容并从原偏移重试。
- 文件结果使用来源、目标会话、消息 ID 去重与渲染，不再丢失不同消息里的同名文件。排名按消息时间排序。
- 更多结果增加 `limited` 覆盖标记：文件源 total 超过已取条数，或会话排名达到每源上限时，不能将候选数称为完整总数。
- 聊天导出的立即/定时成为执行方式；定时计划列表迁到任务工具，不作为内容种类。精确消息集合不能退化为整个会话的定时范围。
- 聊天与空间各自维护对象集合；普通会话多选可复制到工具草稿，虚拟会话不传给真实消息导出。账号变化重新挂载工具草稿。
- 收藏导出每次重新进入可重读，取消本轮加载不会留下永久的已启动闸门；先展示本地条目，再替换在线结果，两条路径均失败可重试。等待保存位置之前复制精确 CID 和联系人分组，避免异步等待改写目标。

## 验证与边界

离线夹具覆盖旧响应隔离、失败重试、分页失败、同名文件、候选上限、收藏重入/账号变化、执行方式和精确集合的防扩大。最终 CI 结果以实际运行回执为准。

全局搜索仍是已接入的七类，空间、收藏、频道等尚未因此接入。统一导出尚未完成所有内容种类的精确选择、生成内容导出和所有快捷入口归一，本记录不将这些目标标记为完成。未对真实 QQ 数据执行导出或在线抓取。

## 用户实测反馈修复

- 居中问题：导出/任务误用了 `presentation="panel"`，被非模态侧面板的右对齐样式接管；改回居中遮罩，不更改助手等其它工具的容器。
- 全选问题：过去为每个已选会话渲染一个 `<details>`，折叠时子树仍挂载并触发消息查询。改为虚拟列表中的逐行范围入口，单次只挂载一个范围编辑器；默认按会话导出时不查询逐条消息。
- 多选交接：保留挂载的导出工具只在首次读 `initialSelection`，后续更换选择没有进入状态。用户明确再次打开导出时复制当前账号的新选择并切换草稿身份；相同选择保留工具内草稿，内容页选择不被工具修改。
- 克隆空列表：共享列表传入的 owner 被固定打开为 `sessionId=null` 的新草稿。改为读取最近活跃会话；没有新会话时查询旧版历史并以只读方式展示，真正无记录时仍可新建草稿。搜索定位优先于旧的 owner 打开目标，历史读取失败显示重试，不冒称无记录。

回归夹具覆盖 1500 个会话全选后的有界 DOM、单编辑器、新一轮选择交接、克隆私聊/群聊恢复与旧版只读。额外用离线 HTML 投影核验桌面/手机视口、浅深主题与自定义强调色；不代替在线 QQ 的实际导出验收。

用户随后指出助手等工具同样未居中：全局工具统一使用居中模态外壳；通用 `Modal` / `OverlayLayer` 的 `panel` 增加独立居中布局标识，移除强制满高并约束窄屏边界，保留其非模态语义。不改动已迁入主区的 `page`，也不将有就地语义的 `popover` 一律改成中心弹窗。

## 完整目标续作：收藏检索

用户要求所有功能完善后再美化 UI 并推送。总目标与待验收项记录在[完整交付清单](./content-tools-completion-matrix-20261018.md)，不将前一轮回归修复称为完整交付。

- 收藏成为默认并列搜索类别。源为当前账号 `collection.db`、已采集历史及本次已浏览摘要，按 CID 合并最新元信息；搜索本身不取凭据或联网。
- 检索已解码摘要、来源、图片说明、已缓存文本/音频转写和图文正文。复用现有 `parse5` 依赖提取 HTML 文字，不索引标签属性、脚本和显式隐藏内容；未解码的二进制不冒称正文覆盖。
- 服务执行完整本地分页并返回命中总数；预览条数与更多页相互独立，时间相同以 CID 稳定排序。只保留当前页的短摘要到 IPC 结果。
- 命中可按 CID 直接打开本地缓存详情，不依赖收藏当前列表页；读取失败可重试，已消失条目与无结果分开，连续跳转会丢弃旧响应。
- 慢来源改为并行且独立失败；某一来源出错时只标记该分组，不清空其它来源的有效结果。更多页继续沿用已有请求隔离和重试。
- 新增服务与真实组件离线回归，覆盖跨页、正文提取、来源边界、分页、无网络、失败隔离与精确定位。未操作真实 QQ 或推送；最终门禁记录另行追加。
