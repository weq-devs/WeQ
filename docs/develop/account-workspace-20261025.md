## 目录进度

- `bootstrap.scanStaticDirsProgress` 回传 `candidate` 和 `done`。目录先出现；数量、大小使用 `null` 表示未知，`sizePending` 区分累计与完成，`probe: null` 表示身份尚未验证。旧 `scanStaticDirs` mutation 保留并复用相同实现。
- 目录遍历仍限制 4096 个目录、64 个结果，不跟随符号链接；无浅层结果才询问递归。停止订阅后不继续下一次目录或身份探测；已经运行中的不可中断文件／原生调用允许自行结束，其结果不再回传。
- `exportViewer.pick({ directory: true, deferScan: true })` 先返回一次性目录授权；`scanProgress` 逐项注册并回传可读来源。已发现来源立即可以浏览，追加结果不重置用户选择，结束时才撤掉扫描提示。
- 浅层无结果时重新签发递归授权；拒绝递归、过期与取消均不扩大读取范围。未完成订阅关闭时撤销该次注册的媒体访问能力，正常结束或读盘失败后已显示来源由查看器显式关闭。
- 导出来源最多每批 64 项，注册表允许旧、新两批短暂交接；搜索、消息读取和媒体沙箱不变。
- 本地资源统计的分类、源文件比例与月份图表随已完成目录更新，不再等待全部分类结束；完成前明确显示「已统计」累计值，并保留当前目录的扫描动画。
