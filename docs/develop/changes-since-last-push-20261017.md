## 我们新增与调整

| 项目 | 当前净变化 |
| --- | --- |
| 漫游消息进入时间线 | 群聊/私聊读取、前后翻页、定位与刷新复用本地/漫游混排；本地优先，保留可信来源标记，切换会话后拒绝迟到结果；漫游行不误用原库修改/删除入口。 |
| 消息序号显示 | 增加持久化 seq 显示设置，默认关闭；普通消息和灰条显示有效序号，不编造未知值。 |
| 手动批量补全 | 会话顶部工具栏和妙妙工具入口；预选当前会话，按本地锚点、日期及选定目标扫描候选缺口；支持未知前区间、限速、请求预算、暂停、继续、取消、移除与持久断点。不是常驻归档采集后台。 |
| 统一 SSO 路径 | 新任务只用 `transport=sso`，每次最多一个 30-seq 物理窗口；删除 SDK 桥配置/执行链和独立 sso500 聚合层，不承诺单包或单次逻辑调用取得 500 条。 |
| 数据身份与原始证据 | 保存原始 protobuf，区分精确 ID 和 random，保留同 seq 不同 ID；私聊按已确认 NT 会话序号核验；不完整观察单独保存，不当作正常消息或缺口已恢复。 |
| 请求与恢复语义 | 共享 FIFO/冷却，派发前先持久化物理请求预约；缓存命中不计网络预算；写盘失败不提交覆盖，取消仍保存在途有效结果；未确认失败保留在途窗口，不自动重派。 |
| 旧数据兼容与导出 | 不删除旧缓存表；旧 sso30 任务保持选项/hash 可继续，旧 SDK/sso500 任务保留但禁止续作；按数据库分页导出全部已接受缓存，不受 UI 2000 条上限限制。 |
| 研究资料清退 | 用户要求研究源码彻底撤出 Git；研究目录、脚本、专用测试和研究记录均移到仓库外，相关本地历史也清理。仅保留产品真正使用的 SSO/缓存/任务实现，不把研究工具作为产品依赖。 |
| 本地门禁收尾 | 修复无 Rust 模式仍从递归测试调用 cargo 的问题，保留全部非 Rust 测试；补门禁步骤回归，并格式化本次将纳入 Git 的研究源码。 |

此前已在本地历史中的 `be430bf4`（时间线/seq）、`e5f14b5c`（手动批量任务）属于本次基准之后。SDK 中间实现已撤销，其未推送历史随后按用户要求清除，不作为当前能力。
