# 审计第三批修复（2026-10-27）

范围为 F07（认证记录回收）、F08（链接预览内存缓存）、F13（Bot 默认日志隐私）。
仅修改相关资源与日志边界，不修改鉴权凭据、有效会话 TTL、预览内容、模型提示或消息交付内容。

## F07：认证资源

`AuthGate` 默认最多 4096 个有效会话、4096 个失败来源记录、256 个等待中的登录。
每分钟及登录时回收过期条目；会话仍使用原有 12 小时闲置 TTL，失败记录仍按最后失败后一小时重置。
带长连接监听器的会话保留原有精确到期计时器，正常访问仍刷新期限，注销或到期仍通知长连接。
一个撤销回调抛错不会阻断其他回调或服务关闭，错误只记录固定提示。

容量满时不踢有效会话，也不淘汰尚在保护期内的失败记录。新会话或等待队列无法受理时，HTTP 返回 503、
Retry-After 与明确的繁忙提示，不冒充密码错误，不覆盖现有 cookie；正常受理的凭据错误仍返回 401。
过载时尚未验证凭据的请求也可能收到 503。
失败来源表满后，未知来源采用共享的保守 30 秒退避，直到溢出保护闲置一小时。成功登录只清除该来源的记录，
不清空共享溢出保护，也不因其他记录过期腾出位置就绕过保护。
这是过载时的保守策略，可能让新的合法登录等待或稍后重试；正常使用规模下不改变原有逐来源退避。

等待中的登录同样有界，关闭时中断退避、停止清理定时器并禁止旧实例重新创建会话。
`diagnostics()` 仅暴露数量及溢出保护是否生效，不返回来源地址、sid 或令牌。
这些约束不等于给 HTTP 连接数、全部请求类型或同一会话的所有监听器设了全局上限。

## F08：链接预览缓存

内存默认最多 1024 项、8 MiB 字符串体积估算，使用 LRU 淘汰；字节口径为完整 URL 与条目 JSON 的 UTF-16 长度估算，
并非 V8 堆快照或进程 RSS。对象开销另外受条目数约束，临时请求、返回值和磁盘缓存不计入该估算。
访问时最多每分钟扫描一次过期项；单项命中过期也立即失效，没有新增空闲后台计时器。
成功七天、失败半小时的原有 TTL 保持不变，失败项仍可到期重试。

淘汰只影响内存，不删除磁盘结果或封面。超大项可以跳过内存但继续从磁盘读取，不因此丢弃预览。
键仍是完整的 trim 后 URL，不去除查询参数、不合并不同资源；磁盘键与格式兼容。
同 URL 的磁盘读取与抓取共用在途 Promise；内存保存与返回值隔离，调用者修改不能撑大已计量缓存。
有效缓存形状经过检查，损坏派生缓存走重建，不改变权威资料。

`memoryDiagnostics()` 只返回项数、估算字节、淘汰数和在途数量，不返回 URL。
本批没有为全部预览抓取增加全局队列或修改截图出网策略，不将缓存上限冒称完整进程内存上限。

## F13：Bot 日志

默认采用单行 JSON 元数据日志，按北京时间标记时间。对端关联标识使用每次实例随机密钥的 HMAC，
不记录原始 QQ 号、群号、昵称、persona 名称、消息正文、生成回复、LLM 决策自由文本或原始异常消息。
可保留的上下文采用白名单，只含长度、数量、耗时、状态、HTTP 状态和受限类别。
运行时 child logger 共享脱敏与调试状态；异常上下文不会因附带 errorMessage/stack 绕过默认策略。

同步检查了启动成功、连接重试、WebUI 错误、导出入口启动和停止失败路径：连接地址中的令牌不输出，
导出入口捕获配置解析与运行时启动错误，仅记录固定阶段、受限错误类别和常见 I/O 代码，不打印堆栈或 cause。
消息输入、模型调用及实际交付内容保持原值，不通过删减聊天内容来隐藏日志问题。

显式高级选项 `BotConfig.logging.debugContentUntil` 必须是带时区的 ISO 截止时间，最多未来 30 分钟。
开启时告警；正文及错误详情每条最多 512 字符并通过 JSON 转义，不能伪造多行日志头。
截止时间与实例内单调时钟共同约束窗口，时钟回拨不能延长；过期字段按关闭处理。
实例一旦观察到到期即锁定关闭，不会因后续时钟回拨而重新开启。
停止立即关闭旧实例，重启/重载不重设绝对截止时间；没有正文调试的常驻计时器。
本批不删除旧日志，也不声称 service 全部文件日志、外部模型服务日志或用户自行打印的对象都已脱敏。

## 验证入口

- `web_auth_resources`：无人再访问的过期项、活跃会话、容量拒绝、失败溢出及旧记录保留、关闭中断、回调失败隔离。
- Web 原有认证、真实 HTTP 与 WS 脚本继续验证；HTTP 增加容量 503、Retry-After、cookie 保留反例。
- `link_preview_memory`：容量和字节预算、LRU、磁盘保留、查询参数、超大项、返回值隔离、TTL 与派生缓存损坏。
- `bot_logging_privacy`：实际编排的私聊/群聊、回复、错误及默认元数据白名单；短期调试、立即关闭、到期和时钟回拨。
- `bot_stop_integration`：实际 Bot 与本机 WS/HTTP 夹具，确认默认隐私与配置调试状态透传。
- `bot_export_shutdown`：运行真实生成入口的子进程，验证原有停止收尾及配置/启动异常不泄露私有字段。
