# 群成员列表实时刷新

2026-11-09（北京时间）。

群成员分页与名片补全来自 `group_info.db`，不能依赖 `nt_msg.db` 的消息变化通知。
实时监听启用时，主进程复用 `DbWatchService` 监听成员数据库的实际路径，覆盖数据库主文件、WAL 等旁文件及原地写入；通过独立的 `account.onGroupInfoChanged` 订阅通知渲染端，不触发消息窗口重读或新消息提示。

收到通知后，前端合并短时间内的变更，清除群成员分页、错误、已读完标记与按需名片缓存，并刷新正在查看的聊天群、联系人群详情、成员搜索与退群成员列表。未打开的群仅清除缓存，下次查看时重读，不遍历所有群查询。

成员增减会改变分页偏移。失效的在途分页最多从首屏补读一次，连续变更时丢弃结果；搜索与名片补全同样拒绝旧代请求。退群成员名片保留供历史发言解析，但不再加入当前成员名单。切换账号、关闭账号或关闭实时监听时卸载群资料监听。

离线回归覆盖：群资料监听目标与卸载、相同关键字刷新、旧搜索和名片补全迟到、分页失效与偏移重置、退群成员过滤。实际 QQ 侧的入群、退群、名片与管理员变更仍需运行更新后的应用验证。

本轮验证：桌面端相关 49 个、数据库成员查询 6 个、数据库监听 3 个测试通过；本次改动文件 Biome 检查通过。桌面端 Node 类型检查通过；Web 类型检查仅剩工作区既有 macOS 签名改动的 `TS6307`：`src/shared/mac-signing.json` 未包含在 `tsconfig.web.json` 的文件范围中。本次未修改该签名配置，未构建、替换或重启运行中的应用。
