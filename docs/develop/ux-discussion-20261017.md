# 界面与工具设计约定

面向维护者的设计边界。当前操作入口见[使用手册](../guide/index.md)，功能缺口见[能力盘点](content-capability-census-20261018.md)。本文不保存个人问答、施工顺序或提交授权。

## 内容与操作

- 原生内容与日常交互优先，管理工具不取代内容浏览器。普通聊天、频道、数据线、公众号等保留各自的数据来源与身份。
- 真实和虚拟会话共用消息列表，生成内容保留来源标记，不伪装成 QQ 历史。WeQ 助手由工具入口打开。
- 设置管理全局默认；工具管理本次操作。工具内覆盖参数不隐式修改默认值。
- 搜索始终是当前账号的全局搜索，类别可调，不随页面暗中切换范围。“全部”仅指已接入来源，不等于完整云端历史。
- 分析与导出从工具或内容上下文交接对象，复用同一配置流程。独立分析结果在主区域阅读；内容查看器不另建第二套工具配置。

## 选择、草稿与任务

1. 内容页同一时刻只有一个活动多选组，以稳定身份保存；不累积跨内容的隐形混合清单。
2. 工具复制内容选择为独立草稿，调整不反向修改内容页。一次导出一种内容，允许该种类内的多个对象。
3. 确认后固定目标与参数；不连续条目用精确 ID 集合，不能退化为日期区间或全部内容。正文是否冻结取决于各类导出契约。
4. 任务按账号隔离，关闭配置不等于取消任务。暂停、重新执行与字节级断点恢复必须区分。
5. 提供预设目录、开始前选择、完成后选择三种保存方式；桌面与 Web 使用各自的文件访问能力。

## 交互边界

- 内容页、会话侧栏、应用内浮窗、锚定窗格和模态确认各有用途，不能因为都叫“弹窗”而统一加遮罩。具体归位见[窗口与浮层](nonmodal-surfaces-20261018.md)。
- 导航保留聊天和报告现场；隐藏页停止键盘、滚动等前台交互，不因此取消已确认后台任务。内存现场不等于重启恢复。
- 真实发送、本地插入/修改和只读预览明确区分。预览不发送、不编辑、不标已读；服务端接受不代表对方已读。
- 所有内容与工具适配深浅主题、有效主题色、背景、窄屏和减少动态效果。平台不支持的操作明确禁用，不用空按钮表示已覆盖。

实现入口：`MainView.tsx`、`WorkspaceTools.tsx`、`WorkspacePages.tsx`、`shared/content_selection.ts`。协议、测试及实际可用范围以各专题和当前源码为准。
