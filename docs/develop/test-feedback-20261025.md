# 离线测试精简与反馈验证（2026-10-25）

## 实施范围

- 14 个桌面端小型测试文件归并为 6 个同领域文件，原有 84 个用例全部保留；不合并模块 mock 契约不同的测试。
- 9 个配置测试文件归并为 2 个文件，保留全部 28 个用例，共用独立临时配置目录夹具。
- 消息开关按保存、恢复和失败阶段共享挂载；逐项校验设置键、请求、刷新、失败不改值和禁用，并验证成功重试会清除错误，避免复用现场产生假阳性。
- 不依赖 DOM 的测试显式声明 Node 环境；剪贴板身份解析和群公告解码存在间接 DOM 依赖，仍使用 happy-dom。
- 桌面端切换线程池，保留逐文件隔离。根命令限制包并发和 worker 数，不再等待构建依赖顺序；CI 取消重复的 Web 单测，保留构建产物冒烟。

使用入口及继续新增测试的规则见 [测试约定](./testing.md)。本次仅修改测试、运行配置和文档，不修改产品行为。

## 实际验证

下列耗时均为本机观测，不是 CI 性能承诺。桌面端对比均使用 2 个 worker；期间其他任务有并行改动，文件和用例总数并非严格固定，不能把总数相等当成覆盖等价的证据。

| 验证 | 调整前 | 调整后 |
| --- | --- | --- |
| 桌面端全量 | 740.41 秒，420 文件、2834 用例，2 个失败 | 311.24 秒，416 文件、2834 用例，同样 2 个失败 |
| 配置层定向 | 8.12 秒，9 文件、28 用例全部通过 | 7.27 秒，2 文件、28 用例全部通过 |
| 归并的桌面端用例清单 | 14 文件、84 用例 | 6 文件、84 用例，逐组计数一致 |

工作区全量复核：native 23、agentlab 83、platform 37、codec 131、db 161、protocol 704、service 2169 个用例通过；protocol 另有原有的 1 个 TODO。

桌面端最终只有 `unread_router.test.ts` 的两个基线失败：`getUnreadInfos` 调用比旧断言多一个 `undefined` 参数。本轮未放宽这两处断言，也未跳过对应测试，因此全量命令仍返回失败，不能称为全部通过。

另以 desktop / web 两个包实测调度：桌面端复现上述两个失败时，Web 的鉴权、HTTP 和 4 个安全测试均完整通过。旧依赖排序下，这轮全量执行没有启动 Web；取消排序后 Web 可独立执行，退出码仍保留桌面端失败。

新增根命令参数的回归断言，覆盖不排序、有界并发、完整收集失败、失败即停以及仅改动模式允许无相关用例。对本轮修改的 TS/JS/JSON 做定向 Biome 检查；未以全仓格式化、缩短超时、关闭隔离或删除失败用例提速。
