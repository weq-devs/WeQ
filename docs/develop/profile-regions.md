# 个人资料地区选择

所在地与家乡允许只选择上级地区，其余层级设为「不限」，也允许全部不限。编辑器只在用户选择后形成可保存值；读取失败或未返回字段仍是 `null`，不自动当成不限。

## 编码约定

Android QQ `ProfileCodecUtils.CODE_NO_LIMIT` 为字符串 `"0"`，`encodeLocCode` 将空字符串与 `"0"` 都编码为整数零；其他代码按 ASCII 大端打包，不按十进制行政区划代码转换。`decodeRemoteCode(0)` 返回 `"0"`。

- 当前地区：仍写原有 20032 字段，三个大端 uint32，共 12 字节。
- 家乡：仍写原有 24002 字段的国家／省／市，区县另写 20043，区县不限也显式提交四字节零值。
- 例如中国、福建、城市不限：`00000031 00003335 00000000`。
- 全部不限为全零；缺失、截断或未知代码不转换为全部不限。

`QQ_REGIONS` 由官方目录生成，各级补充代码 `"0"` 的不限节点。目录中的空代码规范为 `"0"`；编码仍兼容旧空字符串路径。部分国家没有省级、但其空省级节点包含具体城市，必须保留这条分支，不能将任意零值当作路径终止。已有代码为 `"0"` 的虚拟区县同样编码为零，展示为不限。

## 编辑与读回

切换上级后，下级优先回到不限，清除旧地区残留；只有不限选项的下级控件禁用显示，缺省省级之下仍有城市时城市可选。保存后沿用现有独立读回比较，不以请求成功代替保存确认。

测试覆盖全部原始目录路径、各层不限、无省级城市、非法父子组合、明确零值与缺失字段的区别，以及所在地／家乡的编辑提交。浏览器夹具为 `apps/desktop/test/browser/profile-region.html`，验证脚本通过 `pnpm exec tsx apps/desktop/test/browser/run-profile-region.mjs` 运行；可设置 `WEQ_PLAYWRIGHT_IMPORT`、`WEQ_BROWSER_EXECUTABLE` 和 `WEQ_REGION_QA` 复用本机浏览器并保存截图。

这些编码结论依据 Android 静态调用链与离线用例；测试不修改真实账号资料。真实 QQ 服务端是否保留某项选择，以实际保存后的独立读回为准。
