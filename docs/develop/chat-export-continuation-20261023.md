# 聊天导出续作与增量（2026-10-23）

## 边界

普通群聊、私聊接入消息级记录；不更改联系人、空间、生成对话、独立资源及频道私聊的续作协议。旧任务没有消息记录时，首次续作从当前来源建立记录，不冒称恢复了旧进程未落盘的正文。

`MessageJournal` 在选中消息交给格式器之前追加 JSONL，完整换行是提交边界，关闭时 fsync。重启只舍弃未提交尾行，已提交行解析失败则报错，不静默略过。记录支持 bigint，正文按流读写，内存仅保存身份集合，不一次载入整份正文。多格式共用同一消息记录。

## 续作语义

- 来源文件标记和漫游摘要仍用于报告及失效格式断点，不再把正常写入当成不可续作。
- 消息范围、筛选和会话身份决定记录文件；格式、媒体、头像等变化只重建视图。已捕获正文优先保留，不同步后来的编辑与删除。
- 普通导出按 msgId 去重，精确来源选择按 `messageSelectionKey` 区分漫游与本地行。漫游消息后来落入本地时，普通归档不增加副本。
- 增量重新扫描选中来源以发现晚到的早期历史；仅追加未见身份，但各格式文件会重新生成，不声称是格式文件的字节级追加。晚到历史排在捕获记录之后，非数据库事务快照。
- 暂停等待并行任务退出后，以只回放模式生成有效正文；收尾期间禁止另存、续作和删除。完成格式仍按 SHA-256 校验。

## 文件位置

有有效预选位置时，单文件用 `wx` 独占创建（自动命名遇冲突递增），整包创建任务专属子目录。应用缓存只保存任务索引，消息记录留在目标侧的隐藏进度目录。无预选位置沿用「先生成，稍后保存」；无效目标保留缓存和保存失败回执。直接结果由用户拥有，删除任务不删除目标。

## 跳过与转发

跳过独立阶段会先暂停收尾，保留已写文件，关闭对应选项后续作；正文不可跳过，报告记录 `skippedStages`，内容状态为 partial。取消或删除任务期间的跳过请求不自动恢复任务。

转发先使用 40900 本地缓存；在线补全沿用 `ForwardMsgService.fetchRemote` 与既有在线限制，递归有深度和资源循环保护。消息记录包含已展开内容；内部媒体参与同一媒体扫描、路径标注和表情收集。无法展开的卡片计入 `unresolvedForwards`，不当成完整正文。

## 验证范围

## 2026-10-24 后续调整

本节覆盖上文对应旧行为：暂停只中止后续处理、关闭在途写入并保留原始消息断点，不再自动重建正文。显式 `finalizeTask` 才进行只回放收尾，wire 状态提供 `isFinalizing`，界面显示「收尾中」；收尾完成后才允许另存半程结果。

基线选择只校验会话类型与会话标识，不以账号、范围或格式作匹配门槛。原记录不受本轮新读取范围或筛选影响。选择器读取目标或上级目录里的基线清单，显示名称、会话、条数、格式、范围、更新时间与文件大小，不加载正文；唯一匹配预选，零匹配提示新建或另选，多匹配要求明确选择。后端同样拒绝静默选“最新一份”。批量目标通过会话键分别传入路径，明确新建的会话不会误用父目录里的其他基线。

进度清单随导出发布，旧任务仍可由当前任务索引补充展示。基线复制到新任务自己的进度位置，使用独立导入文件完成后再重命名，不回写原基线。去重时比较可比的消息正文摘要，保留旧内容并记录冲突 ID 样本；跨基线与新记录的正序号汇总为候选缺口，提醒与报告不把序号不连续冒称为服务端消息丢失。缓存展开、路径和元素标识等非正文差异排除在比较之外，范围在结构化报告中注明。

完整性报告新增离线 HTML，与 JSON 来自同一报告对象，包含概览、冲突、候选缺口、阶段表和完整结构化记录；开启 CSP，正文转义，不加载远端资源，支持深浅主题和窄屏表格滚动。单文件另存时 JSON／HTML 两种旁附报告一起校验发布，重名均不覆盖；任务报告入口优先打开 HTML。

导出配置开关不提前 arm 官方转写抓包。根据实际会话凭据、PID 绑定与抓包能力判断授权需求，提示上送到当前导出工具的外层标题栏。确认导出时可集中授权或跳过对应在线项目；密码表单复用原 token IPC，不新增密码存储或网络接口。取消只自动取消本次新产生的请求；共享已有请求仍可在当前弹窗授权，但不会因跳过而自动取消。只有任务创建成功后才移交本弹窗启动的抓包，取消预检或关闭配置只回收自己未移交的会话，不停掉原有导出抓包。
