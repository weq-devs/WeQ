# 联系人精确导出

日期：2026-10-18（北京时间）。继续完整 UX 目标；本项完成不等于所有内容、最终美化与推送已完成。

## 目标与接口

- `contacts/friends` 多选进入联系人好友模式，`contacts/groups` 进入群成员模式并保留多个群号；`contacts/group:<code>` 可表达单群的精确成员 UID。
- `startContactsExport` 新增可选 `uids`，省略保持旧的分组/整群语义，明确集合绝不退化为全部。IPC 不接受空数组，底层导出器的空数组只代表零行。
- 好友导出器在补资料与收集头像之前按 UID 过滤；若同时给分组条件，取交集并校验精确身份齐全。工具里精确 UID 模式不再把发现用的分组筛选传成导出条件。
- 群成员按每群独立 UID 集合过滤。选中身份消失时显式失败，不产生「完整成功」假象，也不扩大范围。
- 任务创建复制联系人配置与格式数组；运行、持久化、重启读取及报告的 `contacts` 字段均保留精确目标。暂停/失败后可以按原范围重新执行，界面明确标为「重新执行」，不是增量断点继续。
- 同一执行只汇集一次联系人数据，多种格式共用该份内存结果；人数不按格式重复累加，各格式数量单独记录。它不是数据库事务快照，不宣称验证了完整服务端历史；重新执行时资料内容可以随本地缓存更新，但目标 UID 不变。
- 联系人单文件缓存使用任务身份区分，同名任务不互相覆盖。Web 保留用户可读下载名，vCard 的扩展名为 `.vcf`；群成员的 vCard 回退统一成 CSV 并去重。
- 在读取或补资料阶段取消/暂停后，不再启动联系人文件写入。已经开始的写入先收尾，不发布为已完成结果，收尾期间不能重复启动；界面明确显示暂停收尾状态。头像导出等待已在途的共享缓存读取结束，但不再发起后续读取或启动导出头像写入，不强制中断其它消费者的共享请求。
- 每个格式写入前先持久保存目标路径与阶段，再次核对取消信号，覆盖阶段通知中同步取消的情况。删除联系人任务时同步移除其自有报告，不碰其它路径。
- 群成员时间显示按北京时间，不依赖服务器时区；原始秒数输入不变，超出日历范围的值保持原始数字文本而非伪造日期。

## 选择与目录

- 新的导出目录复用本地好友、资料、群详情及群成员接口，按完整分页读取，不用亲密度榜前两千条冒充好友全集。无新依赖、无网络或 QQ 在线操作。
- 选择器复用 `ConversationPicker` 的虚拟列表与共用多选控制器，QQ 号、昵称均可搜索；Ctrl/Command、Shift 和键盘全选/清空沿用同一契约。
- 多群只读群目录，不逐群预取成员；只有明确打开一个成员范围时才取该群完整目录。窄屏复用列表/范围切换，关闭范围回到群列表。
- 范围是独立草稿。列表外身份保留并计数，用户明确操作才移除；空精确集合禁用提交。等待保存位置时变更草稿不会改写已确认的目标，多群启动期间切号停止后续创建。
- 导出成功后保留当前联系人草稿，避免精确导出完成后下一次操作无声扩大回全部。
- 短窗口压缩固定栏、保留可滚动配置区与可操作列表；长名称在短屏截断显示并保留完整标题。窗口化列表定位使用真实 `clientHeight`，不再假定请求的 480px 仍是可见高度。
- 隐藏工具停止新目录读取，联系人模式不查询聊天计数；目录查询的可见状态不参与确认后的任务取消判断，关闭界面仍保留草稿和已确认的后台操作。

## 保存方式切换

- `preset` 的目录是单次明确覆盖或全局预设；`before` 只携带本次选择（Web 为服务器根内的相对子目录）；`after` 不携带目录。
- 从 Web 的相对子目录切回预设时，不把相对路径冒充预设位置；共享 hook 优先恢复预设模式的本次目录草稿，否则使用全局预设，界面显示与准备保存的参数一致。显式恢复默认会清除各模式本次草稿。
- 目录选择期间合并重复请求、禁用保存控件与提交，不使用旧位置准备导出；卸载或切换账号后的选择结果不写入草稿。
- 模式切换与本次覆盖不自动写全局设置，只有明确「设为默认」才更新。准备保存期间切号或卸载会丢弃旧参数，不为新账号启动旧任务。
- 使用真实保存控件检查 Web/桌面的 before、preset、after 六种短屏状态，包含长相对子目录与长预设路径；布局可滚动且底部按钮可见。最终回执记录实际结果。
