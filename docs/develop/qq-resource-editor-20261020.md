# QQ 资源与管理交互续作

基线：`origin/dev` 的 `5927d3e1`；分支：`feat/qq-resource-editor`。

## 商城单张表情保存

- 单张详情复用 `getMarketPackImage` 取得既有 GIF 缓存，不枚举同包或新增密钥恢复链路。
- 默认保存、本次另存、稍后保存沿用公共保存准备与资源任务；系统选择器取消不建任务，任务完成后从导出任务列表查看结果、打开或另存。
- 单文件格式固定为原有 GIF，公共保存机制避免覆盖同名内容；获取期间切换账号实例或配置不发布旧来源结果。
- Web 的浏览器下载仅登记现有缓存文件，不询问服务器保存目录；服务器保存仍走公共策略。
- 验证：19 项商城入口、保存选择与资源任务回归通过；桌面主进程、渲染层类型检查通过；4 组深浅主题、自定义主题色及 390/1200px 布局检查通过。
- 未做真实 QQ 下载或原生选择器点选，不冒称真机端到端验收。

## 公告运行态复核

本轮开始时未发现运行中的 WeQ/Electron，无法完成“运行实例重载后只读复核”。此前源码修复仍保留，运行态验收待后续可用实例，不用离线用例代替。

## 邮件附件保存

- 附件只用现有不透明令牌和 `mail.download`，不改变认证、下载协议或附件范围。下载进入公共资源任务的私有目录，完整后发布，保存、取消、失败及另存回执沿用任务列表。
- 保存主动作沿用公共偏好，菜单只改本次；位置取消不发起下载，也不关闭邮件正文。Web 明确区分服务器保存与原有浏览器下载。
- 公共单文件输出新增原文件名输入，保留大小写扩展名、多重扩展名和无扩展名文件；不把附件强制当成 JSON 或添加 bin 后缀。原有格式型导出不受影响。
- 创建、排队执行与下载完成均核对邮箱服务实例及账号配置；失效令牌不创建任务，来源变化不发布迟到结果，异常信息仍经过邮箱脱敏边界。
- 补齐商城单张与邮件附件的任务类型标签，避免被旧兜底误标成群文件。
- 验证：44 项桌面邮箱、商城、公共保存及回执回归，11 项服务输出形态回归通过；桌面 node/web 类型检查通过；桌面/Web 深浅主题、自定义主题色及 390/1200px 共 8 组布局检查通过。未访问真实邮箱、下载真实附件或点选原生保存框。

## 气泡、字体与挂件保存

- 商城条目的另存与消息装扮卡片的单项／整包另存共用面板级保存锁及公共菜单；不为每个商城卡片创建保存查询。
- 保留 `buildDecorationFile`／`buildDecorationBundle` 的真实资源转换，先得到实际 TTF、静态 PNG 或动画 ZIP，再用公共保存准备选择对应文件位置；ZIP 是既有单文件结果，不误判成目录，也不新增资源格式。
- 生成与系统选择期间检查账号、配置和服务实例；取消不建任务，不覆盖原资源。完整结果进入公共资源任务，保存失败时仍有可重试的缓存和回执。
- Web 的服务器保存通过公共目录策略，浏览器下载沿用原宿主分配及下载句柄，二者独立；写入使用独占创建，不覆盖同名文件。
- 验证：30 项装扮转换、保存路由／控件、商城页及任务标签回归通过；桌面 node/web 类型检查通过。8 组深浅主题、自定义主题色与宽窄布局检查覆盖桌面／Web 控件，发现并修复 Web 卡片内部按钮越界后复验。真实装扮资源下载与原生保存框点选未实测。

## 个人空间相册导出

- 相册内媒体勾选与相册列表整本导出两个既有入口均迁移公共保存菜单及资源任务；固定所选目标与账号配置，不在排队时清空选择，不再让渲染层直接拼磁盘路径或逐页写用户目录。
- 单项媒体按实际 URL 与已有视频本体／封面回退决定文件名及类型；多项和整本相册使用资源包。只有单项视频在文件选择前取一次已有本体 URL，整个任务不新增媒体协议或格式；签名失效仍明确失败，不扩展失效补全。
- 整本导出保留原有 30 条分页、最多 10000 页、重复项去重、提前空页／重复页检测及成功文件；页读取失败作为单独失败项记入资源清单，不把未知数量当作完整结果。分页大小提到桌面共享常量，与浏览入口一致。
- 下载使用原有 `downloadUrlToFile`，传递取消信号并等待所有在途 worker 收尾。取页／取视频 URL、选择位置、下载和发布前核对来源。旧导出接口仍保留兼容，但同样受服务器保存根与来源约束。
- 来源变化会清空对应选择；取消选择器保留选择，已排队任务从公共任务列表查看进度、停止、失败清单、另存与打开。Web 不把服务器写入冒充本机下载。
- 验证：38 项相关资源路由、空间相册界面、保存准备与任务标签回归通过；桌面 node/web 类型检查通过；媒体／整本两个入口在桌面／Web、深浅主题、自定义主题色与 390/1200px 共 16 组工具栏布局检查通过。布局使用合成内容，不涉及真实 QQ 媒体或原生选择器点选。

## 年度报告导出

- 末页原有 HTML／PDF／长图三个入口沿用公共单文件保存、偏好及本次菜单；文件名在桌面共享模块统一。位置取消不创建任务或启动捕获；三条 RPC 返回任务 id 或取消的 `null`，前端不把排队冒称已落盘。
- HTML 使用原有自包含文档，PDF／PNG 仍调用原宿主的 `renderHtmlToPdf`／`renderHtmlToLongPng`。没有更换捕获引擎、格式或空间发布流程。完整结果留在私有任务缓存，用户后续另存不重新捕获；宿主不支持时保留原错误。
- 选址、预热与捕获后核对账号／配置及服务实例；报告 HTML 缓存按年份、页面集合及读取范围隔离，范围变化不复用上一份文档。无旧范围字段的界面在本次报告首次可用来源绑定，不能把旧报告提交给新来源。
- 公共保存菜单与服务器位置弹窗增加可选 `portalTarget`，报告复用既有全屏浮层宿主；未传的其他页面保持原来的 body 挂载。末页仅在窄／矮窗口收紧排版，超高内容保留内部原生滚动，不抢报告舞台翻页。
- Web 明确是服务器保存，浏览器下载由公共任务列表提供。捕获进行中取消会等待原宿主调用返回，再丢弃未完整发布的结果，不承诺中断宿主截图或新的续传能力。
- 验证：54 项报告路由、末页、原 HTML 页面、范围隔离、公共保存及浮层挂载回归通过；桌面 node/web 类型检查通过；桌面／Web、深浅主题、自定义主题色、390/1200px 宽与 480/800px 高共 16 组工具栏检查通过，三种格式及菜单均在画布内可见。捕获单测使用宿主替身，未把它冒称真实 PDF／长图引擎或原生选择器点选验收。

## 聊天媒体与群文件单个保存

- 盘点并接入图片右键下载、图片／视频灯箱、文件卡片和群文件列表。语音原来只有播放／转写，本项按明确的语音范围接同一播放来源保存，不新增编码器、媒体协议或模型调用；SILK 已解码为 WAV 的字节使用 WAV 后缀。
- `account.mediaSave.save` 固定来源与账号配置，返回任务 id 或位置取消的 `null`。来源只包含现有 URL、消息／转发子消息定位或群文件身份；文件本地打开仍沿用原记录，保存只复制，不删除原件。原 `media:export`／`file:download` 保存 IPC 也委托到同一任务链路，受理不等于已落盘，剪贴板路径不变。
- URL 来源继续用原媒体／资源处理器，Web 同源绝对路径先还原已有挂载路径。共享原报告的协议 URL 转换器，未另写一套映射。远程 HTTP 在 Electron 保留原 `net.fetch` 会话，经可选宿主能力读取，Web 使用原生 fetch。
- 实际图片格式结合原有探测器与响应类型确定，已解码语音／视频使用实际类型；原文件及无后缀文件保留文件名。元数据只读取有界前缀并关闭响应，队列中不持有打开的下载流；运行时重新打开并按流写私有结果，大视频不调用 `arrayBuffer`。空媒体、部分响应或准备后类型变化不发布成有效文件。
- 保存请求的来源校验通过请求级 AsyncLocalStorage 传给现有媒体处理器，在缓存读取后、后续元素查找和取票后写缓存前检查；不让旧请求重新绑定新来源。普通播放未传校验时保持原行为。转发文件继续使用携带消息、子消息及既有未知场景换链；明确 token 不匹配不回退成另一个文件。
- Web 浏览器下载使用同一任务的完整结果及原下载注册，不混用服务器目录选择；只在界面仍有效时触发链接，等待最多轮询十五分钟，关闭／切源停止等待但不删除结果。显式停止只取消在途媒体任务，已完成结果保留；共享任务管理器也拒绝把完成任务改成取消，竞态回归先失败再修复。
- 语音保存控件不沿用转写按钮的悬停隐藏状态，文件卡片拆分打开与保存命令，长名称保留完整提示；灯箱菜单沿用各自文档，复制和缩放保持原行为。
- 验证：142 项桌面离线路由／真实 React 交互、原聊天、媒体 CORS 及范围回归，8 项服务资源任务回归通过；桌面 node/web 与 Web 服务端类型检查通过。24 组桌面／Web、深浅主题、自定义主题色与 390/1200px 的文件、语音、群文件及灯箱控件检查通过。独立 Electron 44.9.0 的 `net.fetch`→Node 流实际复制 4 MiB 并验证中止传播，临时输出与独立配置已清理；没有访问真实 QQ 数据或点选原生保存框，不冒称完整下载端到端验收。未运行全量 CI。

## 本地资源管理保存入口盘点

以 `CacheView` 的全部 13 个分类及其子组件为范围，逐一检查按钮和事件链路；本项只迁移已有保存能力，不把“能预览”视作新增导出的授权。

| 分类 | 已有操作及保存去向 | 本次处理 |
| --- | --- | --- |
| 图片墙资源、QQ空间缓存 | 图片卡片 → 全局图片灯箱 → 保存 | 复用已迁移的 `MediaSourceSave`／`account.mediaSave.save`，不重复实现 |
| 图片资源 | 缩略图预览，灯箱优先原图、缺失时用缩略图 → 保存 | 保留选择来源规则，复用同一公共保存策略 |
| 视频资源 | 仅有原视频时可打开全局视频灯箱 → 保存 | 保存原视频而非封面；仅有封面时不新增保存入口 |
| 头像资源 | 大小头像回退预览、缓存路径计算 | 无保存按钮，不新增 |
| 系统表情 | PNG／APNG／Lottie 预览、补全官方缓存 | 补全是资源安装而非用户另存，不改下载目录或导出策略 |
| 商城表情 | 本地 GIF／PNG 格式面板预览 | 无保存按钮，不新增 |
| 商城表情包 | 表情包详情、图片预览、密钥工具 | 无保存按钮，不新增；独立商城页的单张保存已在前项迁移 |
| 自定义表情 | 原图／缩略图面板预览 | 无保存按钮，不新增；收藏表情导入导出另属后续任务 |
| 关联表情 | 关键词下 GIF 预览 | 无保存按钮，不新增 |
| File 目录、下载文件 | 筛选／排序／刷新、在系统中打开或定位 | 不是另存，不改原文件、不新增复制导出 |
| 语音资源 | 本地 SILK 播放解码、转写 | 无保存按钮，不新增；聊天语音保存与此页是不同入口 |

数据库管理及 Blob 编辑器不在本地缓存分类中，其“保存”是修改数据库单元格，不是导出文件；清理和分析也保持既有独立入口。

新增 6 条真实组件回归，从缓存卡片打开实际图片／视频灯箱，再检查公共保存请求中的资源 URL、原文件名和默认策略；覆盖图片墙、空间缓存、原图优先、缩略图回退、原视频保存及封面不可导出。分页数据使用合成夹具，不访问本机 QQ 缓存。没有新生产代码或用户行为变化，因此本项不重复追加 Changelog，也不重复已有灯箱的主题布局验收。

验证：明确按文件过滤的缓存分类、媒体保存界面及路由共 35 项通过，定向 Biome 和 `git diff --check` 通过。首轮 `test --` 命令意外扩成桌面测试全集，已中止；扩跑出现一条非本项的 `message_repeat` 成员列表断言失败，未宣称全集通过，未修改该逻辑。未运行全量 CI、真实 QQ 下载或原生保存框。

## 空间互动即时反馈

- 说说点赞点击后立即高亮，以当前可见数量为基准做有界预估；未知自己的点赞状态或数量时不杜撰增量。请求期间串行锁定，异常、未确认及未发送结果恢复点击前状态；受理／确认只保留暂存反馈，不冒称远端已校准。
- 写操作开始同步使旧摘要失效，并取消已有读取；结束后复用原摘要和互动读取器，不增加 QQ 协议。远端摘要即便返回与点击前相同的布尔值，也通过读取版本校准按钮。公共会话仍在刷新其他缓存时，先收到的校准结果在操作结束后仍会应用。
- 校准失败保留已受理操作的即时反馈，提供可见提示和只读重试，不诱导重发；连续取消失败时恢复上一笔即时状态，避免基于旧远端数量重复增减。摘要只返回部分数据时标明未完整校准。
- 根评论保留既有文字／图片接口，发送显示进度且不重复提交；仅受理／确认才清理原稿和更新已知数量，失败／未确认保留原稿。按草稿编辑版本保护等待期间的后续编辑，即使改回相同文字也不误清空。不创建假的远端评论 ID 或本地伪造评论条目。
- 写入后保留互动区展开状态，刷新评论及摘要数量，绕过“与我相关”旧评论 Promise；完整列表仍按根评论计数，不把回复混入。互动状态、草稿及请求按 QQ 号和配置范围重建，旧来源回执不更新新来源。群相册的原点赞回执语义不变。
- 针对性验证包含点击前失败用例与连续计数失败用例，再修复转绿；使用合成数据，无真实空间写入。布局检查覆盖 390/1200px、深浅主题、两种自定义强调色及减少动态效果；测试浏览器与临时预览服务器验后关闭。
- 最终验证：88 项空间互动、原 QQ 主动操作界面／路由、写会话、选择、相册保存及回复展示回归通过；渲染层类型、定向 Biome 与 diff 检查通过。8 组最终截图检查按钮和状态提示边界，实际强调色与设置一致。未运行全量 CI，也未在真实空间点赞或发表评论。
