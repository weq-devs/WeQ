# 会话分析时间轴 + 我的主场轮盘（2026-10-18）

## 1. 聊天分析：默认最近一年，拖动重算

- 群聊 / 私聊分析首次打开时，服务层以**最后一条消息**为基准取最近 365 天作为默认窗口；
  不是以 `now` 为基准 —— 很多会话早就停了，按 now 切会得到一张空图。
- `getGroupStatsReport` / `getBuddyAnalytics` 接受 `startTime` / `endTime`（unix 秒，
  含首尾）。两者都不传时，只有显式 `recentYear: true` 才启用默认窗口；周报 / MCP 等
  旧调用方继续得到全历史口径。
- 一次扫描同时产出：
  - **全历史** `timeline.daily/weekly`（顶部周柱状图与绿墙）；
  - **所选区间**的 totals / 排行 / 时段 / 类型 / 词云 / 口头禅 / 小团体。
- 拖动选择只在**松手**时提交；拖动过程只动选区矩形。区间重算时保留首屏时间轴的
  同一份引用，所以绿墙与顶部周图不会跟着闪。群聊区间重算会把时间范围下推到
  `listBatch`（`skipTimeline: true`），不再把整段历史读出来再丢掉。
- 周口径：周一为一周起点，本地时区；SQL 侧周序号以窗口起始日期为 0
  （`julianday(date(...)) / 7`），与渲染层的 `buildWeekKeys` 对齐。

## 2. 我的主场：前 8 群轮盘

- `home` 页新增 `groups: HomeGroupCard[]`：按「我发出的条数」取前 8，带群号、群名、
  我的发言数、全群消息数、成员数与最多 53 周的 sparkline。`top` 仍保留冠军群的
  完整签名（等级 / 头衔 / 话题）。
- sparkline 走一条只读 `(40027, 40050)` 的 `GROUP BY 群号, 周序号` SQL，不解码正文。
  「历史以来」口径下取最后 53 周。
- 交互：
  - 轮盘画在页面的左右边界上，没有容器边框；当前卡居中放大，相邻卡压暗，
    距离超过 2 张的卡片隐藏（仍留在轨道上，可以转回来）。
  - 滚轮 / 触控板：页面内先转轮盘；转到首/尾后不再 `stopPropagation`，
    由报告舞台接管后续滚动去翻页。一次连续手势最多转一格。
  - 键盘 / 竖向滑动：通过 `registerPageGuard` 转一格，到边界才放行翻页；
    这个守卫**只在当前页注册**（所有页常驻 deck，非当前页注册会抢翻页）。
  - 横向拖动超过 36px 切换，拖动后吞掉紧随其后的 click，避免误触卡片。
