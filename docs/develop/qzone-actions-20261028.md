- 评论框随评论展开出现；选择回复后输入框移到被回复的评论／回复正下方，取消回到普通评论框，切换目标保留文字草稿。空友爱看沿用 `qzonePublic.reply`，分别传原始根评论和可选原始回复，不把回复身份混成根评论。
- 转发复用 `QzoneForwardDialog`：上方文案，下方原动态。空友爱看提交给既有 `qzonePublic.forward`。
- `settings.qzoneForwardQuotePrevious` 默认 false，持久化到用户配置，设置页通过 `bootstrap.setQzoneForwardQuotePrevious` 保存；备份沿用现有默认配置结构校验。
- 开启引用后输入 `//：` 加当前转发对象的正文；读取设置后聚焦并设置 selection 为 0，不在输入期间异步覆盖草稿。
