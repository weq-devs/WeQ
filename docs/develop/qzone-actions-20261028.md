日期：2026-10-28（北京时间）。桌面与 Web 复用渲染组件，版本号不变。

2026-10-29 续修：点赞名单通过独立 Portal 复用 `useOverlayAnchor` 自动翻转与贴边定位，避免被空间滚动容器裁切；三列紧凑名单、长昵称省略并保留完整悬停提示，鼠标可连续移入名单。评论加图／发送按钮统一为 40px 点击区域及 20px 图标，不再随输入框伸展被挤小。

## 已接入

- 常规说说将点赞写操作移到数据操作行，悬停／聚焦读取点赞名单，点击执行赞／取消；复用既有乐观更新、回滚、账号隔离和远端校准。
- 评论框随评论展开出现；每条评论和回复具有回复目标选择按钮。空友爱看沿用 `qzonePublic.reply`，分别传原始根评论和可选原始回复，不把回复身份混成根评论。
- 转发复用 `QzoneForwardDialog`：上方文案，下方原动态。空友爱看提交给既有 `qzonePublic.forward`。
- `settings.qzoneForwardQuotePrevious` 默认 false，持久化到用户配置，设置页通过 `bootstrap.setQzoneForwardQuotePrevious` 保存；备份沿用现有默认配置结构校验。
- 开启引用后输入 `//：` 加当前转发对象的正文；读取设置后聚焦并设置 selection 为 0，不在输入期间异步覆盖草稿。
- 「与我相关」自动翻页每轮至多 5 次；只有向下滚动意图（滚轮、触摸、滚动键）才恢复下一轮。只展开通知时才补读原文与评论，取消列表内自动逐卡补齐。

## 接口缺口

| 内容 | 当前源码事实 | 界面表现 |
| --- | --- | --- |
| 常规说说定向回复 | `qqActions.qzone` 仅有 like、unlike、comment，`commentQzoneMsg` 未支持根评论／回复目标参数 | 可选择评论／回复目标并编辑，明确提示缺接口并禁用发送，不回退为一级评论 |
| 常规说说转发写入 | 有只读转发名单服务，无常规说说转发 mutation；不拿旧 tid 拼公共域 union_id | 完整转发弹窗、引用设置与原动态预览，禁用提交 |
| 空友爱看点赞名单 | 现有公共域服务只有赞切换与详情，没有名单方法；旧空间名单按 uin/tid，不能跨用 | 悬停展示数量及未接入状态 |
| 空友爱看推计数 | 已有 Upvote／Downvote 写接口与已推状态，但当前已核样本没有可验证的推计数字段 | 保留推操作和状态；计数未知为 `?`，不根据操作次数伪造总量 |

常规说说转发次数复用已返回的 `forwardNum`／动态 `forwardCount`；缺失不猜成 0。自己是否已赞以现有名单和完整性判断，不将未读全名单的缺席当作未赞。
