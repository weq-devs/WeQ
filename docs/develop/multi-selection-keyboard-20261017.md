# 多选修饰键与键盘契约

日期：2026-10-17（北京时间）。需求：UX 讨论 S29。执行位置在消息操作补齐之后、原重构剩余事项之前。

## 统一交互

共享实现：`apps/desktop/src/renderer/src/hooks/useMultiSelection.ts`，范围计算复用现有 `selectMessageIds`，不另建按行号保存的选择模型。

| 操作 | 行为 |
| --- | --- |
| Ctrl/Command + 点击 | 切换该项，保留其它已选项；可进入支持就地多选的内容列表。 |
| Shift + 点击 | 按当前展示顺序，从稳定身份锚点选中连续范围。 |
| Ctrl/Command + Shift + 点击 | 在已有选择上追加范围。 |
| Ctrl/Command + A | 选中当前候选集合，保留筛选外已有选择；不会虚构未加载的服务器条目。 |
| Ctrl/Command + Shift + A | 清空当前选择组；必须保留一项的格式选择仍执行其原有约束。 |
| Space / Ctrl/Command + Space | 切换焦点项；在可进入多选的列表中，修饰后的 Space 可开始选择。 |
| 上下方向键、Home、End | 在当前组内移动焦点；窗口化列表可定位到未挂载的末尾项。 |
| Shift + 方向键/Home/End | 扩展范围；Ctrl/Command 同时按下时追加范围。 |
| Escape | 退出内容页多选，或清空工具中的选择；空选择时允许外层窗口继续处理 Escape。独立创建/邀请等窗口沿用取消关闭语义。 |
| 消息 Ctrl/Command + C | 复制所选消息纯文本，保留原能力。 |
| 消息 Ctrl/Command + Shift + C | 复制所选消息富文本。 |

快捷键只作用于当前聚焦/最近交互的选择组。输入框、文本编辑区域、其它模态窗口、隐藏页面及禁用选择器不接受外层列表命令。按下修饰键后、点击完成前松开，也只处理一次选择，不误触卡片预览。

选取文件夹仍使用原有目录读取与缓存：选择的是实际子树文件，不把展示行号或目录名称当作文件身份。关闭群文件选择窗口后不再继续收集下一目录；已经在途的只读请求不能假装撤销。快捷键不会直接发送、导出、下载、清理资源、安装配置或替用户勾选确认/同意问题。

## 接入盘点

| 界面 | 接入方式 / 边界 |
| --- | --- |
| 消息及系统灰条 | 共享锚点、范围与键盘，保留纯文本复制，补富文本快捷键。 |
| 会话（真实/虚拟）、好友、群列表 | 复用单一内容选择状态；高亮选择，键盘与窗口化滚动配合。 |
| 我的收藏 | cid 稳定寻址；键盘跨分页定位，不按页内索引选错。 |
| 空间相册及媒体 | 保留普通点击预览/进入；修饰键选择及键盘范围统一。 |
| 导出会话、数据库、群相册 | 独立工具草稿选择；不反向修改内容页选择。 |
| 好友分组、收藏类型及精确收藏 | 两个不同选择层分别建组；保持空类型筛选的既有“全部”语义，精确空条目仍代表零条。 |
| 精确消息及列表外已选项 | 使用 msgId，不用时间范围近似；未显示的已选身份保留。 |
| 导出格式、媒体/装扮/补全类别、表情来源 | 批量更新整个集合，避免逐项调用旧闭包覆盖前一个更新；禁用条件与至少一种格式约束保留。 |
| 合并转发、单条/逐条转发目标 | 同一目标选择器，一次提交完整集合；发送中的 fieldset 不被快捷键绕过。 |
| 防撤回保护范围及通知范围 | 复用已接入的会话选择器。 |
| 消息补全会话 | 共用窗口化选择；不会因快捷选取就扫描或发送补全请求。 |
| 群文件目录/文件 | 目录键投影到真实子树，原子提交选择；加载中不可开始导出或改动同一草稿。 |
| 闪传下载选择 | 保留普通目录/压缩包进入行为；目录覆盖后代，防止重复下载同一文件。 |
| 商城来源过滤、批量下载表情包 | 来源组与内容组分开；保留普通点击预览，不触发下载。 |
| 创建群、邀请成员、克隆群成员 | 只增加选择交互，保留各自提交按钮和权限校验。 |
| 关系图谱白名单/黑名单群选择 | 独立草稿，确认后才更新图谱。 |
| 群提醒词成员范围 | 沿用原有防抖保存；范围锚点使用 uid，成员搜索中可连续选择。 |
| 缓存分类与资源清理自选 | 保留禁用项和确认阶段；快捷键不执行清理或填写确认文本。 |
| MCP 客户端、模型列表及能力标签 | 只改变选中集合，不安装或发起模型请求。 |
| 全局搜索范围、日志等级 | 两类过滤组各自接入；不接管关键词输入框的原生文本快捷键。 |
| 年报空间分享页面选择 | 仅选页，不发送；原有最多九张及文案校验保留。 |

独立开关、单选菜单、播放/展开控制、确认和同意勾选不属于多选列表，不把“全选”扩展为批量改变这些设置。
