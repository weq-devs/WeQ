# 已完成任务清除

统一任务列表提供「清除已完成」，确认框显示本次项目数，并提示未保存导出结果的数量。
仅处理确认时选中的成功任务；失败、取消、暂停、等待、运行及保存中任务保留。

导出沿用任务删除接口的缓存清理规则，不删除已保存目标；闪传只移除指定成功下载记录，
不删除下载文件；漫游只移除已完成任务，不修改聊天数据库；好友克隆只移除完成记录，
不删除克隆体。确认期间切换账号或数据源会停止操作，服务端再次校验来源与任务状态。

逐项清除失败不会阻断其他来源，结束后刷新各任务查询并报告实际清除数量。

定向验证：桌面端 `current_tasks.test.ts`、`clear_completed_tasks.test.ts`，服务层
`flash_completed_cleanup.test.ts`；浏览器运行 `node apps/desktop/test/browser/run-completed-task-cleanup.mjs`，
覆盖深浅主题、两档宽度、自定义主题色与减少动态效果。均使用离线合成数据。
