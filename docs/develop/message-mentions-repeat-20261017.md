# 提及、引用与相同消息重发

## 身份与剪贴板

- 群输入 `@` 使用实际成员候选，支持搜索尚未加载的成员；权限和全体成员额度由 QQ 决定。
- 提及保存为 token，UID 优先，缺少时才用 UIN。同名不认作同一人；剪贴板 HTML 只恢复文字与明确身份，不接受脚本、事件或任意标签。
- 候选可展示群名片/备注，但插入、粘贴和发送前的提及文案使用昵称，缺失时保留 QQ 号或 UID。不能照搬来源备注或按名字猜身份。
- 外部纯文本不具备可靠提及身份，按普通文字处理。引用框文字继承气泡前景色，不能固定为白色或深灰。

## `+1` 边界

- 只比较最新窗口最后两条的实际元素，不比较 `[图片]` 等摘要，不跨过灰条、撤回或失败记录；同 UID 的备注差异不改变身份。
- 只有最新一条提供按钮，复用现有发送适配，不修改输入草稿，发送中防重复触发。
- 保留表情子类型、贴纸包/GUID、媒体指纹和提及目标。无等价适配、身份或资源时明确失败，不降级为占位文字。
- 红包、交易及系统内容不参与等价重发；服务端接受不代表收端已展示。

源码：`lib/mentionClipboard.ts`、`lib/mentionIdentity.ts`、`lib/messageRepeat.ts`、`ChatPane` 及现有发送服务。回归：`mentions_reply.test.ts`、`message_repeat.test.ts`、`composer_identity_ui.test.ts`；合成发送不等于真实 QQ 收端验收。
