## 行为

1. 引用框文字继承气泡文字颜色。先以真实 CSS 测试复现我方浅色装扮仍固定使用白字，再修复；同时避免对方深色气泡的引用固定使用深灰字。
2. 群输入框输入 `@` 可显示成员候选，支持中文/标点后的触发、键盘选择、滚动加载已加载分页，以及查询尚未加载的群成员；不再固定截断为八人。
3. 草稿中的提及保留为元素 token。复制消息与选中正文时，普通文字和带唯一身份的 HTML 一并写入剪贴板；粘贴仅解析文字和身份，不恢复脚本、事件、图片或任意 HTML。
4. 粘贴与 `+1` 共用身份名称解析：UID 优先，只有缺少 UID 才使用 QQ 号；使用当前账号的群成员/资料名称，按现有群名片、备注、昵称顺序显示，不照搬来源备注。同名不同人不混淆，未找到身份名称时显示唯一 ID，不猜人。
5. `+1` 比较最新窗口最后两条的实际元素，不比较 `[图片]` 等摘要，不跨过系统灰条、撤回或失败条目；同 UID 的不同备注不改变目标身份。仅最新一条显示按钮，切到历史窗口不显示。
6. 发送复用现有媒体/转发元素适配与消息发送服务，不修改输入草稿；连点只触发一次。普通/超级/随机表情、贴纸 GUID 与包、图片媒体指纹及提及目标保留；无等价适配、缺少资源或没有身份时明确失败，不降级成占位文字。
