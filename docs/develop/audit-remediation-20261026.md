# 2026-10-26 审计修复边界

本轮基于同日审计的 F01-F14 修复确定性权限、存储和异步终态问题。以下描述源码行为，不代表正式发布、真实 QQ 数据或五平台安装包验收。

权限模式是兼容新功能，正式发布应按 MINOR 递增，而不是一律加入补丁版本；本轮仅追加 Unreleased，由既有发版流程统一写入版本号，不改已发布版本章节。

## 助手权限

- 默认 `sandbox`，旧配置缺省或模式值无效时也回落到沙箱。脚本在独立 worker 中使用 QuickJS/WASM，宿主函数与对象不会直接进入解释器；跨边界只传 JSON 文本。
- 每次脚本有 32 MiB 解释器内存、256 KiB 栈、最多 40 次工具调用，以及 1-45 秒执行时限。外层 worker 负责硬终止，日志、代码和返回结果均有长度上限；工具名最多 128 字符、参数最多 200000 字符，调用次数和参数结构在发送跨线程消息前检查，避免队列淹没宿主。
- 沙箱只开放 `tool_permissions.ts` 中显式审核过的查询与隔离脚本，另保留 service 内的受控报告、调查计划和工作笔记。未知工具、SQL、宿主文件、发送、红包、凭据及外部 MCP 不会自动获得沙箱权限；沙箱不会为列举工具而连接外部 MCP。
- `unrestricted` 必须由设置页显示风险警告并确认，后端首次切入也要求 `confirmUnrestricted: true`。确认字段不写入配置，权限模式按账号严格原子保存，失败不会发布未持久化的授权。
- 任意权限脚本使用 Node，可在当前系统用户权限内读写删除外部文件、执行命令和联网，不提供隔离，也不自动提权。此模式不能承诺逐项确认或撤销副作用。
- 执行必须同时满足本轮权限快照和当前账号设置；模式切换取消在途任务，账号身份约束继续生效。沙箱中的嵌套工具调用沿用同一检查。
- 对外 MCP 服务器另用显式只读清单，与内置助手的任意权限无关。`assistantOnly` 不再是唯一过滤条件。

## 外部连接与运行时

- MCP SDK 升至 `1.32.2`，HTTP/SSE 共用最终端点来源约束及拒绝重定向的 fetch；SSE 发布的跨源消息端点同样被拒绝。客户端工具调用向 SDK 传递取消信号。
- desktop/native 的 Electron 同步升至 `44.9.1`。Remote 辅助程序要求 Go `1.27.3` 或以上稳定版，既检查构建输入，也检查实际二进制中的 Go 版本。
- Web 发布 manifest 显式携带 QuickJS 运行依赖，避免开发机能解析包、独立 Web 分发却缺失 WASM 依赖。
- 安全依据：[Electron 公告](https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9)、[MCP SDK 公告](https://github.com/modelcontextprotocol/typescript-sdk/security/advisories/GHSA-6prh-2h8m-c8cw)、[Go 1.27.3 发布记录](https://go.dev/doc/devel/release#go1.27.3)。

## 文件与恢复记录

- 克隆 ID 使用统一的不透明字符集，路由和真实存储层都验证；拒绝路径分隔符、编码分隔符、绝对路径、父目录段以及链接/目录条目，合法历史 ID 保持可用。
- 克隆保存使用同目录临时文件、文件同步和原子替换；不能从 agentlab 反向依赖 service，因此在现有 store 内完成写入序列，不引入包依赖环。坏记录及读取失败显式报错，不被当作空记录覆盖。
- 用户配置及账号配置迁移复用 service 现有原子写助手。坏配置保留，修复后须显式 reload；普通缓存型 JsonStore 也不再覆盖本次读取失败的原件。
- 删除恢复日志采用严格 JsonStore，先落盘再发布内存态、再改消息类型。记录写失败阻断 SQLite；写库失败保留原始类型以供重试或恢复，不假称已经回滚。恢复后日志清理失败也保留记录，可安全重试。
- 同一消息的删除/恢复串行，防止恢复先删日志、迟到删除后写入的交错。测试使用明文 SQLite 夹具，不使用真实聊天数据库。

## 请求终态与界面

- 替换/关闭全局对话框前，旧确认返回 `false`、密码返回 `null`；迟到关闭回调携带请求 ID，不能关闭新框。DialogHost 卸载也结算请求。
- 消息编辑器补齐标题关联、关闭按钮名称，复用现有焦点约束与 Escape 处理，不新增一套焦点管理。
- 脚本停止时，仍在宿主执行的调用以 `unknown` 快照返回，不让迟到完成改写已经交付的 trace。单工具超时或未知终态会停止本轮、补齐未执行同批调用的结果，不继续让模型自动重试。

**F07 仍是部分缓解**：取消信号已贯通助手、脚本回调和外部 MCP，但并非所有 native/QQ/服务工具都能撤销。尚无跨重启的持久化幂等账本或统一远端对账协议；返回的 operationId 是调用标识，不是可查询终态服务。已发送操作可能迟到完成，不能宣称“取消即无副作用”。

## 打包

- `beforePack` 按 `${os}/${arch}` 在独立目录构建 Remote helper；五个桌面 release job 准备 Go。
- `afterPack` 校验实际包内 helper 为非空普通文件、具有目标平台所需的执行权限，Go 平台/架构及最低版本匹配。
- 本轮在 macOS 真实交叉编译五个平台 helper，并用最小 Electron 打包夹具验证实际资源复制；这不等于五个平台都已运行或完整 WeQ 包已验收。
- 完整 `build:unpack` 在本机已有依赖悬空链接处失败；当前仓库 native 安装记录与锚定正式产物不同。本轮保留本地候选原件，正式产物在隔离目录验证，不为使打包变绿覆盖原件或放宽发布检查。
