# 手动批量漫游补缺

入口与操作见[缺失消息](../guide/chat-view.md#5-缺失消息)。传输统一走 [SSO 小窗](unified-sso-history-20261017.md)，不提供 SDK/500 条聚合通道。

## 计划与覆盖

- 本地扫描只根据已观察锚点构建候选 seq 区间，不发送历史请求；最早锚点之前的未知区间需明确选择。
- 日期按北京时间解析。不限制会话选择数量或在线请求次数，仍保留暂停、取消、间隔与在线条件检查。
- 目标只含可寻址的普通群/私聊，不能把数据线、频道或公众号当普通私聊发包。
- 区间保持压缩形式，不预先展开成海量小窗。只有实际核验并保存的 seq 扣减覆盖；短页、空页不填平缺口。
- “完成”表示所选候选区间已被覆盖，不等于服务端完整历史；内容为空或未解析另行计数。

## 持久化与恢复

- `RoamingBackfillManager` 的任务按 configId 保存于 `roaming-jobs/<configId>/tasks.json`，消息进入既有 `roam-msg/<uin>.db`，不改 QQ 原库。
- 来源配置、库身份、选项 hash 与边界锚点绑定；普通本地新增可扣除，不能只因 inode/mtime 变化拒绝续作。
- 派发前原子保存预约，写盘失败不派发；缓存提交后才推进断点。重启显示暂停，明确继续后复核已落缓存的在途窗口。
- 暂停/取消停止新请求，在途有效响应收尾保存；切号停止继续派发，重开不自动续作。
- 最多保留 10 个任务，最近窗口回执有界。显式删除仅删任务元数据，不删除漫游缓存；损坏断点保留并报错，不清空覆盖。

源码：`account/roaming_backfill.ts`、`gap_history.ts`、`sso_history_window.ts`；界面为 `components/RoamingBackfillPanel.tsx`。回归见 `roaming_backfill.test.ts`、`sso_history_window.test.ts`，覆盖断点失败、来源变化、取消、覆盖扣除及旧任务兼容；合成测试不证明真实 QQ 历史完整。
