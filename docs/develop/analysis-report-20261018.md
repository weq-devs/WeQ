## 时间与读取契约

- 好友分析、群画像、群成员分析、群会话力图和入群批次都接受可选 `startTime` / `endTime`，单位为 Unix 秒，起止都包含。两侧均省略表示全部历史；显式零边界不会扩大为全部历史。
- 边界必须是安全的非负整数，反向窗口在路由校验时拒绝；服务也独立校验，直接调用不能绕过。统计日历日、小时与火花相邻日固定使用北京时间，不取运行机器默认时区。无效或未知消息时间不生成 1970 日期，但全部历史的消息数仍保留这些真实行。
- 消息遍历复用数据库 `browse` 的时间/rowid 游标，新增可选 `newer` 方向，原调用默认 `older` 不变。好友的会话切分按稳定时间正序计算，避免乱序 seq 产生负回复时间；相同时间以 rowid 落定顺序。
- 群会话力图使用同一游标的轻量发送者/时间投影，不为时间线解码正文。群画像与成员统计仍按有界页读取，不把前若干条当全部历史，也不因空 seq、重复 seq 或分页边界丢记录。
- 路由接受可选 `expectedAccountUin` / `expectedAccountConfigId`，分派时复用当前账号校验后再获取服务。切号及同号切换数据源后才抵达路由的旧请求明确拒绝；已经开始的读取持有原服务，不会转向新服务。这不是在途查询取消，结果消费端仍须隔离过期响应。新工具结果须带确认时身份，原接口未带身份的调用保持兼容。
- 统计内部游标保留原始整数消息时间；大于 JavaScript 安全整数的异常时间不会因舍入重复翻页。轻量时间线也保存独立原始游标，图形计算忽略无法转换成有效日期的时间，不把异常时间伪装成可用日期。

## 入群批次的边界

成员列表是当前本地缓存，不是历史时点完整名册。传入时间范围时，只把已知入群时间落在范围内的当前缓存成员参与分批；入群时间未知的行不猜时间，也不混进时间范围。批次门槛的群人数仍来自当前群资料，缺失时回落到完整当前缓存成员数，不因过滤后的候选变少而擅自降低门槛。

成员发言条数与全群消息分母都使用同一所选消息时间窗口。展示与导出时须区分“当前缓存成员资料”和“所选时间的消息统计”，不把这份报告冒称历史成员快照。

## 界面接入

- `WorkspaceTools` 的分析扇区现在打开同一工具宿主中的实际配置。年度、好友、群、成员四类都有真实对象与时间输入；目录复用 `contactsExportPreview` / `exportGroupDirectory`，对象列表窗口化，未截掉目录末尾。
- 配置确认前复制对象和时间参数，再核当前 uin/configId；等待期间防重复提交，切号销毁表单并丢弃旧响应。表单重开保留本账号草稿，不反向修改内容页选择。结果 ID 复用已有支持非安全 HTTP 环境的前端 ID 生成器，不要求 Web 必须提供 `crypto.randomUUID`。
- `AnalysisReportPage` 在主区域承载现有报告。好友、群、成员卡片以 embedded 模式复用原内容、关闭和长图保存，不套用会隐藏操作的 `exportMode`；查询失败可重试，群统计、批次、力图分别保留失败状态。时间口径进入卡片和长图载荷，成员资料明确标为当前缓存。
- 图片保存只在真实导出桥接存在时启用；没有该桥接的 Web 等环境禁用按钮并给出能力提示，不把入口存在算作平台已支持。此项没有新增浏览器截图服务或图像依赖。
- 年度报告支持工具确认后直接进入所选年份的 deck，旧入口继续保留年份页，未进入时不扫描正文。每个结果使用独立 `reportInstance` 目录查询键；该字段只隔离客户端缓存，不改变服务端年份口径。返回不自动刷新目录而重置页码，手动刷新一份报告不覆盖同年份其它结果。
- `WorkspacePage.retainOnNavigate` 允许报告在普通导航后保留，当前内容作为可选标签返回。显式关闭才移除该结果；普通内容、临时搜索和右栏仍沿用原行为。隐藏报告不监听翻页键、不继续预加载下一页、不重算图谱尺寸；全局翻页键不抢工具和输入控件。
- 年度报告字体改为当前报告根节点和浮层宿主的局部令牌，按节点版本拒绝晚到下载，数字保留原排印。注册过的 face 仍共享，关闭或清理一份结果不影响其它结果。
- 群力图主色与高亮跟随有效强调色，文字和边线读主题令牌；隐藏时停止模拟，减少动态效果时初始布局直接落定。卡片日期与入群批次时间显示固定北京时间。
