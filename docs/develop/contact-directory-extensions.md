# 联系人目录扩展

好友／群目录共用 `ContactDirectoryRuntime`、联系人指标缓存及 `useContactDirectoryOrder`。新增字段不修改 QQ 原库、不增加 native 接口；老版 metrics v1 文件继续读取。

## 指标与在线更新

`ContactMetric` 新增 energy、source、sourceGroup、schools、joinedAt、grade、freezeState。schools 为学校名称数组，来源两项为文本，其余为数值；空字符串、空数组、真实 0 和未知分别保留。

能量、教育、好友线索和群扩展详情读取成功后投影到同一个账号缓存。`project` 支持成功响应将缺省值显式清空；失败使用 `failed` 保留旧成功值。重建路由的 fields 支持上述字段，切换控件时的刷新弹窗只提交本次所需字段，常规刷新按钮仍更新全部。

学校仅投影当前查看者可见的经历，和本地学校按去首尾空白后的实际名称合并；同校按身份去重，多学校保留多个展示位置。QQ 群来源统一归类，有明确来源群号或明确 QQ 群／群聊／群号文案即可识别，原文与具体群号不被改写。来源群链接复用已有名片读取入口，原资料页继续严格展示来源原文。

## 本地摘要与画像

账号绑定的 `contactMetrics.localTimes` 每次只推进一个 128 行的 rowid 倒序页，扫描 c2c 或 group 消息表。游标保留十进制整数精度，按发送时间取最大，不假设 rowid 与发送时间同序。发送状态必须明确成功，排除空／删除类型、灰条及无有效元素的正文。

`DirectoryTimeReader` 在当前宿主内保留摘要、合并并发读取；文件变更使下一轮重新核对，覆盖历史补入、删除和原位更新。每页由背景数据库优先级及账号 AbortSignal 调度。前端只有时间排序可见且不在多选时续读；失活不再请求下一页。初始补齐与已确认无本地记录使用不同状态，不写入新的历史数据库。

已确认发送的会话预览带有 directoryTime，作为首屏种子；原始 recent_contact 预览不含充分的发送状态，不能直接拿更新时间作为有效消息时间。草稿及失败／可能未送达预览不提供种子。

`localJoins` 使用本人 UID，缺 UID 的旧记录才按本人号码补全，排除明确已退群的成员行；同群精确 UID 优先于号码回退。在线补全复用现有群成员读取。

`cachedProfiles` 批量返回已完成缓存中的 UID、affinity、computedAt，不读取聊天或调用模型。画像完成、淘汰及配置失效通过 changed 的 profiles 标记使前端清除旧摘要并重读；低频查询补充断连恢复。缓存仍沿用现有内存上限与生命周期，不持久化好感度目录。

## 验证

定向回归覆盖排序分组、真实 SQLite 游标／身份／删除反例、缓存投影、账号关闭、并发及画像零计算。浏览器脚本 `apps/desktop/test/browser/run-contact-directory-order.mjs` 使用隔离 RPC，检查多学校、QQ 群统一来源及真实名片入口、浅深主题、320／390／1180 宽度，以及 200／1000 个合成联系人的绘制、切换和滚动对照。开发服务器与并行编译会影响这些数据，不能当作正式安装包耗时。
