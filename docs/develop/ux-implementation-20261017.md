## 全局搜索范围与请求生命周期

- 标题栏搜索下拉为已接入五类提供复选框，默认全选，支持清空与全选；未选类别不渲染结果，也不会调用其数据库搜索。空范围不等于全部，不触发索引构建。
- `searchQuick` / `searchSlow` 的范围参数可选，兼容原调用方；`searchMore` 类别与服务端共享常量。慢查询复用分类排名缓存后再截取预览，修复原先忽略 `limit`、固定返回三条的问题，避免同关键词切换范围串用截断结果。
- 搜索 Hook 按账号、关键词、范围和重试轮次绑定结果；新条件第一帧隐藏旧结果，200ms 防抖后仅查询所需分类。切换条件或卸载会丢弃原响应；快速或慢速查询失败时分别停止占位并显示重试，不把失败伪装为无结果。
- 新增 service 5 项、desktop 5 项专项，覆盖默认兼容、空范围、未选类别跳过、慢查询范围与条数、异步晚到响应、切号、重试与卸载。服务层新增用例先执行，四项失败复现后才修改实现。
