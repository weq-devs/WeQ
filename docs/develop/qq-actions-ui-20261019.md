# QQ 主动操作界面接入（2026-10-19）

## 范围

本批同时覆盖最早的写能力候选和后续合入的主动操作协议，不以协议目录存在代替界面完成。已有备注、置顶、消息策略、个人资料、群资料和精华入口继续复用；新增群资源管理、收藏表情、申请处理、群待办、聊天回调、输入广播及通用加群等入口。用户已移除群头衔有效期需求，未新增其交互。

入口对应表见[用户指南](../guide/qq-actions.md)，命令和签名依据见[协议清单](./protocol-actions-20261019.md)。没有新增运行模块依赖，不把未确认字段拼入任意属性包。

## 账号与结果边界

- `account.qqActions` 使用已有 `requireExpectedAccount` 和 QQ 在线检查，所有输入必须携带 UIN 和配置 ID；跨异步阶段同时确认服务实例与 QQ PID。
- 同一账号的主动操作串行保护，重复点击不重放。删除、退群等操作复用现有确认框，资料和评论由明确的保存／发送按钮提交，不引入第二套弹窗状态。
- `withQQAccountScope` 以 UIN／配置 ID 重建编辑子树；`useQQAction` 在确认和文件选择结束时复核当前子树，旧异步结果不会填进新账号。
- 图片读取只允许账号媒体或本应用文件选择器已授权的路径，有界读取至 20 MB；普通群文件继续复用流式上传，不把大文件整体读入内存。
- 群文件在 hash、取会话、打开上传源和发布前复核；收藏上传在取会话／token 后复核，排序在两次写入之间复核；相册评论取得原始 cell 后复核。
- 本批新增 Web 写操作在异步取凭据完成后、每次 HTTP 写入前复核；显式鉴权失败后的取票重试也受同一校验约束。相册分片在下一片开始前复核，不自动重发分片。
- 远端返回后不再用账号切换把已发送操作改成“未发送”。缓存刷新失败与写入结果分开，输入广播可以跳过无关缓存刷新。
- 机器人回调的非零业务结果必须显示失败，不因 OIDB 外层成功就提示受理。未知的消息定位、缺失按钮 ID、机器人 App ID 或转发子消息不得使用外层消息伪造请求。
- 相册视频的互动使用视频 ID，删除使用封面 lloc；缺少删除定位不猜测，缺少点赞元数据不连带阻断删除或评论。
- 群待办列表的序号以字符串保留，写入时校验 uint64 上界，不经 `Number` 舍入后定位另一条消息。
- 申请操作合入原通知卡片，只绑定同一身份最新的待处理申请；退群、邀请和自己的申请不误作审批。通知查看状态与待处理状态独立，按账号／数据源隔离。

## 通用加群

新增 `GetGroupJoinInfo`：`0x88D_110`，请求明确选择加群方式、群名和问题，不查询标准答案。结构依据为 Lagrange.Core 固定版本 [D88DGroupInfo](https://raw.githubusercontent.com/LagrangeDev/Lagrange.Core/20c2ba079b5ee67156bd71419ed54ea61a24e91f/Lagrange.Core/Internal/Packets/Service/Oidb_0x88D.cs)（7／15／24）及[陌生群查询服务](https://raw.githubusercontent.com/LagrangeDev/Lagrange.Core/20c2ba079b5ee67156bd71419ed54ea61a24e91f/Lagrange.Core/Internal/Services/System/FetchStrangerGroupInfoService.cs)。参考实现未请求问题，本批是按已知结构补查询，不宣称已验证当前服务端向所有未入群账号返回问题。

问题状态分别表示 `available`、明确非问题模式下的 `not-required` 和 `unavailable`。空结果、拒绝读取、字段缺失均不能伪装为没有问题；错误群号的响应拒绝使用。

群分享链接仅接受已知 QQ HTTPS 域名，复用现有分享解析工具。主进程保存限时、不透明的目标 token，不向渲染进程返回 authKey；提交时确认目标、有效期、账号及尚未入群，再交换／读取分享信息。实际提交消费 token，未知回执不自动重发。

`SendGroupJoinRequest.invokeWithOutcome` 保留旧入口兼容，只将既有空 ACK 形状判为 `accepted`，其余未建模回包为 `unconfirmed`。即便 accepted 也只表示申请受理，不表示已经入群；安全挑战的具体响应仍未完整建模，不提供绕过。

## 验证与未覆盖项

验证使用合成 UID／UIN、黄金字节、模拟网络、账号与 PID 变化及本地临时文件，不读真实 QQ 数据库，不发送真实 QQ 写请求。

- 协议回归：问题字段选择、缺失与拒绝、错群响应、入群回答、未知回执、上传阶段失效保护以及既有文件／状态／群操作黄金样本。
- 服务回归：Web 取票前后与鉴权重试的身份保护，群文件／群管理编排、Web 写 CGI 及已有账号写保护。
- 桌面回归：账号与配置绑定、uint64 边界、确认取消、文件目录、图片评论、多问题之外的单回答流程、草稿隔离、扩展状态、原始按钮定位及输入广播节流。
- 布局：9 个功能面板 × 5 组视口／主题组合，共 45 组离线 Playwright 检查；覆盖浅色、深色、跟随系统、不同主题色／背景、320px 窄屏与低高度窗口。位图由本地夹具提供，不是读取真实 QQ 媒体。

真实权限、跨端同步、好友免打扰未确认回包、陌生群问题可见性、加群安全挑战及各类写入恢复仍需指定测试对象后验收。本批未继续实现生日／地区／学校、完整好友分组管理、相册视频上传、其他输入事件或登录设备主动查询。
