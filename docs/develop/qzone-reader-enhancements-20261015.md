# 空间读取边界

配方编号见 [Web 接口参考](qzone-web-api-reference-20261015.md)，用户入口见[空间、相册与频道](../guide/album-qzone.md)。

## 说说与动态

- R02 正文完整性为三态：明确更多、明确结束、标记缺失。只有明确更多才自动补读；缺标记不等于归档完整。
- R02 返回整段而非文本分片，没有验证过正文分页游标；重复读取不拼接。停滞/循环或达到上限停止，失败和重试保留最长已读正文，作者/tid 不匹配拒绝。
- R04 仅在已知图片总量大于返回 pic 时补图；顶层视频不抵图片数，补图 URL 也不证明原件已下载。
- 特别关心在好友动态筛选中使用服务端 `scope=7`；换范围清空旧游标和行，不能靠本地昵称筛选代替。
- R17“与我相关”展示折叠互动提示，按服务端提示识别赞、评论、转发、@；不从原帖正文猜类型，不自动加载原帖全文或媒体。只使用实际前进的服务端 offset。
- R18“那年今日”和转发名单没有产品入口；R13/R14 尚未替换主页说说源，见 [TODO](qzone-todo.md)。

## 相册与安全

- R20 使用有界相册分页，以相册 ID 合并；短页不一定结束，重复页/总数变化停止自动遍历，未知总数不冒称完整。
- R22 按请求的 picKey/lloc/sloc 精确绑定，不从响应任选视频。无可播放 URL 时仍是封面，不伪造播放成功。
- 切页或切号取消前台读取并拒绝迟到结果；失败不自动无限重试。远端 JSONP/对象字面量只解析数据，不执行脚本。
- 分页共用进程级[限流](qzone-pagination-rate-limit.md)，不新建绕过账号会话的登录或凭据缓存。

源码：service 的 `account/web/qzone*.ts`、desktop 的 `main/ipc/routers/qzone.ts`、`views/QzoneView.tsx` 和 `lib/qzone.ts`。测试使用合成响应；第三方配方或离线回归不等于当前腾讯服务端兼容性保证。
