## 修正

- 业务操作继续显示自定义撤销／重做项，并使用实际业务描述和可用状态。
- 文本编辑、有文本历史的桥接页面及无桥接窗口切换到 Electron 原生 `undo`／`redo` 角色，由原生编辑上下文判断操作与历史；无桥接网页、频道／空间页及开发者工具不再假定始终可撤销。
- 没有明确业务撤销时均交给原生角色，包括空历史与焦点不在网页的系统原生对话框，不把“无 WebContents 焦点”误当作无编辑上下文。
- 自定义项与原生项互斥显示，均设置 `acceleratorWorksWhenHidden=false`，隐藏项不会抢占可见项的快捷键。
- 窗口焦点变化及时刷新；渲染进程退出清除旧桥接状态，内容销毁后刷新菜单，不留下旧业务操作描述。
