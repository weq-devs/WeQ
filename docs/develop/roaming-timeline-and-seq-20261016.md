# 漫游时间线与消息序号

实现日期：2026-10-16（北京时间）。

## 行为

- 缺口按钮直接将本轮拉取到的可信记录插入主聊天时间线，不再用弹窗承载普通补全记录。
- 消息下方保留小字“漫游”。原件仍在 QQ 库，补全记录仍在按账号隔离的 WeQ 漫游缓存；不将渲染视图反写为 QQ 原始消息。
- 群聊与私聊的最新页、向前/向后分页、按 seq 定位上下文与实时刷新共用缓存混排逻辑。查询使用各页的原有方向、边界和条数上限，支持纯缓存页；普通读取不联网。
- 本地消息优先；保留本地同 seq 的灰条。QQ 后续同步到本地时，重新读取窗口会由本地行替代同 seq 的漫游行。
- 漫游行的 UI 标识独立于本地 msgId，并带 seq，避免服务端 random/零值与原库雪花 ID 混淆。媒体回查保留原始 msgId。
- 私聊仅接受已确认 NT 会话序号的漫游行。旧编号不与本地 seq 混排，拉取时保留独立查看窗口并提示未定位的原因；不按时间、内容或相似昵称猜测身份/位置。
- 每次点击至多检查八个连续空窗（每窗最多 30 个 seq），保留续查游标；未补齐的缺口不会被标为完成。出错可重试，切换会话/窗口后不将旧请求结果插入新窗口。
- 漫游行不提供原库编辑、删除、撤回入口；多选包含漫游行时禁用原库删除。现有媒体的漫游缓存回查不变。
- 设置 → 个性显示 → 显示消息序号（seq），默认关闭，持久化到 AppSettings.showMessageSeq。开启后显示有效的正整数序号，普通气泡与系统灰条均适用；不伪造未知序号。
- 原始消息数据、导出格式及现有“补充漫游记录”导出选项不变。
