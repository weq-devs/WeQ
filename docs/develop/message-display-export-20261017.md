隐私模式仍是视觉滤镜，不是数据访问控制、加密或不可逆匿名化；导出文件与 DOM 数据不因此改写。

SSO 仍逐物理小窗执行共享 FIFO 和至少 500ms 请求间隔；取消预算不取消暂停、取消、账号隔离、错误保留窗口和精确覆盖核验。已退役通道及旧缓存不删除或重新启用。

说说正文补读没有完整标记时不声明全文；附图扩充不宣称原件质量。转发名单未恢复上线。收藏来源字段、二进制正文、附件原件 / 预览身份及失败回执沿用现有缓存和覆盖报告，不将“已列出 URL”当作“已取得原件”。

## 后续：主页头像与聊天交互

2026-10-17 根据后续请求补充：

- `AvatarOrb` 不再绕过 `cachedAvatarUrl` 直取固定 CDN 图片。主页在重新激活、聚焦或恢复可见时复核头像桥；刷新参数仅放在桥 URL，不改变上游来源和磁盘缓存身份。
- 「优先使用 CDN」模式通过浏览器 `cache: reload` 读取头像，自己创建的 Blob URL 在替换、退出时释放；请求取消与迟到结果隔离，失败不锁死后续重试，用户传入的 Blob URL 不由本组件回收。
- 发送中使用旁侧 `LoaderCircle`，不占消息下方状态行；正常回执后直接移除。失败、疑似静默拒收保持原有下方提示；减少动态效果时保留静态状态标识。
- 未入库的 WeQ 消息不再被右键入口拒绝，可复制、多选，并按回执状态和有效序号判断引用、贴表情、撤回。修改 / 删除仍要求真实本地行；发送投影保留已取得的 random，不以临时 UI ID 冒充原库消息 ID。
- 多选支持 Ctrl/⌘ 单条切换、Shift 从锚点选择区间、Ctrl/⌘+Shift 追加、Ctrl/⌘+A 全选已加载消息。区间算法与 Set 没有数量截断；不会为了全选自动读取整库，也不改变 QQ 合并转发的协议约束。
- 纯文本复制包含按时间线排列的昵称、北京时间秒级时间、正文；媒体复用已有摘要标签，非法时间标成未知。按钮和 Ctrl/⌘+C 共用处理，输入框、编辑器与其它对话框的快捷键不被接管。JSON 复制保留，灰条也支持选择。
- 窄屏多选栏使用五个有名称和提示的图标按钮，避免按钮被挤出视口。
