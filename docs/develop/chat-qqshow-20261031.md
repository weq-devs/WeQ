# 聊天头像的 QQ 秀（2026-10-31）

## 目标

- 设置 → 自定义消息显示新增「聊天 QQ 秀替换头像」，默认开启。
- 开启后消息头像改用成员的 QQ 秀全身像，外层仍占头像的 36px，形象本身宽 44px（约头像的 1.2 倍），不再渲染头像与头像挂件。
- 只查进入可视区域的头像；本地已有有效映射不重复请求，服务端全局串行发 OIDB（批次与个性主页共用队列）。
- 形象 URL 按账号落本地映射，默认 5 分钟过期（可按分钟配置），个性主页共用这份缓存。

## 数据流

```
消息头像 (messageBubble.tsx)
  → useChatQqShow(uin, enabled, ref)   // IntersectionObserver 可见触发，24ms 窗口合批
  → dressup.chatQqShows({ uins })      // 最多 120 个 uin
  → ChatQqShowService.resolve()        // 命中缓存直接返回，未命中串行查询
  → GetQqShowUrl (0xFE1_3)             // 既有协议，需在线 QQ 实例
  → config/accounts/<accountId>/qqshow.json
```

- 缓存文件结构：`{ version: 1, entries: { [uin]: { hasShow, url, fetchedAt } } }`。
- 没有 QQ 秀也写一条 `hasShow: false`，避免对同一个人反复空查。
- 查询失败不覆盖旧记录；过期记录仍可用于展示。
- IPC 返回绝对到期时间 `expiresAt`，前端不重新延长服务端缓存；仅可见头像挂到期定时器，无形象结果同样到期重查。失败退避 30 秒，离屏或关闭开关后取消刷新。
- 前端在途去重；切换账号或修改有效期时清空内存缓存，忽略旧代请求的迟到结果。
- 超过 4 个有效期（最少保留 4 天）或 5000 条时清理最旧记录，文件不会无限增长。

## 表现

- 图片经 `weq-media://qqshow` 代理并落盘缓存，读取时按 QQ 秀分钟设置判断有效期，过期后显式刷新且失败保留旧图；浏览器使用 `no-cache`，查询结果到期时间作为本地代理版本参数，保证固定上游 URL 也会重载，不向 CDN 添加版本参数。
- 外层保持头像的 36×36，全身像绝对定位、底边对齐、向上自然溢出（宽 44px），不改变消息行高；图片加载失败回退到普通头像。
- 个性主页的 `peerQqShow` 改为先读这份映射，因此有效期内/离线时也能显示形象。

## 边界

- 只有能拿到 QQ 号的成员（`identityValue` 为数字）才参与查询；纯 uid 的成员保持普通头像。
- 聊天头像与个性主页共享过期时间；设置字段为 `qqShowCacheMinutes`，范围 1–525600 分钟。旧 `qqShowCacheDays=14` 迁移为 5 分钟，其他自定义天数换算保留。改设置不重写已有记录的时间戳。
- 该缓存属于用户数据（谁有 QQ 秀），不写入日志与导出产物。
