# 意图感知与互动画像解耦

## 边界

- `InteractionProfileService` 只接收 `profile*` 配置、消息读取函数、API 端点解析和本地模型端口，不接收逐条意图缓存或会话分析开关。
- 保留 `account.intentSense.getProfile` 和同一账号配置文件，避免另建平行配置与破坏现有客户端；旧入口仅委派，不再承担画像计算。
- 画像从统计窗口中截取最近的对方有效文本，独立做情绪、人格与互动风格推断。API 情绪结果按样本序号校验、去重，越界或无效值不参与评分。本地模式通过所选资源的端口分析，不写入消息意图缓存。
- 同一对方的并发画像读取合并。画像设置更新独立递增版本，使旧在途结果失效；意图设置、清空分析缓存不改变画像版本或失败冷却。
- 没有画像自身的情绪依据时，`affinity` / `tier` 返回 `null`，走势为空，雷达不补默认情绪外露轴；统计、话题与明确标记的启发式人格仍可展示。客户端仍保留画像入口。

## 配置与模型

- `featureSettingsVersion: 2` 将旧 `follow` 一次性固化为原 API 引用或本地资源。桌面侧传入旧全局资源选择以保留显式本地模型；启用状态不变。
- 画像独立保存 `profileEngine`、`profileProviderRef`、`profileLocalModelId`、超时与失败冷却。新配置默认仅本地统计，不隐式选择联网服务。
- 意图本地资源仍沿用全局 `modelResources.intent`；画像资源按账号保存。二者选择相同模型时复用文件和 worker，不同模型时按目录分别路由，五分钟无推断请求后释放空闲 worker。
- 下载接口新增可选 `modelId`，画像页下载所选资源，不改写意图资源；旧客户端省略参数时保持原下载语义。
- 会话的意图覆盖开关不再隐藏画像。画像刷新跟随消息变化，不再等待意图分析完成事件；查询缓存键包含画像版本。

## 验证范围

离线合成夹具覆盖配置迁移、独立 API 和本地端口、分析缓存隔离、失败冷却隔离、在途版本隔离、并发合并、空样本、无情绪评分、设置写入与 worker 资源路由。真实 QQ、真实 API、模型权重推理及桌面浅深主题目视验收不属于这些离线测试的证明范围。
