# 开发控制台日志

桌面未打包运行、独立 Web 非 production 运行时，公共 logger 同时输出到启动终端。
正式运行默认不新增镜像。原有文件日志格式和内存诊断文件不变；这不是全仓 `console.*`
或 nt_helper 日志的接管。开发启动器会单独整理开发子进程的终端输出。

桌面 main / preload / renderer 与内置 Web 的 Vite 配置均关闭自动清屏；启动、构建和
热更新保留已有终端记录。进度显示仍可更新当前行。

## 配置

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| `WEQ_LOG_CONSOLE` | 开发 `1`，正式 `0` | `0` 关闭、`1` 显式开启终端输出 |
| `WEQ_LOG_LEVEL` | `info` | 终端最低级别：`debug` / `info` / `warn` / `error` |
| `WEQ_LOG_SCOPES` | 空 | 逗号分隔的精确模块名；只过滤 INFO / DEBUG，WARN / ERROR 不受模块过滤 |
| `NO_COLOR` | 未设置 | 存在时关闭颜色；非 TTY 输出也不带颜色 |

```bash
pnpm dev
WEQ_LOG_LEVEL=debug WEQ_LOG_SCOPES=trpc,media-download,database pnpm dev
WEQ_LOG_CONSOLE=0 pnpm dev
```

默认 INFO 聚焦启动、账号、连接变化、媒体汇总和服务状态，不镜像其他模块全部历史 INFO。
指定模块或使用 DEBUG 级别可查看其他模块的现有日志；WARN / ERROR 仍遵循最低级别。
配置错误回落对应默认值，并提示一次。

## 如何阅读

终端每条记录采用「北京时间 `HH:mm:ss`、级别、模块、事件摘要、关键结果」的短文本，
不输出 JSON、日期、时区、进程名或 PID。INFO 为绿色、WARN 为黄色、ERROR 为红色；模块
与普通数值为青色，时间、字段标签和堆栈弱化显示，慢耗时额外标黄。非 TTY 与 `NO_COLOR`
使用相同排版的纯文本。默认隐藏内部事件名、长关联 ID、成功状态、空值和未知占位；
DEBUG 补充短关联 ID 与有界诊断摘要。耗时自动使用 ms / s，大小使用 B / KB / MB，
错误堆栈独立缩进，默认最多六帧，DEBUG 最多二十帧，其余仍可从文件读取。

启动、账号和 MCP 生命周期事件显示中文摘要，模块和 API 方法名保留英文；终端不重复
显示应用上下文中的日志目录，地址已含端口时不再重复列端口。文件原文不变。

## 开发启动与热更新

`pnpm dev` 的主进程、预加载和内置 Web 构建各显示开始、完成、耗时与产物数量，
不列出逐文件路径、大小及模块转换进度。通过 Vite logger 与构建生命周期生成摘要，
构建警告、错误及定位内容仍显示，失败不会显示成功摘要。热更新逐次保留，同条记录
中的重复路径去重。正式构建命令维持 Vite 默认输出；`WEQ_LOG_LEVEL=debug pnpm dev`
保留完整构建输出。

构建摘要中的数量标为「产物数」。默认将大包告警的通用建议收为一行阈值摘要；插件计时
只显示累计耗时与关键插件明细，明细接续原 WARN，不另标为 INFO。DEBUG 保留原始建议、
计时说明及链接；其他构建警告和错误不变。

开发启动器接收子进程 stdout/stderr，各自转发至原通道。已有 WeQ 格式的记录不重复
包裹，Vite、Electron/macOS 系统消息与无法识别的开发子进程消息统一补齐来源前缀。
系统消息不按内容屏蔽；系统自带时间/PID 不重复展示，正文仍保留。管道继承原终端的
颜色能力，`NO_COLOR` 仍优先；长行分段、UTF-8 跨块和退出尾行均保留。Ctrl+C 或终止
信号转发给本次开发子树，POSIX 上使用独立进程组清理，不影响其他开发实例。

`WEQ_DEV_CONSOLE`、`WEQ_DEV_STDOUT_TTY` 和 `WEQ_DEV_STDERR_TTY` 由启动器内部传递，
不需要手动设置，也不要将其加入长期 shell 环境。`WEQ_LOG_CONSOLE` 只控制公共 logger
的镜像，不用于关闭构建诊断和原始系统消息。

```text
19:44:23 WARN  trpc  慢请求  account.getUnreadInfos  耗时 2.28s
19:44:24 INFO  media-download  媒体下载汇总  耗时 930ms  共 12  来源 外部 rkey
```

文件仍保留原始 ISO 时间格式与完整结构化字段。终端展示会隐藏凭据字段、移除 URL 查询和片段、限制字段
长度及嵌套深度，不展开正文、原始响应及二进制；不修改业务原对象。

- 启动显示应用版本、运行模式、平台、架构、原生加载结果和日志目录。实载原生构建信息可在 DEBUG 终端中查看；拿不到版本时不拿 pinned 版本冒充实载版本。
- tRPC query/mutation 超过 1 秒会告警；普通成功调用为 DEBUG。订阅不按存活时间判慢。请求 ID 使用 `operationId`，只存在于日志上下文，不进入业务返回值；嵌套 MCP、账号和 tRPC 操作沿用它。
- 参数校验、未登录、维护期间拒绝请求、业务前置条件与取消为 DEBUG；取消的 `outcome` 为 `cancelled`。在线探测超时、明确的远端业务拒绝及读取请求的网络故障为 WARN；未知失败、数据库故障、进程退出及写操作结果不明仍为 ERROR。同一异常在共用入口和 HTTP/WS 回调之间不重复打印堆栈，传输层独有错误仍会上报。
- 预期状态在产生错误的位置使用 `OperationError` 或结构化错误码标记，日志入口有界遍历 `cause`，不按中文文案匹配。凭据链返回不可用时由上层请求或后台任务统一告警，底层仅保留 DEBUG；编程错误仍保留 ERROR。
- 原生 OIDB 明确拒绝使用 WARN，传输与应答解码异常保留 ERROR；普通内存扫描未取得物料时先使用 WARN，仍可由上层尝试其他读取路径。裸包发送和密钥探测不在返回边界重复记录同一次失败。
- 媒体命中缓存、逐图成功和单次尝试为 DEBUG；成功路径按来源每 5 秒汇总次数、失败数、累计耗时。最终失败包含媒体散列标识和各阶段原因计数，不打印 fileToken 或 rkey。禁止在线请求或运行态失活不作为最终失败告警。
- 数据库 `jsQueueWaitMs` 和 `nativePromiseAwaitMs` 任一超过 500 毫秒会报告，两者独立计量。后者包含原生异步等待，**不是纯 SQL 执行耗时**。慢样本始终附带匿名查询指纹和源码调用点；普通快查询不展开调用栈或计算指纹。`WEQ_DATABASE_DIAGNOSTICS` 仅控制完整的有界逐查询历史。
- 定向诊断可通过 `observeSlowDatabaseOperations(observer, thresholdMs)` 独立订阅更低阈值的样本；默认日志订阅仍使用 500ms，各订阅分别过滤，不因诊断采样而增加普通告警。
- 主应用开发版的未处理异常与 Promise rejection 通过显式日志桥接上报；不全量转发 DevTools console。渲染进程异常退出沿用现有恢复入口记录。
- macOS 不在未知账号的启动期预加载安装目录中的 QQ wrapper。完整模式确认目标 QQ 后，预热与诊断重新扫描均选择该进程实际加载的模块，避免安装旧版和热更新版重复注册 Objective-C 类；不屏蔽其他 `objc` 错误。已加载两份模块的旧进程需完整退出再启动，HMR 不能移除它们。

重复 WARN / ERROR 首次完整输出，同模块、事件、关联对象与错误的后续记录在 30 秒内
聚合次数，汇总只显示原事件、定位方法及新增次数，不重复旧耗时与堆栈。
聚合表最多 512 项，正常退出刷新；文件端不聚合。不同请求的操作 ID 不会阻止同一错误
聚合，完整关联信息在文件日志保留。内存、DOM 和动画等连续采样继续单独落盘。

独立 Web 首次启动展示临时访问令牌的专用入口保持不变，不通过通用 logger 落盘。
Web 浏览器没有桌面日志桥接时，前端异常仍在浏览器 DevTools 查看。
