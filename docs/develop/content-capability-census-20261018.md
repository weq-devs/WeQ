# 现有内容能力盘点

日期：2026-10-18（北京时间）。对应 D22，不把父级入口存在当作所有子内容已支持。表中“缺口”是后续施工范围，不是新增不可用选项，也不表示在线服务提供了尚未验证的接口。

## 正文与关联资源

| 内容与真实层级 | 当前读取与身份 | 当前统一能力 | 明确缺口 |
| --- | --- | --- | --- |
| 普通私聊、群聊及其消息元件 | `MsgService`、消息 ID、会话及来源；引用、合并转发、图片/语音/视频/文件由原查看器展开 | 会话/文件/聊天记录搜索，消息精确多选，消息与资源导出 | 全局消息搜索覆盖与索引上限需单独验证；不能把文件搜索等同所有正文检索；转发内部节点的独立选择与导出核查 |
| 数据线、公众号、服务号 | `message_source.ts` 已有专门迭代器；`unified_search.ts` 保留分类 | 沿现有会话组织与专用数据源读取 | 精确多选、搜索正文、导出入口和来源字段逐条实测，不能套普通私聊 SQL |
| 频道私聊 | nodeId / msgId；稳定 seq/time/id SQL 游标 | 本地全库搜索与精确跳转、共享多选、精确导出与持久任务 | 尚需统一返回现场；不扩称频道网站群聊已被本地库覆盖 |
| 收藏八种内容 | CID；文本、链接、相册、音频、视频、文件、位置、富媒体 | 正文搜索、共享选择与精确导出 | 各子类型资源自包含、附件缺失和保存策略完整验收 |
| 空间说说 | uin/tid；详情、原转发、互动、媒体 | 观察文本搜索，单作者共享选择、精确 tid 导出任务 | 跨作者动态的离散集合；评论/回复/赞/转发的独立层级与可搜索字段 |
| 空间相册与照片 | uin/albumId；`qzone.albumPage` / `albumDetail`，照片及视频由原查看器读取 | 相册观察文本搜索与精确相册定位 | 相册和照片共享选择、精确资源导出；不以说说导出替代照片导出 |
| 群相册与照片 | groupCode/albumId；`GroupAlbumDialog` 与 `AlbumExportLightbox` | 相册观察文本搜索；现有相册勾选和下载 | 正文页共享选择到唯一工具；离散照片及跨相册集合；任务与保存策略核查 |
| 群文件与目录 | groupCode/folderId/fileId；保留目录上下文 | 文件名观察搜索，目录精确定位；工具已有递归目录选择 | 正文页共享多选交接；冻结目录展开结果；独立下载任务统一归位 |
| 群公告、精华 | `listGroupBulletins`、`getGroupEssenceWithContent`；原群内查看器 | 原查看、精华消息定位 | 公告稳定身份和缓存范围核查；搜索、选择、导出未归一，不凭标题猜 ID |
| 闪传文件集合 | fileSetId 与实际文件条目；`FlashTransferViewer` / `flashListFiles` | 原文件选择、下载和独立任务管理 | 搜索观察、共享选择、统一任务与保存流程；保留过期/不可访问结果 |
| 邮件、附件与文件夹 | opaque mail id/folderId；附件独立 id；`MailPage` | 邮件观察文本搜索及定位，原邮件批量操作/附件下载 | 共享选择、邮件精确导出、附件自包含和下载任务统一；原正文缓存不是完整邮箱档案 |
| 克隆私聊、克隆群聊、助手对话 | kind/owner/session/message ID；旧版会话显式 null | 持久正文搜索、共享多选、精确快照导出任务 | 语音/表情/助手产物自包含；临时未持久消息不伪造稳定 ID；统一长任务 |
| 合成素材与合成记录 | `CompositionWorkspace`、持久合成历史与素材库 | 原独立工作窗口、复制/发送/转发/导出实现 | S33/S34 各路径实际操作、重启与异常恢复验收；不把合成记录当真实 QQ 历史 |

## 目录与配置数据

| 内容 | 当前能力 | 缺口与边界 |
| --- | --- | --- |
| 好友与群成员 | 名称/备注搜索；UID 精确导出；群成员范围独立 | 群名片、非好友、退群成员等子列表能力核查，不把主好友列表当完整人员库 |
| 自定义、商城与系统表情 | 自定义表情统一工具；商城离线目录搜索/packId 定位，保留原下载能力 | 图片条目精确选择交接及任务归位；商城目录不是用户已下载资源；系统资源不伪造业务消息 |
| 个性装扮 | 原装扮浏览/设置及资源导出 | 逐类核查气泡、字体、挂件等已有资源操作；配置不是聊天内容 |
| 明文数据库 | 统一工具调用原数据库选择与导出 | 账号、保存、取消与 Web 下载验收；不在全局正文搜索中隐式解密全库 |
| 分析与报告结果 | 原好友/群/成员分析、年度报告及导出实现 | 对象/时间/报告类型统一配置，主区域结果标签与返回；不能只跳回旧入口 |

## 跨内容未完成项

1. 搜索跳转已接入返回原查询、类别、分页结果、滚动与焦点；原浏览页面自身的会话/层级/资源现场仍需逐类核对，不把搜索结果快照替代完整内容导航历史。
2. 全来源任务投影与控制：导出、历史补全、媒体/闪传/商城下载、克隆生成等保留原能力并按账号隔离；关闭配置不取消执行。
3. 工具内就地准备与全局默认分离；必要配置后恢复独立草稿，不隐式改全局设置。
4. 所有类别三种保存策略、失效目录、命名冲突、缺失条目和账号切换；桌面/Web 及窄屏、深浅色、强调色、背景、减少动态效果实际验收。

实施状态与当轮门禁证据仍以[完整交付清单](./content-tools-completion-matrix-20261018.md)为准。本盘点不宣称以上缺口已实现，也不替代逐项回归。
