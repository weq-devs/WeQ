| 内容与真实层级 | 当前读取与身份 | 当前统一能力 | 明确缺口 |

| 数据线、公众号、服务号 | `message_source.ts` 已有专门迭代器；`unified_search.ts` 保留分类 | 沿现有会话组织与专用数据源读取 | 精确多选、搜索正文、导出入口和来源字段逐条实测，不能套普通私聊 SQL |
| 频道私聊 | nodeId / msgId；稳定 seq/time/id SQL 游标 | 并入消息搜索、精确跳转、共享多选、精确导出与持久任务；列表 / 聊天往返保留现场 | 不扩称频道网站群聊已被本地库覆盖；重启恢复与全历史覆盖另验 |
| 收藏八种内容 | CID；文本、链接、相册、音频、视频、文件、位置、富媒体 | 正文搜索、共享选择与精确导出 | 各子类型资源自包含、附件缺失和保存策略完整验收 |
| 空间说说 | uin/tid；详情、原转发、互动、媒体 | 观察文本搜索，单作者共享选择、精确 tid 导出任务 | 跨作者动态的离散集合；评论/回复/赞/转发的独立层级与可搜索字段 |
| 空间相册与照片 | uin/albumId；`qzone.albumPage` / `albumDetail`，照片及视频由原查看器读取 | 相册观察文本搜索、精确相册定位、媒体 / 整本相册选择与资源导出，接入保存任务 | 分页完整性、视频地址失效和封面回退仍需分别核对；不以说说导出替代照片导出 |
| 群相册与照片 | groupCode/albumId；`GroupAlbumDialog` 与 `AlbumExportLightbox` | 相册观察文本搜索；现有相册勾选和下载 | 正文页共享选择到唯一工具；离散照片及跨相册集合；任务与保存策略核查 |
| 群文件与目录 | groupCode/folderId/fileId；保留目录上下文 | 文件名观察搜索、目录精确定位、正文多选与文件管理器；单文件保存接入公共策略及任务 | 递归目录冻结、缺失文件和混合批次仍需完整验收 |
| 群公告、精华 | `listGroupBulletins`、`getGroupEssenceWithContent`；原群内查看器 | 原查看、精华消息定位 | 公告稳定身份和缓存范围核查；搜索、选择、导出未归一，不凭标题猜 ID |
| 闪传文件集合 | fileSetId 与实际文件条目；`FlashTransferViewer` / `flashListFiles` | 原文件选择、下载和独立任务管理 | 搜索观察、共享选择、统一任务与保存流程；保留过期/不可访问结果 |
| 邮件、附件与文件夹 | opaque mail id/folderId；附件独立 id；`MailPage` | 观察文本搜索、批量选择、查询后冻结邮件集合导出与附件保存，接入公共保存和任务 | 附件失效、部分成功与跨文件夹分页完整性仍需核对；原正文缓存不是完整邮箱档案 |
| 克隆私聊、克隆群聊、助手对话 | kind/owner/session/message ID；旧版会话显式 null | 持久正文搜索、共享多选、精确快照导出；已知媒体标记与附件句柄随包保存，带校验/缺失清单 | HTML/Markdown 附件外部依赖仍需离线化盘点；临时未持久消息不伪造稳定 ID；统一长任务及全来源保存/下载整体验收 |
| 合成素材与合成记录 | `CompositionWorkspace`、持久合成历史与素材库 | 独立工作窗口、复制/发送/转发/导出实现 | 各路径实际操作、重启与异常恢复验收；不把合成记录当真实 QQ 历史 |

## 目录与配置数据

| 内容 | 当前能力 | 缺口与边界 |
| --- | --- | --- |
| 好友与群成员 | 名称/备注搜索；UID 精确导出；群成员范围独立 | 群名片、非好友、退群成员等子列表能力核查，不把主好友列表当完整人员库 |
| 自定义、商城与系统表情 | 自定义表情统一工具；商城离线目录搜索/packId 定位，保留原下载能力 | 图片条目精确选择交接及任务归位；商城目录不是用户已下载资源；系统资源不伪造业务消息 |
| 个性装扮 | 原装扮浏览/设置及资源导出 | 逐类核查气泡、字体、挂件等已有资源操作；配置不是聊天内容 |
| 明文数据库 | 统一工具调用原数据库选择与导出 | 账号、保存、取消与 Web 下载验收；不在全局正文搜索中隐式解密全库 |
| 分析与报告结果 | 统一对象/时间/类型配置，主区域报告与关闭返回，不再额外显示顶部页签；合并非好友、历史群及退群/名册外发言人，兼容仅 QQ 号成员；年度统计固定北京口径，十五页阅读布局已有逐页核验记录 | 分析长任务和结果持久恢复仍需完成；不能用页面现场保留代替重启恢复 |
