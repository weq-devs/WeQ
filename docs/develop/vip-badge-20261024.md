# 顶栏会员徽标（VIP / SVIP / 大会员）

日期：2026-10-24

## 需求

顶栏昵称后显示自己的 QQ 会员身份：VIP 红、超级会员金、大会员蓝黑，年费加「年」前缀；
不是会员就什么都不显示。

真正的难点不是「显示」，而是**什么时候能拿到数据**：会员信息要靠 `vip.qq.com` 域的
p_skey 走 web cgi，而 p_skey 可能在任意时刻才可用 ——

- WeQ 先启动、QQ 后上线；
- QQ 重启换了 pid，旧票据作废、新票据要重新换；
- 登录流程顺手收下的 p_skey 已经落盘，QQ 完全没开也可能还有效；
- 长期在线期间等级 / 年费会变。

## 数据来源与优先级

```
在线/离线 seed 票据有效 ──► club.vip 接口 ──► AccountConfig.vip ──► 顶栏
        │
        └ 失败 / 没有票据 ──► AccountConfig.vip（上次结果） ──► 顶栏
                                   │ 还没有缓存
                                   └► profile_info_v6 21000 privileges ──► 顶栏
                                              （只能推出超会/大会员 + 等级）
```

`account.getSelfVip` 按这个顺序取值，并在返回值里带 `source: 'club-api' | 'local'`，
渲染层把「来自本地资料库」写进悬浮提示 —— 本地兜底拿不到年费与到期时间。

## 接口

```
GET https://club.vip.qq.com/qqvip/api/medal/home/queryUserInfo?g_tk=<bkn(p_skey)>
Cookie: uin / p_uin / skey / p_skey（vip.qq.com 域）
Referer: https://club.vip.qq.com/qqvip/medal/my
```

`g_tk = bkn(p_skey)`（`computeBkn`，与 `dress_mall` / `self_dress` 同一套）；
`vip.qq.com` 的 p_skey 在 `*.vip.qq.com` 通用（`friend_dress.ts` 已实测）。

### 字段语义

| 字段 | 含义 | 置信度 |
| --- | --- | --- |
| `isVip` | 普通会员 | 抓包已验证 |
| `isSvip` | 超级会员 | 抓包已验证 |
| `isBvip` | 大会员（通常同时 `isSvip=true`） | 抓包已验证 |
| `isVipYear` | 年费 —— **超会也用它**，不是 SVIP 专属 | 单样本推断 |
| `isBvipYear` | 大会员年费 | 单样本推断 |
| `vipLevel` | 超会/会员等级 | 抓包已验证 |
| `bvipLevel` | 大会员等级 | 抓包已验证 |
| `club_end_timestamp` / `superclub_end_timestamp` | 到期时间（unix 秒，字符串） | 抓包已验证 |
| `sVipExpireTime` / `sSVipExpireTime` | 同义可读串（北京时间，不带时区） | 抓包已验证 |
| `clubStatus` | 3 = 有效 | 抓包已验证，但未参与判断（三档 is* 已是结论） |

归一规则（`packages/service/src/account/web/vip_info.ts`）：

- `tier` 取 `bvip > svip > vip` 第一个 true；
- `level` 取对应档位（普通 VIP 没有独立等级字段，展示时不写等级）；
- `year`：大会员看 `isBvipYear`，其余看 `isVipYear`；
- `expireAt`：数字时间戳优先，缺失才解析 `s*ExpireTime`（显式补 `+08:00`，避免
  非东八区用户看到差几小时的到期日）；
- 三档全 false → `null`（不是会员，顶栏不渲染）。

> 首次用真实账号联调时请核对：`code` 非 0 的取值集合、`isVipYear` 是否真的覆盖
> 超会年费。若与假设不符，调整 `vip_info.ts` 的 `AUTH_CODES` / 归一逻辑。

## 刷新时机（`apps/desktop/src/main/vip_badge.ts`）

`VipBadgeService` 是账号级后台服务，与 `AccountMonitorService` 同构（开账号 start、
换号/关号 stop）：

1. **start()** 立刻试一次 —— 用落盘的 `loginPskey['vip.qq.com']`，QQ 没开也能出徽标；
2. **`onlineCredentialsReady`** —— AccountMonitor 登记 SSO 会话成功时发出（QQ 上线、
   QQ 重启换 pid），这时走活 hook 换新票；
3. **6 小时定时器** —— 只在 QQ 在线时尝试，校正等级 / 年费变化。

节流：同一时刻只有一个请求在飞；两次请求至少间隔 60s；失败 5 分钟后重试。
任何失败都只记日志（离线且无票据是预期情况），不打断开账号。

换票细节在 service 层的 `fetchAccountVipInfo`（`packages/service/src/account/vip.ts`）：

- 有 seed 先用 seed（省一次 hook 往返）；
- seed 失败且 QQ 在线 → 删掉落盘 seed、走活 hook 重试一次（同 `home_dress.ts`）；
- seed 失败且 QQ 离线 → 换不出第二张票，直接失败，等下次时机。

`WebCredentialProvider` 每次新建，不跨调用复用 —— p_skey 短命，缓存跨调用只会把
过期票一直喂给 cgi。

## 缓存

写在账号级配置 `config/accounts/<configId>.json` 的 `vip` 字段（与 `homeDress`
同类），天然按账号隔离、切号不串：

```json
"vip": { "tier": "bvip", "year": true, "level": 8, "expireAt": 1794988400, "fetchedAt": 1792783132822 },
"vipCheckedAt": 1792783132822
```

`vipCheckedAt` 与 `vip` 分开字段是因为「`vip` 缺失」有两种含义：**还没查过**（该退回
本地特权清单）和**查过了、不是会员**（不该退回）。有这个时间戳就以在线结论为准，
否则退会以后本地那份旧资料会把徽标又顶回来。

同步改了两处备份校验（否则备份恢复会报错）：
`bootstrap/backup_settings.ts`（字段白名单 + 类型）、`bootstrap/backup_restore.ts`
（合并删除名单）。

## 界面

- 组件 `apps/desktop/src/renderer/src/components/VipBadge.tsx`，插在 TitleBar 的
  昵称与在线状态之间 —— **独立兄弟节点**，不嵌进 `.app-title-bar-nick`（那个 span
  自带 ellipsis，会把徽标裁掉）。
- 纯 CSS 文字胶囊（`styles/self-profile.css`）：`VIP` 红、`SVIP` 金、`大会员` 蓝黑，
  年费加「年 」前缀。刻意**不**取 `--weq-accent-effective` —— 会员色是 QQ 的身份
  语义，不能跟着用户换主题色变紫/绿。
- 深浅模式各一套 `--vip-badge-*` 变量（`html[data-theme='dark']` 覆盖），深色下压暗
  底色、提亮文字，避免在半透明顶栏上失去对比。
- 布局 `flex: 0 0 auto` + `nowrap`：窗口变窄时昵称先缩。≤600px 展开搜索时与昵称一起
  隐藏（`styles/workspace-tools.css`）。
- 文案不含隐私信息，因此**不进** `privacy.css` 的模糊名单（截图模式的模糊名单是逐
  元素列的，独立 DOM 不列就不会被糊）。

历史素材 `resources/svip/*.png`、`resources/yearsvip/*.png` 是固定金底红字的位图
（`SVIP1`..`SVIP10` / `年SVIP1`..），既表达不了「三档三色」，也不跟随深浅模式，
故本次未采用，仅在需求确认阶段 checkout 出来看过。

## 真机验证要点

1. QQ 在线开账号 → 顶栏出现徽标；日志 `scope: vip-badge` 有 `vip-fetched`。
2. 关掉 QQ、重启 WeQ（配置里仍有 seed pskey）→ 徽标来自 seed 或缓存。
3. WeQ 先启动（QQ 未开）→ 再开 QQ，约 5s 内徽标自动出现（`onlineCredentialsReady`）。
4. 切换账号 → 徽标跟随，不串号。
5. 浅色 / 深色 / 换几个主题色各看一眼；窄窗口展开搜索时徽标让位。
