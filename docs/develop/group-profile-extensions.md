# 群扩展资料读取

桌面与 Web 群资料页的「群状态」及群名片的本人时间通过 `useGroupProfile` 复用相同资料读取服务。Remote 使用同一账号路由，不依赖消息列表的逐条读取，也不参与首屏会话目录或成员批量刷新。

成功读取的群等级（`grade`）、冻结状态和本人入群时间同时投影到账号联系人指标缓存，用于群目录分组及「我的入群时间」排序；目录本身不自动逐群联网。用户可通过现有联系人缓存任务更新这些字段，历史群不加入在线更新范围。失败保留旧成功值；群等级和冻结状态在成功响应缺省时清空对应投影，未知不变为 0。

## 协议

复用 `GetGroupJoinInfo` 的 `0x88d_110`。仅 `includeExtensions: true` 时在原查询中选择扩展字段，普通入群设置、精确群查询等旧调用的请求保持不变。

| GroupInfo tag | 模型字段 | 说明 |
| --- | --- | --- |
| 36 | grade | 群等级，保留服务端原值，不转换成成员等级或星级 |
| 37 | activeMemberCount | 不附加未经确认的统计周期 |
| 43 | portraitSequence | 头像序列 |
| 44 | portrait | count@1、pictures@2、defaultId@3 |
| 49 | joinedAt | 本人入群 Unix 秒；缺失、0 和 1 均为未知 |
| 91 | freezeState | 0 显示正常、1 显示已冻结，其他值显示原始状态码 |
| 100 | freezeReason | 原始原因编号，不猜文案 |

图片信息内部 tag 1–5 分别保留图片编号、裁剪左／上／右／下坐标。缺少任一数字是 `null`，明确返回的 0 则保留。头像结构不含 URL，不能据此构造历史头像相册。

原有字段依据为 Android QQ 9.3.75 的实际 FieldMap 及 `0x88d_110` 真实回包；本人入群时间已在 Android QQ 9.3.85 的 FieldMap、模型赋值与日期消费链复核，桌面真实回包兼容性仍待验证。认证、皮肤、富文本简介等候选未纳入此接口。协议测试以独立十六进制夹具核对 wire tag，而非只用同一 schema 编码后解码。

## 本人入群时间

`getGroupExtendedProfile` 额外返回归一化的 `joinedAt`，优先使用协议 tag 49；未返回时按当前账号 UID 查询本地本人记录，缺 UID 才按本人 UIN 查询。成员已退出、0／1 占位不作有效日期，不为补这一个字段查询全群成员。两种来源均缺失时保留指标缓存中先前已知的值，不伪造日期。旧扩展资料缓存没有此字段时仍可读取。

快速群名片和完整群资料概览共用这个值，以北京时间显示日期和时分秒。打开具体资料时按需读取，不等待它再展示群名等本地信息；本地生成群不向真实群资料接口查询。群排序复用现有「我的入群时间」选项和相同指标，本地批量本人时间只补缺失值，不用较大的旧值覆盖协议更新结果。

## 读取与缓存

- 账号路由 `getGroupExtendedProfile` 必须携带账号号、config ID 和群号，返回前重新核对账号／数据源以及目标群。
- 默认只读取缓存。桌面与 Web 打开具体群资料、恢复前台或网络重连时自动请求刷新，服务端五分钟内复用已有成功快照，不添加后台轮询；正常状态不显示刷新按钮，读取失败时可原位重试并跳过时效检查。Remote 的界面更新策略不受此变更影响。
- `GroupProfileReader` 合并同群在途查询，并复用联系人在线请求队列。内存最多保留 200 个快照；按账号现有联系人缓存根的 `group-profiles/<群号>.json` 原子保存。
- 离线或请求失败保留旧快照，界面区分缓存、读取中、读取失败及缓存保存失败。有效新响应未返回的字段变为未知，不用旧值冒充本次返回。
- 关闭账号或 QQ 进程切换后丢弃迟到响应。资料中不保存云端群名／备注，不写 QQ 数据库或会话名称缓存。

## 定向验证

协议覆盖独立 wire 夹具、缺失／零值、未知状态、原请求兼容和错群响应；服务覆盖并发合并、时效／强制刷新、离线重开、缓存异常和迟到响应；路由覆盖账号／数据源绑定。定向浏览器回归 `apps/desktop/test/browser/run-group-join-time.mjs` 覆盖名片与完整资料的本人时间、主题、窄屏和切群，需提供可用的 Playwright 与浏览器运行环境。
