# 后台帧释放与有界自动恢复（2026-10-27）

## 背景与边界

本机再次记录到主窗口渲染进程的 Blink / PartitionAlloc OOM，主进程仍运行。
十秒采样中，隐藏文档的 Blink 分配持续增加，而 DOM、受管帧、图片 decoded 缓存
基本稳定。挂件帧动画仍报告 running，是应做对照的候选，不是已证明的唯一根因。

本轮不替换 Chromium 分配器、不提高 V8 堆上限、不按 RSS 阈值重载、不强制 GC，
也不把受管解码预算当成全部原生/GPU 内存上限。改动分为减少后台分配和异常恢复两层。

## 装扮资源

消息装扮、生效装扮和报告挂件共用 `manageDecorationAnimation`：

- 文档隐藏或匹配 `prefers-reduced-motion: reduce` 时取消在途预热、移除开播规则、
  释放本消费者持有的帧 pin；最后一个持有者释放后摘掉解码图片的 src。
- 保留静态首帧规则与字体，避免隐藏/恢复时字体回退和消息几何变化。没有清聊天、
  配置或磁盘缓存；不保证 Chromium 立即归还所有驻留页。
- 初次在后台挂载不启动动态帧解码。回到前台且允许动态效果时，重新按现有的
  字节/帧数/并发预算预热，全部成功并经过两帧后才开播；失败保持静态。
- 动画规则单独持有并在暂停时移除，不在每次恢复后继续拼接；卸载移除可见性和
  媒体查询监听，迟到的解码回调不能在后台或卸载后重新开播。
- 既有按消息可见范围、标签活动状态和共享引用计数的释放保持不变。

这条修复消除了一条已复现的后台预热/播放路径；不能仅凭合成场景就宣称真实业务
的长期 Blink 增长或历史 OOM 已全部消失。

## 自动恢复

主窗口启用有界策略，状态保存在主进程，不依赖失效的 renderer：

- `crashed`、`oom`、`abnormal-exit`、`memory-eviction` 首次退出后等待 1 秒，
  只重载页面，不重启主进程或后台任务。
- 每 10 分钟最多自动重载一次，按单调时钟计算；`did-finish-load` 不清空额度。
  10 分钟内再次退出，或自动恢复期间再次退出，改用原生手动恢复提示。
- 主动终止、正常退出、启动失败、完整性失败和未知原因不自动重载。
- 自动或手动重载开始后，15 秒内没有 `did-finish-load`、主 frame 加载失败
  （不含取消导航的 -3）或 reload 同步抛错时，回退原生提示，不循环重试。
- 关闭窗口可主动进入原生提示并取消待执行自动恢复；已完成加载、销毁或退出
  后不执行过期定时器或对话框结果。不会为自动恢复主动显示隐藏窗口。

`did-finish-load` 只证明文档加载完成，不是全部业务初始化成功回执。
JS 渲染异常仍由既有 `RendererErrorBoundary` 处理，不冒充进程崩溃。

沿用现有重载路径和新建的非持久化 React Query 客户端，不新增业务请求回放或
变更重试配置。后台已提交操作可能继续执行；未保存草稿和临时界面状态可能丢失，
恢复后仍应核对操作实际结果，不保证无损恢复。

事件日志保留原来的原因白名单与退出码，新增固定 `auto-reload` 和 `reload-failed`
事件，不写正文、URL、账号、堆快照或原始异常文本；现有内存诊断轮转不清空。

## 验证

针对性回归先复现旧版隐藏后仍持有帧和不自动恢复的问题，再验证新实现。
覆盖重复隐藏/恢复、初始隐藏、减少动态效果、迟到解码、共享释放、生效装扮，
以及恢复冷却、重复事件、连续崩溃、同步失败、加载失败、超时、销毁/退出和
手动介入。使用合成数据，不读 QQ 数据库、不联网。

11 个专项测试文件共 46 项通过；修改文件的 Biome 检查、桌面主进程与渲染端
类型检查通过，未运行全量 CI。

独立 Electron 44.9.1 无 DevTools 实例使用实际源码和本地合成 PNG，消息、生效
装扮和报告挂件共 12 帧：连续 5 轮窗口隐藏后 retained/pinned 为零、running
动画为零，恢复后重新持有 12 帧、3 个动画，规则数保持不变。真实
`process.crash()` 实收 `reason=crashed, exitCode=11`，首次退出后自动重载，
新 PID 可执行页面代码；第二次退出转原生提示接口且重载次数仍为 1。
这里用受控返回值替代实际原生按钮选择，未将它表述为人工按钮点验或 OOM 复现。

Playwright 连接默认改变了测试页面可见性，因此隐藏行为不以其结果验收；
另用它检查同一离线夹具的浅/深色、桌面/窄屏、静态与动态帧和减少动态效果。
这不是完整业务界面主题验收。证据保存在本机已有 WeQ 项目的
`work/renderer-auto-recovery-20261027/`，非仓库中的真实用户数据。

此变更需要加载新主进程及渲染代码才生效；源码提交、独立实例验证、日常实例
实际运行及长期稳定性是不同状态，不相互替代。
