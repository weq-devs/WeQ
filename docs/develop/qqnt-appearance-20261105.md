# QQ NT 外观预设与对照记录

日期：2026-11-05（北京时间）。

## 来源与实现

参考本机 macOS QQ NT **7.0.3-54395** 的静态样式提取，以及该版本效率模式的实际浅色、深色主界面和通用设置界面。
原始 CSS、规则索引和本机研究文件不纳入仓库，产品不加载 QQ CSS、字体或原始图片。

在 `state/theme.ts` 现有组件风格列表中增加 `qqnt`，沿用 `weq.theme-component-style` 和 `data-component-style`。
样式集中在 `styles/qqnt-appearance.css`；共享外观层新增可选输入框圆角与弹层圆角 token，其他风格仍沿用原来的回退。

| 对照对象 | 来源 | 实现 |
| --- | --- | --- |
| 普通按钮 | `pcqqkit.5360bf66.css` 的 `.q-button` | 圆角 4px，字号 14px，行高 18px，padding 5px 11px |
| 输入框外壳 | 同文件 `.q-input` | 圆角 8px；焦点使用 WeQ 自定义主题色 |
| 消息容器 | `31999.fc7b6fa1.css` / `78733.5e70559e.css` 的 `.msg-content-container` | 普通文本气泡圆角 12px；媒体、语音、卡片和纯代码不套此规则 |
| 会话选中态 | 本机实际深浅界面及用户对照截图 | 中性灰表面，内缩 2px，不沿用经典预设的主题色侧边高亮 |
| 会话行与角标 | 提取的 12px 内边距/头像后间距，以及用户对照截图 | 舒适行高 64px、头像 40px；时间与标题同一行，未读标记无描边 |
| 联系人工具栏 | 用户实际界面截图 | 透明底复用侧栏表面，去掉 contact-tools 的外边距及工具栏底线，避免嵌套边距 |
| 搜索与输入区 | 本机实际界面、提取的控件形态 | 搜索框 8px、轻分隔、无玻璃模糊 |
| 顶栏与设置控件 | 本机实际界面 | 中性表面与独立深色值，主按钮仍复用可读性派生色 |

颜色来自提取出的语义关系与实际界面的视觉校准，不冒称已读取 QQ 所有运行时 computed style。
用户提供的深色对照图中，时间主要实色像素为 `#7a7a7a`、消息预览为 `#808080`；QQ NT 预设仅对对应列表字段采用这些值，未把截图中的其他界面文字一并变暗。
提取结果中的动态变量缺项没有当作确定的默认色值。
本机 QQ 启用了个性气泡，因此实际聊天中的装扮素材不作为默认气泡的颜色或几何基准。
本轮只临时切换 QQ 白天/夜间观察，结束时恢复原来的夜间模式并关闭本轮打开的设置窗口。

## 保持的行为

- QQ NT 为默认并排在预设首位，默认背景为纯净；预设、密度、背景和主题色分别持久化，保留已有有效选择。
- QQ NT 舒适行高为 64px，其余风格仍为 62px；风格切换与密度切换都触发虚拟列表重新测量，不改用户已经拖拽的侧栏宽度和输入区高度。
- 群助手使用主消息列表的 `conversation-row`、`row-main`、`row-meta` 与 `row-unread`，行尺寸集中在 `conversation-list-row.css`，不再独立设置头像/文本/角标布局。
- 纯色背景使用 QQ NT 风格中性画布，其余背景继续复用已有机制。
- 移动端保留安全区和触控尺寸；减少动态效果时不增加转场。
- 只新增主题样式，不改消息收发、媒体加载、账号与数据库路径。

## 验证入口

单测：`pnpm --filter @weq/desktop exec vitest run test/component_appearance.test.ts`。

浏览器回归：

```bash
node apps/desktop/test/browser/run-component-appearance.mjs
node apps/desktop/test/browser/run-qqnt-appearance.mjs
```

可用 `WEQ_PLAYWRIGHT_IMPORT` 指向已有 Playwright，`WEQ_BROWSER_EXECUTABLE` 指定本机 Chromium 系浏览器，
`WEQ_APPEARANCE_ARTIFACTS` 指定本地截图和 JSON 报告目录。
`WEQ_QQNT_REFERENCE` 可指向本机提取的 `pcqqkit.5360bf66.css`，浏览器会独立渲染原始 QQ 按钮和输入框，与 WeQ 对照几何值，并记录原 CSS 的 SHA-256。
无该变量时仍执行界面回归，但不宣称做过原始 CSS 数值对照。

整页夹具使用真实 `AppRail`、`ConversationList` 和 `ChatPane`，仅数据与后端替换为离线夹具。
截图不包含用户聊天数据。`--serve` 可启动本地交互预览，启动时输出地址。
控件矩阵覆盖四套风格、深浅模式、六种背景、两种密度与 1280/390/320 宽度；另检查聊天正文、对比度、触控尺寸和实际 QQ CSS 几何。
群助手回归逐项比较两处行高、内边距、头像、标题、预览、时间字号和角标描边，覆盖四套预设与两种密度。
联系人工具栏单独检查透明底、零外边距、横向对齐和满宽，覆盖三种宽度与深浅模式。

这些验证不等于已安装或发布，也不等于所有 QQ 窗口的像素级复刻。

本轮结果：44 项针对性单测、288 组控件矩阵、84 组聊天/群助手/联系人浏览器检查全部通过；前端 TypeScript 与改动文件 Biome 检查通过。未运行全量测试、打包或发布。
