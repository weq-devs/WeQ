# Web / Remote 功能对齐（2026-10-26）

## 目标与边界

Web 和手机 Remote 复用桌面 renderer、业务 router 与 service，不建设另一套业务界面。
Remote 原生壳仍归独立的 WeQ-Remote 仓库，本轮不修改配对、设备凭据、原生 WebView 或安装包。
不启动真实 QQ 操作，不重启在用服务。以下为源码实现范围，不代表各业务均经真机验收。

| 能力 | 本轮后实现状态 | 边界 |
| --- | --- | --- |
| 聊天、联系人、空间、邮箱、收藏、频道、应用、分析与导出 | 继续共用既有桌面业务页面 | 不是本轮逐项验证的声明 |
| 手机 QQ 资料与状态 | 顶部头像与更多入口打开共享 SelfQQControls | 不再连接原先无操作的回调 |
| QQ 号 / 群号搜索、好友 / 群通知 | 手机顶部加号接入 QQExactLookup 和原通知回调 | 不接桌面原先无操作的添加 / 建群回调 |
| 从浏览器设备发送普通文件 | 已补齐字节计划、分段暂存与 QQ 发送 | 非空、≤100 MB；不支持群临时会话 |
| 年度报告 PDF、长图、空间分享图 | 内置 Web / Remote 复用电脑离屏渲染 | 独立 Node Web 无渲染引擎，仍明确报不支持 |
| 桌面文件框依赖入口 | 尚未全量替换 | 包括收藏表情 ZIP 导入、部分 QQ 图片选择与合成媒体选择 |
| 桌面更新、远程授权管理、系统认证及窗口操作 | 保持桌面边界 | 不通过修改 canReveal 等能力标记放开 |

## 实现

- `composerSend.ts` 的普通文件计划接受字节或路径，桌面路径保持优先。
  `MainView` 的同一发送事务根据来源选择原路径或 `withBrowserFile`，不另建乐观消息流程。
- 复用既有相册视频的 `FileUploadStaging`，保留兼容导出名，增加调用方大小、最小体积和
  文件名配置。每段 ≤1 MiB，严格核对偏移与规范 Base64，句柄绑定 AccountServices 实例，
  完整接收后才能 acquire；发送前仍检查账号配置与 QQ pid。暂存使用随机私有目录，
  `0600` 文件，空间不足停止。成功 / 失败都回收，取消或丢失连接的闲置句柄到期回收。
- 客户端逐段检查会话与账号，校验服务端进度，不自动重试 mutation。清理失败不覆盖原始发送错误。
- `DesktopWebRuntime` 显式接收仅包含三种渲染方法的能力对象。Web host 的文件框、
  系统启动、文件管理器与应用更新边界不变；独立 Web 不引入 Electron。
- PDF / 图片捕获各用独立内存 partition。离线加载只放行本次报告文件和 data URL，
  拒绝其他 file / HTTP 请求、页面导航及权限请求。可见的报告预览窗口行为不变。
- 手机加号菜单提供遮罩关闭、Escape 关闭、页面变化自动关闭；菜单与列表入口使用
  44px 以上触控目标。QQ 操作表单采用 16px 输入字号，避免窄屏输入触发自动放大。
  颜色沿用现有主题 token，显式保留深色覆盖。

## 验证

使用合成数据，不碰真实 QQ 数据、不调用 QQ 网络接口：

- 桌面端 11 个针对性测试文件共 69 项通过，覆盖输入框、手机导航与视口、分段附件、
  账号隔离、偏移检查、失败清理、Web / Remote 请求宿主和报告保存。
- 协议文件发送 15 项、服务层消息发送 90 项通过。浏览器无路径文件和私聊发送身份检查
  均先补用例复现失败，再修改实现。
- renderer / 主进程 TypeScript 检查、28 个指定源码 / 测试文件 Biome 检查、Web 完整生产构建通过。
  构建仍有既有大 chunk 提醒，没有提高阈值掩盖。
- Web 服务鉴权、HTTP、安全测试及 Electron 依赖隔离检查通过，245 个打包资源无 Electron 专属产物。
- Playwright 合成界面覆盖 320 / 390 / 760 / 1180px、深浅色、绿 / 浅黄主题色、
  paper / dots 背景和减少动态效果。打开查询弹窗、资料编辑、更多页及聊天返回均可用，
  没有页面异常或横向溢出。检查发现并修复了窄屏资料标签继承横向 180px flex-basis
  所致的异常留白。
- 独立 Electron 冒烟实际调用 PDF、长图与逐页 PNG 捕获，生成 12,567 / 33,685 /
  47,721 字节的合成产物并检查 PDF / PNG 输出。仅证明本机捕获，不代表 QQ 分享成功。
