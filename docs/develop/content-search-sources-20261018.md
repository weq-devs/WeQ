# 全局搜索新增来源

本页记录来源、覆盖与稳定定位；使用方式见[全局搜索](../guide/chat-view.md#全局搜索)。

## 来源契约

`UnifiedSearchService` 的空间、相册、群文件、邮件、商城和频道来源与普通消息、收藏、生成对话并列。精确类别与 DTO 以 `account/unified_search.ts` 为准；预览与更多复用读取契约，失败按类别隔离，不启动未选类别的读取。

空间、相册、群文件、邮件使用每账号 configId 独立的 `ContentSearchStore`。只投影正文文字、名称、源身份和可用原始数值时间；没有可核验数值时间的群相册等记录按观察顺序排序，不猜格式化时间的时区。不保存原始 HTML、图片签名 URL、Cookie、下载令牌或原始响应。邮件 HTML 复用已有 parse5 正文提取，不执行脚本或请求资源；空间动态只采用查看器已有的 data-fkey/data-tid/data-key 契约，不猜 feed.key，不索引广告、操作栏或评论控件。

索引有界：默认 16 MiB / 两万条，单条正文超过上限标记截断；回收也明确记入 coverage。原子写入合并在 250ms 窗口，切号时 flush 并关闭，晚到的旧来源不会写进新账号；不认识的文件版本或原件无法解析时保留原件，当前观察仍可在内存检索，标明尚未持久化。已读详情不会被后续列表摘要覆盖。群文件保留群号/目录/fileId 组合，不在缺少权威定位证据时把不同目录记录合并；缓存旧位置打开时仍需验证。邮件按不透明 id 保持身份，成功移至已删除后清理索引项。

这里只索引通过本版本浏览接口观察到的内容，不宣称已经覆盖所有历史原始缓存、旧导出目录、所有评论或云端全部记录。结果 coverage 使用 observed-cache，不把缓存记录数当作完整云端总数。

商城搜索复用既有 RFC4180 离线目录，coverage=offline-catalog；不是实时商城抓取。频道私聊按本地 direct_node_list_table 列出的会话扫描 guild 消息页，coverage=local-database；不扫描频道群聊，不把最新五十条当全库。排名池只缓存一个关键词和会话水位，十五秒失效；大命中池不常驻缓存，但本次结果仍可完整分页。首次全库读取可能耗时，没有通过候选上限截断冒称完整结果。

缺少频道库或离线目录时，coverage 明确使用 available=false，界面显示来源尚不可用，而不是把缺源当作完整零条历史。频道展示名复用频道昵称、全局昵称与 CommonProfile 缓存昵称的顺序兜底，不能只匹配 tinyId。

频道扫描与导出使用本地 SQL 的 `(seq, time, msgId)` 稳定游标，空 seq/time 按零排序，保留零序号、同序号、负数及 64 位消息身份；不再依赖 `seq > 上页末尾` 跳过重复序号。查看器按消息 ID 读取上下文和更早页，旧 seq 接口保留兼容。节点列表按物理 nodeId 去重，可选昵称资料库缺失不隐藏有效正文。切号取消在途搜索，等待中的页面返回后不会继续翻页或回填旧缓存；导出持有的独立读取器不受搜索取消影响。

## 稳定定位

- 空间：uin/tid 或 uin/albumId，复用原空间内部深链。
- 群相册：groupCode/albumId，不按名称查找；缺失相册显示不可访问。
- 群文件：groupCode/folderId/fileId，读取目标目录后高亮真实文件，缺失时不改选首行。
- 邮件：真实 opaque id 与 folderId，不靠列表第一页定位；写信未保存时先确认。
- 商城：packId 可直接打开详情，不要求它已出现在当前列表页。
- 频道：nodeId/msgId/msgSeq，回读历史上下文并验证消息身份，重试也不退回最新页。

## 回归入口

service `content_search.test.ts` 覆盖持久化、账号路径隔离、回收声明、未知格式原件保护、详情/摘要、群文件目录上下文、频道跨多页和统一搜索失败隔离。desktop 的内容投影、搜索卡片、相册/文件精确跳转、邮件与频道回归使用合成数据，不触达真实 QQ。

`guild_stable_page.test.ts` 与 `guild_stable_export.test.ts` 使用明文 SQLite 合成夹具，经过实际数据库、服务、导出任务路径验证稳定分页、精确历史定位及离散消息集合，未读取真实账号数据库。

更多结果使用服务端原始行数维护 nextOffset，渲染按稳定身份去重；重复结果、总数或覆盖水位变化时保留已加载现场，提示来源更新并支持从第一页刷新，不把去重后的条数用作下一页偏移，也不声称获得了完整最新事务快照。

搜索返回现场使用 `useSearchReturn`，按账号、全局关键词与类别集合绑定，条件变化后丢弃，避免条件改回时复活旧现场。点击命中不清空全局查询；下拉记录滚动和稳定命中 key，更多页额外保存实际关键词、已加载结果、原始 nextOffset 与分页失败状态。返回只恢复内存快照，不重新拉第一页；重新搜索显式读取最新结果。更多页在工作区激活后的下一帧恢复滚动与焦点，避免隐藏页面聚焦失败或工作区默认聚焦覆盖命中。StrictMode 的模拟重挂载不重复执行恢复查询。

`search_return.test.ts` 挂载实际标题栏、下拉、工作区与更多页，验证返回、账号隔离和 StrictMode；`search_more.test.ts` 验证恢复后的原始分页游标与修改后的词。普通内容页自身的完整导航历史不在这份快照内。

剩余内容层级与任务整合见[能力盘点](content-capability-census-20261018.md)，不要把父级命中当作全部子资源已索引。
