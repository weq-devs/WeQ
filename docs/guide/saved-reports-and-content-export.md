# 报告、精确选择与资源导出

## 分析报告

从分析工具创建好友、群聊或群成员报告后，关闭报告页不停止后台计算。任务列表可以查看报告、
继续、取消或重试；分析工具底部的历史报告入口可重新打开已保存的结果。年度报告仍在原入口。

重启后未完成报告显示为待继续，打开报告或点击继续才接续。已完成报告直接读取保存结果，
不重新扫描聊天记录。群报告按消息统计、入群批次和关系图分别保存阶段；失败后继续未完成阶段。

刷新或调整日期会产生新版本。新结果成功前仍显示上次成功结果；版本选择器可以查看此前的
成功版本。阅读位置随报告保存。移除任务不会删除报告，删除历史报告需要另行确认。

## 精确选择

好友动态的多选按作者和帖子身份区分。相册浏览支持整本相册与单项照片／视频选择，
在同一浏览工作区切换相册时保留选择。可使用 Ctrl／Cmd、Shift，或工具栏的全选已加载项、
反选和退出多选。尚未加载的条目不会被“全选已加载项”自动选中。

点击导出后，工具接收当前集合的副本，显示范围和数量。相册集合可进入编辑列表，去掉不需要的
条目后再导出。离散照片集合不会转成整本相册，也不会将跨作者帖子转为整段日期。
已失效或无法读取的条目列入失败清单，其他条目继续保存。

## 自包含资源

生成成果中的 HTML 和 Markdown 会收集明确引用的图片、音视频、CSS、字体、脚本及静态
模块依赖，并在导出副本中改写为包内相对路径。CSS 导入、图片候选集和循环模块引用也会处理。
普通超链接保留；原成果、草稿和附件不被改写。

资源清单包含依赖关系、包内路径、哈希和失败原因。导出过程不运行页面脚本。
不能静态确定的动态模块、已识别的运行时网络调用和临时 blob 资源会标明未本地化，
有此类记录的成果不标为完整离线。脚本的运行环境要求仍然存在，例如浏览器模块可能需要本地 HTTP 服务。

合成记录导出为 `composition.json` 与 `media/`，JSON 中媒体使用相对路径，相同内容只保存一份。
媒体缺失不阻止其余条目导出。旧版本引用本机路径的合成 JSON 的读取格式不变。
保存沿用共享导出偏好和任务列表，Web 使用服务器保存入口，Remote 使用已有文件交接能力。

## 搜索子内容

成功读取的群公告和精华归“消息”，闪传文件归“文件”，空间评论及回复归“空间”。
搜索只使用已经取得的内容，不在启动时补扫全部在线历史。结果展示来源和命中内容，
打开后定位并高亮对应公告、精华、文件或评论。公告搜索不包含定位原消息功能。

内容被移除或当前无法读取时会提示，并保留原搜索结果。没有可靠身份的记录不会伪造可跳转目标。

## 普通消息通知与角标

设置中的“新消息系统通知”默认关闭，“应用图标未读角标”默认开启，两者均为共享设置。
浏览器通知需要该浏览器允许通知，角标取决于当前平台是否提供此能力。

普通通知只处理真实新消息事件中的他人新收到消息，忽略自身发送、漫游和旧历史，合并同一批次
同一会话的消息并去重。免打扰和群助手中的群不会提醒，正在前台阅读的会话不会重复提醒。
隐私模式或锁定状态只显示通用提示。点击通知使用已有会话定位，角标使用现有未读结果，
不另行扫描数据库。Web／Remote 使用现有浏览器通道，不新增手机原生通知桥。
