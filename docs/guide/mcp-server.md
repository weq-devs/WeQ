# MCP 服务器

WeQ 内置一个 **MCP（Model Context Protocol）服务器**，让外部 AI 客户端（Claude Desktop 等）
通过本地 HTTP 接口读取**当前账号**的聊天数据。

打开位置：**设置 → MCP 服务器**。

## 1. 服务开关

- **启用 MCP 服务器**：开启后开始监听；首次开启会自动生成令牌；
- 服务与账号绑定：**仅在已登录账号时监听**，切换 / 退出账号会自动停止；
- 只绑 `127.0.0.1`，每个请求都需要带 **Bearer 令牌**；
- 状态行显示「运行中 / 已启用（等待账号）/ 已停止」与访问地址，可一键复制。

## 2. 连接信息

| 项 | 说明 |
| --- | --- |
| **端口** | 修改后立即重启服务（若正在运行）。端口被占用时会自动向后探测并在提示里告知实际端口 |
| **令牌** | 可显示 / 隐藏 / 复制；可**重新生成** |
| **客户端配置** | 可粘贴的客户端配置 JSON 片段 |

## 3. 一键安装到本机 AI 客户端

- **扫描本机已安装的 MCP 客户端**：列出各客户端的安装状态；
- 每个客户端显示状态：**已是最新** / **需更新** / **可安装**；
- 勾选后点安装，WeQ 会把自身写入选中的客户端（会**自动启用服务，不重复安装**）；
- 安装完成提示「重启 AI 客户端后即可在对话中调用 WeQ 工具」；
- 支持重新扫描。

> [!note]
>
> 拿到令牌就等于拿到当前账号的聊天数据，请像对待密码一样保管令牌，不要把地址和令牌暴露到
> 公网。
