左栏 **设置** 打开主内容整页，一级分类下再选择具体页面；不会叠加设置弹窗。空间页和 WeQ 助手内的局部齿轮复用对应配置。

## 常规与保存

窗口行为控制关闭按钮是退出、最小化到托盘还是询问。开机启动与后台服务联动，具体能力依平台显示。

「常规 → 窗口行为 → 发送正在输入状态」可设置全局默认开关（初始关闭），并查看所有已设置的会话特例。私聊输入框键盘按钮的切换会保存为特例，重开会话或重启后仍保留；特例按账号与数据源隔离。特例列表同时保留开启和关闭项，即使与当前默认值相同也不隐藏，可直接切换或删除；删除后该会话恢复跟随全局默认。

「常规 → 窗口行为 → 通知」可分别设置成功和失败通知的停留时长，单位为秒；成功默认 3 秒，失败默认 -1（不自动关闭）。可填 -1 或 1 至 86400 的整数，保存后立即生效并在重启后保留。确认超时等警告使用失败时长；仍在运行的任务进度不受完成态时长影响，完成后才开始计时。悬停或聚焦横幅时暂停自动关闭。

短期横幅的计时分类与其图标、颜色独立：任务已创建、设置已保存等普通提示使用成功时长；未找到消息、读取失败、结果未确认等提示使用失败时长，不改变原文案和样式。原有常驻提示与长期任务继续使用各自的计时规则，不再有普通短期提示固定回退到 10 秒。

需要点击保存才提交的设置，即使值与当前记录相同也可保存，保存完成后仍可再次主动提交；不会因为按钮可用就自动提交。读取尚未完成、正在提交或输入无效时仍可能禁用。

默认保存提供「每次询问保存位置」和「自动保存到默认文件夹」；旧版明确保存过的「先生成，稍后保存」偏好继续保留。工具中的本次选择不会自动写成默认值，详见[统一导出](export.md)。账号配置管理和缓存目录分别位于账号、数据分类。

## 个性显示

- 主题支持浅色、深色和跟随系统，可自定义主题色及背景。
- 公共按钮、发送键和列表选中项会选择与底色相配的文字，极浅／极深主色也保留可辨认边界，不改写选定的颜色。清除自定义色后，界面与助手封面恢复当前主题的预设色。
- 消息显示控制 Markdown、逐条装扮、头像挂件，以及独立的消息序号/秒级时间开关。
- 链接预览可能联网获取元数据；关闭后链接仍可点击。无封面时的后台网页截图会执行远端脚本，默认关闭。
- 隐私模式是视觉遮罩，不改变原始数据或导出内容。

## 账号、安全与凭据

账号管理列出已保存配置，可设置默认进入或删除非当前配置；删除不会移除 QQ 本体数据。同号在线/静态配置仍是独立数据来源。

接入与监听管理当前账号的实时读取等设置；媒体来源配置本地绑定及外部图片目录。数据库密钥、rKey、clientKey 等敏感值集中在「高级与诊断 → 账号凭据」，默认隐藏，离开后重新掩码，不应截屏或写入反馈。

点击窗口标题栏自己的头像，可打开「QQ 资料与状态」，修改 QQ 昵称、个性签名、性别和头像，以及在线状态和自定义状态。编辑器顶部展示当前头像、昵称和 QQ 号，点击头像即可更换；昵称与性别并排分组，窄窗口下改为单列，签名独立展开。每个资料字段单独保存并显示对应字段的反馈，不覆盖未编辑资料；自定义状态表情复用聊天的图片网格，支持搜索和选中预览，仅展示状态接口支持的本机经典表情。选择表情不会立即发送，点击保存才修改状态；Escape 先收起表情网格，不关闭资料窗口。操作需要当前账号在线能力就绪，会真实修改 QQ 账号资料，不是 WeQ 的本地显示别名。回执显示已提交或尚未确认时，应先检查 QQ 和本机同步结果，不自动重发。关闭编辑器会丢弃未保存的草稿，切换账号会收起编辑器；账号切换入口仍在左侧栏。选头像期间切换账号或数据源，会取消旧文件的提交。

窗口标题栏的昵称与个性签名之间显示 QQ 本地缓存的在线状态及已支持的扩展状态图标，每 15 秒刷新；修改状态后也会刷新。状态未读到或未知时不显示，长文案截断后可悬停查看完整内容。本地缓存刷新不代表已向 QQ 服务端实时查询。

### 受限模式

QQ 不在线、完整功能被关闭或在线会话尚未就绪时，标题栏右侧显示红色的「受限模式」；完整模式不显示。启动时或运行中进入受限状态会出现可点击的横幅，打开与标题栏相同的详情，不遮挡整个窗口，仍可浏览本地聊天记录。受限原因全部解除且确认恢复后，显示「已恢复完整模式」成功通知，停留时长遵循成功通知设置；启动时就处于完整模式不通知。

详情列出当前原因及对应引导，可重新检查状态或启用完整功能。真实的管理员授权请求会在详情内提供密码框；关闭详情不取消请求，需明确选择「取消本次授权」，超时后请求及密码框自动清理。密码不保存到配置。受影响功能的悬停提示以「受限模式下无法……」说明不可用的操作。

系统原因按实际能力显示：macOS 在缺少会话凭据且 SIP 开启时解释内存读取限制，密码不能绕过 SIP；Linux 遇到 ptrace 权限限制时提供临时提权及免密重试；Windows 不显示 SIP 或 Linux ptrace 引导。凭据完整且功能可用时，不会仅因进程不是 root 或 SIP 开启而显示受限。状态检查失败单独提示，不冒充 QQ 离线或待提权。

应用锁支持 TOTP 及平台提供的系统认证，可设置空闲自动上锁；不能把锁屏当数据库加密。

[防撤回](anti-recall.md)在账号分类配置；查看记录时进入对应会话查看器。「空间与邮箱」分类中的 QQ 空间提供专用分页限流，保存后即时影响新派发请求，不清零近期用量；QQ 邮箱提供按账号保存的未读数显示与新邮件提醒开关。空间与邮箱页面右上角都有设置齿轮，直接打开各自局部设置，不离开当前页面。

## 数据与维护

### 备份与恢复

「数据与存储 → 备份与恢复」支持导出、导入及恢复默认设置。Native 组件过期或损坏时，也可从组件诊断界面进入，不必先打开 QQ 账号。

- 备份范围可分别选择通用与界面设置、账号配置与偏好、API 配置与凭据、克隆体与助手数据；账号和克隆数据域可单独勾选。界面偏好可独立排除。
- 备份为**未加密 ZIP**，可能包含 API 密钥、数据库密钥、克隆对话、记忆与参考语音，应存放在可信位置。不要作为问题反馈附件公开发送。它不是完整磁盘备份，不包含 QQ 原库、漫游 SQLite 缓存、本地模型、bot 运行入口或本机应用锁密钥。
- 桌面端选择文件保存／读取；Web 端分片上传 ZIP，导出后提供下载入口。单文件最多 64 MiB、总展开数据最多 256 MiB、归档最多 260 MiB、8192 项，超限会明确报错，不生成部分成功备份。同名输出文件不会被覆盖。
- 导入先选择范围和冲突策略，再查看预览并确认暂存。通用设置总会应用；账号、克隆或同 ID 的 API 项可选择跳过或覆盖。覆盖克隆数据域会替换该域，不合并对话。
- 跨机器重新选择 QQ 数据源后，数据域标识可能不同。可将来源映射到**同 QQ 号**的本机已有账号配置；这时保留目标账号的接入信息、密钥与运行凭据。多个来源不能同时映射到同一目标。
- 默认保留本机导出目录和外部图片库路径；如明确取消，可恢复来源设置中的路径引用。不会因缺少外部缓存根而创建替代目录。缺少的克隆素材、模型提供方或 QQ 装扮资源会提示，可能需要重新配置或获取。
- 暂存后仍使用当前运行数据，可取消待恢复任务。保存正在编辑的内容后再重启；桌面端可确认后重启 WeQ，Web 需重启服务进程，刷新网页不等于重启服务。
- 冷启动先恢复文件，再构造业务服务。失败会回滚；回滚未完成时保留原件与事务现场，并显示独立恢复错误，可重试，不能在混合数据上继续打开账号。成功后显示应用、跳过与警告回执。
- 界面偏好在服务端提交后，由发起恢复的设备应用并确认。确认失败可重试，不重复覆盖后来修改的偏好。换设备时可明确改到当前设备恢复，或放弃这次界面偏好恢复；后者不会撤销已恢复的 WeQ 数据。

「恢复默认设置」仅重置通用设置、导出预设及此设备界面偏好，同样需要确认与重启；保留 API、账号、克隆数据和本机应用锁密钥。

### 缓存与维护

「存储与网络」管理缓存位置、CDN 偏好与 WeQ 自身的存储占用。「WeQ 存储管理」统计模型、配置、日志、持久数据、应用内导出产物、当前及旧默认缓存、桌面运行与更新资源，分别显示总占用和可清理大小；保留数据只显示大小、路径与保留原因，没有复选框。只有明确可重新下载或生成的缓存支持清理，未勾选时清理全部可清理项，不会删除保留数据。读取失败或统计不完整会明确提示，可以刷新重试。显示的是逻辑文件大小，不代表卷实际分配空间；QQ 原始数据和任意外部导出目录不在这项统计内，维护工具中的 QQ 资源统计仍独立保留。

损坏处理配置数据库容错级别，容错记录展示实际降级与隔离。可能丢数据的级别需要确认；坏页体检和修复从维护工具进入。

维护工具包含本地缓存、数据库管理、存储占用、清理缓存、数据库修复、导出明文数据库、密钥扫描和其它设备密钥。各项独立打开，数据库修复使用独立窗口。本地缓存按表情 / 头像 / 图片与视频 / 文件 / 语音 / 空间分组浏览 `nt_data` 资源；整体分析用「存储占用」、批量删除用「清理缓存」，详见[本地资源页](database-view.md)。静态账号不可用的资源维护会禁用；清理和修复仍需选择与确认，打开分类不会直接执行。抓包与逆向解析位于「高级与诊断 → 高级诊断」，说明见[维护与诊断工具](wonderful-tools.md)。

数据库修复的体检、修复、记录和回滚均在带系统边框的独立窗口内。窗口跟随主界面主题和主题色，收起设置或账号返回首页不会卸载正在使用的修复界面；重复打开会聚焦原窗口，不会将其目标静默换成另一账号。应用锁定时隐藏修复内容，关闭主应用时一并关闭工具窗口。

### NineBird（macOS / Linux）

NineBird 会修改 QQ 的启动加载配置，按平台需要提权；安装/还原不是普通显示设置。具体操作以平台界面为准，不支持的平台不显示该项。

## 模型与识别

- 「API 配置」维护提供方、Base URL、API Key、模型能力与 TTS 语音合成服务，可从服务方拉取模型列表。不要在反馈中提供密钥。
- API 与 TTS 都可新建多套配置，包括同名、同厂商或同地址但密钥不同的配置。新建分配独立标识，编辑及重复保存沿用原标识，不覆盖其他提供方或改变已有克隆体的引用。模型选择按提供方分组，同名配置另附标识以区分，未选择的提供方不会自动接管调用。
- API 与 TTS 的连接测试在横幅中显示进度和结果，不锁住配置弹窗，也不自动保存配置。请求使用启动时的地址、凭据和模型；测试期间可修改、保存或关闭表单，未保存修改仍按原规则确认。同一配置的在途测试防重复，不同配置可独立测试；关闭设置后仍会完成原任务，失败不另弹对话框。TTS 成功生成的样例语音可从结果横幅重播。
- 对带温度参数的模型调用，若服务明确拒绝该参数或仅允许模型默认温度，会去掉 `temperature` 后重试一次，保留原配置值、模型和上下文。参数范围／类型、鉴权、限流和网络错误不会触发这种回退；两次实际请求在 API 用量中分别记账。助手已有正文、推理或工具片段后不重新生成。
- 「[意图感知](intent-sense.md)」按账号配置总开关、API / 本地引擎、分析上文与缓存，并在本页管理全局意图模型资源；单会话开关在会话头部的会话设置里。
- 「推荐回复」独立配置启用开关、API 模型、自己发送后推荐及推荐上文条数，不受意图感知开关或分析引擎可用性约束，也不使用本地模型生成或自动发送消息。
- 「语音识别」管理[语音转文字](voice-transcribe.md)的本地模型；「图片识别」独立管理 OCR 与筛图模型，并单独说明 QQ 在线 OCR。
- 「好友克隆」提供「添加」入口，打开原有好友选择与训练流程；已有克隆体可管理聊天模型、生成参数、额外提示、发言意愿、错别字、语音及记忆，训练时的检索与视觉模型保留原绑定，不直接替换已有向量。
- 「互动画像」独立启用，管理统计范围、采样与推断方式，可跟随意图感知模型、仅做本地统计，或选择本地／独立 API 模型。
- 图片识别分别选择文字识别模型与筛图模型。图片灯箱和导出可复用；在线失败时能否本地回退取决于平台和已下载模型，不支持的平台会明确提示。
- QQ 在线 OCR 是 QQ 服务端能力，不是本地模型；不需要下载本地模型，但需要 QQ 在线及对应凭据。
- 「API 用量」显示当前账号的调用、token 和场景信息。

模型资源与旧配置迁移见[模型设置](model-resources.md)。

## 服务与更新

- [MCP](mcp-server.md)让外部客户端访问当前账号能力，注意工具的读写范围。
- 外部 RKEY 配置在本机在线凭据不可用时补充媒体下载票据；测试只验证连通性，不保证所有媒体仍可下载。
- SSE 向配置目标发送消息事件，测试按钮会真实发送测试事件。地址与 token 属于敏感配置。
- 外部 RKEY 与 SSE 测试也使用后台横幅；切换编辑目标不会把前一配置的迟到结果写进当前表单。
- 后台服务管理 daemon、公众号推送及更新监控；界面关闭不等于服务停止。
- “帮助与关于”分为「版本与更新」「常见问题」「日志」「反馈」。版本信息、软件更新与更新提醒集中在同一页；日志页同时提供保留时长设置和日志查看器；反馈页保留原反馈表单与提交入口。旧帮助入口转到常见问题，旧更新提醒入口转到版本与更新。Web 不提供桌面应用自替换；原生组件兼容或过期问题以当前界面提示处理。
- 更新下载完成后可点击「重启并安装」，安装退出不受“关闭时询问／最小化到托盘”偏好拦截。按钮会显示「正在重启」并避免重复提交；系统准备或安装失败会显示原因，可重试安装，不必先重新下载。开发版仍只支持检查更新。
