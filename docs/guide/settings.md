# 设置总览

左栏点 **设置** 打开设置弹窗：左侧是分类导航，右侧是分类内容。共 12 个分区。这一页逐个介绍；
其中防撤回、语音、MCP、模型配置等有专门页面，会在对应小节给出链接。

| 分区 | 一句话 |
| --- | --- |
| 全局设置 | 应用级设置：版本、更新、窗口、账号列表、缓存目录、日志 |
| 个性显示 | 主题、主题色、背景、组件风格、消息渲染开关 |
| 应用锁 | 上锁方式与空闲自动锁定 |
| 账号基础 | 当前账号的资料、密钥、rkey、实时与媒体开关 |
| 防撤回 | 撤回拦截触发器（见[防撤回](./anti-recall.md)） |
| 数据库宽容 | 坏库容忍级别、账本与隔离清单 |
| 语音配置 | 转文字模型 + TTS 服务商（见[语音转文字](./voice-transcribe.md)） |
| 模型配置 | AgentLab 的模型提供方（见[AgentLab](./agentlab.md)） |
| MCP 服务器 | 外部 AI 客户端接入（见[MCP 服务器](./mcp-server.md)） |
| 外部 RKEY | 用外部服务器补全媒体下载凭据 |
| SSE 推送 | 新消息实时推送到自定义地址 |
| 守护进程 | weq-daemon 健康、公众号推送、更新监控、开机自启 |

---

## 1. 全局设置

- **版本信息**：WeQ 版本 + Electron / Chrome / Node 版本；
- **软件更新**：检查并安装更新（桌面版；网页版无法自我替换，不显示）；
- **窗口 · 关闭按钮**：点击标题栏关闭按钮的行为 —— `最小化到托盘` / `直接退出` / `每次询问`；
- **现有配置**：列出所有已保存的账号配置：
  - 显示头像、昵称、QQ 号、数据目录；
  - 徽章标示「静态账号 / 手机备份」「默认进入」「当前账号」；
  - 「设为默认」/「取消默认进入」控制自动进入；
  - 「删除」只移除 WeQ 侧配置，**当前已登录账号不可删除**；
- **网络 · 优先使用 CDN**：开启后头像与聊天图片 / 视频封面由界面**直连 QQ 服务器**，不经
  WeQ 中转（离线时看不到本地缓存，失败自动回退）。适合 Web 版省服务器带宽；
- **缓存目录**：媒体缓存落盘位置，可自定义或重置默认（下次进入账号生效）；
- **导出保存目录**：设置后导出任务一键批量保存，不再逐个弹窗选路径；
- **清理缓存**：列出可清理的缓存类别与占用，可勾选单独清理或清理全部（默认全部）。
  这些缓存都会在需要时自动重新下载，**不影响聊天记录、克隆体数据与导出产物**；
- **日志**：日志保留时长（超期自动清理，当天永远保留）与「打开日志文件夹」；
- **NineBird**（macOS / Linux）：安装 / 还原 NineBird（详见下文第 12 节）。

## 2. 个性显示

- **基础模式**：浅色 / 深色 / 跟随系统；
- **主题色**：拖动色相条 + 明度条挑选，或输入 Hex、点预设色。界面主色、描边、按钮都会跟随；
- **界面背景**：纯净 / 纸感 / 细网格 / 微点阵 / 淡洗染 / 电报墙；
- **组件风格**：目前仅「经典」，更多规划中；
- **纯文本消息渲染 Markdown**：把普通文本里的 `#` 标题、`**加粗**`、代码块渲染成富文本
  （WeQ 特有；QQ 原生 Markdown 消息不受影响）；
- **聊天头像挂件**：把 QQ 里正在用的挂件叠在聊天页自己的头像外圈；
- **消息装扮（气泡 / 字体 / 挂件）**：逐条渲染消息装扮（来自消息 DB 列 40801），关掉后统一用
  全局装扮；
- **链接预览卡片**：一条消息只有一个链接时抓取标题、简介、封面渲染成卡片（结果本地缓存；
  关掉后链接仍可点，但不出网）；
- **无封面时网页截图**：网页没提供封面图时，在隔离后台窗口打开并截取首屏当封面
  （会真正运行对方页面脚本，沙盒内、不落盘、退出即清，**默认关闭**）。

## 3. 应用锁

- **总开关**：开启后可用左下角「立即上锁」锁定应用；
- **解锁方式**：
  - **WeQ 验证器（TOTP）**：RFC 6238，绑定流程在独立弹窗完成（二维码 + 密钥 + 6 位码确认）；
  - **Windows Hello 等系统认证**（平台支持时）；
- **空闲自动锁定**：选择无操作多久后自动上锁（0 = 关闭，仍可手动上锁）。

## 4. 账号基础

与当前打开账号相关的设置：

- **账号资料卡**：头像、昵称、QQ 号、签名；
- **数据库密钥**：显示 / 隐藏 / 复制，并显示算法（page / kdf HMAC）；
- **下载 rKey**：列出各类媒体（私聊图片、群聊图片等）的 rkey，可刷新；
- **客户端 key / p_skey 等**；
- **实时消息**：是否监听新消息；
- **自动注入 QQ**：开启 = 完整功能（含部分在线能力）；**关闭 = 完全离线模式**（见
  [妙妙工具](./wonderful-tools.md)）；
- **原生媒体绑定**（静态账号）：是否使用原生媒体目录；
- **外部安卓 chatpic 目录**：导入其它设备导出的图片目录作为兜底（校验三个子目录后自动启用）。

## 6. 数据库宽容（salvage）

这一屏回答三个问题：**现在是什么级别**、**想开哪一级的代价**、**到底降级过什么**。

- 声道 / 级别从「严格（默认）」到更宽容的级别；级别 0 是默认，也占一行，让你随时看到关掉会回到
  什么；
- **会丢数据的级别必须当场确认**，确认框就内联在被点的那一行里；
- **账本**记录降级过什么，**隔离清单**列出被整表放弃的表，可让它重新试一次；
- 坏页扫描不在这里 —— 已搬到[妙妙工具 → 数据库修复](./wonderful-tools.md)（那边对任意账号
  可用）。

## 8. 模型配置

给 AgentLab / WeQ 助手配置模型提供方：

- 可新建 / 编辑 / 删除提供方（含厂商模板，默认模板是硅基流动 SiliconFlow）；
- 每个提供方填写名称、厂商、Base URL、API Key，并维护**模型列表**；
- 每个模型标注能力：**聊天 / 向量 / 视觉**；
- 克隆与助手会按能力挑选可用模型。

## 10. 外部 RKEY

让**没有在线 QQ 进程**的机器也能补全聊天媒体：通过外部 rkey 服务器（目前支持 NapCat 的
`/get_rkey_server` 接口）拉取媒体下载凭证。

- 全局配置，一份配置所有账号通用；
- 可导入多份，但**同时只能启用一条**（或都不启用）；
- 下载图片 / 表情时优先用本机在线 QQ 自己获取的 rkey，本地不可用才回退到启用的外部服务器；
- 支持新增 / 编辑 / 删除、启用 / 停用、只探测连通性的「测试」。

## 11. SSE 推送

把 QQ 新消息**实时推送**到你配置的推送地址（HTTP POST + Bearer access_token）。

- 同一套 `nt_msg.db` 监听，外加**防抖合并 + seq 跳变阈值**：QQ 刚启动大量写表时不再逐条推送，
  而是合并成一条 `mass` 事件并预览最新一条；
- 可配置多个推送目标，同时只启用一条；
- 可调防抖毫秒与大量消息阈值；「测试」会发一条 ping 事件探测连通性。

## 12. 守护进程

`weq-daemon` 的控制面板（取代旧的「WeQ 助手」设置页）：

1. **健康性**：探活 / 版本 / HTTP 服务 / docroot；
2. **推送到 QQ 公众号**（原 WeQ 助手）：开关 + 端口 + 更新推文说明；
3. **GitHub release 监控**：守护进程轮询开关 + 最近发现 + 系统通知；
4. **开机自动启动**：GUI **不注册任何原生自启**，只把意图交给守护进程，开机由守护进程拉起
   WeQ。

### NineBird（macOS / Linux）

- **macOS**：把 NineBird 的 hooker + loader 部署进 QQ 沙箱容器，并把 QQ 的 `package.json`
  main 指向 `loadNineBird.js`（提权操作，密码经 stdin 喂给 `sudo`，WeQ 自身保持非特权）；
- **Linux**：只需提权写入一个 `loadNineBird.js` 持久 stub，还原时删除；
- 非 macOS / Linux 平台该卡片渲染为空。
