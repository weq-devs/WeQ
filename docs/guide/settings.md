# 设置总览

左下角 **菜单 → 设置** 打开主内容整页，一级分类下再选择具体页面，默认进入「常规 → 启动与主页」。设置保留侧栏和原页面，QQ 登录账号管理与 Protobuf / JCE 逆向直接在正文查看，密钥扫描和撤回记录等工具使用遮罩弹窗；数据库修复与 QQNT 抓包使用独立系统窗口，日志查看器仍在日志页内。空间页和 WeQ 助手内的局部齿轮复用对应配置。应用锁与隐私模式位于「常规 → 隐私」；有新版本时设置按钮、关于 WeQ 分类及版本与更新项分别标记来源。

切换设置页面时，离开的界面会卸载，已登记的未保存表单、展开状态与滚动位置保存到本机，回来时重新构建，不再让全部访问过的页面驻留内存。普通返回不重新跳到之前的搜索结果，新的搜索仍会定位对应项目；后台下载、更新等已提交任务继续运行。表单草稿按账号和数据源隔离，不自动提交。点击右上角 × 关闭设置时，有未保存内容会先提醒：选择「继续编辑」保留当前页面与草稿，选择「放弃修改」清除本次设置现场；没有未保存内容则直接关闭。关闭后普通重开回到「常规 → 启动与主页」，从搜索或快捷入口打开仍定位指定页面。离开凭据页、相关令牌页面或锁定应用后，敏感字段重新掩码；验证器绑定在离开页面时取消尚未确认的绑定。

搜索定位设置后，高亮框短暂停留再淡出，约 2 秒后自动消失；再次搜索同一项会重新高亮。启用系统「减少动态效果」时不播放淡出动画，仍会自动清除高亮。

不通过右上角 × 关闭，而是切换设置分类、子页面或进入消息、联系人等主页面时，当前页有未保存内容会先拦截切换。选择「先保存」留在当前页完成保存；选择「暂时离开」继续原来的切换，保留页面路径和未保存内容，返回后可继续编辑。关闭询问框同样留在当前页，不执行切换。已保存的页面直接切换，不重复询问；OneBot 内嵌编辑表单也支持暂时离开后恢复。

## 软件更新

「关于 WeQ → 版本与更新」提供「检查测试版」开关，默认关闭，并保存到本机应用设置。关闭时只检查正式发布，开启时同时检查正式版和测试版，取版本较新者；纯数字版本但标记为 GitHub 测试发布的版本同样受此开关控制。切换后旧的更新检查结果失效，需重新检查，不会将较旧正式版当作可用更新提示降级。

检查先读取公开发布目录，再对选定版本的加速源进行探测和安装包取样测速；界面显示当前／最新版本与选中的源，下载失败仍按排名切换。测试版下载、Mac 官方包校验及安装沿用同一检查选项，不只改变界面提示。

## 常规与保存

「常规 → 启动与主页」位于第一个二级页面，依次展示开机启动、启动时进入和主页设置。「开机自动启动」位于最上方；原独立主页设置合并到页面最底部，旧主页入口仍可直接定位。

「启动时进入」可选择主页、消息或上次退出时所在页面，默认进入主页，已有配置保留明确保存的选择。选择主页或消息时，每次重新启动都会从初始状态进入，不恢复各页面的子页面、筛选、选中项和阅读位置；即使上次异常退出，也遵循此选择，设置偏好与未发送草稿保留。选择上次页面时仍还原原栏目与阅读现场。应用进程仍在运行时，界面崩溃重载会接回已打开的账号并恢复现场，不重新应用启动页设置。未自动打开账号时仍先显示账号选择页，打开账号后进入所选栏目。

「常规 → 启动与主页 → 主页」中的个性标签、问候语和一言可独立开关，默认全部开启，标签与一言可以同时显示。偏好全局保存，重启后保留。

主页显示开关与一言屏蔽词集中在同一张「主页」卡片内。一言屏蔽词每行一个，点击「保存」后生效；按正文与出处作不区分大小写的字面包含匹配，空行忽略、重复词合并。最多保存 1000 个词，每词不超过 200 字；全部句子被屏蔽时不显示一言，不影响标签、问候语及助手报告的候选句。切换设置页面保留本机未保存草稿，恢复草稿不等于已应用配置；关闭设置并确认放弃修改后清除草稿。

窗口行为控制关闭按钮是退出、最小化到托盘还是询问，默认最小化到托盘，在「常规 → 提醒与窗口」设置。开机启动独立管理系统登录项，不依赖后台服务，仅安装版桌面端支持。

桌面主窗口可拖动边缘收窄为竖屏，最小尺寸为 360 × 520。宽度不超过 760 时，直接使用 WeQ Remote 共用的单栏界面：会话列表与正文单栏切换，底部为「消息、联系人、空间、更多」四个入口，其他功能从「更多」进入；正文左上角返回会话列表。桌面保留原生窗口操作与顶部拖动区，拉宽后恢复并排布局。默认打开尺寸仍为横版。

「自启时显示窗口」位于开机自动启动下方，默认关闭：系统登录自启后保持托盘运行，手动打开或从托盘/Dock 唤出时仍显示窗口。开启后，下次系统登录自启时显示主窗口。关闭自启不会清除这个偏好；托盘不可用时仍显示窗口，避免无法找到应用。

macOS 菜单栏显示彩色 WeQ 图标，左键点击直接打开主窗口；右键点击显示「显示主窗口」与「退出 WeQ」菜单。

macOS / Linux 桌面端可在「常规 → 提醒与窗口 → 窗口」开启「使用仿 Windows 窗口按钮」，默认关闭。关闭时使用系统原生窗口按钮；开启后改用右上角的最小化、最大化／还原与关闭按钮。macOS 主窗口立即生效，Linux 主窗口重新进入账号后生效，独立窗口下次打开时生效。账号选择页始终保持各平台统一样式，右上角提供关闭按钮，不受此设置影响。标题栏空白处可拖动窗口，受限模式入口不受拖动区影响。

macOS 的 `Cmd+Q`、应用菜单「退出 WeQ」、Dock 图标右键「退出」及托盘退出均请求彻底退出，不受关闭按钮偏好影响，也不再弹确认框：选中的就是退出，直接结束进程并停止全部后台服务。
关闭按钮偏好为「每次询问」时，若仍有后台服务在运行（MCP、OneBot、QQ 公众号推送、Web、Remote 或 SSE 推送），关闭确认框会列出这些服务，可取消或改为最小化到托盘。
已保存的账号、配对和开机启动设置保留；开启自启时，由系统在下次登录时直接启动 WeQ。
只关闭窗口并选择最小化到托盘时，后台仍正常运行。

开启 QQ 公众号推送而尚未启用系统登录自启时，会推荐同时开启自启，也可只开启推送。
推送服务仍启用时关闭登录自启，会提示下次登录后需要手动启动 WeQ，可选择保留或仍关闭自启；
不会擅自停用推送。系统自启待批准时会明确提示，不将已请求注册当作已经生效。
更新安装及已经确认的应用重启、退出后清除沿用原流程，不重复弹助手退出提示。

「基础功能 → 互动与防撤回 → 隐藏正在输入状态」采用「默认展示、按需隐藏」：启用范围可选「关闭」「按会话勾选」「永久全选」，关闭时照常向对方展示正在输入状态。选择「按会话勾选」后显示「隐藏正在输入状态的会话」及已选择数量，点击「编辑会话」打开与防撤回一致的独立选择弹窗，只列出私聊会话，点击「保存选择」后按账号与数据源分别保存；关闭未保存的选择时会确认是否放弃修改。「永久全选」则所有私聊都不再展示。私聊输入框不再有单会话开关按钮，添加或移除隐藏会话都在设置里完成。

「常规 → 提醒与窗口 → 应用内横幅提醒」可分别设置成功和失败通知的停留时长，单位为秒；成功默认 3 秒，失败默认 -1（不自动关闭）。可填 -1 或 1 至 86400 的整数，保存后立即生效并在重启后保留。确认超时等警告使用失败时长；仍在运行的任务进度不受完成态时长影响，完成后才开始计时。悬停或聚焦横幅时暂停自动关闭。

短期横幅的计时分类与其图标、颜色独立：任务已创建、设置已保存、状态未改变、重复操作提醒、输入校验、文件类型限制、正常空结果（如未找到消息、图片未识别到文字），以及已自动改用文件附件发送等提示使用成功时长；消息加载或逐条转发被主动停止且没有实际失败时，也使用成功时长。读取失败、结果未确认、确认超时等提示仍使用失败时长，不改变原文案和样式。原有常驻提示与长期任务继续使用各自的计时规则，不再有普通短期提示固定回退到 10 秒。

右下角与当前状态关联的横幅会随问题解决自动收起：「待提权」、受限原因及状态检查失败会更新为当前状态，确认恢复后旧警告自动消失，即使失败通知设为不自动关闭或正在悬停也一样。同一目标的连接测试重试会原地更新横幅，通过后不保留上一次失败提示；其他目标的错误、仍未解决或尚未确认结果的提示不因此关闭。

需要点击保存才提交的设置，即使值与当前记录相同也可保存，保存完成后仍可再次主动提交；不会因为按钮可用就自动提交。读取尚未完成、正在提交或输入无效时仍可能禁用。

「常规 → WeQ 存储管理」只提供数据与缓存清理，不再提供默认保存方式、默认保存目录或缓存目录设置；已有偏好、原目录与任务产物保留。保存行为详见[统一导出](export.md)。账号配置管理位于「凭据与账号 → WeQ 账号管理」。

## 主题与聊天显示

原「聊天消息」拆为「基础功能」下的三个二级设置页面，不增加三级导航。搜索设置或使用旧快捷入口时，直接进入对应二级页并定位具体条目；旧「聊天消息」整页入口进入「阅读与未读」。

| 二级页面 | 设置内容 |
| --- | --- |
| 阅读与未读 | 消息红点、联系人未读数、群助手计数、阅读定位、自动跟随、同步已读到 QQ |
| 消息显示 | 时间与序号、头像与装扮、文本与链接、语音自动转文字、图片预览内存预算 |
| 互动与防撤回 | 使用 QQ 个性字体发送、隐藏正在输入状态及范围、防撤回启用范围、触发器状态、启用防撤回与通知名单、撤回记录 |

- 主题支持浅色、深色和跟随系统，可自定义主题色及背景。
- 「常规 → 主题与背景 → 组件风格」默认采用排在首位的 QQ NT，并保留经典、简约、复古外观：简约使用无框按钮、下划线输入框与侧边选中线；复古使用方形控件、立体描边、凹陷输入框与实心选中项。预览展示实际控件形态，选中后立即应用并在本机保存；缺失或不再提供的风格选择回落到 QQ NT。默认背景为「纯净」，已保存的主题色、背景、密度与风格保持不变。
- 复古风格同时覆盖侧栏导航、聊天文本气泡、分段选项、设置与收藏／装扮等功能页的工具栏、任务面板及菜单浮层；深浅色分别适配，继续跟随自定义主题色、背景和界面密度，纯图片与表情等消息内容保持原有显示方式。
- 「界面密度」可独立选择舒适或紧凑，调整通用控件、设置行、会话与联系人列表、表格的间距，不改变字号、主题色和背景。窄屏保留适合触控的按钮尺寸。
- 公共按钮、发送键和列表选中项会选择与底色相配的文字，极浅／极深主色也保留可辨认边界，不改写选定的颜色。清除自定义色后，界面与助手封面恢复当前主题的预设色。
- 消息气泡与消息字体可分别开关，自己和对方的消息均遵循。头像挂件独立控制，包括消息记录中的挂件、本地使用的挂件与自己 QQ 账号的静态挂件；没有额外的消息挂件。
- 同条消息同时带有个性气泡和字体、且两项显示均开启时，等气泡底图解码与字体加载成功后一起显示；加载中或任一项失败时保持默认字体、文字颜色和气泡。仅有一种装扮或主动关闭另一项时，已开启的装扮独立加载，挂件与动画不阻塞文字显示。
- 「消息显示」将时间与序号、头像与装扮、文本与链接、语音、图片分别分组；网页截图紧跟链接预览，QQ 秀缓存有效期紧跟 QQ 秀开关。「阅读与未读」中的「在消息图标上显示红点」独立控制消息图标的汇总提醒，原「显示消息汇总红点」仍可搜索定位。
- 「时间与序号」中的「显示发送日期」位于序号与时间开关之间，默认关闭，按北京时间以 `yyyy-mm-dd` 显示；可与「显示发送时间」独立开启。
- 「图片与表情 → 图片预览内存预算」默认 128 MiB，可设为 0–1024 MiB，点击保存立即生效。预算内保留最近看过的图片、动画表情和商城表情，超额时优先淘汰较早查看的离屏预览；0 表示不保留离屏预览。预算按解码后像素估算，不是图片文件大小，也不是进程内存硬上限：当前可见图片和动画额外帧可能使实际内存更高。该缓存按渲染窗口独立管理，切换账号时清空，不改变本机磁盘缓存。
- 「阅读与未读」可设置「从第一条新消息开始阅读」（默认关，关闭时进入会话显示最新消息）、「发送消息后定位到最新消息」（默认开）和「群助手显示总消息数」（默认关，关闭时仅显示未读圆点，不影响助手内各群的未读数）。
- 「自动跟随最新消息」默认开启，控制加载完成后新到消息的跟随。未开启「从第一条新消息开始阅读」时，进入会话及分批加载期间始终定位最新消息，不受自动跟随开关影响；手动向上滚动后保留阅读位置。
- 「向下滚动时显示定位到底部按钮」默认开启，向下浏览时可快速回到最新消息，并保留最新消息预览入口；关闭仅隐藏滚动触发的按钮，不影响「xx 条新消息」提醒。
- 「互动与防撤回」中的「使用 QQ 账号设置的个性字体发送消息」默认开启；关闭后发送请求不带个性字体。自己发送的消息先按本次请求显示字体，读回后按读回记录显示，字体可能随之变化；本地使用中的个性字体仍可按作用范围覆盖显示，不改变发送请求。
- 「聊天 QQ 秀替换头像」默认开启：开启后消息头像换成成员的 QQ 秀全身像（比头像略宽，不挤动消息布局），同时不再显示头像挂件；关闭后恢复头像与挂件。头像进入可视区域后才查询，未命中缓存的成员逐个请求。形象 URL 按账号缓存，有效期默认 5 分钟，可在同一处按分钟调整；个性主页共用这份缓存。到期时只刷新仍可见的头像，离屏后等再次看到才刷新；失败时保留旧形象，30 秒后可重试。旧版默认 14 天自动迁移为 5 分钟，其他自定义天数换算为分钟保留。
- 自己发出的气泡在回读前采用 QQ 账号配置，回读后以实际消息为准；「个性装扮」中使用的气泡与字体仍可按作用范围覆盖本地显示，不改变实际发送。
- 链接预览可能联网获取元数据；关闭后链接仍可点击。无封面时的后台网页截图会执行远端脚本，默认关闭。
- 应用锁的启用开关、解锁方式、验证器绑定和空闲自动锁定集中在同一张「应用锁」卡片内；验证器绑定仍在独立弹窗中完成。
- 隐私模式只遮罩身份、私人内容和凭据：头像、昵称、账号标识、消息与邮件正文、照片、文件名、识别结果等；群人数、时间、消息 seq、等级、个性装扮、统计、操作按钮和任务状态保持清晰。混排区域只遮罩具体字段，不模糊整张卡片或整个气泡；关系图保留匿名节点、连线和统计。
- 隐私模式是视觉遮罩，不改变原始数据、复制结果或普通导出内容，不静音语音／视频。敏感字段的原生悬浮提示会临时隐藏，关闭后恢复。第三方网页、系统文件选择器，以及未建模的数据库／协议／日志原始内容不属于自动脱敏承诺；公开分享前仍需检查截图。
- 桌面端可开启「在菜单中截图瞬间临时启用隐私模式」，默认关闭。开启后截图前关闭菜单并临时遮罩，完成、取消或失败后仅撤销本次覆盖，不修改永久隐私偏好；截图期间修改永久偏好，以最新值为准。关闭该选项时保留原来的直点/长悬停截图行为。该选项随设备界面偏好备份，Web 不显示原生截图控件。

## 账号、安全与凭据

账号管理列出已保存配置，可设置默认进入或删除非当前配置；删除不会移除 QQ 本体数据。同号在线/静态配置仍是独立数据来源。

「监听与读取」管理数据库监听与 QQ 内存读取，不再重复展示当前账号资料；全局已读同步偏好位于「基础功能 → 阅读与未读」，防撤回位于「基础功能 → 互动与防撤回」。关联资源目录及外部安卓图片缓存位于「WeQ 账号管理」，资源关联仍按原账号/数据源保存，外部安卓图片缓存仍是全局配置。数据库密钥、rKey、ClientKey 和外部 rKey 集中在「凭据与账号 → 凭据管理」，默认隐藏，离开后重新掩码，不应截屏或写入反馈。在线会话与其他设备密钥扫描也从凭据页打开。

「同步已读状态到 QQ」默认开启，统一控制自动阅读及手动标记。已有配置保留明确保存的选择，缺少的字段使用开启的默认值。两类设置不一致时，开关仍显示开启，并注明“仅自动阅读同步”或“仅手动标记同步”，未操作不会改变原组合。关闭时同时停止两种同步；重新开启需确认，随后同时启用。受限或离线时只保留偏好，不会因此发送上报；标为未读也不能恢复其他端已清除的提醒。

「自动启用完整功能」只控制自动尝试策略。关闭后仍可从受限模式详情为当前来源手动启用，手动请求仅保存在宿主本次运行中，不写配置或备份，也不代表授权或凭据已经就绪。重载窗口或 Web 页面不会清除请求，切换来源、退出账号或重启宿主后则不继承。凭据、媒体补全、收藏、邮箱和其他在线入口依据当前有效运行态与真实 QQ 能力共同判断，关闭自动策略不会撤销已经明确作出的本来源手动请求。

「进入受限模式时横幅提醒」默认开启，仅用于正常运行后进入受限模式的被动提醒。启动自动尝试完整功能时，无论成功、失败或等待授权均不发模式横幅，实际状态和授权入口仍可从标题栏详情查看；手动启用的授权、进度及结果不受此开关影响。关闭期间会继续跟踪状态变化，重新开启不会补发已经发生的提醒。该偏好随通用设置备份与恢复。

旧配置备份没有包含的设置字段会保留本机已有值，仅为本机也缺少的字段补默认值；明确选择「恢复默认设置」仍会重置通用偏好。已读自动/手动混合组合按原值往返，宿主手动完整功能请求及截图临时覆盖不在备份中。

「基础功能 → 通话录音」配置**通话接通后录音**的内容与位置：录音来源可选仅本端、仅对方或双方混合；可同时录电脑正在播放的声音（Windows 与 Linux 支持，macOS 需要虚拟声卡）；保存位置默认按账号放在应用数据目录的 `recordings` 下，也可自选目录。录音**不会自动开始**，要在通话窗口里手动点录音键。通话结束后窗口里可直接播放；如果这通电话在聊天里留下了通话记录，那条消息旁边也会出现播放按钮（QQ 客户端写入这条记录之前不会出现）。通话窗口底部的「通话与录音设置」抽屉改的是同一份配置，改哪边都一样。同一页的「记录 UDP 流量」打开后，发起的通话会把本机收发的全部 UDP 数据报自动写成 pcapng，放在录音目录下的 `udp/` 里，格式与 UDP 抓包面板导出的相同，可以直接用 Wireshark 打开（默认关闭，视频通话的文件可能很大）。

点击窗口标题栏自己的头像，可打开「QQ 资料与状态」，修改 QQ 昵称、个性签名、性别和头像，以及在线状态和自定义状态。编辑器顶部展示当前头像、昵称和 QQ 号，点击头像即可更换；昵称与性别并排分组，窄窗口下改为单列，签名独立展开。每个资料字段单独保存并显示对应字段的反馈，不覆盖未编辑资料；自定义状态表情复用聊天的图片网格，支持搜索和选中预览，仅展示状态接口支持的本机经典表情。选择表情不会立即发送，点击保存才修改状态；Escape 先收起表情网格，不关闭资料窗口。操作需要当前账号在线能力就绪，会真实修改 QQ 账号资料，不是 WeQ 的本地显示别名。回执显示已提交或尚未确认时，应先检查 QQ 和本机同步结果，不自动重发。关闭编辑器会丢弃未保存的草稿，切换账号会收起编辑器；账号切换入口仍在左侧栏。选头像期间切换账号或数据源，会取消旧文件的提交。

窗口标题栏的昵称与个性签名之间显示 QQ 本地缓存的在线状态及已支持的扩展状态图标，每 15 秒刷新；修改状态后也会刷新。状态未读到或未知时不显示，长文案截断后可悬停查看完整内容。本地缓存刷新不代表已向 QQ 服务端实时查询。

### 长期授权

桌面端在「凭据与账号 → 监听与读取 → 长期授权」检查、启用、修复或撤销本机权限助手。启用和撤销均需管理员批准，不保存管理员密码；打开设置或搜索该项不会自动安装。提权提示与导出授权提示中的「管理长期授权」会结束本次待处理请求并跳转，完成设置后需重新执行原操作。

助手是独立的小型原生服务，不复制 Electron、Node 或聊天数据。系统只安装一份可执行文件，按系统用户分别授权；撤销自己的授权会中断自己的助手操作，最后一位用户撤销时移除共享组件。安装后系统启动服务，空闲时不抓包；WeQ 关闭或连接断开后清理该连接持有的抓包会话。

macOS 使用 launchd，Windows 使用系统服务，Linux 使用 systemd。macOS 的 SIP、Windows 的 Npcap 依赖及其他系统保护仍然有效，长期授权不能绕过它们。Linux 无 systemd、旧版原生包未包含助手或服务不可用时，不会假报已启用，原有临时授权路径保留。

普通应用更新可继续使用协议和接口都兼容的助手；助手自身仍遵循原生组件有效性约束。组件过期、协议不兼容或权限助手接口已更新时，需要更新原生组件并重新「修复授权」，旧授权不会继续生效；系统授权记录不因过期自动删除。需要修复时，受限模式会直接显示原因和「管理长期授权」入口，不再让界面停在「正在启用完整功能」等待。长期授权属于本机系统状态，不随配置备份迁移到其他电脑。

安装失败时设置页会给出中文原因和下一步，而不是原生组件的英文原始报错。常见的一种是安装目录不安全：Linux 的 `/opt`（或 macOS 的 `/Library/PrivilegedHelperTools`）必须由 root 拥有且其他用户不可写，从备份恢复数据后目录属主可能变成你自己的账号，此时会提示执行 `sudo chown root:root <目录>`，命令需要用户在终端里自己执行——WeQ 不会代改系统目录，否则该目录又会变成普通用户可写。修好后点「重新检查」再启用即可。

### 受限模式

macOS 开启 SIP 时，QQ 登录与完整功能引导合并为一个随状态变化的主按钮：「准备并打开 QQ」「打开 QQ」「修复并打开 QQ」「登录其他账号」或「启用完整功能」。已有副本运行不会阻止打开新实例，已运行的 QQ 不会被自动退出；副本设置、打开已有窗口和手动重新检查收进「更多」。在此为当前来源打开 QQ 后，检测到当前账号在线会自动继续启用；请求仅在宿主本次运行对当前来源有效，不修改自动启用偏好。创建或更新副本不再自动展开截图、麦克风和摄像头授权引导，相关权限仍可在副本设置中按需处理。

QQ 不在线、当前来源未启用完整功能或在线会话尚未就绪时，标题栏右侧显示红色的「受限模式」；完整模式不显示。启动自动尝试全程保持静默，即使最终受限也不发横幅。当前来源曾确认完整功能就绪后，再进入受限状态才按提醒设置显示可点击横幅，打开与标题栏相同的详情，不遮挡整个窗口，仍可浏览本地聊天记录。自动恢复只收起横幅，不另发成功通知；在受限模式中手动启用时显示授权、进度和结果，全部受限原因解除且确认恢复后显示「已启用完整功能」，停留时长遵循成功通知设置。切换来源不会继承旧来源的提醒或恢复回执。

详情列出当前原因及对应引导，可重新检查状态或启用完整功能。其他系统或 macOS 未启用 SIP 时，QQ 不在线会提供「启动 QQ」按钮，打开本机已安装的 QQ；Web 客户端启动的是运行 WeQ 服务的宿主上的 QQ。启动不等于已登录或已启用完整功能，仍需在 QQ 中登录当前账号，并满足本来源的自动策略或手动请求，之后重新检查真实能力；未检测到安装或启动失败会在详情内提示，不会自动改变自动启用偏好。真实的管理员授权请求会在详情内提供密码框；关闭详情不取消请求，超时后请求及密码框自动清理。密码不保存到配置。授权后会在会话凭据就绪时自动重新检查并恢复在线功能，无需手动刷新；仅提交密码不会被视为已恢复。受影响功能的悬停提示以「受限模式下无法……」说明不可用的操作。

若 QQ 刚登录时只读到部分凭据，或设备身份暂未就绪，后台会延迟重试，补齐后自动恢复，无需重新打开账号。已有在线票据仍有效也不会阻止补齐当前会话；身份暂缺本身不会反复请求管理员密码。明确取消授权后则保持安静，直到手动重新检查或 QQ 进程更换。

提交授权后，等待凭据读取、原生会话登记或自动重试期间，标题栏和常驻进度提示持续显示「正在启用完整功能」。不会因密码框关闭、刷新请求结束或旧的完整状态缓存而提前报成功；当前会话真正就绪后才结束进度并显示恢复成功。明确取消或确认失败时回到可重新检查的受限状态。

有尚未处理的管理员授权请求时，标题栏、详情及横幅优先显示「待提权」，不显示进入中的旋转进度或自动重试说明。最后一项授权提交后才切回「正在启用完整功能」；恢复期间若再次需要授权，会重新显示待提权。

系统原因按实际能力显示：macOS 桌面端在 SIP 开启且 QQ 不在线时，启动页和账号页均引导创建、启动独立的 [QQ 调试副本](./macos-debug-copy.md)，不再提供普通「启动 QQ」按钮；缺少会话凭据时也提供副本管理入口，无需关闭 SIP。读取端也必须带调试权限，管理员密码不能替代签名权限。Linux 遇到 ptrace 权限限制时提供临时提权及免密重试；Windows 不显示 SIP 或 Linux ptrace 引导。凭据完整且功能可用时，不会仅因进程不是 root 或 SIP 开启而显示受限。状态检查失败单独提示，不冒充 QQ 离线或待提权。

应用锁支持 TOTP 及平台提供的系统认证，可设置空闲自动上锁；不能把锁屏当数据库加密。

[防撤回](anti-recall.md)在「基础功能 → 互动与防撤回」直接显示开关、保护模式、触发器与通知状态；保护/通知名单通过工具编辑，未保存关闭需确认。撤回目录和会话消息在同一遮罩工具内切换，可返回目录；设置页面与侧栏始终保留。基础功能中的 QQ 空间提供专用分页限流，保存后即时影响新派发请求，不清零近期用量；QQ 邮箱提供按账号保存的未读数显示与新邮件提醒开关。空间与邮箱页面右上角都有设置齿轮，直接打开各自局部设置，不离开当前页面。

QQ 空间的「在线翻页限速」使用“每 [秒数] 秒最多 [页数] 页 [保存]”单行表单；普通状态重读不覆盖未保存输入。「不让 ta 看我的空间」「不看 ta 的空间」以头像和昵称排列名单，接口未返回昵称时补读本地资料，未取得资料时明确标记，QQ 号可在悬停时辨认。点击头像或昵称打开对应名片；点击标题旁的加号可搜索好友或输入 QQ 号添加，点击成员旁的叉号并确认后移除。添加、移除后重新读取名单核对，未确认时保留输入。读取失败可重试，不会显示成空名单；好友资料中的对应单人开关仍保留。

## API 配置

每个 LLM 模型旁可点击「自动检测能力」，使用少量合成文本和内置色块图片检测聊天、向量与视觉接口，可能产生 API 费用，不发送聊天记录或个人图片。检测通过会勾选对应能力，服务方明确不支持则取消勾选；鉴权失败、限流、超时、网关错误或无效输出显示「未确定」，保留原选择。视觉检测需正确识别两张不同颜色的图片，接口接受图片本身不算通过；「未确定」不等于不支持，仍可手动调整。结果仅更新草稿，点击「保存 provider」后生效。模型列表导入的能力仍是按名称猜测，不代表实测结果。

「AI 功能 → API 配置」分为 LLM 和 TTS 语音合成两块，服务商继续使用原有编辑弹窗，不替换设置侧栏。LLM 可分别保存多个 provider 和模型，并单独设置默认模型；只列出支持聊天的模型，选择后即时保存，也可明确清空。

默认选择按 provider ID 和模型 ID 保存，修改服务商名称、端点或密钥不改变引用；删除已选 provider 或模型时保留选择并显示不可用原因，不自动切换到别的模型。读取失败可重试，保存失败保留原选择。原有各功能的显式选择和未选择状态不因此改变。

意图、互动画像、推荐回复、新建及编辑克隆体、WeQ 助手等 API 模型入口默认选中「默认（当前：具体模型）」，不再提供「未选择」；未指定模型的旧配置也使用默认，已有具体模型保持原样。可选向量检索仍可选择「不使用向量」。每次调用按当前默认解析；默认未配置、模型已删除或能力不匹配时明确报错，不改用其他服务商。聊天默认模型并不一定支持向量或视觉能力。全局默认模型本身仍可清空，不继承自身。

意图感知、互动画像和推荐回复的设置按用途直接分区展示，不再设置「高级设置」折叠入口；克隆体回复设置与漫游拉取参数同样直接展示。

意图分析和推荐回复会在实际默认模型变化后更新缓存，旧模型的迟到结果不会写入新缓存。克隆体的向量索引绑定训练时的模型：若训练时选了默认向量模型，之后更换默认导致索引空间变化，需要重新训练，不能将原索引交给另一模型查询。导出独立 bot 时会固定导出当时实际使用的模型和服务商，不依赖电脑之后的全局默认。

API 配置备份包含默认模型。导入旧备份没有此字段时保留本机默认；跳过冲突保留本机已存选择（包括未设置），覆盖冲突则采用导入值，允许明确清空。

意图感知、互动画像和推荐回复是三个独立设置页，首先展示「功能与模型」，之后分别展示显示方式、触发方式、分析或统计范围、生成参数、结果展示、请求与缓存等适用分区。功能区放各自的启用开关和「自动／手动」模式，模型配置统一使用「运行方式」「服务商与模型」等名称；推荐回复只使用 API，不显示不适用的运行方式切换。关闭功能后仍可配置模型，不会连带修改其他功能。开关、模式和模型选择即时保存，数字参数编辑后按所在分区的「保存」提交；读取失败、保存中和非活动页面统一禁止修改，失败时可重新读取。旧配置默认自动；手动时通过消息右键或多选菜单运行意图感知、进入互动画像页生成画像、点击推荐栏的开始图标生成推荐，具体见[意图感知](intent-sense.md)。

所有参数分区直接展示，按参数名称搜索可定位，不会因定位而保存参数或启动模型。切换页面保留草稿，非活动页面停用无必要的读取与订阅。本地意图资源仅在本地模式下显示于「功能与模型」内，不另设卡片；资源全局共享，功能选择仍按原账号作用域保存。不适用的模型配置直接隐藏，旧搜索入口定位到运行方式；实际错误与重试入口保留。意图感知页的「意图与推荐缓存」同时清除这两项功能的缓存，不影响互动画像。

「显示方式 → 批量分析时显示胶囊动画」默认开启；关闭后，批量及自动分析在结果到达前不显示胶囊、动画或失败占位，也不预留空间，消息正文和后台分析照常进行。已有结果仍直接显示；单条手动分析始终立即显示胶囊动画，已有结果也直接重算，完成后恢复「常驻显示」等显示偏好。

推荐回复的「回退内容」可开启或关闭，并通过统一列表添加、修改、删除句子及恢复默认列表。每条最多 500 字符，最多 100 条；保存时去除首尾空白，不接受空白或重复项。模型未配置、调用失败、冷却或没有有效候选时，从列表随机抽取不重复内容，数量不超过推荐候选上限；关闭或列表为空时不回退。列表编辑不影响已保存的历史。

推荐回复的「缓存与历史」可设置「最近推荐过期时间（分钟）」，默认 1 分钟，`-1` 永不过期、`0` 立即过期。仅在进入会话时限制尚未覆盖最新消息的推荐，已覆盖最新消息及停留期间正在显示的候选不因超时清空。因过期而没有候选时，推荐栏显示距上次推荐的时间，最多两个单位，满一分钟不显示秒；历史推荐仍可展开查看。

「缓存与历史 → 每会话保留的推荐轮数」默认 500，范围 0–10000，一轮包含一次生成的全部候选。改设置不立即删除历史；下次生成并保存新一轮时，按上限保留最近轮次并清理淘汰轮次的详情。0 只停止新增保存，已有历史仍可读取，当前推荐、缓存和本轮详情照常可用；未保存的本轮详情随当前缓存保留，不在重启后恢复。

## 数据库与资源

### 备份与恢复

应用备份或恢复默认设置前，会先等待已有请求结束；等待超过 15 秒时终止本次操作，显示仍未结束的请求，并恢复弹窗操作。此时尚未修改配置或数据，相关任务结束后可重试，不会强行中断原请求或在其仍运行时替换文件。

配置备份、读取与上传备份、预览及应用恢复、恢复默认设置均不向任务列表新增任务；操作进度、结果与错误直接在设置页或确认弹窗中显示。

「关于 WeQ → 配置备份与恢复」紧跟版本与更新，支持导出、导入及配置重置。Native 组件过期或损坏时，也可从组件诊断界面进入，不必先打开 QQ 账号。

- 备份范围可分别选择通用设置、账号配置与偏好、API 配置与凭据、克隆体与助手数据；账号和克隆数据域可单独勾选。「通用设置」下的「界面外观与布局」可独立排除。
- 备份为**未加密 ZIP**，可能包含 API 密钥、数据库密钥、克隆对话、记忆与参考语音，应存放在可信位置。不要作为问题反馈附件公开发送。它不是完整磁盘备份，不包含 QQ 原库、漫游 SQLite 缓存、本地模型、bot 运行入口或本机应用锁密钥。
- 桌面端选择文件保存／读取；Web 端分片上传 ZIP，导出后提供下载入口。单文件最多 64 MiB、总展开数据最多 256 MiB、归档最多 260 MiB、8192 项，超限会明确报错，不生成部分成功备份。同名输出文件不会被覆盖。
- 导入先选择范围和冲突策略，再查看预览并确认恢复。通用设置总会应用；账号、克隆或同 ID 的 API 项可选择跳过或覆盖。覆盖克隆数据域会替换该域，不合并对话。
- 跨机器重新选择 QQ 数据源后，数据域标识可能不同。可将来源映射到**同 QQ 号**的本机已有账号配置；这时保留目标账号的接入信息、密钥与运行凭据。多个来源不能同时映射到同一目标。
- 默认保留本机导出目录和外部图片库路径；如明确取消，可恢复来源设置中的路径引用。不会因缺少外部缓存根而创建替代目录。缺少的克隆素材、模型提供方或 QQ 装扮资源会提示，可能需要重新配置或获取。
- 确认后在当前进程内应用，无需重启桌面端或 Web 服务。请先保存正在编辑的内容；恢复会关闭当前账号，等待旧服务收尾，应用文件事务后通知各窗口与 Web 页面刷新。导出、模型下载或数据库修复在途时，会说明具体任务，请完成或停止后重试。
- 恢复失败会回滚；回滚未完成时保留原件与事务现场，并显示独立恢复错误，可重试，不能在混合数据上继续打开账号。恢复备份或恢复默认设置成功后直接显示原有业务页面，不再要求点击「继续」；应用、跳过与警告回执可在本设置页查看。旧版本遗留或中断后尚未应用的暂存，可在原位置直接「应用恢复」或取消；冷启动仍可接续恢复。
- 界面偏好在服务端提交后，由发起恢复的设备应用并确认。确认失败可重试，不重复覆盖后来修改的偏好。换设备时可明确改到当前设备恢复，或放弃这次界面偏好恢复；后者不会撤销已恢复的 WeQ 数据。

「恢复默认设置」统一恢复通用设置、界面外观与布局、联系人分组与排序、消息显示范围、搜索与日历显示偏好、默认进入账号、导出预设，以及所有账号的防撤回、群关键词提醒、意图感知、装扮选择、邮箱提醒、数据库容错和年度报告偏好。确认后立即应用并刷新界面，无需重启。「清除 API 配置」与「清除 WeQ 服务配置」提供两个同级开关，默认关闭以保留当前配置，并在开关下注明包含范围。API 配置包括模型、TTS、MCP、OneBot、外部 rkey、SSE 的配置与凭据；WeQ 服务统一恢复本次列出的 Web 服务、远程服务与连接模式、Tailscale 网络连接、系统登录自启、启动时显示窗口、Web 服务自动启动及 WeQ 助手服务设置，范围按本机实际配置显示，没有待重置配置时对应开关不可用。自定义目录仍逐项选择「保留当前」或「恢复默认」，默认保留。目录仅变更路径引用，不迁移或删除文件。会话置顶、免打扰、屏蔽、草稿、账号列表、克隆与助手内容及各类业务缓存保留；装扮资源与已安装清单、设备配对、网络身份和本机应用锁密钥同样保留。选择停用连接服务会断开对应的浏览器或手机连接。恢复默认、应用遗留暂存和界面偏好交接均使用居中确认弹窗，可取消或按 Esc 返回；处理中不能重复提交，失败原因保留在弹窗内供重试。

### 缓存与维护

「常规 → WeQ 存储管理」只管理 WeQ 自身数据与缓存的占用及清理；CDN 偏好位于「数据库与资源 → 资源加载」，桌面端与 Web 共用，默认关闭。开启后 QQ 头像、聊天图片和视频封面优先尝试 CDN 直链，仍沿用原有回退，不是全局离线开关。「空间清理」分别显示本页占用、普通缓存可清理大小和历史数据库备份占用。未勾选时只清理可重新下载或生成的普通缓存；收藏媒体、QQ 秀、共享装扮和装扮预览也支持清理。防撤回配置不再列入；清除意图分析、容错记录、克隆与助手数据、旧装扮资源时保留各自的应用设置和旧配置，配置文件也不计入这些项目的占用。

历史数据库备份置顶并默认展开，显示账号、数据库、备份时间、占用及修复记录关联状态。删除备份只移除该份文件、更新备份清除状态，保留修复记录与报告；修复记录在「数据库修复」中管理，不再提供整个修复工作区的清理。「历史程序修补备份」单独展示，不与数据库备份混淆。元数据不能确认归属的备份仅统计和定位。

识别结果、漫游记录、克隆与助手数据、导出、搜索索引、模型等与普通缓存分开。明确选择并确认损失后，先在当前进程清除可直接处理的项目，不默认重启；当前服务持有的配置、数据库等不会被直接删除。若剩余项目被占用，再单独询问是否「重启并继续清除」，且只重试被占用的剩余项目；取消重启保留这些项目，已完成的清理不撤销。权限、路径校验和读取失败会显示具体原因，不冒称重启即可解决。清除结果保留在存储管理中。

「关于 WeQ → 配置备份与恢复」只提供一个「恢复默认设置」入口，不再提供删除账号与应用配置、全局配置文件的按钮。原有配置备份包内容不变，不会将整个桌面运行目录加入备份。桌面磁盘、代码、GPU 与着色器缓存归入「常规 → WeQ 存储管理」；远程连接身份、Cookie、界面偏好、锁文件等运行状态不提供空间清理入口。闪传下载成品不参与空间清理，旧文件保留原位，可从下载任务定位或打开旧下载目录。

清理项目按用途合并：同类缓存跨目录显示为一行，桌面各类运行缓存合并为「桌面运行缓存」，同时保留来源路径；空项目和空分类不显示。数据库备份仍可按份选择，损失影响不同的数据分别列出。

清除备份会失去回滚能力，清除密钥配置需要重新配置，原图或云端内容已过期的数据可能无法恢复。由托管 QQ 等其他程序占用的项目需先退出对应程序。确认退出后清除时，请先停止正在进行的任务，等待自动重新打开应用，不要在清除期间手动启动。默认缓存清理不会包含风险数据。应用安装资源交给系统卸载，未知业务目录、符号链接与统计不完整的项目不开放删除。Web 页面仍可清理普通缓存，风险数据需回到电脑桌面端操作。

读取失败或统计不完整可以刷新重试。显示的是逻辑文件大小，不代表卷实际分配空间；其它 QQ 数据目录和任意外部导出目录不在这项统计内，「数据库与资源 → 资源目录管理」的 QQ 资源统计独立保留。托管 QQ 数据目录可能包含自己的本地聊天库和媒体，清除它们可能永久丢失记录，需先退出托管 QQ 并自行备份。

「数据库与资源 → 损坏与修复」管理损坏提醒并打开独立修复窗口；「数据库宽容」配置容错级别，摘要和记录弹窗展示实际降级与隔离，保留隔离表重试。可能丢数据的级别仍需要确认。

占用汇总和刷新位于列表上方，「开始清理」位于列表最下方。历史数据库备份固定置顶，其他分类和组内条目按占用从大到小排列；同量备份按时间从新到旧排列，未识别数据置底。展开分类可查看明细并定位文件。零占用且统计正常的项目不展示；`.DS_Store`、`Thumbs.db` 和 `desktop.ini` 不单列，仍计入总占用，不会因此删除这些文件。

原维护工具按用途归位：数据库浏览、表格、SQL 与编辑模式直接显示在「数据库管理」正文，工具栏「导出」打开公共明文导出面板，默认选中当前库，仍可在同一来源中扩选；取消后保留原浏览现场。「资源目录管理」（原「QQ 存储管理」）直接在正文提供占用概览、资源清理和资源浏览，共用扫描状态，清理确认及逐项结果也留在原页；密钥扫描位于「凭据管理」；QQ 登录账号工具位于「QQ 账号管理」。设置打开工具不关闭设置侧栏。资源查看按表情 / 头像 / 图片与视频 / 文件 / 语音 / 空间分组浏览 `nt_data` 资源，详见[本地资源页](database-view.md)。静态账号不可用的资源维护会禁用；清理和修复仍需选择与确认，打开分类或搜索结果不会直接执行。抓包与逆向解析位于「凭据与账号 → 诊断工具」，说明见[维护与诊断工具](wonderful-tools.md)。

扫描遇到读取失败或数量上限时，会保留部分统计并提示重新扫描，不把部分结果当成完整清理范围。清理只删除白名单目录内的普通文件，不跟随目录链接；空目录和链接保留，不影响主动下载文件或关联的外部原件。结果中的删除量是成功删除文件的逻辑大小，不代表磁盘实际可用空间增长；失败项单独计数，完成后统一刷新统计。

数据库修复的体检、修复、记录和回滚均在独立窗口内，默认使用系统边框，macOS / Linux 开启「使用仿 Windows 窗口按钮」后下次打开改用自绘标题栏。窗口跟随主界面主题和主题色，收起设置或账号返回首页不会卸载正在使用的修复界面；重复打开会聚焦原窗口，不会将其目标静默换成另一账号。应用锁定时隐藏修复内容，关闭主应用时一并关闭工具窗口。

## AI 功能

- 「API 配置」维护提供方、Base URL、API Key、模型能力与 TTS 语音合成服务，可从服务方拉取模型列表。不要在反馈中提供密钥。
- API 与 TTS 都可新建多套配置，包括同名、同厂商或同地址但密钥不同的配置。新建分配独立标识，编辑及重复保存沿用原标识，不覆盖其他提供方或改变已有克隆体的引用。模型选择按提供方分组，同名配置另附标识以区分，未选择的提供方不会自动接管调用。
- API 与 TTS 的连接测试在横幅中显示进度和结果，不锁住配置弹窗，也不自动保存配置。请求使用启动时的地址、凭据和模型；测试期间可修改、保存或关闭表单，未保存修改仍按原规则确认。同一配置的在途测试防重复，不同配置可独立测试；关闭设置后仍会完成原任务，失败不另弹对话框。TTS 成功生成的样例语音可从结果横幅重播。
- 对带温度参数的模型调用，若服务明确拒绝该参数或仅允许模型默认温度，会去掉 `temperature` 后重试一次，保留原配置值、模型和上下文。参数范围／类型、鉴权、限流和网络错误不会触发这种回退；两次实际请求在 API 用量中分别记账。助手已有正文、推理或工具片段后不重新生成。
- 「[意图感知](intent-sense.md)」按账号配置总开关、API / 本地引擎、分析上文与缓存，并在本页管理全局意图模型资源；单会话开关在会话头部的会话设置里。
- 意图模型资源仅在本地模式直接展示；“常驻显示”“悬停显示”及“批量分析时显示胶囊动画”位于意图感知的显示方式分区，旧高级设置搜索入口仍可定位。
- 「推荐回复」独立配置启用开关、API 模型、自己发送后推荐及推荐上文条数，不受意图感知开关或分析引擎可用性约束，也不使用本地模型生成或自动发送消息。
- 「语音识别」管理[语音转文字](voice-transcribe.md)的本地模型；「图片识别」独立管理 OCR 与筛图模型，并单独说明 QQ 在线 OCR。
- 图片识别的「识别并发」与语音识别的「转录并发」统一在设置中调整（1–32，默认 5）；开始导出时读取保存的值。导出对话框只保留本次识别、转写和在线功能开关，不再放置并发输入框或筛图模型下载项。
- 两页均将 QQ 在线能力与本地识别分别组织为独立卡片；在线卡片管理并发，本地卡片管理模型下载与删除，图片识别的文字模型与筛图模型按用途分组。
- 好友克隆从消息列表「+」创建；打开克隆体会话的「设置」可管理聊天模型、生成参数、额外提示、发言意愿、错别字、语音及记忆，并更新画像或删除克隆体。全局设置不再单列克隆页，训练时的检索与视觉模型保留原绑定，不直接替换已有向量。
- 「互动画像」独立启用，管理统计范围、采样与推断方式，可仅做本地统计，或选择本地／独立 API 模型；旧「跟随意图感知」在迁移时固定为当时选择，之后分别保存。
- 图片识别分别下载文字识别模型与筛图模型，下载完成即可使用，无需单独选用。图片灯箱和导出可复用；在线失败时能否本地回退取决于平台和已下载模型，不支持的平台会明确提示。
- QQ 在线 OCR 是 QQ 服务端能力，不是本地模型；不需要下载本地模型，但需要 QQ 在线及对应凭据。
- 「API 用量」显示当前账号的调用、token 和场景信息。

模型资源与旧配置迁移见[模型设置](model-resources.md)。

## 服务与更新

- [MCP](mcp-server.md)让外部客户端访问当前账号能力，注意工具的读写范围。
- 外部 RKEY 配置在本机在线凭据不可用时补充媒体下载票据；测试只验证连通性，不保证所有媒体仍可下载。
- SSE 向配置目标发送消息事件，测试按钮会真实发送测试事件。地址与 token 属于敏感配置。
- 外部 RKEY 与 SSE 测试也使用后台横幅；切换编辑目标不会把前一配置的迟到结果写进当前表单。
- QQ 公众号推送位于「WeQ 服务」的独立二级页，沿用既有开关与端口，资源只在 WeQ 运行期间提供；完全退出后不再提供新请求，QQ 已缓存的内容可能仍显示。版本检查复用应用内更新，不再提供退出后的独立版本轮询。
- 各服务的运行状态、地址、开关与端口在各自的管理页查看和配置。
- “关于 WeQ”分为「版本与更新」「配置备份与恢复」「常见问题」「日志」「反馈」。版本信息、软件更新与更新提醒集中在同一页；日志页同时提供保留时长设置和日志查看器；反馈页保留原反馈表单与提交入口。旧帮助入口转到常见问题，旧更新提醒入口转到版本与更新。Web 不提供桌面应用自替换；原生组件兼容或过期问题以当前界面提示处理。
- 日志页切走或窗口隐藏时停止读取，返回后保留所选文件、等级筛选、暂停跟随和滚动位置，并补读离开期间新增的内容；文件被截断时重新载入，不擅自恢复跟随。暂停跟随只暂停自动滚到最新位置，不代表停止读取文件。
- 更新下载完成后可点击「重启并安装」，安装退出不受“关闭时询问／最小化到托盘”偏好拦截。按钮会显示「正在重启」并避免重复提交；系统准备或安装失败会显示原因，可重试安装，不必先重新下载。开发版仍只支持检查更新。
- 「版本与更新 → 软件更新」可设置自动检查更新频率，单位为分钟，默认 60，正数不设上限（支持小数），`-1` 表示永不。保存后立即重新计时；安装版启动后仍会延迟检查一次，设为 `-1` 时也关闭启动检查，手动检查不受影响。开发版不自动检查。
