# 导出中心

左栏点 **导出** 进入导出中心。布局是「左侧导出模式 + 右侧选择面板 + 下方任务列表」。

```
┌──────────────┬───────────────────────────────────────────┐
│ 导出模式      │ 选择面板（会话 / 数据库 / 格式 / 选项）     │
│  · 聊天消息   ├───────────────────────────────────────────┤
│  · …         │ 任务列表（进度 / 日志 / 失败 / 暂停 / 删除）│
└──────────────┴───────────────────────────────────────────┘
```

## 1. 聊天消息导出

选格式 → 选会话（支持全选 / 反选 / 清空 / 搜索，每行显示消息数）→ 打开灯箱细项 → 开始导出。

### 格式

| 格式 | 说明 |
| --- | --- |
| JSON | 结构化 |
| JSONL | 每行一条 |
| XLSX | Excel 表格 |
| CSV | 逗号分隔表格 |
| TXT | 纯文本 |
| HTML | 网页（会自动下载配图到 `media/` 并本地引用） |

### 灯箱细项

**时间范围**：全部时间 / 今天 / 近 7 天 / 近 30 天 / 近一年 / 自定义。

**内容选项**：

| 选项 | 说明 |
| --- | --- |
| 导出媒体 | 媒体文件随消息一起导出；开启后可按类别筛选 |
| 　媒体类别 | 图片 / 语音 / 视频 / 文件·群文件 / QQ 系统表情 |
| 消息补全 | 扫描 seq 空窗，从 QQ 服务端拉取本机缺失的消息（**需在线 QQ**） |
| 导出头像 | 导出发送者头像 |
| 补全媒体 | 重新下载本地缓存里没有的媒体（需 rkey） |
| 补全装扮 | 下载本地未缓存的装扮资源（关掉时只导出已缓存部分） |
| 导出装扮资源 | 气泡 / 字体 / 挂件（只导出会话实际用到的款） |
| 语音转文字 | 自动把语音转成文字（需已配置离线模型，见[语音转文字](./voice-transcribe.md)） |
| ChatLab 交换格式 | 仅 JSON / JSONL 可选 |
| 自动保存 | 导出完成后自动弹保存路径（不记忆上次目录） |

**空间互动**（好友空间导出时）：按 tid 补全评论 + 点赞（best-effort）。

## 2. 频道私聊数据

导出本地频道私聊记录，使用与完整消息相同的格式，但**不支持漫游拉取**。

## 3. 解密数据库

选数据库文件 → 选导出路径 → 把加密的 SQLite 解出为**原始 sqlite** 供研究。解密有两种强度：

- **安全保存**：更稳妥；
- **快速解密**：更快。

## 4. QQ 空间导出

导出好友或自己的空间说说。

格式：JSON / TXT / HTML（HTML 会强制把配图下载到 `media/` 并本地引用）。

## 5. 导出联系人

| 子项 | 格式 |
| --- | --- |
| 好友列表 | JSON / JSONL / CSV / XLSX / TXT / **vCard** |
| 群成员列表 | JSON / JSONL / CSV / XLSX / TXT |

## 6. 导出收藏

把 QQ 收藏导出为表格：JSON / CSV / XLSX / TXT。图片只写 CDN URL，不下载。

## 7. 定时导出任务

和「聊天消息导出」相同的选择与灯箱，额外多一个**定时设置**：

| 模式 | 参数 |
| --- | --- |
| 每天定时 | 指定 HH:MM |
| 间隔执行 | 指定间隔小时数 |

- 模板可多选导出格式；
- 预设时间窗（如「近 7 天」）在**每次触发时**重新计算，所以会自然向前滚动；
- 任务列表显示下次运行时间与历史触发记录（完成 / 部分 / 失败 / 跳过 / 取消）。

> [!tip]
>
> 「补全缺失消息」需要在线 QQ 且未开启完全离线模式。若离线运行，会提示只能读取本地缓存库中
> 的漫游消息。

## 8. 群相册导出

选群 → 在灯箱里选目录 / 相册 / 时间范围 → 批量下载相册媒体。

## 9. 群文件导出

选群 → 浏览群文件目录树 → 批量下载。

## 10. 商城表情下载

搜索并批量下载商城表情包：

- 按来源筛选：免费 / 付费 / VIP / SVIP；
- 分页浏览包目录，点包查看该包表情；
- 批量下载。

## 11. 任务列表

所有导出都是任务形式，列表里能看到：

- 任务名与目标；
- 进度条与实时日志；
- 失败明细（可打开失败灯箱查看每条失败原因）；
- 暂停 / 继续 / 删除任务。
