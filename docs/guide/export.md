# 统一导出

任务列表顶部的「清除已完成」可批量移除成功任务。确认框显示本次项目数，并单独提醒尚未保存的导出结果；失败、取消、暂停和进行中任务不清除。清除会移除任务记录与导出缓存，但不删除已保存文件、克隆体或聊天记录。

从左下角菜单选择 **导出**，依次确认内容种类、对象、范围与格式，保存方式沿用全局设置。会话/消息右键、内容多选或页面导出按钮也进入同一流程，并带入对应选择；每次只导出一种内容。

单会话入口与消息多选入口直接打开导出配置，固定沿用会话或精确消息 ID，不再经过会话与消息范围选择器。消息多选不再额外选择时间范围；仍可配置格式、媒体和保存方式。

工具内调整的是独立草稿，不改变内容页多选。新一轮选择会更新带入范围；相同选择关闭重开保留工具内调整。确认后固定本次目标，等待目录时再改草稿不会改变已确认任务。切号会丢弃旧草稿。

## 保存方式

保存方式只有「每次询问保存位置」「自动保存到默认文件夹」，使用分段控件切换。旧版“稍后保存”默认偏好改为每次询问，保留已有默认目录；旧任务产物仍保留，未保存结果需要重新选择位置。没有默认文件夹时，启用自动保存会先选择文件夹，取消不启用。

通用保存入口只保留一个按钮，不再提供箭头菜单或页面临时保存方式。按钮行为仅由设置中的「每次询问」「自动保存」决定，进入多选也不展开保存设置。所有新任务在开始前确定位置，取消选择不创建任务，也不改变全局偏好。

「每次询问」弹出位置选择，初始目录依次使用上次同类保存位置、设置中的默认文件夹、桌面；确认后记住同类位置，取消不改变记忆。「自动保存」直接使用默认文件夹，不受历史选择影响；未配置或默认文件夹不可用时明确报错，不弹选择器、不改存其他位置。

位置准备和任务创建绑定点击时的账号与数据源。等待期间切换账号或同号配置会停止旧操作，不把旧位置、格式或精确范围用于新来源；批次已创建的任务保留，未创建的目标停止。

Web 的通用保存按钮保存至服务器：每次询问时输入服务器导出根内的子目录，自动保存不弹位置选择。任务列表中的「下载到浏览器」是已生成结果的取回入口，本机位置由浏览器决定。

统一任务入口在生成前按实际产物选择保存框：单文件可指定文件名，整包、多格式或多个对象选择文件夹；头像、媒体、HTML、OCR／转写与装扮等实际附加产物也参与判断。

导出工具的群相册、群文件确认窗也只提供一个导出按钮并沿用统一保存偏好；内容先进入后台任务缓存，再保存到指定位置。完成包内的 `files/` 保存实际资源，`resource-results.json` 记录成功数量与失败文件，任务报告单独保留。同名相册使用不同目录。取消位置选择保留当前选择、不建任务；部分下载失败的任务仍可保存成功资源并查看失败清单。

资源任务目前不支持中断续传：暂停、取消或进程退出后，未完成的资源需要重新选择并建任务；已经完成的其他任务结果不受影响，重启后仍可另存。商城单张表情、邮件附件、气泡／字体／挂件另存、个人空间相册、年度报告、聊天媒体和群文件单个保存已接入公共保存；资源管理页其余已有保存入口仍在逐项盘点迁移。

没有交互界面的后台任务不能弹出系统选择器：如果采用询问模式、又没有准备过本次位置，会先生成并保留在任务列表中，等待用户保存，不改写全局偏好；已配置默认文件夹的自动保存不受影响。

## 1. 聊天消息导出

选择格式与会话，可搜索、全选或清空；行末范围按钮一次编辑一个会话的消息。大量选择不会同时加载所有消息选择器，窄屏关闭范围后返回会话列表。

支持 JSON、JSONL、XLSX、CSV、TXT、HTML；HTML 随包保存配图，JSON/JSONL 可选 ChatLab 交换格式。

普通私聊与群聊任务按消息保存续作进度。QQ 继续写入数据库、WAL 或漫游缓存变化不再阻断续作；已记录的消息保留，继续时补入当前范围内尚未记录的消息。选项变化会重新生成受影响格式，不把旧格式断点当成新结果。

- 暂停只停止后续工作、保留消息断点，不自动收尾。可直接继续；需要文件时点「收尾」，显示「收尾中」，完成后可「保存现有进度」。JSON、HTML、表格不会把半截写入当成完整结果。
- 已确定保存位置时直接写入该位置，不再生成整份缓存后复制。单文件采用独占命名，整包放在任务独立子目录，不覆盖已有同名文件。开始时目标不可写会保留缓存结果供重新选择；已经直写的目标消失后需要恢复原位置，不创建失效目录的替代位置。
- 完成任务的「增量导出」补入未记录的消息，并重建所选格式。它是追加式归档，不会同步删除或覆盖已归档的旧消息；后补的历史消息排在已归档记录之后。会扫描来源以发现早期空缺，不仅按最新时间截断。
- 配置窗口可选择「增量基线文件夹」，只校验会话，允许扩大或更换本轮读取范围；原基线消息始终保留，新结果写到本次位置，不回写原基线。同一消息内容不同会保留旧内容并提示，合并序号出现可疑缺口时也会提醒，不阻断导出。
- 可以选择包含多份导出的上级文件夹。选择界面直接列出导出名称、会话、粗略条数、格式、范围、更新时间和记录大小；唯一匹配项会预选，多个匹配项需明确选定，未找到时可新建或重新选择。批量会话可分别选基线或新建。
- 任务详情里的独立阶段可逐项跳过，如头像、某类补全、OCR 或转写；运行中跳过会先保存进度再继续其他工作。正文阶段不可跳过，用户跳过的项目写入完整性报告。

- 合并转发递归包含内部正文、媒体路径与系统表情。本地缓存缺失时，开启「补全缺失消息」且 QQ 在线可复用在线接口补取；离线、过期或服务端失败仍保留卡片，报告标记未展开数量，不宣称内容完整。

暂停或跳过时会停止后续工作；已进入的不可取消请求或原生操作需要先返回，期间显示「暂停中」。只有明确点击收尾才显示「收尾中」，不会提前另存仍在写入的文件。

官方语音转写抓包、受限状态下的漫游拉取或在线识别等项目需要授权时，当前配置窗口标题栏显示「需要提权」。直接开始导出会打开提权弹窗；可以授权，也可以「跳过需提权项目」后导出其余内容。密码表单复用系统授权通道，不在配置开关阶段提前启动抓包。

批量导出统一提供「附带完整性报告」选项，默认关闭，覆盖聊天记录、频道私聊、空间、联系人、收藏、生成对话、邮件、群文件、群相册、空间相册、商城／自定义／收藏表情以及多份数据库导出。有配置弹窗时直接在其中选择，其他批量入口使用统一确认弹窗；取消后不创建任务。勾选后生成 JSON 和 HTML，任务里的报告按钮优先打开 HTML，另存结果时两种报告都会保存。定时导出沿用创建时的报告选择。普通单文件下载不自动附带报告，下载失败仍在任务详情及资源结果清单中记录。报告展示内容冲突、可疑序号缺口、阶段状态及失败信息，不把序号空窗冒称为已证实的消息丢失。

目标位置中的 `.weq-export-*`（单文件）或 `.weq-export/`（整包）是后续续作与增量所需的消息记录，不是待搬运的暂存包；不要在仍需续作时单独删除。删除任务只清理应用缓存，不删除直接写入的目标文件。频道私聊及其他资源任务不因此获得消息级续作能力。

| 选项 | 作用 |
| --- | --- |
| 时间与内容范围 | 全部、时间预设或自定义；精确消息集合不退化为连续日期 |
| 导出媒体 | 按图片、语音、视频、文件、系统表情等类别保存 |
| 消息补全 | 在线扫描候选 seq 缺口，不保证服务器完整历史 |
| 补全媒体/装扮 | 尝试取得本地缺失资源，依凭据、权限和远端可用性而定 |
| 导出头像/装扮资源 | 保存会话使用的头像、气泡、字体或挂件 |
| 语音转文字 | 使用已配置的[离线语音模型](voice-transcribe.md) |
| 图片文字识别 | 在线优先或本地回退，取决于在线状态与已下载模型；可先筛除无文字图片 |

图片识别结果写入消息和 `ocr.json`，已缓存的同图结果可复用。在线图片链接可能过期，有链接不代表能成功识别；具体模型和平台限制见[设置](settings.md#ai-功能)。

普通聊天支持立即导出和定时执行；精确选择的不连续消息仅支持立即导出，不会扩大为定时整会话范围。

## 导出查看器

工具菜单的「导出查看器」支持 WeQ 导出文件夹与聊天 JSON/JSONL，暂不支持 HTML、TXT、CSV、XLSX 等文件。文件夹优先读取配套消息日志，避免把同一会话的 JSON 重复列出；没有基线的旧文件夹也可识别当前目录内的聊天 JSON/JSONL。父文件夹可以列出多份带基线的导出。

选择的文件夹不是导出目录时，会自动扫描下一级文件夹；仍未找到时询问是否递归扫描。递归不跟随符号链接，最多检查 4096 个目录、列出 64 项，受限或有目录无法读取时会提示列表可能不完整。文件与文件夹选择各自记忆上一次位置。

同次最多打开 64 份导出。目录探索沿用基线目录的有界扫描，不无限递归；目录或文件过多时会提示选择更具体的位置。

列表展示名称、会话、粗略条数、格式、大小和北京时间更新时间。消息每页最多 100 条，可搜索或按北京时间日期筛选；合并转发逐层展开，目录内已有图片、音频、视频可预览，其他附件可在文件管理器中定位。查看不会修改原文件、抓包或自动联网补全媒体。

当前账号存在同类型、同标识的会话时，可「打开会话」或定位本机已有的原消息；嵌套转发内部不提供原会话跳转。消息已不存在或没有有效序号时会提示，不按昵称猜测位置。有唯一配套基线时可「增量导出」，进入原有配置流程并预填基线，允许调整范围；旧文件缺少会话标识或基线时，相应操作不可用。新 JSON/JSONL 会写入明确的会话标识，旧私聊文件可能只能离线查看。

WeQ 的 ChatLab JSON/JSONL 也可查看，但导出时已转成文本的媒体和转发内容不会恢复成原有结构。

JSON 单文件上限 64 MiB，超限时请选择同份导出的 JSONL 或消息日志。JSONL 流式读取，单行上限 8 MiB；过深或过长的消息显示明确的截断提示。当前查询会扫描消息以统计匹配条数，大文件首次读取或筛选可能需要等待。读取期间文件变化会要求重新打开，不把混合版本显示成完整快照。

## 克隆与助手对话

读取当前账号已保存的克隆私聊、克隆群聊及助手会话，支持整场或精确消息集合。尚未持久化的流式回合不可选；所选消息消失时明确失败，不退回整场。

支持 JSON、JSONL、TXT、CSV、XLSX，保留本地生成来源、角色及工具过程，不伪装成 QQ 记录，不支持 ChatLab 或漫游补全。确认后保存独立正文快照；源会话变化或删除不改写任务，暂停/重启后可按原快照重新执行。

已知本地语音、表情与已完成的助手附件随包保存在 `resources/`，资源清单记录消息对应、相对路径、校验和缺失原因。任务提示 **已完成 · 资源缺失** 时正文仍可保存，详情可查看失败文件。

HTML/Markdown 附件的外链不自动抓取，因此不承诺整个包已完全离线。暂停后复用并校验已有资源，不再次调用模型；删除任务不删除已经另存的结果。格式与资源契约见[开发说明](../develop/generated-content-export-20261018.md)。

### 助手附件卡片

卡片只提供一个「保存」按钮并沿用全局偏好。已有导出卡片只保存原任务，不重新导出；报告附件把现成文件纳入保存任务，不再次调用模型。取消选择不创建任务，已生成的结果仍保留。

排队或创建任务不等于文件已经保存，卡片会显示处理与保存状态；保存成功后提供打开结果与在文件夹中显示。再次保存失败仍显示上次保存位置，重试优先复用完整任务缓存；用户已删除报告保存任务后，也可从仍保留的原报告重新创建。

Web 卡片的保存按钮保存至服务器，需要本机文件时从任务列表下载已生成结果；本机下载位置由浏览器控制，不触发重新生成。

## 2. 频道私聊数据

导出本地频道私聊，格式与普通聊天相同，但不支持漫游拉取。可从正文多选带入消息，也可在工具内编辑范围；全选只包含已加载候选，后续加载不自动扩选。

消息 ID 集合固定到任务，不叠加旧日期预设，不将空集合转为全部；媒体、装扮和各格式共用同一范围。

## 3. 解密数据库

从「设置 → 数据库与资源 → 数据库管理」的工具栏导出时，公共面板默认选中当前库，并绑定当时的账号与配置来源；扩选只使用该来源的库清单。取消回到原浏览现场，提交后由同一套后台任务继续管理。单独从公共导出入口进入时仍由用户选择数据库，不自动导出全部库。

保存位置尚未返回时切源或关闭面板，不会继续创建旧目标任务。任务请求已经发出后，离开面板不取消已建立的后台任务；结果仍在任务列表管理。同一来源隐藏期间收到成功回执后，返回时会同步任务状态，不再保留那次已提交的勾选。

选择数据库后，安全保存与快速解密各保留一个按钮并沿用全局保存偏好。单库使用 `.db` 文件保存框，多库选择文件夹，结果进入后台任务，完成后可继续保存；Web 端从任务列表取回已生成结果。

安全模式更稳妥，快速模式可按库大小回退安全实现；QQ 在线时仍需确认快速模式风险。暂停或取消会停止后续数据库，已开始的原生解密需要先返回，再清理未完成包，不提供中断续传。多库部分失败时，只保留成功文件与失败清单；单库失败不会作为可保存的完整文件发布。

明文副本可能包含全部聊天数据，应保存在受控位置。后台任务会保留明文缓存供另存；删除任务清理该任务的缓存，不删除已另存的副本，也不改动原加密库。

## 4. QQ 空间导出

导出自己或指定空间的说说，支持 JSON、TXT、HTML。空间页的导出按钮进入同一工具；精确多选使用空间 UIN 与 tid，不要求对象必须是好友。

在联系人选择页使用「空间｜都导出｜相册」分段选择内容，「都导出」位于中间。可单独导出说说、单独导出相册，或在一个任务和空间包中同时保存两者；输入 QQ 号可添加名册外的目标空间。相册按上传时间筛选，单独选择相册时不读取说说，也不受旧说说多选范围影响。

联合导出保留原说说历史捕获与多格式流程，相册索引保存到 `albums/index.json`，所选 TXT／HTML 格式也生成对应相册索引。两部分共同引用包内 `media/`：相同 URL 合并下载，不同 URL 下载后按实际内容校验和复用同一文件；原图、缩略图或不同视频内容不会因地址相似而误合并。索引保留相册归属、媒体原地址、本地路径和失败原因，视频只能取得封面时明确记录，不作为完整视频计数。

精确任务只读所选 tid 的详情、互动及媒体，不扫描整空间或混入旧缓存；空集合、删除/无权或身份不匹配会报错。整空间导出保留分页、日期与历史捕获能力，正文仍截断或媒体缺失会记入覆盖报告。

多格式共用读取结果，条数不重复相加。暂停/重启后按原 tid 重新读取服务器，**不是不可变正文快照或字节断点**。

## 5. 导出联系人

联系人名单、群聊名单和群成员名单支持 JSON、JSONL、CSV、XLSX、TXT；好友另支持 vCard。

联系人页面工具栏的「导出名单」菜单提供「导出联系人名单」「导出群聊名单」；群聊右键菜单也可直接打开「导出群成员名单」。它们都进入同一个导出工具，通过名单范围区分用途，不会将群聊名单误当成成员或聊天记录。

群聊名单默认导出全部本地群资料，也可精确选择群。表格包含群号、群名称、群备注、成员数、人数上限、群主 UID、创建时间（北京时间）和离群原始标记；未缓存的字段不补猜。此模式不下载联系人头像，数据范围是当前本地资料目录，不等同于已核验的在线在群名单。

默认可按好友分组或整群导出，也可从内容多选带入精确 UID。精确模式中搜索和分组只用于查找，不追加未选联系人；筛选外已选项保留，空集合禁用提交。

多个群各建独立成员任务，不因全选群就预读所有成员。确认后固定 UID 与格式，身份消失明确报错；多格式共用一次读取，同名任务不覆盖。暂停或失败后使用 **重新执行**，按原目标重读资料，不冒充断点继续。成员时间按北京时间显示。

## 6. 导出收藏

支持 JSON、CSV、XLSX、TXT，可从收藏页带入全部、筛选结果或当前 CID。在线尝试补详情和已声明附件，离线使用缓存；附件放入 `media/`，报告区分摘要、详情、原件、预览和未取得内容。

按 CID/类型筛选时不附带其它收藏的整账号原始响应。搜索、日历与精确范围共用原消息读取规则，不用时间区间近似离散集合。

## 7. 定时导出任务

在聊天导出选择 **定时执行**，配置每天时刻或间隔小时。定时是执行方式，不是内容种类，目前不适用于所有导出来源。

时间预设在每次触发时重新计算。在 **任务 → 定时任务** 查看下次运行及触发记录，可暂停、启用、立即执行或删除。需要补全时仍须满足 QQ 在线和当前账号条件。

## 8. 群相册导出

选择群、相册和时间等范围，批量下载媒体；可用范围以实际相册权限为准。

## 9. 群文件导出

选择群并浏览目录树，再下载所选目录或文件；过期及不可访问项单独报告。

## 10. 商城表情下载

从左栏 **个性装扮 → 商城表情** 搜索、按免费/付费/VIP/SVIP 筛选并批量下载。商城目录与已下载资源不是同一范围，详见[表情资源](emoji-resources.md)。

## 11. 导出表情包

自定义表情分“我的表情”和“收到的表情”。本地原图优先，可用在线地址尝试补全，缺原图时可能使用缩略图；统计会区分原图、缩略图和缺失。结果按来源分目录，完成后从任务保存。

## 分析长图、机器人与空间相册

通用导出新增「机器人」，相册合入原有「QQ 空间」项；分析长图仍属于分析工具和报告页：

- **分析长图**：选择好友、群聊或群成员及时间范围，生成预览后保存为 PNG。原分析报告内的「保存为图片」使用同一公共保存流程；取消位置选择不捕获图片，确认后固定当前统计数据并创建后台任务。捕获失败可在任务详情查看，已完成的长图可继续另存。当前长图捕获仍需桌面图片导出桥接，独立 Web 不提供该能力。
- **机器人**：选择已有克隆体，配置 NapCat／SnowLuma 连接、QQ 号、端口与模型等，生成独立 OneBot 部署包。原克隆体设置中的导出入口保留，使用同一表单与后台任务；保存跟随全局偏好，取消不生成产物，任务创建不表示已经保存完成。包内 `files/` 包含引擎、配置、README 和 persona 资源。
- **空间相册**：与说说共用目标联系人、内容分段、时间配置及后台任务，不再作为独立内容种类；原空间页的相册浏览和精确媒体保存入口保留。

机器人和空间相册的批量导出可选择附带完整性报告。三种内容的结果统一由任务列表管理，不改变聊天导出的续作或定时范围。

## 12. 任务列表

左下角菜单上部直接显示当前任务列表，点击任务或标题旁的展开按钮打开完整面板。左侧提供「当前任务／定时任务」两个页签与列表，右侧显示所选任务的步骤和操作，或所选计划的设置。「当前任务」聚合当前账号的导出与保存、漫游拉取、好友克隆和闪传下载，进行中的任务优先；完成、失败和暂停记录仍保留。收起面板或切换页签保留选中项，不取消后台执行；原有暂停、继续、重新执行、保存和删除操作仍可使用。

定时任务右侧可以修改名称、执行方式、时间或间隔及导出格式，保存后更新原计划；启用、暂停、立即运行、删除和最近触发结果仍独立展示。导出对象与保存策略不会因修改这些设置而扩大或重置；新建计划继续通过导出配置选择对象和范围。每天执行的时刻按运行设备的时区解释，下次执行和历史触发日期按北京时间显示。

漫游进度只表示候选 seq 的实际覆盖量，不把已发出的请求当作成功，也不证明全部历史完整。无法确定总量时使用不定进度，不伪造百分比。定时计划的「已启用」表示允许触发，不代表正在执行；触发后的实际执行记录在「当前任务」查看。

已完成任务的「保存」同样沿用全局保存偏好。询问模式按真实产物选择保存框：单文件可指定文件名，完整性报告作为 `.report.json` 旁附文件保存；多文件包选择文件夹。明确指定的文件名与已有文件或报告冲突时，需要重新选择名称；由默认或本次文件夹自动生成的文件名会避让重名，不覆盖原件。不支持硬链接的磁盘使用独占流式复制，校验通过后才报告成功，复制期间目标文件可能已经可见。取消保存保留结果，批量保存中取消会停止后续选择，不计为任务失败。

保存成功后，桌面端提供「打开保存结果」「在文件夹中显示」。再次另存失败时仍可打开上一次成功保存的结果。Web 的保存位置是服务器目录，本机下载位置仍由浏览器控制。

“执行完成”不等于内容完整。保存前应核对缺失资源与覆盖报告；统一长任务尚未覆盖所有下载和生成来源。
