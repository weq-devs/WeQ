# 导出中心

左栏点 **导出** 进入导出中心。布局是「左侧导出模式 + 右侧选择面板 + 下方任务列表」。

```
┌──────────────┬───────────────────────────────────────────┐
│ 导出模式      │ 选择面板（会话 / 数据库 / 格式 / 选项）     │
│  · 聊天消息   ├───────────────────────────────────────────┤
│  · …         │ 任务列表（进度 / 日志 / 失败 / 暂停 / 删除）│
└──────────────┴───────────────────────────────────────────┘
```

## 1. 聊天消息导出

选格式 → 选会话（支持全选 / 反选 / 清空 / 搜索，每行显示消息数）→ 打开灯箱细项 → 开始导出。

### 格式

| 格式 | 说明 |
| --- | --- |
| JSON | 结构化 |
| JSONL | 每行一条 |
| XLSX | Excel 表格 |
| CSV | 逗号分隔表格 |
| TXT | 纯文本 |
| HTML | 网页（会自动下载配图到 `media/` 并本地引用） |

### 灯箱细项

**时间范围**：全部时间 / 今天 / 近 7 天 / 近 30 天 / 近一年 / 自定义。

**内容选项**：

| 选项 | 说明 |
| --- | --- |
| 导出媒体 | 媒体文件随消息一起导出；开启后可按类别筛选 |
| 　媒体类别 | 图片 / 语音 / 视频 / 文件·群文件 / QQ 系统表情 |
| 消息补全 | 扫描 seq 空窗，从 QQ 服务端拉取本机缺失的消息（**需在线 QQ**） |
| 导出头像 | 导出发送者头像 |
| 补全媒体 | 重新下载本地缓存里没有的媒体（需 rkey） |
| 补全装扮 | 下载本地未缓存的装扮资源（关掉时只导出已缓存部分） |
| 导出装扮资源 | 气泡 / 字体 / 挂件（只导出会话实际用到的款） |
| 语音转文字 | 自动把语音转成文字（需已配置离线模型，见[语音转文字](./voice-transcribe.md)） |
| 图片文字识别 | 自动识别图片里的文字：写进 `ocr.json`（含每行文字的像素坐标框），并把文字回写进导出文件 |
| 　在线识别 | 勾了「图片文字识别」后出现：优先让 QQ 服务端识别（需 QQ 在线），失败 / 过期的回退本地模型 |
| 　识别并发 | 同时向 QQ 服务端发起的识别请求数（默认 5；连续失败 10 张会自动放弃在线） |
| ChatLab 交换格式 | 仅 JSON / JSONL 可选 |
| 自动保存 | 导出完成后自动弹保存路径（不记忆上次目录） |

**图片文字识别**的开启条件是二选一：QQ 在线，或者已下载本地识别模型。开启后：

- **预筛选**：先用超轻量的筛图模型（1.7 MB）甩掉风景 / 人像这类没有文字的图，再送识别
  —— 强烈建议开（识别是导出里最慢的一步）。没下载时面板里可以直接下载，下完自动设为当前模型。
- **在线识别**（可选）：让 QQ 服务端识别，从最新的图往旧的试（QQ 图片链接约 9 天过期）；
  连续失败 10 张就判定在线那条腿不可用，剩下的全部回退本地模型。
- 结果分两处：`ocr.json`（文件名 → 文字 + 坐标框 + 来源），以及消息文件里
  `[图片: 名字]` 锚点回写成的文字（HTML 是图片下方那行小字换成识别结果）。
- **同一张图只识别一次**：结果按图片 md5 缓存在本机（灯箱里点过「识别文字」、MCP 问过、
  以前导出过都算），命中就整条流水线都不用跑；服务端副本已过期（QQ 图片链接约 9 天寿命）
  的图只要以前识别过，也还能出文字。

**空间互动**（好友空间导出时）：按 tid 补全评论 + 点赞（best-effort）。

## 2. 频道私聊数据

导出本地频道私聊记录，使用与完整消息相同的格式，但**不支持漫游拉取**。

## 3. 解密数据库

选数据库文件 → 选导出路径 → 把加密的 SQLite 解出为**原始 sqlite** 供研究。解密有两种强度：

- **安全保存**：更稳妥；
- **快速解密**：更快。

## 4. QQ 空间导出

导出好友或自己的空间说说。

格式：JSON / TXT / HTML（HTML 会强制把配图下载到 `media/` 并本地引用）。

也可从原生 QQ 空间页顶部的导出按钮打开；好友空间导出当前好友，其它栏目导出自己的说说。导出会按需补取截断正文及缺失附图，保留转发原文和媒体。详情失败、仍截断或媒体未取得时保留可见内容，并在覆盖报告中记录，不把已观察内容当作完整历史。

## 5. 导出联系人

| 子项 | 格式 |
| --- | --- |
| 好友列表 | JSON / JSONL / CSV / XLSX / TXT / **vCard** |
| 群成员列表 | JSON / JSONL / CSV / XLSX / TXT |

## 6. 导出收藏

把 QQ 收藏导出为表格：JSON / CSV / XLSX / TXT。也可从收藏查看弹窗顶部导出全部、当前筛选结果，或在详情中只导出当前收藏。

在线时复用收藏详情、图片 / 音频及文件 / 视频附件获取链路，离线时只复制已缓存附件。表格含本地附件相对路径，附件置于 `media/`；覆盖报告区分已取得、未取得、原件、预览和质量未核验。按 CID 或类型筛选时不附带其它收藏的整账号原始响应。

聊天导出的会话列表不再限制条数，支持搜索、全选和反选，列表只渲染可视区域。时间范围与聊天搜索、日期跳转共用七级消息密度日历，日期均按北京时间计算；多选导出时按所选会话合计每日消息数。

## 7. 定时导出任务

和「聊天消息导出」相同的选择与灯箱，额外多一个**定时设置**：

| 模式 | 参数 |
| --- | --- |
| 每天定时 | 指定 HH:MM |
| 间隔执行 | 指定间隔小时数 |

- 模板可多选导出格式；
- 预设时间窗（如「近 7 天」）在**每次触发时**重新计算，所以会自然向前滚动；
- 任务列表显示下次运行时间与历史触发记录（完成 / 部分 / 失败 / 跳过 / 取消）。

> [!tip]
>
> 「补全缺失消息」需要在线 QQ 且未开启完全离线模式。若离线运行，会提示只能读取本地缓存库中
> 的漫游消息。

## 8. 群相册导出

选群 → 在灯箱里选目录 / 相册 / 时间范围 → 批量下载相册媒体。

## 9. 群文件导出

选群 → 浏览群文件目录树 → 批量下载。

## 10. 商城表情下载

搜索并批量下载商城表情包：

- 按来源筛选：免费 / 付费 / VIP / SVIP；
- 分页浏览包目录，点包查看该包表情；
- 批量下载。

## 11. 导出表情包

把本地自定义表情导出成一个图片文件夹，分两种来源：

| 来源 | 数据源 | 策略 |
| --- | --- | --- |
| **我的表情** | emoji.db 收藏 / 添加记录 + `personal_emoji` 目录 | 本地有原图直接导出；没有原图但库里有在线地址就**下载补全**；下载不到再退到缩略图；都没有才放弃 |
| **收到的表情** | `emoji-recv/<月>/{Ori,Thumb}` 目录 | 有原图导原图，只有缩略图的用**缩略图补一份**（thumb → ori 补全） |

- 面板顶部两张来源卡：显示各自的原图 / 缩略图 / 可下载 / 缺失统计 + 预览小格；
- 勾选来源后「导出」起一个任务，走「扫描表情 → 补全原图 → 导出图片」三段进度，
  每段都有独立进度条与滚动日志；
- 产物是 bundle 下的「我的表情 / 收到的表情」两个子文件夹，完成后在任务列表
  「保存文件夹…」保存到本地。

## 12. 任务列表

所有导出都是任务形式，列表里能看到：

- 任务名与目标；
- 进度条与实时日志；
- 失败明细（可打开失败灯箱查看每条失败原因）；
- 暂停 / 继续 / 删除任务。
