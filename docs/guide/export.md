# 统一导出

从工具按钮选择 **导出**，依次确认内容种类、对象、范围、格式与保存方式。会话/消息右键、内容多选或页面导出按钮也进入同一流程，并带入对应选择；每次只导出一种内容。

单会话入口与消息多选入口直接打开导出配置，固定沿用会话或精确消息 ID，不再经过会话与消息范围选择器。消息多选不再额外选择时间范围；仍可配置格式、媒体和保存方式。

工具内调整的是独立草稿，不改变内容页多选。新一轮选择会更新带入范围；相同选择关闭重开保留工具内调整。确认后固定本次目标，等待目录时再改草稿不会改变已确认任务。切号会丢弃旧草稿。

## 保存方式

首次使用默认询问保存位置。全局设置的常用选择为「每次询问保存位置」「自动保存到默认文件夹」；以前明确选择过“先生成，稍后保存”的偏好继续保留，不在升级时改写。没有默认文件夹时，启用自动保存会先选择文件夹，取消不启用。

| 模式 | 行为 |
| --- | --- |
| 预设目录 | 使用全局默认或本次覆盖 |
| 开始前选择 | 先选本次目录；Web 使用服务器根内的相对子目录 |
| 完成后选择 | 任务完成后再保存结果 |

各模式独立保留本次目录，Web 相对子目录不会带进预设模式。恢复默认只清除本次覆盖；明确选择“设为默认”才改变全局设置。选择目录期间不能提交，失效目录或空间不足会提示。

没有交互界面的后台任务不能弹出系统选择器：如果采用询问模式、又没有准备过本次位置，会先生成并保留在任务列表中，等待用户保存，不改写全局偏好；已配置默认文件夹的自动保存不受影响。

## 1. 聊天消息导出

选择格式与会话，可搜索、全选或清空；行末范围按钮一次编辑一个会话的消息。大量选择不会同时加载所有消息选择器，窄屏关闭范围后返回会话列表。

支持 JSON、JSONL、XLSX、CSV、TXT、HTML；HTML 随包保存配图，JSON/JSONL 可选 ChatLab 交换格式。

| 选项 | 作用 |
| --- | --- |
| 时间与内容范围 | 全部、时间预设或自定义；精确消息集合不退化为连续日期 |
| 导出媒体 | 按图片、语音、视频、文件、系统表情等类别保存 |
| 消息补全 | 在线扫描候选 seq 缺口，不保证服务器完整历史 |
| 补全媒体/装扮 | 尝试取得本地缺失资源，依凭据、权限和远端可用性而定 |
| 导出头像/装扮资源 | 保存会话使用的头像、气泡、字体或挂件 |
| 语音转文字 | 使用已配置的[离线语音模型](voice-transcribe.md) |
| 图片文字识别 | 在线优先或本地回退，取决于在线状态与已下载模型；可先筛除无文字图片 |

图片识别结果写入消息和 `ocr.json`，已缓存的同图结果可复用。在线图片链接可能过期，有链接不代表能成功识别；具体模型和平台限制见[设置](settings.md#模型与识别)。

普通聊天支持立即导出和定时执行；精确选择的不连续消息仅支持立即导出，不会扩大为定时整会话范围。

## 克隆与助手对话

读取当前账号已保存的克隆私聊、克隆群聊及助手会话，支持整场或精确消息集合。尚未持久化的流式回合不可选；所选消息消失时明确失败，不退回整场。

支持 JSON、JSONL、TXT、CSV、XLSX，保留本地生成来源、角色及工具过程，不伪装成 QQ 记录，不支持 ChatLab 或漫游补全。确认后保存独立正文快照；源会话变化或删除不改写任务，暂停/重启后可按原快照重新执行。

已知本地语音、表情与已完成的助手附件随包保存在 `resources/`，资源清单记录消息对应、相对路径、校验和缺失原因。任务提示 **已完成 · 资源缺失** 时正文仍可保存，详情可查看失败文件。

HTML/Markdown 附件的外链不自动抓取，因此不承诺整个包已完全离线。暂停后复用并校验已有资源，不再次调用模型；删除任务不删除已经另存的结果。格式与资源契约见[开发说明](../develop/generated-content-export-20261018.md)。

## 2. 频道私聊数据

导出本地频道私聊，格式与普通聊天相同，但不支持漫游拉取。可从正文多选带入消息，也可在工具内编辑范围；全选只包含已加载候选，后续加载不自动扩选。

消息 ID 集合固定到任务，不叠加旧日期预设，不将空集合转为全部；媒体、装扮和各格式共用同一范围。

## 3. 解密数据库

选择数据库与输出位置，将加密库导出为明文 SQLite。安全模式更稳妥，快速模式可按库大小回退安全实现。明文副本可能包含全部聊天数据，应保存在受控位置。

## 4. QQ 空间导出

导出自己或指定空间的说说，支持 JSON、TXT、HTML。空间页的导出按钮进入同一工具；精确多选使用空间 UIN 与 tid，不要求对象必须是好友。

精确任务只读所选 tid 的详情、互动及媒体，不扫描整空间或混入旧缓存；空集合、删除/无权或身份不匹配会报错。整空间导出保留分页、日期与历史捕获能力，正文仍截断或媒体缺失会记入覆盖报告。

多格式共用读取结果，条数不重复相加。暂停/重启后按原 tid 重新读取服务器，**不是不可变正文快照或字节断点**。

## 5. 导出联系人

联系人名单、群聊名单和群成员名单支持 JSON、JSONL、CSV、XLSX、TXT；好友另支持 vCard。

联系人页面工具栏的「导出名单」菜单提供「导出联系人名单」「导出群聊名单」；群聊右键菜单也可直接打开「导出群成员名单」。它们都进入同一个导出工具，通过名单范围区分用途，不会将群聊名单误当成成员或聊天记录。

群聊名单默认导出全部本地群资料，也可精确选择群。表格包含群号、群名称、群备注、成员数、人数上限、群主 UID、创建时间（北京时间）和离群原始标记；未缓存的字段不补猜。此模式不下载联系人头像，数据范围是当前本地资料目录，不等同于已核验的在线在群名单。

默认可按好友分组或整群导出，也可从内容多选带入精确 UID。精确模式中搜索和分组只用于查找，不追加未选联系人；筛选外已选项保留，空集合禁用提交。

多个群各建独立成员任务，不因全选群就预读所有成员。确认后固定 UID 与格式，身份消失明确报错；多格式共用一次读取，同名任务不覆盖。暂停或失败后使用 **重新执行**，按原目标重读资料，不冒充断点继续。成员时间按北京时间显示。

## 6. 导出收藏

支持 JSON、CSV、XLSX、TXT，可从收藏页带入全部、筛选结果或当前 CID。在线尝试补详情和已声明附件，离线使用缓存；附件放入 `media/`，报告区分摘要、详情、原件、预览和未取得内容。

按 CID/类型筛选时不附带其它收藏的整账号原始响应。搜索、日历与精确范围共用原消息读取规则，不用时间区间近似离散集合。

## 7. 定时导出任务

在聊天导出选择 **定时执行**，配置每天时刻或间隔小时。定时是执行方式，不是内容种类，目前不适用于所有导出来源。

时间预设在每次触发时重新计算。在 **任务 → 定时计划** 查看下次运行及触发记录，可暂停、启用、立即执行或删除。需要补全时仍须满足 QQ 在线和当前账号条件。

## 8. 群相册导出

选择群、相册和时间等范围，批量下载媒体；可用范围以实际相册权限为准。

## 9. 群文件导出

选择群并浏览目录树，再下载所选目录或文件；过期及不可访问项单独报告。

## 10. 商城表情下载

从左栏 **个性装扮 → 商城表情** 搜索、按免费/付费/VIP/SVIP 筛选并批量下载。商城目录与已下载资源不是同一范围，详见[表情资源](emoji-resources.md)。

## 11. 导出表情包

自定义表情分“我的表情”和“收到的表情”。本地原图优先，可用在线地址尝试补全，缺原图时可能使用缩略图；统计会区分原图、缩略图和缺失。结果按来源分目录，完成后从任务保存。

## 12. 任务列表

在工具 **任务** 中查看执行任务、定时计划及已有漫游拉取。关闭窗格或导出配置不取消已建任务；可查看进度、日志、阶段失败明细，并按来源提供暂停、继续、重新执行和删除。

已完成任务的「保存到／另存到其他位置」按真实产物选择保存框：单文件可指定文件名，完整性报告作为 `.report.json` 旁附文件保存；多文件包选择文件夹。已有同名文件或报告不会被覆盖，需要重新选择名称。取消保存保留结果，批量保存中取消会停止后续选择，不计为任务失败。

保存成功后，桌面端提供「打开保存结果」「在文件夹中显示」。再次另存失败时仍可打开上一次成功保存的结果。Web 的保存位置是服务器目录，本机下载位置仍由浏览器控制。

“执行完成”不等于内容完整。保存前应核对缺失资源与覆盖报告；统一长任务尚未覆盖所有下载和生成来源。
