# 统一导出

从悬浮工具选择 **导出**，在弹窗中选择内容种类、对象与范围，再配置格式和执行方式。每次只导出一种内容；执行结果与定时计划在独立的 **任务** 工具中管理。

聊天与空间分别保留对象选择，不会将一个种类的选择套到另一个种类。普通会话多选可带入聊天导出；精确消息和收藏集合继续使用独立草稿，不反向改动内容页的选择。切换账号会清除工具中保留的草稿。

保存目录按模式区分：预设模式使用已配置位置或本次覆盖，开始前选择只使用本次位置，完成后选择不携带旧目录。Web 开始前填写的相对子目录不会带入预设模式；切回某个模式会恢复该模式的本次目录草稿，没有本次覆盖时预设模式使用全局默认。点击“恢复默认保存设置”清除本次草稿，不会修改全局设置。选择目录期间暂不能启动导出。

## 1. 聊天消息导出

选格式 → 选会话（支持全选 / 反选 / 清空 / 搜索，每行显示消息数）→ 打开灯箱细项 → 开始导出。

聊天内容选择上方可切换 **立即导出 / 定时执行**。精确选择的不连续消息仅支持立即导出，不会自动扩大成定时任务的整个会话范围。

会话行右侧的范围按钮打开该会话的消息选择，任一时刻只编辑一个会话。全选大量会话不会逐个打开或读取消息选择器。窄屏编辑消息范围时暂时收起会话列表，关闭范围面板返回列表。

内容页完成新一轮多选后，再点击工具中的导出，会复制这一轮选择；仅关闭再打开且选择未变时保留工具内调整的草稿。

### 格式

| 格式 | 说明 |
| --- | --- |
| JSON | 结构化 |
| JSONL | 每行一条 |
| XLSX | Excel 表格 |
| CSV | 逗号分隔表格 |
| TXT | 纯文本 |
| HTML | 网页（会自动下载配图到 `media/` 并本地引用） |

### 灯箱细项

**时间范围**：全部时间 / 今天 / 近 7 天 / 近 30 天 / 近一年 / 自定义。

**内容选项**：

| 选项 | 说明 |
| --- | --- |
| 导出媒体 | 媒体文件随消息一起导出；开启后可按类别筛选 |
| 　媒体类别 | 图片 / 语音 / 视频 / 文件·群文件 / QQ 系统表情 |
| 消息补全 | 扫描 seq 空窗，从 QQ 服务端拉取本机缺失的消息（**需在线 QQ**） |
| 导出头像 | 导出发送者头像 |
| 补全媒体 | 重新下载本地缓存里没有的媒体（需 rkey） |
| 补全装扮 | 下载本地未缓存的装扮资源（关掉时只导出已缓存部分） |
| 导出装扮资源 | 气泡 / 字体 / 挂件（只导出会话实际用到的款） |
| 语音转文字 | 自动把语音转成文字（需已配置离线模型，见[语音转文字](./voice-transcribe.md)） |
| 图片文字识别 | 自动识别图片里的文字：写进 `ocr.json`（含每行文字的像素坐标框），并把文字回写进导出文件 |
| 　在线识别 | 勾了「图片文字识别」后出现：优先让 QQ 服务端识别（需 QQ 在线），失败 / 过期的回退本地模型 |
| 　识别并发 | 同时向 QQ 服务端发起的识别请求数（默认 5；连续失败 10 张会自动放弃在线） |
| ChatLab 交换格式 | 仅 JSON / JSONL 可选 |
| 保存方式 | 预设目录、开始前选择、完成后选择；本次覆盖不自动改动全局默认 |

**图片文字识别**的开启条件是二选一：QQ 在线，或者已下载本地识别模型。开启后：

- **预筛选**：先用超轻量的筛图模型（1.7 MB）甩掉风景 / 人像这类没有文字的图，再送识别
  —— 强烈建议开（识别是导出里最慢的一步）。没下载时面板里可以直接下载，下完自动设为当前模型。
- **在线识别**（可选）：让 QQ 服务端识别，从最新的图往旧的试（QQ 图片链接约 9 天过期）；
  连续失败 10 张就判定在线那条腿不可用，剩下的全部回退本地模型。
- 结果分两处：`ocr.json`（文件名 → 文字 + 坐标框 + 来源），以及消息文件里
  `[图片: 名字]` 锚点回写成的文字（HTML 是图片下方那行小字换成识别结果）。
- **同一张图只识别一次**：结果按图片 md5 缓存在本机（灯箱里点过「识别文字」、MCP 问过、
  以前导出过都算），命中就整条流水线都不用跑；服务端副本已过期（QQ 图片链接约 9 天寿命）
  的图只要以前识别过，也还能出文字。

**空间互动**（好友空间导出时）：按 tid 补全评论 + 点赞（best-effort）。

## 克隆与助手对话

统一导出中的「克隆与助手对话」读取当前账号已保存的克隆私聊、克隆群聊及助手会话，旧版克隆记录独立显示。可导出整场持久对话，或从内容页多选消息带入精确集合，也可在工具中重新选择；切换对话分别保留各自范围。

支持 JSON、JSONL、TXT、CSV、XLSX。结构化文件使用 `weq-generated-content/1` 或 `weq-generated-message/1`，保留本地生成来源、对象与会话身份、原始毫秒时间及原记录的角色、工具过程、动作、回复和提及字段，不伪装为 QQ 服务器消息。表格和 TXT 中也保留完整记录的 JSON 列，不提供 ChatLab 或漫游补全选项。

选中记录里的克隆语音/表情标记、助手附件卡片会通过现有本地句柄解析，并随导出包保存到 `resources/`。助手导出附件若本身是目录，会保留目录内的相对资源；正在执行的任务不会被当作已完成附件复制。同名不同身份分别保存，多格式共用同一份资源，原消息和引用仍原样保留。

`generated-resources.json`（`weq-generated-resources/1`）记录消息与资源的对应、包内相对路径、实际复制时间，以及逐文件的 `字节数:SHA-256` 校验值；JSON/JSONL 和表格也包含对应资源信息。缺失资源不会悄悄扩大读取范围或联网补取，清单标明 `missing`，任务提示部分资源缺失。暂停时保留已复制资源，恢复先校验快照，不重新调用模型或换用变化后的原件；完成并持久化后清理重复的私有副本。

有缺失时，任务显示 **已完成 · 资源缺失**，正文可以正常保存；点击资源阶段的失败数量查看文件及原因，完整清单仍随包保留。删除任务只清理其导出缓存，不删除已经另存到其它位置的结果。

资源清单的完整性范围为持久媒体标记和附件句柄（`known-generated-assets`），不是对附件正文的任意依赖抓取。HTML/Markdown 内的外链和脚本保持原文，不自动联网下载，也不将其中出现的本机路径当作授权文件；含外部依赖的附件不能据此冒称已完全离线化。

尚未持久化的流式回合不能精确选择；持久化后刷新记录身份即可选择。选中条目已经清空、删除或不存在时，导出明确报错，不自动扩大为整场对话。任务创建后正文和消息集合进入独立快照，源会话继续回答或被删除不会修改已确认任务；暂停后或重启应用后可按原快照重新执行。保存策略与其它导出共用，关闭工具不取消已创建任务。

## 2. 频道私聊数据

导出本地频道私聊记录，使用与完整消息相同的格式，但**不支持漫游拉取**。

频道私聊正文支持多选，所选消息可带入统一导出工具；也可在导出会话行末打开消息范围，按页选择本地消息。精确范围使用消息 ID 集合，不把间断选择替换成起止日期；空精确集合不能提交。全选仅包含当前已加载消息，向上读取更多记录不会自动加入未选条目。

确认后消息集合复制到任务快照，等待保存位置时修改草稿不会改变本次目标。精确集合不再叠加历史时间预设，频道媒体、装扮及多格式产物使用同一消息范围。重开任务列表保留原范围，不会转为全部消息。

## 3. 解密数据库

选数据库文件 → 选导出路径 → 把加密的 SQLite 解出为**原始 sqlite** 供研究。解密有两种强度：

- **安全保存**：更稳妥；
- **快速解密**：更快。

## 4. QQ 空间导出

导出好友或自己的空间说说。

格式：JSON / TXT / HTML（HTML 会强制把配图下载到 `media/` 并本地引用）。

原生 QQ 空间页的导出按钮统一打开共享导出工具，不再另开旧配置弹窗。单个空间的说说列表支持多选，Ctrl/Command、Shift 及全选使用相同的列表契约；全选只包含已经加载的说说，不自动加入后续页。当前空间可以不是好友，仍按空间 UIN 和说说 tid 带入独立草稿。

工具内的空间行末可单独编辑说说范围，只有开启精确模式才读取该空间的可选条目；搜索只筛选已载入内容，未载入的已选 tid 保留。精确范围不转换为日期，不叠加旧时间预设，空精确集合不能提交。任务确认时复制目标和 tid 集合，后续草稿变化不影响本次任务。

精确任务按 tid 直接读取详情，只对这些条目补全互动和下载媒体，不扫描整空间，也不将账号历史缓存中的未选说说打包。条目已删除、无权读取或身份不匹配时任务明确失败，不静默漏掉后发布为完整结果。整空间导出保留原有分页、日期与历史捕获能力；正文仍截断或媒体未取得时在覆盖报告中记录，不把已观察内容当作完整历史。

JSON/TXT/HTML 共用一次读取结果，任务和报告按实际说说条数计数，不把格式副本重复相加。暂停或重启后可按原范围重新执行；这是再次读取原 tid，不是保留服务器正文快照或字节断点，内容后续发生变化时以重新读取结果为准。

## 5. 导出联系人

| 子项 | 格式 |
| --- | --- |
| 好友列表 | JSON / JSONL / CSV / XLSX / TXT / **vCard** |
| 群成员列表 | JSON / JSONL / CSV / XLSX / TXT |

联系人模式可从内容页的好友或群多选带入，也可在工具内重新调整。默认按好友分组或整群导出；开启「精确选择」后，好友与群成员使用独立 UID 集合，空集合不能提交。精确选择时，分组和搜索仅用于查找条目，不会把未选联系人追加到导出中；筛选之外的已选项保留，可明确清除。

群列表可多选，每个群创建独立的成员任务；行末范围按钮一次只打开一个群的成员选择器，不因全选群聊而逐群预取成员。好友、群目录和当前群成员均读取全部本地页，长列表只渲染可见行。

确认导出后即固定本次 UID 和格式，等待保存位置期间修改草稿不影响已确认目标。任务及覆盖报告保留精确 UID，成功后草稿不会自动扩大回全部联系人。选中身份已从当前本地列表消失时明确报告失败，不退回整组、整群或全部好友。

同一任务的多个格式共用本轮读取的数据，人数不会按格式重复累加。同名任务各自保留结果；Web 下载的电子名片使用 `.vcf` 扩展名。联系人任务暂停或失败后，任务工具提供 **重新执行**，按原范围从头读取本地资料并生成结果，不冒充断点继续。

入群时间和最后发言时间按北京时间显示，不随服务器时区改变；原始秒数输入不被修改，超出日历范围的值保留为数字文本。

## 6. 导出收藏

把 QQ 收藏导出为表格：JSON / CSV / XLSX / TXT。也可从收藏查看弹窗顶部导出全部、当前筛选结果，或在详情中只导出当前收藏。

在线时复用收藏详情、图片 / 音频及文件 / 视频附件获取链路，离线时只复制已缓存附件。表格含本地附件相对路径，附件置于 `media/`；覆盖报告区分已取得、未取得、原件、预览和质量未核验。按 CID 或类型筛选时不附带其它收藏的整账号原始响应。

聊天导出的会话列表不再限制条数，支持搜索、全选和反选，列表只渲染可视区域。时间范围与聊天搜索、日期跳转共用七级消息密度日历，日期均按北京时间计算；多选导出时按所选会话合计每日消息数。

## 7. 定时导出任务

在「聊天消息导出」中切换 **定时执行**，选择会话后创建计划，配置页额外提供**定时设置**。定时执行不是单独的内容种类。目前只有普通聊天支持定时，不将这一能力冒称为所有内容均可定时。

| 模式 | 参数 |
| --- | --- |
| 每天定时 | 指定 HH:MM |
| 间隔执行 | 指定间隔小时数 |

- 模板可多选导出格式；
- 预设时间窗（如「近 7 天」）在**每次触发时**重新计算，所以会自然向前滚动；
- 在 **任务 → 定时计划** 查看下次运行时间与历史触发记录（完成 / 部分 / 失败 / 跳过 / 取消），并暂停、启用、立即执行或删除计划。

> [!tip]
>
> 「补全缺失消息」需要在线 QQ 且未开启完全离线模式。若离线运行，会提示只能读取本地缓存库中
> 的漫游消息。

## 11. 导出表情包

把本地自定义表情导出成一个图片文件夹，分两种来源：

| 来源 | 数据源 | 策略 |
| --- | --- | --- |
| **我的表情** | emoji.db 收藏 / 添加记录 + `personal_emoji` 目录 | 本地有原图直接导出；没有原图但库里有在线地址就**下载补全**；下载不到再退到缩略图；都没有才放弃 |
| **收到的表情** | `emoji-recv/<月>/{Ori,Thumb}` 目录 | 有原图导原图，只有缩略图的用**缩略图补一份**（thumb → ori 补全） |

- 面板顶部两张来源卡：显示各自的原图 / 缩略图 / 可下载 / 缺失统计 + 预览小格；
- 勾选来源后「导出」起一个任务，走「扫描表情 → 补全原图 → 导出图片」三段进度，
  每段都有独立进度条与滚动日志；
- 产物是 bundle 下的「我的表情 / 收到的表情」两个子文件夹，完成后在任务列表
  「保存文件夹…」保存到本地。

## 12. 任务列表

在悬浮工具的 **任务 → 执行任务** 中管理导出结果，关闭导出配置不会取消已经创建的任务。列表里能看到：

- 任务名与目标；
- 进度条与实时日志；
- 失败明细（可打开失败灯箱查看每条失败原因）；
- 暂停 / 继续 / 删除任务。
