# QQ NT 外观预设

在「设置 → 主题与背景 → 组件风格」中选择 **QQ NT**。
也可以在设置搜索中输入「QQ NT」或「QQNT」定位组件风格。

预设调整按钮、输入框、菜单、会话选中态、聊天标题栏与消息气泡，提供独立的浅色和深色表面。
群助手复用主消息列表的行样式；QQ NT 中的时间与标题对齐，未读数字使用无描边标记。
QQ NT 为默认风格并排在选项首位，默认背景为「纯净」；已保存的风格和背景保持不变，随时可切回经典。

主题色、界面背景、深浅模式与界面密度分别保存，选择 QQ NT 不会重置这些设置。
选择「纯色」背景时，聊天画布最接近 QQ NT 默认的中性表面；其他背景仍然保留。
自定义主题色会继续作用于按钮、焦点和自己的消息气泡。

本预设保留 WeQ 的功能、导航、窗口和输入区拖拽尺寸，以及移动端的导航与触控区域。
个性装扮中的聊天背景、媒体、表情和卡片仍按原有方式显示。
它不复制 QQ 的账号铭牌、付费气泡素材或其他装扮，也不依赖本机安装 QQ 才能使用。
