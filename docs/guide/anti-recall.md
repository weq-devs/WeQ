# 防撤回

QQ 的撤回 = **原地改写消息行**。WeQ 的防撤回通过在 QQ 的 `nt_msg.db` 上安装一个 SQLite
`BEFORE UPDATE` 触发器，直接**取消**这次改写，于是原消息内容完整保留。

## 1. 打开位置

**设置 → 防撤回**。

## 2. 总开关

打开「启用防撤回」后，WeQ 会安装触发器；关闭则卸载触发器。

## 3. 两种保护模式

| 模式 | 说明 |
| --- | --- |
| **按会话勾选** | 触发器只对**勾选的会话**生效。私聊 / 数据线按 uid 过滤，群按群号过滤 |
| **永久全选** | 触发器不做会话筛选，对该账号下**所有会话**生效，不需要也不看会话选择 |

切换模式会重建触发器。

### 会话选择器

在「按会话勾选」模式下，复用导出页的会话选择器：

- 支持**全选 / 反选 / 清空 / 搜索**；
- 数据源与导出页同一个 `listConversationsWithCount`，所以每一行的 id 恰是触发器的过滤值
  （私聊 = uid、群 = 群号）。

## 4. QQ 正在运行时的提示

装 / 卸触发器无论 QQ 是否运行都会**立即执行**。但如果 QQ 正开着，它可能仍按已加载的旧 schema
运行，改动要等 QQ 重启才真正生效。因此 QQ 运行时界面会提示「**可能需重启 QQ 才生效**」。

## 5. 查看被拦下的撤回

防撤回生效后，被拦下的撤回消息内容保持完整。要集中查看：

- 打开对应会话，点标题栏的 **↺ 撤回列表**（详见[消息编辑与删除](./message-edit.md)）；
- 聊天里被拦截的消息气泡上也会带撤回标记，管理员撤回他人消息时会显示撤回者昵称。

## 6. 和「删除」的关系

WeQ 自己的「删除消息」走的是和 QQ 撤回一样的机制（原地改写行 + 半透明覆盖），因此：

- **删除列表** = WeQ 主动删除、可恢复；
- **撤回列表** = QQ 要撤回、被 WeQ 拦下，不可（也不需要）恢复。
