# 防撤回

QQ 的撤回 = **原地改写消息行**。WeQ 的防撤回通过在 QQ 的 `nt_msg.db` 上安装一个 SQLite
`BEFORE UPDATE` 触发器，直接**取消**这次改写，于是原消息内容完整保留。

## 1. 打开位置

**菜单 → 设置 → 基础功能 → 聊天消息 → 防撤回**。菜单里的防撤回快捷入口也定位到同一分区，不再占用单独的二级设置页。

设置页直接显示总开关、保护范围、触发器状态、撤回通知，以及保护/通知会话的选择摘要，不再分成三个页签。点击「编辑保护会话」「编辑通知会话」打开选择工具；点击「查看撤回记录」打开按会话汇总的目录。打开工具不会关闭设置或替换侧栏。

单会话级别的开关在**会话头部顶栏的设置按钮**里（比照设置页的大窗口，左侧分类、右侧内容）：

| 分类 | 能做什么 |
| --- | --- |
| **防撤回** | 是否保护这个会话、是否对它弹通知 |
| **群关键词**（仅群聊） | 关键词 + 每个词的成员范围的完整编辑器，就地改、关窗即保存 |

这里的两个防撤回开关都**依赖上面的总开关**：总开关关着时它们是灰的（开了也不会生效），
面板里会提示先打开防撤回总开关。

## 2. 总开关

打开「启用防撤回」后，WeQ 会安装触发器；关闭则卸载触发器。

开关与模式切换都是**点完就返回**：配置先落盘、触发器在后台重建，不阻塞界面，也不需要 QQ
在线。

## 3. 两种保护模式

| 模式 | 说明 |
| --- | --- |
| **按会话勾选** | 触发器只对**勾选的会话**生效。私聊 / 数据线按 uid 过滤，群按群号过滤 |
| **永久全选** | 触发器不做会话筛选，对该账号下**所有会话**生效，不需要也不看会话选择 |

切换模式会重建触发器。

### 会话选择器

在「按会话勾选」模式下，复用导出页的会话选择器：

- 支持**全选 / 反选 / 清空 / 搜索**；
- 数据源与导出页同一个 `listConversationsWithCount`，所以每一行的 id 恰是触发器的过滤值
  （私聊 = uid、群 = 群号）。

选择工具支持搜索和多选，点击「保存选择」才提交名单；关闭时若有未保存修改，会先询问是否放弃。保存失败保留本次选择并显示错误。切换保护模式不清除原有按会话名单，永久全选时仍可查看、编辑保留的选择。

## 4. QQ 正在运行时的提示

装 / 卸触发器无论 QQ 是否运行都会**立即执行**。但如果 QQ 正开着，它可能仍按已加载的旧 schema
运行，改动要等 QQ 重启才真正生效。因此 QQ 运行时界面会提示「**可能需重启 QQ 才生效**」。

静态 PC 账号是导入的离线快照，QQ 不会往其中写入，不能拦截新的撤回；启用开关会禁用并显示原因。已有记录仍可按原能力查看。

## 5. 撤回通知

在防撤回分区打开「撤回时通知我」，再通过「编辑通知会话」勾选要通知的会话（只有受保护的会话才可能记录下
撤回）：被拦下的撤回会弹**系统原生通知**，点通知会唤起窗口并跳到那条消息。

通知只对**本次运行中新出现的撤回**生效 —— 启动时的历史记录不会补弹。

## 6. 查看被拦下的撤回

防撤回生效后，被拦下的撤回消息内容保持完整。要集中查看：

- **设置 → 基础功能 → 聊天消息 → 查看撤回记录**：按会话汇总目录（条数 + 最近一次撤回时间），点一行在同一工具中查看消息，可返回目录；
- 打开对应会话，点标题栏的 **↺ 撤回列表**（详见[消息编辑与删除](./message-edit.md)）；
- 聊天里被拦截的消息气泡上也会带撤回标记，管理员撤回他人消息时会显示撤回者昵称。

消息详情沿用聊天的气泡，并支持撤回者、被撤回者和正文筛选。读取失败可重试，不会显示成「没有记录」。返回目录会保留目录的阅读位置；关闭工具后回到原设置入口。切换账号/数据源、锁屏或关闭后重开，不会接收旧请求的迟到结果。

## 7. 和「删除」的关系

WeQ 自己的「删除消息」走的是和 QQ 撤回一样的机制（原地改写行 + 半透明覆盖），因此：

- **删除列表** = WeQ 主动删除、可恢复；
- **撤回列表** = QQ 要撤回、被 WeQ 拦下，不可（也不需要）恢复。
