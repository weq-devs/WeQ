# 语音转文字

WeQ 的语音相关功能统一在 **设置 → 语音配置** 里配置，包括两件事：**离线语音识别（转文字）**和
**文字转语音（TTS）**。

> [!note]
>
> 语音配置与账号无关，属于应用级设置。选中的转录模型 ID 存在全局配置里，空 = 功能关闭。

## 1. 转录模型（语音转文字）

「转录模型」卡片列出可用的离线模型：

| 标记 | 含义 |
| --- | --- |
| **推荐** | 官方推荐模型 |
| **已下载** | 模型已在本地 |
| **当前模型** | 正在使用 |

每个模型显示名称、描述、体积（未下载显示「约 X」，已下载显示实际占用）。操作：

- **下载**：显示进度条、百分比、已下载 / 总量、实时速度；下载中所有模型的下载按钮会被禁用；
- **设为当前** / **取消选用**：点已选中的模型即取消；
- **删除**：从本地删除该模型；若删的是当前模型，会同时清空选择。

> [!tip]
>
> 模型文件较大，请在网络良好时下载。模型保存在本地，**删除「账号缓存」不会影响它**。

## 2. 转文字在聊天里的用法

选好当前模型后，聊天里的语音消息即可**转文字**（离线识别，不走网络）。

导出时也可以勾选 **语音转文字**，把语音的转写文字一起写进导出结果（见[导出中心](./export.md)）。

## 3. TTS 语音合成

「TTS 语音合成」卡片配置文字转语音服务商。配好后，**克隆体（好友克隆）才能发语音**；支持复刻
的厂商还能用 TA 本人的声音说话。

### 添加服务商

点「新建」打开弹窗，选择**厂商模板**（会自动带出默认 Base URL），再按模板要求填写字段：

| 字段 | 说明 |
| --- | --- |
| 显示名称 | 必填，ID 由系统从名称自动生成 |
| 服务地址 (Base URL) | 必填 |
| API Key | 部分厂商需要 |
| App ID / Resource ID | 豆包等厂商需要 |
| 模型 / 复刻模型 | 可留空用默认；复刻模型是语音克隆专用 |
| 默认音色 | 预置音色 id |
| 音频格式 / 语速 | 可选 |

支持的厂商模板包括：OpenAI 兼容、GPT-SoVITS、MiniMax、Mimo、豆包、CosyVoice 等。带
**可复刻** 徽章的厂商（如 CosyVoice / GPT-SoVITS）能用克隆体的真实语音作参考音频。

### 操作

- **保存**：写入配置；
- **测试**：校验连通性；能生成的会播放一段样例语音；
- **删除**：移除该服务商。

## 4. 与克隆体联动

在克隆体的「语音」设置里开启语音克隆后，会自动用 TA 的真实语音作参考音频。详见
[AgentLab](./agentlab.md)。
