# 空间、相册与频道

## 1. QQ 空间

左栏 **QQ 空间** 打开原生内容页；桌面和 Web 共用当前账号的空间服务，不再通过内嵌网页浏览。

| 内容 | 操作与范围 |
| --- | --- |
| 好友动态 | 按说说、日志、相册等筛选；特别关心使用服务端范围，不是本地昵称匹配 |
| 说说 | 查看自己或指定 QQ 号，按页加载；明确截断时尝试补正文和附图，失败保留已读内容 |
| 评论与回复 | 按需展开；未读全与已取得的数量分别展示，不将局部名单当全部互动 |
| 与我相关 | 赞、评论、转发、@ 等折叠提示；不自动展开原帖全文或媒体 |
| 图文发表 | 手动输入和选择图片后提交，可选所有人、好友或仅自己可见 |
| 相册 | 页内浏览相册与媒体，保留选择下载和预览 |

读取需要账号具有相应在线访问权限；切页或切号会取消前台请求并拒绝旧结果。发表不会随加载触发，结果未知时先核对自己的空间，避免重复发布。

动态中的日志摘要不等于独立日志全文功能；评论回复写入、转发名单和“那年今日”没有对应产品入口。已加载动态也不是好友全部历史。

说说提供点赞切换及文字／图片根评论。点赞点击后立即高亮并调整已知数量，请求中禁止重复点击；失败或结果未确认时恢复原状态，请求提交后重新读取远端校准。未知数量不猜成零，未读全的点赞名单不据此断言自己没有点赞。评论发送中显示进度，请求提交后更新数量并刷新已展开列表，不强制关闭互动区；失败／未确认保留草稿，等待回执时新编辑的内容也不会被清空。校准失败会显示提示，可点击刷新图标只重试读取，不重复提交写请求。

空间动态只保留顶部说说导出入口；按住 Command / Ctrl 或 Shift 点击说说可多选后导出，Escape 退出多选。搜索跳转的具体说说与动态列表使用同一列阅读布局。

## 2. QQ 频道

桌面版内嵌频道网页，Web 版打开带登录跳转的新标签页；仍受 QQ 当前账号权限限制，不要分享含一次性票据的跳转地址。

## 3. 空间相册

从原生空间页进入相册，不再从“更多功能”打开独立空间相册入口。

相册与媒体按页加载，视频按精确照片键换取可播放地址；封面不代表视频本体已取得。预览支持图片缩放、平移与当前已加载媒体间切换。详情升级失败保留原图并可重试，不自动遍历其它页。

勾选媒体或整本相册后，导出按钮沿用公共保存偏好，旁侧菜单提供本次另存和稍后保存。取消位置选择不创建任务，也不清空选择。单张照片／单个视频使用对应文件保存框，多项媒体或整本相册保存为资源包；视频本体不可用时继续沿用保存封面的回退，并使用图片后缀，不把封面误标成 MP4。

导出进度、停止、部分失败与完成后的保存／另存在任务列表中处理；失败不会覆盖同名原件。Web 端操作保存到服务器，完整结果可从任务列表下载到浏览器，本机目录由浏览器控制。整本相册只遍历选中相册，遇到重复页或提前空页会保留明确失败记录，不冒称导出完整。

预览不显示相册归属页脚，也不额外探测说说所属相册。普通视频与 Live Photo 的 Web 字段存在歧义，当前不自动作 Live Photo 分类。

## 4. 群相册

在聊天右侧群资料栏点 **相册**，进入后查看媒体和大图/视频；窄屏先用顶部 **群资料** 打开同一侧栏。批量下载使用[统一导出](export.md#8-群相册导出)。

相册列表可搜索名称、描述或创建者，并按原有顺序、名称或媒体数量排列。进入相册后可按文件名或上传者搜索，用全部／图片／视频切换类型；列表和网格先展示 120 项，点击“显示更多”继续展示已读取的结果，不额外声称已取得 QQ 侧所有历史。返回相册列表时保留原搜索、排序、滚动位置和打开项焦点。读取或刷新失败显示错误并保留已有内容，可用刷新按钮重试。

点击缩略图进入连续预览，可用两侧箭头或方向键切换当前筛选结果，保留缩放和平移；评论输入框内的方向键仍编辑文字。保存及已有点赞／删除／评论操作集中在当前媒体下方，不在每张缩略图下重复放表单；图片上传入口位于相册工具栏。保存仍沿用公共策略及本次菜单，Web 区分服务器保存和浏览器下载。视频无本体时只展示并保存封面图片，明确提示，不把封面作为视频播放；图片原图读取失败可保留预览图并重试。切换账号或数据源后清除旧预览，返回后也不会被迟到响应重新拉进相册。

## 5. 群公告

右侧资料栏预览当前公告，点击查看完整公告与历史记录，包括发布者、时间及可用配图。

管理员和群主可用顶部加号打开发布编辑器，原有提醒、置顶、确认、新成员公告和附图选项仍保留；旧公告的删除操作在对应正文旁的菜单中，也可右键打开。普通成员仍只读本地公告，不显示写入工具。在线页与本地记录仅按公告 ID 合并，在线未返回的历史仍保留并标注为本地记录，不把单页结果当作全部公告。

发布前仍需确认；失败或结果未确认保留原稿，等待回执时新编辑的内容不会被清空。关闭编辑器或公告页会保护未保存内容，切换账号、数据源或群后不沿用旧草稿及菜单。群待办列表同样把操作贴近内容：完成按钮在该行，管理员的取消操作在该行菜单，进入页面和操作后仍按现有接口读取。

## 6. 群精华

右侧资料栏点 **精华** 查看已设精华的消息及操作者，支持跳转原消息；具体内容依本地缓存和在线权限而定。

## 7. 群文件

右侧资料栏点 **文件**，按面包屑浏览目录、查看名称/大小/时间并下载。批量下载使用[统一导出](export.md#9-群文件导出)。过期或不可访问的文件明确提示失败。

列表中的单个文件保存沿用公共保存偏好，旁侧菜单可本次另存或稍后保存；取消不影响文件列表与缓存。Web 将服务器保存和浏览器下载分开，等待浏览器下载期间可停止本次等待／下载，完整结果仍保留在任务列表，不覆盖已有文件。

## 8. 频道私聊

在 QQ 频道页点击局部 **频道私聊** 按钮，读取本地私聊会话和消息，不包含频道网站群聊的全部内容。

列表与聊天往返保留现场，首次显示最新消息，向上加载更早页；搜索可按精确消息身份打开历史上下文。窄屏通过返回列表切换，不销毁已选会话。

支持多选后进入[频道私聊导出](export.md#2-频道私聊数据)，不支持漫游补全。
