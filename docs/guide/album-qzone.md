# 空间、相册与频道

这一页讲 QQ 空间、两类相册，以及群公告 / 精华 / 文件和 QQ 频道相关功能。

## 1. QQ 空间

左栏点 **QQ 空间**：

- **桌面版**：把空间嵌进一个 `<webview>` 里并手工种登录 cookie，像原生页面一样浏览；
- **网页版**：`user.qzone.qq.com` 禁止 iframe，跨站 cookie 也不是网页能替浏览器写的，因此改成
  **在浏览器新标签页打开**。点击时后端现取一条 ptlogin2 跳转 URL（带一次性 clientKey），
  浏览器跑完 302 链后登录态落在浏览器自己的 cookie jar 里。

## 2. QQ 频道

左栏点 **QQ 频道**，行为与 QQ 空间相同：

- 桌面版内嵌 `<webview>`；
- 网页版在浏览器新标签页打开（`pd.qq.com` 同样禁 iframe）。

## 3. 空间相册（自己的）

左栏「更多功能 → 空间相册」打开查看器，读取**自己的** QQ 空间相册。

- 走空间 web cgi，**需要在线 QQ**（`p_skey` 可由 pt_login 本地快速登录兜底，无需注入）；
- 未登录 / 完全离线时给出回退说明文案；
- 展示逻辑：
  - **只有一个相册** → 直接平铺该相册的全部媒体（照片 + 视频封面，带名称 / 时间）；
  - **多个相册** → 先看相册卡片（封面 + 名称 + 媒体数），点击进入内部媒体列表；
- 媒体列表**分页 + 滚动到底自动加载**；
- 图片统一走 `weq-media://album?src=…`（主进程代取 + 白名单域名校验），不使用裸 `<img src=远端>`；
- 视频条目点封面会按 picKey 现取本体 mp4（列表 cgi 只给封面）后直接进视频灯箱播放；
- 支持勾选 / 全选后**并发下载保存**。

## 4. 群相册

在群聊标题栏点 🖼 打开群相册。

- 左栏列出群相册（标题 / 张数 / 封面 / 描述 / 创建者 / 时间）；
- 进入相册后展示媒体（图片 / 视频），可看大图 / 视频灯箱；
- 也可从[导出中心](./export.md)的 **群相册导出** 批量下载。

## 5. 群公告

在群聊标题栏点 📄 打开群公告面板：

- 顶部显示当前置顶公告；
- 下方是历史公告列表，含发布者（头像 + 昵称）、发布时间、已读数、配图；
- 配图可点击看大图。

## 6. 群精华

在群聊标题栏点 ✨ 打开群精华面板：

- 列出被设为精华的消息（发送者、操作者、时间、激活状态）；
- 内容支持文本 / 表情 / 图片 / 文件；
- 点击可**跳转到原消息**。

## 7. 群文件

在群聊标题栏点 📁 打开群文件浏览器：

- 以**面包屑目录树**浏览（根目录是「全部文件」）；
- 显示文件图标、名称、大小、时间；
- 点某一行可换取直链下载，下载时该行按钮转圈；
- 也可从[导出中心](./export.md)的 **群文件导出** 批量下载。

## 8. 频道私聊

左栏「更多功能 → 频道私聊」打开查看器，读取本地 `guild_msg.db`：

- 左栏私聊列表只读 `direct_node_list_table`，**绝不回扫** `guild_msg_table` 去猜测补全会话；
- 右栏按 node id 查同库的本地消息：从最新 seq 起始（消息贴底），向上滚动加载更旧页；
- 消息渲染复用主聊天的气泡与渲染器（含逐条装扮）；
- 自己的消息用主界面账号头像，对方头像来自 `t_GPro_CommonUserProfile_v2` 派生的 URL（可能为空）。

也可以从[导出中心](./export.md)的 **频道私聊数据** 模式导出（不支持漫游拉取）。
