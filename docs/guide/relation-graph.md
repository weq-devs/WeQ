# 群交集图谱

在联系人页面进入「群交集」，可查看群友圈子、群聊网络、和弦和重叠矩阵。

「群友圈子」「群聊网络」按圈子紧凑排布。首次显示或改变可见节点集合后，视角自动适应画布，避开顶部工具栏；布局收敛后会校准一次。节点数量、共同群或共同成员阈值、好友及群过滤仍决定显示哪些对象与关系，布局不会补造连线。

拖动头像可调整节点位置，拖动画布可平移，滚轮可缩放。手动操作后停止自动调整视角；点击画布右下角的「适应全部」图标，可重新显示全部节点。改变筛选条件时，仍存在的节点沿用原位置参与新布局。

单击头像在附近打开对应的个人或群聊名片；拖动不会打开名片。和弦与重叠矩阵的布局不受上述力图调整影响。
