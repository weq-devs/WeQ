# 群交集图谱

在联系人页面进入「群交集」，可查看群友圈子、群聊网络、和弦和重叠矩阵。

群友圈子与群聊网络最多可选择显示 1000 个节点，另加「我」节点，默认仍为 100。全部交集仍精确计数，不按连线数量抽样；节点和连线越密集，布局与绘制的负载越高，可配合共同群或共同成员阈值调整。

「群友圈子」「群聊网络」初始按圈子紧凑排布，随后采用原版 D3 力模拟。自适应默认开启，视角持续跟随布局、筛选结果及画布尺寸变化，避开顶部工具栏。节点数量、共同群或共同成员阈值、好友及群过滤仍决定显示哪些对象与关系，布局不会补造连线。

这两种图谱的物理布局在独立线程运行，保留原来的拉力、碰撞和完整连线，减少布局计算对界面操作的阻塞。布局失败时可点击重试图标重新启动。

下方设置分为「范围」「显示与权重」「筛选」，大小与拉力选项集中放置，窄屏自动换行。群友圈子的「显示备注名」开关只将头像旁固定显示的昵称替换为好友备注；没有备注时保留昵称，不改变名称的显示阈值、头像内容、悬浮提示、名片或布局。「仅显示好友」与群过滤统一放在「筛选」中。

拖动头像可调整节点位置，拖动画布可平移，滚轮可缩放。实际拖动或缩放后停止自适应，单击头像或空白处不会关闭；点击画布右下角的「适应全部」图标，可恢复持续跟随，直到再次手动拖动或缩放。改变筛选条件不会擅自恢复已停止的自适应，仍存在的节点沿用原位置参与新布局。

单击头像在附近打开对应的个人或群聊名片；拖动不会打开名片。和弦与重叠矩阵的布局不受上述力图调整影响。

更新成员前会确认更新范围；已有信息与线索缓存或群成员名单任务正在运行、暂停时，再次点击更新成员直接打开现有任务，不再询问或重复启动。
