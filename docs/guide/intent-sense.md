# 意图感知

意图感知用 AI 结合**对话上下文**与**中文互联网语用语料库**，逐条分析聊天消息的**意图**（提问 / 请求 / 分享 / 夸赞 / 吐槽 / 玩梗 / 约定…）与**情绪**
（开心 / 兴奋 / 赞叹 / 平静 / 低落 / 生气 / 焦虑 / 亲昵 / 疲惫 / 好奇），能够准确识别正话反说、夸张式赞叹（如在对方展示厉害成果后回复「吓哭了 / 给跪了 / 看傻了 / 恐怖如斯」会判为**夸赞 + 赞叹**而非字面的恐惧/低落）与网络热梗，再把这些信号聚合成对方的互动画像：**好感度**、**MBTI 倾向**、
**互动风格雷达**与**常见话题**。

> [!warning]
>
> 意图、情绪、好感度与 MBTI 都是模型推断，**仅供娱乐参考**。API 引擎会把消息文本
> 发送给你配置的服务商；本地引擎完全离线，消息不出本机。

## 1. 打开位置

**设置 → 模型与识别 → 意图感知**。本地意图资源在本页选择与下载；推荐回复及其上文范围在同分类的 **推荐回复** 页设置。

这里管全局：总开关、分析引擎、分析上文范围、模型资源与分析缓存。推荐回复在独立页面选择 API 模型和上文。单会话的开关在**会话头部顶栏的设置按钮 →
意图感知**里（关掉某个会话后，那里不再出现胶囊）。

会话里的入口还有两处：私聊顶栏右上角的好感度胶囊（点开**互动画像**），以及
**头像资料卡 → 互动画像**（与「个性主页」「查看互动标识」并列）。

## 2. 两种引擎

| 引擎 | 说明 |
| --- | --- |
| **API（OpenAI 兼容）** | 引用「模型与识别 → API 配置」里的服务商与模型。一次调用分析一批消息，还能生成回复建议。 |
| **本地模型（Laya 多语言 ONNX）** | 约 600MB，按需下载到用户数据目录（支持 hf-mirror.com 镜像），之后**完全离线**。推理跑在独立子进程里，不阻塞界面。 |

- 本地引擎基于开源的 [Laya](https://github.com/NandhaKishorM/laya) 多语言 System-1 决策
  模型（Apache-2.0）：意图选择、情绪/强度打分、MBTI 维度倾向都由它完成，单条约
  百毫秒级。
- 推荐回复独立选择 API 模型，分析使用本地模型时也可以调用另一套 API 生成回复；生成失败或未配置 API 时仅保留规则候选兜底，Laya 本身不生成文本。旧 API 引擎配置会复制原 API 选择为推荐回复初始值，之后互不改写；旧本地引擎配置不会自动开启 API 推荐。
- 意图分析、互动画像和推荐回复的 API 模型若明确不支持温度参数，会在同一超时内去掉该参数重试一次，原温度设置不变。成功后正常使用模型结果；仅最终失败才进入原有错误／冷却或规则候选路径，不会因为首次参数拒绝就直接改用本地候选。鉴权、限流、网络及普通取值错误不会触发温度回退。

首次开启后，打开一个会话会自动在后台补齐最近默认 300 条消息的分析（可在「分析范围与时效」中修改；增量：只分析
新消息），胶囊随结果逐条点亮。

### 上文范围

「上文范围」中两项独立设置，均支持 0–100 条，**不包含当前目标消息**：

| 设置 | 默认值 | 实际范围 |
| --- | --- | --- |
| 意图分析上文 | 4 条 | 目标之前的有效文本消息，仍受相邻间隔 8 分钟、总跨度 15 分钟的时效限制 |
| 推荐回复上文 | 23 条 | 最新消息之前的历史；最新消息另外保留，默认总窗口仍为原来的 24 条 |

0 表示不附加上文，仅使用当前目标／最新消息。保存后按实际条数截取，API 批量分析为每条目标分别标注自己的上文，本地分析和候选回复也使用对应范围。

旧配置自动取得默认值；旧上下文格式的分析缓存会重新识别。修改分析条数、模型或时效会淘汰不匹配的分析缓存并更新建议缓存，仅修改推荐条数不会清空分析结果。「清空并重算」同时更新界面缓存版本，旧在途结果不会写回新配置。补齐范围、API 批次、时效和高级缓存参数的默认值及范围见[模型设置](model-resources.md#可调参数)。互动画像的范围与模型另在「互动画像」页设置。

## 3. 界面上的呈现

- **消息胶囊**：私聊与群聊里**最新一条可分析文本消息（包含自己）**下方常驻「意图 + 情绪」两枚胶囊；末尾连续多条由自己发送时，这一轮已分析的文本消息都保留胶囊，收到对方新消息后恢复仅最新一条常驻。悬停
  可分析文本约 0.25 秒，会弹出该消息的意图 / 情绪 / 强度 / 情感倾向与置信度。
  分析中显示加载占位。
  浮窗独立于消息滚动容器显示；靠近输入区时向上避让，输入区高度变化时重新定位，滚动、窗口缩放或切换会话时收起，不遮挡输入操作。
- **好感度胶囊**：私聊头部右上角常驻，五档（初识 / 熟络 / 亲近 / 挚友 / 羁绊）配色
  与图标随分数变化，点击打开**互动画像**；当前统计范围内没有可分析的对方消息时不显示胶囊。
- **互动画像**：好感度与近期走势、MBTI 四维倾向条、互动风格雷达（主动性 / 响应速度 /
  情绪外露 / 话题广度 / 正式度）、常见话题。没有可分析的对方文本（含表情文字）时显示空状态，
  不生成好感度、人格或雷达，不调用画像模型；只有自己发言、空白文本或纯媒体也不会生成。
  读取失败会单独显示错误，可通过「重新计算」重试，不当作没有消息。
- **回复建议**（需在设置里开启）：输入框上方出现 3 条候选回复，点击填入
  输入框，「换一批」重新生成。候选与长回复共用一条横向滚动区域，支持触控板或滚轮连续浏览；
  鼠标悬停不改变位置，切换会话后回到起点。
  回复目标与分析目标独立：「自己发送后分析」与「自己发送后推荐回复」分别保存。旧配置默认继续分析自己的消息，但发送后隐藏旧候选、不发起新推荐；再次收到对方消息后恢复。开启自己发送后推荐时，按最新消息生成新候选，不复用上一轮回复，仍然只填入草稿，不自动发送。关闭对应开关后，迟到结果不再回填。

## 4. 好感度怎么算

好感度是本地统计与情绪分析的综合分（0-100）：近两周情绪倾向（带时间衰减，权重最大）、
回复速度、发起会话比例、消息密度、情绪强度。它**不是**对方的真实态度，只是聊天
互动模式的量化呈现。
