# 意图感知

意图感知用 AI 结合**对话上下文**与**中文互联网语用语料库**，逐条分析聊天消息的**意图**（提问 / 请求 / 分享 / 夸赞 / 吐槽 / 玩梗 / 约定…）与**情绪**
（开心 / 兴奋 / 赞叹 / 平静 / 低落 / 生气 / 焦虑 / 亲昵 / 疲惫 / 好奇），能够准确识别正话反说、夸张式赞叹（如在对方展示厉害成果后回复「吓哭了 / 给跪了 / 看傻了 / 恐怖如斯」会判为**夸赞 + 赞叹**而非字面的恐惧/低落）与网络热梗，再把这些信号聚合成对方的互动画像：**好感度**、**MBTI 倾向**、
**互动风格雷达**与**常见话题**。

> [!warning]
>
> 意图、情绪、好感度与 MBTI 都是模型推断，**仅供娱乐参考**。API 引擎会把消息文本
> 发送给你配置的服务商；本地引擎完全离线，消息不出本机。

## 1. 打开位置

**左栏 → 更多 → 意图感知**。

这里管全局：总开关、引擎、回复建议。单会话的开关在**会话头部顶栏的设置按钮 →
意图感知**里（关掉某个会话后，那里不再出现胶囊）。

## 2. 两种引擎

| 引擎 | 说明 |
| --- | --- |
| **API（OpenAI 兼容）** | 复用「克隆工厂 → 模型服务」里配置的 provider，选一个模型即可。一次调用分析一批消息，还能生成回复建议。 |
| **本地模型（Laya 多语言 ONNX）** | 约 600MB，按需下载到用户数据目录（支持 hf-mirror.com 镜像），之后**完全离线**。推理跑在独立子进程里，不阻塞界面。 |

- 本地引擎基于开源的 [Laya](https://github.com/NandhaKishorM/laya) 多语言 System-1 决策
  模型（Apache-2.0）：意图选择、情绪/强度打分、MBTI 维度倾向都由它完成，单条约
  百毫秒级。
- **回复建议只有 API 引擎支持** —— Laya 是决策模型，不生成文本。

首次开启后，打开一个会话会自动在后台补齐最近约 300 条消息的分析（增量：只分析
新消息），胶囊随结果逐条点亮。

## 3. 界面上的呈现

- **消息胶囊**：私聊里**最新一条对方消息**下方常驻「意图 + 情绪」两枚胶囊；悬停
  任意消息（含群聊）约 0.25 秒，会弹出该消息的意图 / 情绪 / 强度 / 情感倾向与置信度。
  分析中显示加载占位。
- **好感度胶囊**：私聊头部右上角常驻，五档（初识 / 熟络 / 亲近 / 挚友 / 羁绊）配色
  与图标随分数变化，点击打开**意图画像**。
- **意图画像**：好感度与近期走势、MBTI 四维倾向条、互动风格雷达（主动性 / 响应速度 /
  情绪外露 / 话题广度 / 正式度）、常见话题。
- **回复建议**（需在设置里开启 + API 引擎）：输入框上方出现 3 条候选回复，点击填入
  输入框，「换一批」重新生成。

## 4. 好感度怎么算

好感度是本地统计与情绪分析的综合分（0-100）：近两周情绪倾向（带时间衰减，权重最大）、
回复速度、发起会话比例、消息密度、情绪强度。它**不是**对方的真实态度，只是聊天
互动模式的量化呈现。
