# 意图感知

意图感知用 AI 结合**对话上下文**与**中文互联网语用语料库**，逐条分析聊天消息的**意图**（提问 / 请求 / 分享 / 夸赞 / 吐槽 / 玩梗 / 约定…）与**情绪**
（开心 / 兴奋 / 赞叹 / 平静 / 低落 / 生气 / 焦虑 / 亲昵 / 疲惫 / 好奇），能够识别正话反说、夸张式赞叹（如在对方展示厉害成果后回复「吓哭了 / 给跪了 / 看傻了 / 恐怖如斯」）与网络热梗。互动画像是独立功能，直接从聊天记录取样生成**好感度**、**MBTI 倾向**、**互动风格雷达**与**常见话题**，不依赖这里的分析缓存。

::: warning

意图、情绪、好感度与 MBTI 都是模型推断，**仅供娱乐参考**。API 引擎会把消息文本
发送给你配置的服务商；本地引擎完全离线，消息不出本机。

:::

## 1. 打开位置

**设置 → AI 功能 → 意图感知**。本地意图资源在本页选择与下载；推荐回复及其上文范围在同分类的 **推荐回复** 页设置。

意图感知和推荐回复默认均关闭，需分别手动开启。已有账号保留已保存的开关选择；配置缺少对应开关时按关闭处理。

本页管理当前账号的总开关、分析引擎、分析上文范围与缓存；本地模型资源全局共享。推荐回复在独立页面选择 API 模型和上文。单会话的开关在**会话头部顶栏的设置按钮 →
意图感知**里（关掉某个会话后，那里不再出现胶囊）。

互动画像在同分类的「互动画像」页独立开启，分别选择 API 模型或本地模型资源。关闭全局或会话意图感知，不影响画像入口、采样与推断；旧「跟随」配置只迁移一次，不再持续联动。详见[模型设置](model-resources.md#共享资源与迁移)。

私聊顶栏的画像入口跳转到联系人详情的「互动画像」分区；联系人详情还可切换资料、
个性主页与互动标识。小资料卡不再叠加画像弹窗，可先通过展开按钮进入联系人详情。
画像尚未生成、生成中或读取失败时，顶栏入口同样可以点击跳转。

三个设置页各有独立的「模式」分段选项：**自动／手动**，旧配置默认自动，沿用原有行为。手动模式保留已有结果，但不因进入会话、新消息或悬停自动生成：

- **意图感知**：在消息右键菜单或消息多选操作栏点击「意图感知」，只分析指定消息；手动选择自己的消息不受「自己发送后分析」自动触发开关限制。多条消息处理完毕后显示横幅，汇总成功、失败与跳过数量；单条或多条分析失败都会提示，详情保留失败原因。纯图片等没有可分析文本的消息计为跳过，不计为模型失败；单条成功不额外显示完成通知。
- **互动画像**：进入联系人详情的互动画像页时运行；消息页顶栏只读取已完成的画像缓存，不启动计算。
- **推荐回复**：点击推荐栏原刷新位置的开始图标运行；仍可停止当前轮、查看历史和填入草稿，收到新消息不会自动生成下一轮。

切回自动后恢复相应自动触发规则，三个功能互不更改模式，也不清除已有分析结果。

## 2. 两种引擎

| 引擎 | 说明 |
| --- | --- |
| **API（OpenAI 兼容）** | 引用「AI 功能 → API 配置」里的服务商与模型。一次调用分析一批消息；推荐回复另按其独立配置生成。 |
| **本地模型** | 可选自动、自研 QWeQ-NineBird-v1 或 Laya 多语言 ONNX。Laya 约 600 MB，可按需下载（支持 hf-mirror.com 镜像）；自研模型使用随包或已有资源。模型就绪后在独立子进程离线推理。 |

- 自动选择优先使用可用的自研 QWeQ-NineBird-v1，否则回落到开源
  [Laya](https://github.com/NandhaKishorM/laya) 多语言 System-1 决策模型（Apache-2.0）。
  资源选择与宿主可用性见[模型设置](model-resources.md)。模型名称中的 NineBird 不代表恢复旧 QQ 注入组件。
- 推荐回复独立选择 API 模型，分析使用本地模型时也可以调用另一套 API 生成回复；生成失败或未配置 API 时，可按「启用回退内容」设置从统一列表随机提供候选，关闭或列表为空时不回退；Laya 本身不生成文本。旧 API 引擎配置会复制原 API 选择为推荐回复初始值，之后互不改写；旧本地引擎配置不会自动开启 API 推荐。
- 意图分析、互动画像和推荐回复的 API 模型若明确不支持温度参数，会在同一超时内去掉该参数重试一次，原温度设置不变。成功后正常使用模型结果；仅最终失败才进入原有错误／冷却或规则候选路径，不会因为首次参数拒绝就直接改用本地候选。鉴权、限流、网络及普通取值错误不会触发温度回退。

首次开启后，打开一个会话会自动在后台补齐最近默认 60 条消息的分析（可在「分析范围与时效」中修改；增量：只分析
新消息），胶囊随结果逐条点亮。

已经获取并保存在本机漫游缓存中的消息同样支持自动补分析与悬停分析，按聊天时间线规则与本地消息合并、去重，并使用相同的上文范围与自己发送后分析开关。补入较早的漫游消息时，仍会检查自动补齐范围内的分析缺口；范围外可悬停单条分析。此过程只读本机缓存，不会额外联网拉取漫游消息；使用 API 引擎时，待分析正文与上文仍发送到你配置的模型服务商。

### 上文范围

「上文范围」中两项独立设置，均支持 0–100 条，**不包含当前目标消息**：

| 设置 | 默认值 | 实际范围 |
| --- | --- | --- |
| 意图分析上文 | 4 条 | 目标之前的有效文本消息，仍受相邻间隔 8 分钟、总跨度 15 分钟的时效限制 |
| 推荐回复上文 | 30 条 | 最新消息之前的历史；最新消息另外保留，默认总窗口为 31 条 |

0 表示不附加上文，仅使用当前目标／最新消息。保存后按实际条数截取，API 批量分析为每条目标分别标注自己的上文，本地分析和候选回复也使用对应范围。

旧配置自动取得默认值；旧上下文格式的分析缓存会重新识别。修改分析条数、模型或时效会淘汰不匹配的分析缓存并更新建议缓存，仅修改推荐条数不会清空分析结果。「清空并重算」同时更新界面缓存版本，旧在途结果不会写回新配置。补齐范围、API 批次、时效和高级缓存参数的默认值及范围见[模型设置](model-resources.md#可调参数)。互动画像的范围与模型另在「互动画像」页设置。

## 3. 界面上的呈现

- **消息胶囊**：私聊与群聊里**所有已有分析结果的消息（包含自己与漫游消息）**下方常驻「意图 + 情绪」两枚胶囊，不随最新消息变化而隐藏。悬停
  可分析文本约 0.25 秒，会弹出该消息的意图 / 情绪 / 强度 / 情感倾向与置信度。
  批量分析期间，聊天区显示本轮实际待分析消息的处理数与总数，失败数即时显示；悬停进度可查看成功／失败明细，处理数包含成功和失败，不代表已有同等数量的胶囊。本地分析及 API 故障后降级到本地时，每完成一条有效结果便显示对应胶囊，再推进进度，缓存仍按块合并写盘；API 批量返回后立即显示该批结果。结束后显示本轮成功与失败数量，纯成功提示保留两秒，失败提示保留并可重试；已有有效结果不重复分析。历史加载、获取及漫游补入的文本消息从首次显示起就带有两枚固定尺寸的胶囊，尚无结果时立即播放随机意图与情绪图标动画，不等待缓存或批次进度返回，也不因显示动画自动增加分析请求；开启系统「减少动态效果」时保留完整静态图标。已有结果直接显示，异步结果在原位替换动画；确认不可分析或分析失败时停止动画，消息列表不反复收缩。
  同一窗口内所有消息的图标动画保持同相位，同时描画、停留和离场；后加载的消息直接接入当前相位，关闭再恢复动态效果后也保持同步，图标内容仍分别随机。
  胶囊支持键盘聚焦打开详情，Escape 收起；关闭常驻显示时仍可通过键盘聚焦消息内的详情入口。详情只作悬停／聚焦提示，不提供点击操作，也不重复显示常驻胶囊；保留紧凑排版，强度与倾向轨道等宽、标签不换行、数值右对齐。单条请求失败后再次悬停或聚焦会重试，不当作纯媒体或无结果。
  浮窗独立于消息滚动容器显示；靠近输入区时向上避让，输入区高度变化时重新定位，滚动、窗口缩放或切换会话时收起，不遮挡输入操作。
  手动批量分析使用持续横幅逐条显示处理进度，结束后在同一横幅显示成功、失败与跳过数量，完成提示遵循通知停留设置。多条选中消息全部已有结果时，先询问是否重新分析；部分已有结果时只补分析未有结果的消息。单条手动分析不询问，已有结果也直接重新分析。
  「设置 → AI 功能 → 意图感知 → 显示方式」提供独立的「常驻显示」「悬停显示」与「批量分析时显示胶囊动画」开关，按账号保存，旧配置默认均开启。关闭批量动画后，批量及自动分析在有结果前不渲染常驻胶囊、动画或失败占位，也不预留空间；单条手动分析无论动画或常驻显示开关如何设置，均立即显示胶囊动画，已有结果在重算期间暂换为动画，完成后恢复显示偏好。后台分析与悬停补分析照常进行。关闭常驻显示隐藏普通结果与批量等待胶囊；关闭悬停显示立即收起详情，并停止悬停触发的补分析。三项均不清除缓存，也不关闭后台自动分析。
- **好感度胶囊**：私聊头部右上角常驻，五档（初识 / 熟络 / 亲近 / 挚友 / 羁绊）配色
  与图标随分数变化，点击打开**互动画像**；没有画像情绪分析依据时显示「互动画像」入口，不显示默认分数；当前统计范围内没有可分析的对方消息时不显示胶囊。
- **互动画像**：好感度与近期走势、MBTI 四维倾向条、互动风格雷达（主动性 / 响应速度 /
  情绪外露 / 话题广度 / 正式度）、常见话题。没有可分析的对方文本（含表情文字）时显示空状态，
  不生成好感度、人格或雷达，不调用画像模型；只有自己发言、空白文本或纯媒体也不会生成。
  首次加载使用专属画像骨架；读取失败会单独显示错误，可通过「重新计算」重试，不当作没有消息。刷新失败时保留上次画像与分数。
- **回复建议**（需在设置里开启）：输入框上方出现 3 条候选回复，点击填入
  输入框，「换一批」重新生成。候选与长回复共用一条横向滚动区域，支持触控板或滚轮连续浏览；
  鼠标悬停不改变位置，切换会话后回到起点。
  历史候选同样可以左右滑动，但不显示横向滚动条；历史与正式推荐栏的候选滚动区左右边界对齐。
  正式推荐栏和历史每行左侧的灯泡均可点击定位，跳到对应一轮实际使用的最后一条输入消息。
  正式栏右侧的「查看当前推荐详情」按钮和历史每行日期打开同一个轮次详情面板。模型在同一次请求中先概括当前话题与最新消息，再结合完整对话生成候选；面板显示这轮概括、实际模型与供应商、生成时间、请求／总耗时、输入消息数及服务返回的 Token 用量。展开「请求日志」可查看本轮实际的 System Prompt、User Prompt、模型原始返回和回退原因，查看或展开都不会重新请求模型。轮次以独立 ID 关联，候选文字相同也不会混淆；旧历史缺失的信息显示「未记录」，本地规则候选不会冒充模型概括。
  推荐尚未生成完成时也可打开详情，默认展开带时间的实时日志，查看读取输入、准备上下文、发送请求与等待返回等阶段。详情打开期间每半秒更新，生成完成、停止或失败后停止刷新；刷新生成时查看的是新一轮，不会误显示仍保留在推荐栏中的旧候选详情，已打开的面板也不会跳到下一轮。未生成有效候选的轮次不加入候选历史。
  完整请求详情按轮次单独保存在本机，不随历史列表一起传输；历史默认每会话保留最近 500 轮，可在「缓存与历史 → 每会话保留的推荐轮数」设置 0–10000。改设置不立即删除历史，下次新增保存时才淘汰较早轮次并清理详情；0 停止新增落盘但保留已有历史，当前轮次与详情仍通过内存缓存可用。
  开启推荐回复时固定保留单行槽位；进入会话时，若历史中最新一轮推荐已采用会话内最新消息，就直接恢复到正式栏，不受时间限制，也不自动重复生成；手动「换一批」仍会强制重新生成。若尚未覆盖最新消息，但生成时间仍在「最近推荐过期时间」内，也先恢复该轮推荐并等待更新。该期限在「推荐回复 → 缓存与历史」设置，单位为分钟，默认 1 分钟，`-1` 表示永不过期，`0` 表示立即过期；与「同一消息推荐缓存」分别保存。若暂无候选是因为最近推荐已过期，会显示距上次推荐过去多久，按年、天、小时、分钟最多展示两个非零单位，仅不足一分钟时显示秒。停留期间推荐不会因超时自行清空。没有候选且正在生成时才显示「正在生成推荐回复」，生成期间已有候选原样保留且仍可点击，不被加载占位顶替。新消息不会打断或丢弃在途推荐，结果仍对应本轮启动时的消息。空结果、等待对方新消息和失败均有对应状态，失败可重试；生成期间不能叠加刷新，鼠标悬停或键盘聚焦「换一批」后显示「停止」，点击只停止当前轮，后续新消息仍照常自动推荐。
  「换一批」右侧的向上箭头展开回复历史，按内容高度显示、最多显示 3.5 行，且不超过原消息区域一半，超出部分在历史面板内滚动，消息列表同步缩短；再点向下箭头收起。历史由上到下从旧到新排列，展开时定位到底部，最新一轮若已在正式栏中显示则不重复列出。一行对应一次推荐，历史候选仍可填入草稿；行首定位按钮优先按消息 ID 精确定位到该次推荐**实际输入的最后一条消息**，不是当前最新消息。历史按账号、私聊／群聊与会话分别保存在本机，每个会话按设置保留最近若干轮（默认 500）；缓存命中不重复记轮，手动换一批会新增一轮，清空分析缓存不删除回复历史。
  回复目标与分析目标独立：「自己发送后分析」与「自己发送后推荐回复」分别保存，默认均开启；已有配置保留已保存的选择，缺项使用默认值。开启自己发送后推荐时，按最新消息生成新候选，等待期间保留旧候选，仍然只填入草稿，不自动发送。关闭自己发送后推荐时，发送后保留已有候选但不发起新推荐，再次收到对方消息后恢复。关闭功能后，迟到结果不再回填。

## 4. 好感度怎么算

好感度是本地统计与情绪分析的综合分（0-100）：近两周情绪倾向（带时间衰减，权重最大）、
回复速度、发起会话比例、消息密度、情绪强度。它**不是**对方的真实态度，只是聊天
互动模式的量化呈现。

情绪输入来自画像自己选定的模型，而非消息气泡的意图分析结果。仅统计模式、样本不足或画像模型未返回有效情绪时，好感度显示「未分析」，不生成情绪走势或情绪外露默认轴。
