# 资料历史

日常打开资料卡、查看成员名单或读取其他联系人／群资料时，WeQ 会保存接口已经返回的资料，包括当前页面未展示的字段。不需要专门点击更新缓存，也不会为了补历史而额外扫描联系人或下载媒体。

联系人详情的「历史」页签可按资料类别浏览不同版本，展开查看前后字段变化与完整资料。通用名片中的「资料历史」可直接进入。群资料右上角的历史按钮可查看该群的资料及成员历史，完整名单的比较会分别列出新增、退出及成员资料变化；分页结果会标记为分页资料，不代表完整名单。

时间按北京时间显示，表示 WeQ 首次或最近观察到该内容的时间，并非对方实际修改资料的时间。重复读取相同资料只更新最近观察时间；同一内容以后再次出现，仍保留中间的变化顺序。

逐项历史会合并不同接口读到的连续相同内容。头像仅依据已有图片内容确认变化，链接参数改变不等于换头像；尚无图片可核实的旧链接保留在原始资料中，不单独算作换头像记录。

## 逐项查看

名片及完整资料页中，发生过变化的字段旁有历史按钮。各类资料按实际内容展示：

| 字段类型 | 展示方式 |
| --- | --- |
| 等级、累计获赞、能量、亲密度、共同好友数、群人数／容量／活跃指标 | 观察趋势与逐次明细，明细保留准确数值、单位及相邻记录增减；不足两个有效数值时只显示明细 |
| 昵称、备注、签名、简介、地址、生日、性别、职业、血型、关系状态等 | 倒序变更记录，显示本次值与之前值；日期和状态使用业务名称，不显示原始时间戳 |
| 学校、标签、共同群、特权、互动标识、装扮、关系标签、问答 | 条目新增、不再出现和内容变更，可展开同次完整记录；学校保留学历和入学／毕业年份，互动标识保留等级、进度及佩戴状态 |
| 头像、精选照片、QQ 秀 | 历史图片，点击放大；精选照片从对应原始观察补齐已保存的图片地址，只有编号或图片失效时保留引用或失败提示 |

趋势按实际观察时间排列；空值不当成零，也不跨空值连接曲线。图表只覆盖已加载记录，加载更多后向前扩展。条目比较不把头像地址、请求游标等元数据变化当作业务变更；连续相同内容会合并首次／最近观察时间，A → B → A 仍保留三段。

记录中的「观察于」「最近观察」均为北京时间。列表不推断期间每一天的实际状态，也不把分页中未出现的条目直接称为删除。

历史可离线查看。资料页仍优先显示本地资料，离线时可使用已保存的相同资料；会话名称不会被云端历史昵称替换。历史页面不提供恢复或写回 QQ 的操作。

升级后会自动迁入原有联系人指标、群资料和名单缓存；校验失败的原件会保留并提示。当前缓存中原本已被覆盖的旧资料无法补回。历史使用内容去重及无损压缩，头像、照片等继续复用已有媒体缓存；媒体缓存被清理或链接失效后，历史引用本身仍保留，但不保证媒体文件可继续打开。

空间管理中「联系人与群资料历史」单独统计，普通清缓存不会删除这些记录。保存失败会显示错误并保留待重试数据；磁盘空间恢复后，在正常刷盘或退出保存时重试。
