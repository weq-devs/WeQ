# 资料历史

当前只保留 QQ 原生提供的两类历史：

- **个性签名历史**：从个性签名旁的历史入口查看，保留原分页、点赞与评论。
- **本人头像历史**：从本人资料中的「历史头像」查看，保留最早／最后使用时间、排序和图片放大。

## 自建资料历史

WeQ 自建资料历史的展示已暂时撤下，包括联系人、群及群成员资料的逐项变更、数值趋势、集合比较、历史图片与汇总历史。名片和完整资料页不再显示相关入口，也不再为展示查询或补建字段索引。

这不影响 QQ 原生的签名历史和本人头像历史，也不改变当前资料的显示、编辑或普通媒体预览。

## 已有数据

已保存的 `history.sqlite`、资料观察及已经完成的旧缓存迁移仍保留，不因撤下展示删除或回退。原有资料留存与缓存读取逻辑不变；普通清缓存不会删除这些历史记录。
