# macOS 托管 QQ（开发中）

当前入口面向 macOS 桌面版，Web 版尚未打包托管 Worker 与注册桥。

此入口正在开发，尚未完成扫码后的真实收发、数据库生成和持续落库验收。二维码能显示、独立进程能退出，不代表已经具备日常聊天所需的完整兼容性。

## 进入

1. 安装官方 macOS QQ，并在托管登录面板明确开启「完整在线功能」；完全离线模式下不能启动托管 QQ。
2. 从「新的开始」的账号来源选择「托管 QQ」，点击「启动并登录」。
3. 使用手机 QQ 扫码、确认登录。WeQ 分别等待登录、会话票据、数据库密钥验证及账号打开。
4. 只有本实例的账号和数据库均就绪后才进入聊天。停在准备状态或出现错误时，不会把未完成的会话当作在线账号。

二维码旁可刷新二维码、停止本次托管或打开官方 QQ。不能在 WeQ 完成的官方验证需要按实际提示处理；不保证所有风控流程都已适配。

## 数据与退出

- 托管内核在独立后台 Worker 中运行，不载入 WeQ 主进程，不修改 QQ 安装入口，也不需要先启动 QQ 主窗口。
- 专用数据根是 `~/Library/Application Support/weq/managed-qq`，不会自动复制、合并或改写原有 QQ 历史数据。缺少托管数据库时不回落到同号的原有 QQ 数据目录。
- 会话票据和数据库密钥只在主进程与 Worker 的私有通道交接，不进入界面状态快照；数据库口令沿用 WeQ 现有本地账号配置的保存方式。
- 登录完成前离开本次面板会清理面板创建的实例；成功进入聊天后，后台实例保留。
- 切到完全离线模式或正常退出 WeQ 时会停止 WeQ 创建的实例，不结束用户自行启动的 QQ。关闭窗口但保留 WeQ 在托盘中运行不等于退出应用。

已保存的托管配置会重新进入托管入口。自动进入、可配置退出策略、睡眠恢复及真实扫码后的完整兼容性仍在验收和开发中。
