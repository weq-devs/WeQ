# Web 服务与手机连接

桌面端进入「设置 → 服务与集成 → Web 与 Remote」。Web 服务与远程连接是两个独立开关，默认都关闭。

手机 App 的源码与原生构建已迁入独立的 WeQ Remote 仓库，Web 页面、业务功能和电脑授权仍由 WeQ 提供；使用方式与现有配对不变。开发维护入口见[仓库拆分说明](../develop/remote-repository-split-20261023.md)。

## 本机 Web 服务

- **启用 Web 服务**：在当前桌面进程中启动 Web 入口，复用已打开的账号，不再启动另一份 QQ 或 Web 后端进程。仅监听 `127.0.0.1`，界面显示实际可用地址；默认尝试 7690，被占用时向后尝试，不接管其他服务。
- **启动 WeQ 时自动开启 Web 服务**：只保存 Web 自动启动偏好，不自动开启远程网络或批准设备。手动关闭 Web 不会清除这项偏好。
- 本机浏览器第一次打开需要访问令牌，可在设置中复制。令牌在每次启动 Web 服务时重新生成，不出现在地址或状态查询中。
- 复制完成会显示「已复制令牌」并弹出成功提示；剪贴板不可用时会尝试兼容复制，仍失败则在 Web 操作区明确提示，不展示令牌内容。
- 关闭 Web 后，网页请求和订阅停止；远程网络开关不受影响。退出 WeQ 会同时关闭本轮 Web 和远程网络。

开启「允许远程连接」时，若尚未启用 Web 自动启动，会推荐「开启并记住」。选择「暂不开启」不修改偏好；稍后仍可单独开启 Web。

## 连接方式

顶层只有「局域网」和「Tailscale」；Tailscale 下再选择手机上已有或没有 Tailscale。手机首页仍只保留扫码和配对链接输入。扫码即发出连接申请；粘贴链接后点箭头或键盘「连接」。电脑弹出连接请求，核对校验码后批准一次，手机随即进入 WeQ Web。均不需要自建服务器。

### 局域网

1. 开启 Web 与远程连接，选择「局域网」，直接生成二维码。
2. 手机扫码，电脑批准。无需 Tailscale 登录或 Key。

手机通过系统路由连接电脑，使用 HTTPS 和二维码中的证书 SHA-256 指纹校验电脑身份。局域网列表只提供私有 IPv4，不接受公网域名、回环或明文 LAN。电脑提供多个地址时可选择实际可达的地址。当前监听 TCP 7691，系统防火墙需允许访问；局域网变化、DHCP 地址改变或客户端隔离可能影响可达性。

### Tailscale

#### 手机上已有 Tailscale

1. 选择「Tailscale → 手机上已有 Tailscale」，手机的系统网络需能访问电脑的 Tailscale 地址。
2. 手机无需 Auth Key 或再次登录。地址列表只包含 `100.64.0.0/10` 的 HTTPS 地址；电脑尚未入网时，先通过上方验证链接连接电脑节点，或连接电脑的系统 Tailscale 后刷新地址。
3. 手机扫码直接使用系统网络，不启动 App 内嵌节点。首次电脑批准后长期保存凭据。

电脑可使用系统 Tailscale（TCP 7691），也可使用 WeQ 已配置的内嵌电脑节点（HTTPS TCP 7692）。网络 ACL 需允许相应端口。配置过内嵌网络后，切换配对页面不会关闭它；各入口共用设备授权和稳定证书，不删除已配对设备。刷新地址会短暂重启连接入口，不清除凭据。

#### 手机上没有 Tailscale

1. 选择「Tailscale → 手机上没有 Tailscale」，开启远程连接，点「验证 Tailscale」完成电脑节点登录。「更换网络」可用新身份重新验证，原节点仍需在原网络管理台移除；不会改变手机已有/没有的选择。
2. 点「生成 Auth Key」进入官方管理台，关闭 **Reusable** 和 **Ephemeral**，使用短期入网 Key。建议将手机节点权限限定到此电脑的 TCP 7691；不能同时保留绕过该限制的全网互通规则。
3. 填入 Key 并生成二维码，手机扫码自动入网、发出连接申请，电脑批准后进入 Web。手机不再弹入网确认或要求登录。

Key 只用于本次邀请，不保存为 WeQ 设置。客户端只能校验 Key 格式，不能证明其为一次性或非临时密钥。内嵌 TS 不占用系统 VPN；系统 VPN 的路由、防火墙或退出节点仍可能影响内嵌连接。

## 记住与删除设备

批准后电脑持久保存设备令牌的哈希，iOS 使用 Keychain，Android 使用 Android Keystore 加密保存令牌；不保存原始入网 Key。切后台关闭当次连接，返回或重启 App 后使用已有凭据重连，不重新扫码、生成 Key 或批准。远程开关及连接方式也会保存，电脑下次启动可恢复服务。

电脑「已配对设备」支持删除，删除后旧令牌失效并断开订阅；手机工具栏也可删除本机保存的电脑凭据。关闭服务不等于删除设备。手机删除只清除手机持有的凭据，电脑上的授权记录可再单独删除。清除凭据、主动删除授权或网络身份丢失后需要重新配对；卸载、系统恢复时凭据是否保留由平台决定。

网页启动时优先复用电脑当前已打开的账号，不会为了连接手机而重新打开该账号。静态页面资源支持压缩传输；同一电脑与授权下，手机在同一 App 进程内重连时可复用隔离的内存缓存，减少重复下载。退出进程后仍可能需要重新下载资源，这不影响已保存的设备凭据。

WeQ 不设置每次使用的验证步骤，但 Tailscale 管理员仍可撤销节点或要求到期重新认证。若需要长期无人值守，可按自身安全策略在官方管理台关闭对应节点的 Key Expiry；这与一次性 Auth Key 的有效期不同。参见 [Tailscale 节点过期说明](https://tailscale.com/docs/features/access-control/key-expiry)。

## 手机竖屏界面

Web 在不超过 760 像素的窗口中使用手机布局，原生手机壳内的 Web 页面也复用这一布局，无需增加原生业务组件。

- 首次进入账号显示消息列表。底部固定「消息、联系人、空间、更多」，未读数保留。
- 邮箱、频道、收藏、年度报告、个性装扮、应用和设置在「更多」中，主页、切换账号与快捷控制也保留在这里。
- 进入聊天或资料详情后收起主导航，使用页内返回按钮回到列表。聊天草稿仍由现有草稿能力保存。
- 设置先显示分类列表，选择分类后显示内容及其二级标签；左上角返回分类，再返回主界面。
- 搜索位于顶部放大镜；聊天输入区按可视视口高度调整，适配安全区，并保留系统双指缩放。

桌面宽屏仍使用原来的标题栏、侧栏和分栏设置。界面调整不改变连接凭据、设备授权或 QQ 数据。

## 安全与范围

- 二维码包含入网秘密，请勿分享或上传。二维码约 120 秒后失效，但这不是 Tailscale Key 的实际过期时间；刷新二维码不能撤销尚未消费的 Key。
- 撤销 WeQ 配对会拒绝该凭据并关闭对应 WebSocket，但不会自动从 Tailscale 网络移除设备，也不会远程抹除手机已经显示的内容。网络节点和 Key 请在 Tailscale 管理台撤销。
- 「完整 Web 访问」不是只读聊天权限，包含当前 Web 版允许的数据读取和业务操作。旧版 `status:read` 设备不会自动升级为完整 Web 权限。
- Web 入口不能管理远程授权、Web 开关或桌面应用更新；文件操作使用 Web 宿主，不在电脑上弹原生文件选择框。
- Android 0.3.0 / iOS 0.3.2 仍为开发测试版，不是应用商店正式发布。真实手机、公共控制面登录、相机扫码、蜂窝切网、长时间耗电及移动端各项业务功能仍需分别验收。
