# Web 服务与手机连接

桌面端进入「设置 → WeQ 服务 → Web 与 Remote」。本机浏览器访问与远程连接是两个独立开关，默认都关闭，任一入口均可单独使用。

手机 App 的源码与原生构建位于公开的 [WeQ Remote 仓库](https://github.com/weq-devs/WeQ-Remote)，[1.0.0b2 安装包](https://github.com/weq-devs/WeQ-Remote/releases/tag/v1.0.0b2)已发布，提供 Android arm64 APK 与 iOS arm64 未签名 IPA，iOS 安装前需正确签名 App 与内嵌 Framework。Web 页面、业务功能和电脑授权仍由 WeQ 提供；使用方式与现有配对不变，配合 WeQ 2.6.0 使用本轮加载进度与缓存改进。开发维护入口见仓库拆分说明。

## 本机浏览器访问

- **允许本机浏览器访问**：在当前桌面进程中启动本机 Web 入口，复用已打开的账号，不再启动另一份 QQ 或 Web 后端进程。仅监听 `127.0.0.1`，界面显示实际可用地址；端口及冲突回退按当前服务端口配置，不接管其他服务。
- **启动 WeQ 时自动允许本机浏览器访问**：只保存本机入口的自动启动偏好，不自动开启远程网络或批准设备。手动关闭本机入口不会清除这项偏好。
- 本机浏览器第一次打开需要访问令牌，可在设置中复制。令牌在每次启动 Web 服务时重新生成，不出现在地址或状态查询中。
- 复制完成会显示「已复制令牌」并弹出成功提示；剪贴板不可用时会尝试兼容复制，仍失败则在 Web 操作区明确提示，不展示令牌内容。
- 关闭本机浏览器访问后，仅停止该入口的网页请求和订阅，Remote 不受影响。退出 WeQ 会同时关闭本轮两个入口及远程网络。

标准浏览器登录会回收过期认证记录，不为腾容量踢掉有效会话。默认最多保留 4096 个有效登录会话；
新登录遇到容量或并发压力时提示繁忙（HTTP 503），可稍后重试或注销不再使用的会话，不代表令牌错误。
大量不同来源连续输错令牌时，新来源可能需要等待 30 秒；清理不会通过删除仍生效的失败记录来放宽限流。

开启「允许远程连接」后，Remote 直接提供共享的 Web 页面与业务 API，不需要开启本机浏览器访问，也不修改其自动启动偏好。关闭 Remote 只停止远程入口；本机浏览器仍可继续使用。两种入口共享电脑当前账号和业务状态，但分别使用浏览器登录与设备配对凭据。

两块设置保留在同一页，操作与错误提示各自独立；一边正在启动、复制令牌或操作失败时，另一边仍可正常管理。

## 连接手机

新版不再要求选择连接模式。Remote 总开关下方同时显示电脑的局域网 IP 和 WeQ 专用 Tailscale IP；专用 Tailscale 服务可以独立启动或停止，不会随之停止局域网入口，也不检测或控制电脑已有的系统 Tailscale。

同一 Wi-Fi 下，开启远程连接后直接点击「生成配对码」，无需开启本机浏览器访问。手机扫码，电脑核对校验码并批准一次即可进入 WeQ Web。局域网通过 HTTPS 连接；监听端口以设置中实际地址为准，防火墙、DHCP 地址变化和无线客户端隔离可能影响可达性。

任务列表、任务详情和日志独立读取，不与其他业务查询合批等待。Remote 不再以统一的十秒响应等待上限中断慢查询；关闭页面或断开连接仍会取消对应网络请求。此修复需要更新电脑端 WeQ 和网络辅助程序，无需更新 iOS 安装包，更新后在手机连接菜单中重新加载页面。

### 通过 Tailscale 跨网络连接

Tailscale 提供内网穿透，让手机和电脑不在同一个 Wi-Fi 下时，也能连接 WeQ，无需公网 IP 或手动配置端口转发。

WeQ Remote App 已内置 Tailscale，无需另外安装客户端。Key 用于让 App 加入电脑所在的 Tailscale 网络：

1. 启动 WeQ 专用 Tailscale 服务，按出现的「登录 Tailscale」入口完成电脑节点登录。
2. 在 Tailscale 管理后台创建 Auth Key；在「生成配对码」旁勾选「嵌入 Tailscale Key」。
3. 点击生成，在弹出的输入框填写 Key 并提交。手机扫码后完成入网并请求 WeQ 配对，电脑批准后进入 Web。

取消 Key 输入不会生成邀请。Key 不保存为 WeQ 设置；手机完成入网后保留自己的节点身份，后续不需要每次提供 Key。专用节点的应用内传输使用 TCP 7691，系统路由 HTTPS 入口使用 TCP 7692，网络 ACL 需允许对应端口。

新版 v4 配对码携带多个连接地址，手机保存这些入口，优先尝试局域网，无法连接时再尝试 Tailscale。手机先探测可达路径，再提交一次配对申请；只读请求或重新打开 App 时也可重新选择路径。需要支持 v4 的新版手机 App；原 0.1.0 不会因电脑更新而自动获得新协议支持。新版手机继续接受旧 v1/v2/v3 邀请。

## 记住与删除设备

批准后电脑持久保存设备令牌的哈希，iOS 使用 Keychain，Android 使用 Android Keystore 加密保存令牌；不保存原始入网 Key。已连接时切后台保留网页，返回前台校验授权，短暂断网在原页重连；重启 App 后使用已有凭据自动连接，不重新扫码、生成 Key 或批准。远程开关及专用 Tailscale 启用偏好也会保存，电脑下次启动可恢复服务。

Remote 冷启动（包括被系统回收后打开），以及手动断开／停止后重新连接，均遵循「设置 → 常规 → 启动与主页 → 启动时进入」当前保存的选择，不受电脑是否一直打开账号影响。选择「主页」或「消息」时从初始页面进入，「消息」只显示列表、不自动打开旧会话；页面的筛选、选中项和阅读位置重置，设置与未发送草稿保留。选择「上次退出时所在页面」时恢复这台手机、当前网页来源及账号配置自己的页面与阅读现场，不跟随电脑端页面；旧会话不可用时显示列表。后台返回、锁屏返回和临时断网重连均保留当前现场，不重新应用启动设置。此修复只需更新电脑提供的 Web 页面，无需更新手机安装包。

电脑「已配对设备」支持删除，删除后旧令牌失效并断开订阅；手机工具栏也可删除本机保存的电脑凭据。关闭服务不等于删除设备。手机删除只清除手机持有的凭据，电脑上的授权记录可再单独删除。清除凭据、主动删除授权或网络身份丢失后需要重新配对；卸载、系统恢复时凭据是否保留由平台决定。

网页启动时优先复用电脑当前已打开的账号，不会为了连接手机而重新打开该账号。静态页面资源支持压缩传输；同一电脑与授权下，手机在同一 App 进程内重连时可复用隔离的内存缓存，减少重复下载。退出进程后仍可能需要重新下载资源，这不影响已保存的设备凭据。

新版共用 Web 会在手机 IndexedDB 中保存昵称、备注、好友与群列表、各类会话目录及摘要，按当前电脑网页来源、账号和配置分区。表情面板的系统表情、最近使用、收藏、商城包列表与已浏览包详情、GIF 标签及已浏览内容、QQ 秀目录、自定义表情最近上传、最近贴表情，以及好友申请、群通知、特别关心和联系人排序指标也会保留。再次进入先显示缓存，再按缓存时间通过现有接口后台刷新；表情等面板仅在打开时读取，不为缓存预取全部目录，刷新失败保留已有数据。列表在内存中被回收后，不会因其他目录更新而丢失已保存内容。缓存只用于列表与摘要，不保存聊天正文或账号密钥；最多保留最近 4 个分区，每个分区最多保留 160 个查询结果，每类目录缓存最多约 10,000 行，超出部分仍通过现有接口读取。表情图片仍使用现有媒体加载与缓存链路，目录缓存不等于已下载所有图片。

会话首屏使用独立请求，避免等待同批的其他目录；后续会话分页、好友／群目录和预览资料分阶段低优先级补齐，保留群助手归类。好友申请与群通知在联系人页打开后读取，好友在线状态也仅在联系人页按需查询，短时间重进复用结果；离开该页不再补后续状态批次。刷新复用现有查询和变更订阅，不增加版本检查或增量同步。

Android 需要更新安装包以稳定保留同一电脑授权的本地代理端口，才能在重连和重启 App 后复用网页存储；端口不可用时提示重试。原随机端口下的数据不迁移，新版首次连接后重新建立缓存。iOS 原生 App 不改，只需更新电脑上的 Web 页面。以上为开发源码行为，不代表真实手机性能已验收。

头像在列表、聊天和弹窗间复用统一的资源地址，小头像控件使用缩略图，较大的头像保留原图。
Web／Remote 对头像保留五分钟浏览器缓存，切换页面不必逐个重新请求；到期后未变化的图片只返回 304，
不重复传图片内容。系统表情、文件图标等共用静态资源也支持短期复用与到期校验。
在 WeQ 内主动更换头像仍立即刷新；其他来源的头像变化会在缓存到期、再次请求时检查。
此项只需更新电脑提供的 Web 页面并在手机重新加载，不需要更换手机安装包，也不会预下载未浏览的头像。

WeQ 不设置每次使用的验证步骤，但 Tailscale 管理员仍可撤销节点或要求到期重新认证。若需要长期无人值守，可按自身安全策略在官方管理台关闭对应节点的 Key Expiry；这与一次性 Auth Key 的有效期不同。参见 [Tailscale 节点过期说明](https://tailscale.com/docs/features/access-control/key-expiry)。

## 手机竖屏界面

Web 在不超过 760 像素的窗口中使用手机布局，原生手机壳内的 Web 页面也复用这一布局，无需增加原生业务组件。

触摸长按在整个页面中复用桌面右键操作，包括会话、联系人、消息及弹窗内的内容，横屏和平板也适用。
移动手指、滚动或加入第二根手指会取消长按；松手不会再触发一次点击。输入框保留系统的光标、选择和编辑菜单。
触摸设备的非编辑内容由 WeQ 长按菜单处理，不再弹出系统文字选择或图片菜单；消息文字可通过 WeQ 菜单复制。
此项只需更新电脑提供的 Web 页面，再在 Remote 中重新加载，无需更换手机安装包。

- 首次进入账号显示消息列表。底部固定「消息、联系人、空间、更多」，未读数保留。
- 页面代码在空闲时分批预加载，消息与联系人列表预渲染并复用。左右切页时旧页与目标页同时跟随手指移动，松手连续滑入或回弹；点击底栏也使用两页过渡。QQ 空间提前准备栏目与骨架，不后台获取内容；停稳后才读取，快速划过不触发读取，滑动期间保留已显示内容。
- 主页、QQ 邮箱、QQ 频道、我的收藏、年度报告、个性装扮、任务、WeQ 助手、分析与报告、导出、导出查看器、合成聊天记录和设置并列显示在「更多」列表中，不再另设菜单按钮。
- 从「更多」打开主页、QQ 邮箱、QQ 频道、年度报告、任务、助手、分析、导出、查看器或合成聊天记录时，保留主顶栏和底部导航；左缘侧滑可返回「更多」，也可直接点底部标签切换页面。
- 邮箱内左缘侧滑先关闭写信或返回上一级邮件会话，再返回邮件列表，最后返回「更多」；写信有未保存内容时先确认，取消后保留原稿。
- 进入聊天或资料详情后收起主导航，使用页内返回按钮回到列表。聊天草稿仍由现有草稿能力保存。
- 设置先显示分类列表，选择分类后显示内容及其二级标签；左上角返回分类，再返回主界面。
- 搜索位于顶部放大镜；聊天输入区按可视视口高度调整，适配安全区，并保留系统双指缩放。
- 普通聊天输入框右侧可直接发送，软键盘使用发送提示；长文展开后回车换行，使用独立发送按钮。发送后保留输入焦点，键盘弹起时不再重复预留底部安全区；表情／更多面板与系统键盘切换显示，选表情不唤起键盘，点回正文继续输入。工具栏及推荐回复的入口保持不变。
- 点击顶部头像打开与桌面相同的「QQ 资料与状态」，「更多」中也保留该入口。
- 顶部加号提供 QQ 号搜索、群号搜索、好友通知和群通知，复用桌面端已有查询与通知入口；QQ 操作取决于电脑当前账号的在线状态和权限。

iOS Remote 移除键盘上方的网页表单导航条需要更新手机安装包；输入框布局与发送提示只需更新电脑提供的 Web 页面并重新加载。系统键盘的实际图标由当前输入法决定。

### 文件与报告

开发源码将布局与客户端能力分开处理：电脑窗口宽度不超过 760px 时使用单栏，仍保留电脑端功能；
手机、平板横屏使用桌面式多栏，较窄横屏收紧导航与列表，连接菜单和 Android 系统返回继续可用。
软键盘不会触发布局方向切换，窗口缩放与旋转保留当前会话、草稿和阅读位置。

Remote 不提供电脑目录选择、QQ 数据与关联资源目录配置、电脑缓存／录音目录修改、电脑文件清理、
实时数据库写入／原地修复／覆盖恢复及 QQ 本机登录数据修改；电脑自启、托盘、权限助手安装、
MCP 本机安装和电脑软件更新安装等也仍由电脑端管理。这些区别与横竖屏无关。
正常聊天、账号切换、只读查看、分析、备份上传恢复和导出继续使用电脑提供的业务服务。

媒体和邮件附件的原位保存优先交给设备下载／分享，不要求选择电脑保存位置。
共享设置仍只有一份；Remote 下载使用本轮任务暂存，不沿用电脑绝对路径，也不改写共享目录设置。
上传取消会停止后续分段和提交并清理本次暂存。助手报告和导出完整性报告可直接预览、下载；
机器人控制台使用客户端打开地址，闪传分享页通过浏览器打开，不依赖 Electron 的嵌入标签。

年度报告在阅读和演示模式均可上滑下一页、下滑上一页。内容可滚动时先滚动，抵达边缘后的下一次
明确手势才翻页；按钮、链接、图表、多指操作和文字选择不会触发翻页，一次手势最多一页。
普通／全屏及横竖屏沿用当前页码；不支持元素级全屏的浏览器使用应用内全屏阅读。

Remote 通话使用页内视图，不因不创建系统子窗口而挂断。iOS 内嵌 HTTP 页面在网页采集不可用时
使用设备原生麦克风和摄像头采集桥；HTTPS 保留原网页采集。Android 旋转保留 WebView 与连接，
并承接全屏视图；iOS 承接网页原生确认、提示与输入弹窗。原生改动需要更新对应手机 App，
源码和构建通过不等于已完成真实设备的权限、采集及旋转验收。

聊天中的「发送文件」可以选择浏览器或手机上的普通文件，不再要求电脑本地路径。
新版网页的设备文件按 1 MiB 分段读取并传到电脑临时目录，单个非空文件最多 2 GiB，
不再要求先把整个文件读进浏览器内存，再复用 QQ 的私聊 / 群文件发送管线；
暂存按闲置时间回收，传输不会自动重试真实发送，
结果不明确时应先检查聊天记录，避免重复发送。群临时会话仍不支持普通文件。

由桌面端开启的内置 Web 和手机 Remote 可以使用电脑离屏渲染，导出年度报告 PDF、长图及生成
空间分享图。报告保存与浏览器下载继续使用既有导出任务入口；分享到空间仍需明确确认和 QQ 在线。
捕获窗口使用独立内存会话，只允许当前自包含报告及内联资源，不读取其他宿主文件或网络资源。
独立 Node Web 部署没有 Electron 渲染引擎，仍不支持 PDF / 图片捕获，可使用 HTML 导出。

开发源码已将个人/群头像、收藏表情与收藏包、群相册图片、公告/评论配图、群文件上传、
邮件附件、本地新增消息图片、合成聊天记录媒体、闪传与自定义聊天背景接入设备选文件及分段暂存。
草稿附件闲置约 30 分钟后回收；真实操作使用附件期间暂停到期清理，账号或数据源变化后停止上传。
这不包含手机本地数据库、chatpic 与导出基线目录的整体导入。

内置 Web / Remote 的私聊、群聊与成员分析也可创建长图导出任务，独立 Node Web 仍需要渲染引擎。
菜单截图在手机壳中生成当前界面图片并打开保存/分享，在支持屏幕采集的普通浏览器中使用浏览器选源，
优先复制到剪贴板，失败则下载 PNG。截图生成或任务受理不表示已保存进手机。
普通浏览器可在网页通知设置中开启撤回、群关键词和邮件提醒；设置各端共享，实际通知由当前浏览器能力
与授权决定。关闭网页后不继续投递，也不替代手机原生推送。

新版 Remote 壳接入 Android 网页文件选择与媒体授权、两端外链和鉴权下载。
Android 通过系统文件保存位置落盘，iOS 下载后使用系统分享菜单；网页生成的 Blob 文件也经过相应处理。
这些原生变化需要更新手机安装包，仅更新电脑上的 Web 页面不会生效。

手机 Web / Remote 的会话页使用单行标题栏，搜索保持常驻，右侧「更多」下拉菜单直接提供
分析、导出、拉取漫游消息、撤回列表、删除列表、添加本地消息和会话设置；群聊另有导出名单、
群资料，以及适用群的反馈入口。短屏时菜单内部滚动，选择操作或点击菜单外部后关闭。
这项页面调整只需更新电脑提供的 Web，不需要更换手机安装包。

桌面宽屏仍使用原来的标题栏、侧栏和分栏设置。界面调整不改变连接凭据、设备授权或 QQ 数据。

### 连接反馈与加载

新版 Remote 连接页在资源下载时用原有圆环显示字节比例，并显示已加载／总大小与资源项数。
电脑按本次 gzip 协商结果在 HTML 内提供首屏 JS/CSS 清单，不增加清单请求；缓存命中也计入已加载资源，
因此数字表示本次首屏资源的完成量，不是移动网络流量账单。单个资源完成后累加数据量，不估算尚未完成的响应体。
下载完成后圆环恢复等待状态，继续显示恢复检查、账号初始化、界面绘制等实际阶段。
需要同时更新电脑端和手机 App；旧电脑未提供清单时仍显示等待状态，不猜测总大小。

主会话界面在恢复检查之后加载，Markdown／代码高亮和备份设置按需加载；基础运行库和图标
合并成稳定资源，减少小请求与更新时的重复下载。Web 启动快照一次读取恢复回执、当前账号和
必要配置，填回原查询缓存，避免界面挂载后重复请求；恢复交接未完成时仍只处理恢复回执。
HTTPS 手机入口支持 HTTP/2，旧客户端继续使用 HTTP/1.1。新版 iOS／Android App 保留资源缓存，
Android 还会边接收资源边交给网页，完整下载后再入缓存；网页 HTML 和业务接口不使用代码长缓存。

实时连接持续未建立时，页面会显示连接或重连状态；恢复连接后自动收起，并补查活动查询、
当前聊天窗口和未读数。短暂握手不闪提示，不重新加载整个页面，也不自动重发消息等操作。
手机底栏和会话列表保留主题色选中反馈，未读数量同时提供给屏幕阅读器；切换页面或进入
详情会关闭「更多」菜单，避免返回后遮住内容。

年度报告、分析报告、关系图与克隆工作区首次打开时按需加载；未访问时不下载它们的
专属代码和样式。首次打开这些页面仍需连接电脑，已访问页面继续沿用原有状态保留机制。

## 安全与范围

- 二维码包含入网秘密，请勿分享或上传。二维码约 120 秒后失效，但这不是 Tailscale Key 的实际过期时间；刷新二维码不能撤销尚未消费的 Key。
- 撤销 WeQ 配对会拒绝该凭据并关闭对应 WebSocket，但不会自动从 Tailscale 网络移除设备，也不会远程抹除手机已经显示的内容。网络节点和 Key 请在 Tailscale 管理台撤销。
- 「完整 Web 访问」不是只读聊天权限，包含当前 Web 版允许的数据读取和业务操作。旧版 `status:read` 设备不会自动升级为完整 Web 权限。
- Web 入口不能管理远程授权、Web 开关或桌面应用更新；文件操作使用 Web 宿主，不在电脑上弹原生文件选择框。
- 手机端仍为开发测试客户端，不是应用商店正式发布。真实手机、公共控制面登录、相机扫码、蜂窝切网、长时间耗电及移动端各项业务功能仍需分别验收。
