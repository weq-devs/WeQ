# 快速上手

这一页讲清楚**从下载到看见第一条聊天记录**的全过程，以及启动时那个 Bootstrap（首页）界面的
每一个按钮。

## 1. 下载与安装

前往 [Releases](../../../releases) 下载与系统匹配的安装包。

| 系统 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| 架构 | x64（**不支持 ARM**） | ARM / Intel | x64 / arm64 |

首次启动需要保证本机已经安装 **QQ NT**：WeQ 读取的是 QQ 的本地数据库，没有 QQ 就没有数据。

macOS 的拖入安装与首次系统放行见 [macOS 安装与首次打开](./macos-install.md)，不需要终端命令或关闭 SIP。

## 2. 首页：Bootstrap 界面

启动后先看到的是 Bootstrap 首页。左上角是品牌 Logo 与版本名，右上角固定两个小按钮：

- **打开日志目录**：出问题时把最新日志一并附上；
- **关闭**（非 macOS）：直接关窗。

页面正中只有两张卡片：

| 卡片 | 作用 |
| --- | --- |
| **现有账号配置** | 打开之前已经确认过的本地密钥，无需重新取密钥。没有保存过配置时按钮置灰 |
| **新的开始** | 检测账号并获取数据库密钥 |

> [!important]
>
> 若启动时检测到「本地组件版本过旧」或「组件安装损坏」，会弹出不可关闭的提示框。**版本过旧
> 的那张框内嵌了更新按钮**，可直接检查 / 下载 / 重启安装；安装损坏则需重新安装。若未检测到
> QQ 安装，同样会弹出提示。

### 自动进入

勾选过「下次打开自动进入该账号」后，WeQ 会在启动的加载页里**静默**测试密钥并直接进入账号，
失败才退回首页并提示原因。自动进入前会先把窗口调整成聊天尺寸并预热首屏查询，所以不会先闪
一下空白头像。

## 3. 选择账号与验证密钥

点任意一张卡片进入**双栏选择页**：

```
┌──────────────────────────┬──────────────────────────────────────┐
│ 左栏 登录面板            │ 右栏 诊断与统计                      │
│  账号列表 + 密钥输入     │  QQ 版本 / 数据目录                   │
│  获取密钥 / 进入         │  本地账号 · 目录大小 · 在线实例       │
│  下次自动进入            │  数据库占用（彩色条形图）             │
└──────────────────────────┴──────────────────────────────────────┘
```

- **现有账号配置**模式：左栏列出已保存的账号，密钥已自动填好，点「进入」即可。右键账号可以删除
  该配置（只删 WeQ 保存的配置，不动 QQ 本体数据）。
- **新的开始**模式：左栏额外有两个来源页签——「在线账号」与「本地备份」。
  未选择在线账号时仍可切到「本地备份」导入，不需要先有本机 QQ 登录记录。
- 账号列表读取失败会显示原因，可点刷新图标重试；已有账号不会因为重新读取失败被隐藏。

### 右栏统计

右栏顶部是 QQ 身份卡：版本号 + 数据目录路径。**点击路径**可以随时重新指定 QQ 数据目录
（例如把 QQ 数据挪到了别的盘）。文件夹叫什么都行——老版本 QQ 迁移过来的目录通常不叫
`Tencent Files`——只要选到「存放 QQ 号子目录 / `nt_qq` 的那一层」即可；选成某个 QQ 号
子目录时会自动上溯一层。下方三张统计卡：

- **本地账号**：`login.db` 里发现的历史账号数；
- **目录大小**：当前选中账号目录的总大小，扫描时数字会实时向上滚动；
- **在线实例**：当前正在运行的 QQ 进程数；

再下面是「数据库占用」卡：按文件大小画出类似 GitHub 语言条的彩色条形，列出最大的若干个数据库。

## 4. 获取数据库密钥

在「新的开始 → 在线账号」下选中一个账号，点「获取密钥」。WeQ 会**自动探测 QQ 在线情况并动态
选择方案**，无需你手动指定：

1. **QQ 在线实例** —— 直接从运行中的 QQ 取密钥。
   - Windows：直接进程内注入；
   - Linux：先弹出授权（`pkexec` 或 root 下的进程内注入）；
   - macOS：受 SIP 限制不注入，改为**提权扫描进程内存**恢复密钥；扫不到会引导「解除 SIP 重试 /
     杀掉 QQ 重启取密钥」。
2. **可快速登录** —— 走快速登录（复用本地 `a1Key`）。
3. **否则** —— 走**扫码登录**，用手机 QQ 扫码。

> [!note]
>
> macOS / Linux 上登录流程需要安装 **NineBird** 才能重启 QQ 取密钥，WeQ 会在需要时弹出管理员
> 密码框自动完成安装。

也可以用手机扫码**登录一个新的账号**：在左栏底部点「登录新的账号」。

### 验证后进入

无论密钥从哪来，点「进入」时 WeQ 都会**先测试密钥**（`testDatabaseKey`）：

- 密钥不正确 → 弹出错误框，拒绝进入；
- 正确 → 打开账号、写入配置，进入主界面。

想省事可以勾选 **下次打开自动进入该账号**。

## 5. 本地备份（静态离线账号）

在「新的开始」页签切到 **本地备份**，选择包含 `nt_msg.db`、`profile_info.db`、`group_info.db` 的目录，导入一份**静态离线账号**：

- 支持平铺数据库目录、Tencent Files 根目录、Windows 的 QQ 号目录，以及 Linux/macOS 的 `nt_qq_<hash>` 账号目录；所选目录没有账号时自动检查下一级，仍未找到则询问是否递归扫描。
- 找到多个账号目录时自动弹出可滚动的选择窗口，逐项展示可验证的账号昵称、QQ 号、数据库数量和体积、媒体目录状态；点击「使用此目录」确认，之后可通过「切换账号目录」重新选择。取消或按 Escape 不改变已选目录。加密库尚无法识别身份时会标记待验证，不把目录名冒充实际身份。
- 明文数据库无需密钥；Android 备份优先尝试自动推导，再验证已有配置密钥。需要其他设备密钥时，先复用同账号已有且仍匹配当前 QQ 进程的会话物料；必要时读取该账号 QQ 内存并按平台流程请求提权，再请求和验证密钥。完全离线或获取失败时可手动输入密钥。
- 备份包含标准 `nt_data` 目录时直接使用其中的图片、语音、视频、文件和表情；没有时保留原有的同账号本机媒体关联与在线补全能力。
- 扫描结果显示包含数据库和媒体的完整账号文件夹，而不是仅显示 `nt_db`；内部会分别定位数据库与媒体。旧备份的 `profile_info_v2` 等资料表也可识别，自动取密钥成功后会显示对应状态。
- 数据目录、密钥、算法都会记住，下次可直接打开；
- 静态账号只有一个数据库快照，因此维护工具里的「本地缓存」入口会禁用；查看快照请用「数据库管理」。

桌面端各用途的文件、文件夹与保存弹窗分别记住上一次确认的位置，重启后仍有效；取消选择不会覆盖记忆。

三端的常见布局如下，迁移到其它位置后仍按目录结构识别，不依赖当前运行系统或根目录名称：

| 来源系统 | 数据库目录 | 媒体目录 |
| --- | --- | --- |
| Windows | `Tencent Files/<QQ号>/nt_qq/nt_db` | 同层 `nt_data` |
| Linux | `~/.config/QQ/nt_qq_<UID哈希>/nt_db` | 同层 `nt_data` |
| macOS | `~/Library/Containers/com.tencent.qq/Data/Library/Application Support/QQ/nt_qq_<UID哈希>/nt_db` | 同层 `nt_data` |
| 平铺导出 | 所选目录中的 `.db` 文件 | 所选目录中的 `nt_data`（如果有） |

## 6. WeQ Web（浏览器版）

除桌面版外还提供 **WeQ Web**：同一套界面跑在浏览器里，适合无桌面环境的机器（NAS / 服务器 /
WSL），或想从别的设备访问。

- 每个平台一个压缩包，**需自备 Node ≥ 22**，无需联网安装依赖；
- Windows 双击 `start.bat`，Linux / macOS 执行 `./start.sh`；
- 终端会打印地址和访问令牌，浏览器打开后粘贴令牌即可进入；
- 默认只监听 `127.0.0.1`，**对外暴露前必须显式设置 `WEQ_TOKEN` 并放在 HTTPS 反向代理之后**。

网页版与桌面版的差异：窗口控制、在文件管理器中定位、应用锁、自动更新、窗口截图、语音转文字
等依赖原生外壳的能力不提供，对应入口会隐藏；QQ 空间 / QQ 频道改为在浏览器新标签页打开；导出
统一落到 `WEQ_EXPORT_DIR`。

详见 [apps/web/README.md](../../../apps/web/README.md)。

## 7. 首次进入的欢迎框

第一次进入账号后会弹出一次欢迎说明框，点击「开始使用」后不再出现（无 ESC / 点遮罩关闭）。

v2.0.0 起这个框还负责**征询是否扫描 QQ 内存**（原先该开关默认开启，用户无从得知可以关）：

- 扫描登录中的 QQ 进程内存可解锁完整体验 —— **拉取漫游消息**、**下载本地不存在的媒体**、
  **发送消息**、**群操作与群管理**、**一键反馈 bug**，以及群相册 / 空间 / 装扮等在线内容；
- 开关**默认勾选（推荐）**，不需要的话取消勾选即可，之后进入的是纯离线模式；
- 也可以随时在 **设置 → 账号基础 → 自动读取 QQ 内存** 里改。

> [!note]
>
> 升级到 v2.0.0 时，确认过旧版欢迎框的用户会**重新看到一次**这个新版引导（以征得上述同意），
> 确认前扫描内存默认关闭。
