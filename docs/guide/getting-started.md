# 快速上手

首次运行时，打开**新的开始**，选择需要使用的账号

> [!important]
>
> 这里不需要做任何额外的操作，**程序会自动完成以下探测**
>
> - 探测QQ数据路径（**支持任意自定义**）
> - 解密登录数据库，获取**全部可用账号**
> - 探测QQ进程，以及各进程的登录状态（**使用锁的机制**）

选择好账号后，**点击获取密钥即可**，大概率能成功获取密钥并成功进入账号

### linux 单独说明

可能会提示提权，**打开进程和修改应用均需要root权限** 
输入密钥即可

### MacOS 单独说明

- 如果你解除了SIP限制，程序可以**直接从QQ内存里面扫描出数据库密钥**
- 如果你没有解除SIP限制，或者QQ没有在线，程序会安装ninebird**帮你拉起QQ获取密钥**
  和linux一样的，安装ninebird的时候**需要提权到root**

> [!important]
>
> ninebird**不影响日常QQ使用**，如果需要卸载，进入账号后可在设置里面完成
