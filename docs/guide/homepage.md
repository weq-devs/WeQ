# 主界面与账号

进入账号后，左侧导航选择内容，右侧浏览或操作。当前分支的界面与已发布版本可能不同。

## 内容与工具

左栏依次提供消息、联系人、QQ 空间、QQ 频道、QQ 邮箱、收藏、个性装扮和设置。克隆会话与普通会话共用消息列表；没有独立的「更多功能」菜单。窄屏导航可横向滚动，账号头像保持可达。

- **标题栏搜索**默认搜索当前账号的真实资料与已浏览空间内容，个人/他人空间可独立选择，生成对话和商城目录可手动加入，详情见[全局搜索](chat-view.md#全局搜索)。
- **工具按钮**打开导出、任务、分析与报告、WeQ 助手和合成记录等操作。全局导出与分析始终显示完整的内容类型和对象列表，只根据当前位置默认选中对应内容，仍可自由切换；会话菜单或消息多选的入口继续沿用指定范围。导出/分析配置居中显示，任务在入口附近展开。
- **漫游拉取**从会话顶部的消息管理或会话右键进入；已有任务也可在任务工具查看。
- **维护与诊断**位于设置，不放在全局工具条。分类见[设置总览](settings.md)。
- 从设置进入数据库管理、存储占用等维护工具时，左栏继续高亮「设置」；关闭工具后返回对应设置页。

设置和个性装扮使用主内容整页；报告、群文件、群相册以及抓包等诊断页面统一不显示额外的顶部页签，使用内容自身的标题和关闭入口。会话附属内容在右侧查看，关闭后恢复群资料栏；会话设置与任务列表在按钮附近打开非模态小窗格。聊天记录搜索、记录查看和本地消息编辑使用可拖动、可缩放的应用内浮窗，双击标题区恢复默认位置与大小，不创建系统窗口。收藏、个性装扮和设置按实际打开状态高亮左栏入口；商城表情已并入个性装扮页签。

## 快捷控制与工具停靠

截图、隐私、主题和锁定位于左栏底部的折叠区域。连续悬停 500ms 展开，连续移出 1s 收起；点击可固定，图钉表示固定状态，再次点击或 Escape 解除固定。固定后失焦或点击外部不会取消。

圆形工具按钮可拖动，也可停靠在快捷控制上方。点击或连续悬停可展开扇环工具菜单；拖动时收起并提示停靠位置。位置和停靠偏好会保留，动画尊重系统减少动态效果设置。

## 消息与联系人

会话列表顶行提供搜索、多选、真实/虚拟范围和添加；“+”先打开菜单，选择后再创建克隆。好友与群列表同样支持搜索和多选，快捷键见[消息页](chat-view.md)。

左栏「消息」入口显示未读消息总数，免打扰会话不计入汇总；超过 99 条显示 `99+`，全部已读后红点消失。「设置 → 个性显示 → 消息显示 → 显示消息汇总红点」可关闭该角标，默认开启，全局保存；不影响会话旁的未读数和已读状态。点击汇总红点会定位到当前列表顺序中最上面一条有红点的会话（置顶优先），自动清除列表筛选，但不打开会话或标记已读；窄屏下会先返回会话列表。

通过 WeQ 发送的消息在服务端确认并保存本地缓存后，会立即更新会话列表的预览、时间和排序，不必等待 QQ 写入会话摘要。重启后仍能从缓存恢复；QQ 同步到同一条或更新的消息后优先显示 QQ 摘要。此更新不写 QQ 数据库，也不增加未读数。

跨设备导入的历史会话如果没有 QQ 已读位置，首次打开账号时不会把全部历史当成未读。WeQ 单独保存本地阅读基线，后续由实时监听确认的新消息才累加；漫游补齐和旧消息导入不增加计数，已有的明确提醒仍保留。未读与阅读进度在重启后保留，并按账号及数据目录隔离；离线目录的阅读位置只保存在 WeQ，不修改原始数据库。

真实聊天会话的右键菜单按状态显示一个标记操作：有未读时显示「标为已读」，全部已读时显示「标为未读」；多选右键菜单只要选区有未读就显示「标为已读」。多选后也可通过底部工具栏批量标为已读或未读，一次最多 4096 个会话。一次将 10 个及以上会话标为未读时会弹窗确认，取消不修改状态；标为已读不弹此确认框。撤销入口仅保留在操作后的提示横幅和 macOS 系统「编辑 → 撤销」（Cmd+Z），不在会话菜单或工具栏另放按钮；输入框内仍优先撤销文字编辑。

macOS「编辑」菜单在业务上下文显示「撤销标为已读」或「撤销标为未读」；文本编辑、网页及开发者工具使用原生撤销／重做，具体名称和可用性由当前编辑历史决定，重做使用 Shift+Cmd+Z。会话标记仍只撤销最近一次操作，不支持重做；输入框或弹窗不会误撤销底层会话标记，切换账号后不沿用旧账号的标记记录。

手动标为已读、未读及撤销会写入可写账号的 QQ 本地数据库，同时保存 WeQ 阅读状态；静态只读目录只保存 WeQ 状态。撤销核对阅读水位后恢复本次改动，并合并期间新增的提醒，不覆盖后来变化的阅读位置。手动标记跨重启保存，撤销记录仅在当前打开的账号会话内有效。

手动操作默认不上报。可在「设置 → 账号接入与消息 → 手动标记时上报已读位置」单独开启，与自动阅读同步开关互不依赖。开启后仅手动已读、以及撤销中推进已读水位的操作会上报；QQ 已读上报不能倒退水位，所以手动未读和向未读恢复的撤销只改本地库，不能保证恢复其他端已清除的提醒。

QQ 中收进群助手的群会在「群助手」内部显示，可按群名或群号搜索。内部支持右键与多选，与主列表共享选区；主列表全选包含助手内部会话，并在总数旁注明数量。内部优先显示已置顶的群，通过右键菜单置顶或取消，不再显示直接置顶按钮；手动调整仅按账号保存在当前 WeQ 客户端，不修改 QQ 的置顶或通知设置。从全局搜索、资料卡等入口打开这些群时仍可正常阅读聊天，不会把群移到主会话列表。

联系人页可切换好友、群聊及好友/群通知。点击资料卡查看详情并打开聊天或分析；群里打开的个人资料另有只读私聊预览，不切换主聊天、不发送、不编辑、不标已读。

好友通知与群通知可点击申请人头像打开资料名片，已处理通知、退群通知和在线新申请同样支持。群通知的名片使用该条通知所属群的信息，不受当前聊天选中哪个群影响；仅有 QQ 号时按 QQ 号查询资料。

已退群成员、群公告发布者、群分析中的发言排行和入群批次人物、收藏列表及详情的来源作者也支持点击头像查看名片。有明确群归属时使用所属群；缺少有效 UID 或 QQ 号时仅展示头像。收藏多选时头像参与原有选择操作，不打开名片；导出的分析图片不包含头像按钮。

好友列表在「特别关心」后显示「亲密关系」，汇集本地资料中当前展示为情侣、死党、闺蜜或基友的好友。头像右下角显示对应关系标志，悬停可查看关系名称；普通好友分组中也保留标志。预设关系选项、搭子关系和亲密度分值不作为入组依据，数据随联系人资料刷新。

频道私聊从 QQ 频道页内的局部悬浮按钮进入，不另占全局导航；窄屏可在列表与消息之间切换。

## 合成聊天记录

工具菜单打开独立合成工作窗。左栏「合成记录」可新建或续编，修改自动保存；旧草稿与历史记录也在此查看。需要另一份版本时使用「创建副本」。保存失败保留内容，切换或关闭前会再次尝试。

新建记录在实际编辑标题或消息内容后才出现在左栏，仅打开窗口或展开消息编辑器不会生成空记录。拖动消息旁的排序手柄可调整顺序，落点线标示插入位置；聚焦手柄后也可用上下方向键移动消息，排序结果自动保存。

消息右键或多选栏的「添加到素材库」只收集快照，不改变当前合成。在工作窗将素材拖到消息之间插入，空白处追加；拖入另一份记录默认嵌套，也可展开插入。自身或循环嵌套会被阻止。

插入内容是独立副本，不随源记录改变。装扮、商城和预览在发起它们的合成窗口内打开。

旧版文本素材会在读取时兼容迁移；重复拖入同一素材会生成独立节点，不复用编辑身份。
损坏、循环或超深记录会单独提示，不清空当前合成，也不删除源记录。外来文件或链接拖放不会让编辑窗口跳转。

## 切换与退出

点击左栏底部账号头像可切换账号、退出、上锁、切换主题、隐私模式或截图。

- 切换时清除旧账号查询与内存现场；同一 QQ 号的在线与静态配置可分别选择。
- 删除账号配置只删除 WeQ 侧配置，不删除 QQ 本体数据；当前配置须先退出。
- 退出会停止该账号的监听并返回账号选择页；未保存的编辑按各页面提示处理。

## 隐私与主题

隐私模式遮罩聊天、资料、空间、收藏、搜索和导出目标，悬停不会揭示明文；桌面截图会包含遮罩。它只是视觉保护，不加密 DOM、数据库或导出文件。

浅色、深色、跟随系统、自定义主题色和界面背景在「设置 → 个性显示」配置。左栏主题按钮是快捷切换，会固定为明或暗模式。
