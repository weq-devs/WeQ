# 主界面与账号

进入账号后就来到主界面。这一页讲界面布局、联系人页，以及左栏底部那个账号头像里的所有操作。

## 1. 界面总览

主界面是「左侧竖排导航栏 + 右侧内容区」的两栏结构。

### 左栏导航

| 图标 | 名称 | 点击后 |
| --- | --- | --- |
| 💬 | **消息** | 最近会话列表 + 聊天窗口 |
| 👤 | **联系人** | 好友 / 群聊 / 通知 |
| ⭐ | **QQ 空间** | 内嵌 QQ 空间（网页版为新标签） |
| # | **QQ 频道** | 内嵌 QQ 频道（网页版为新标签） |
| 书签 | **我的收藏** | QQ 收藏查看与导出 |
| 商店 | **商城表情** | 商城表情包浏览 |
| 调色板 | **个性装扮** | 聊天气泡 / 字体 / 头像挂件 / 聊天背景 |
| ⚙ | **设置** | 主内容区设置页；有新版本时右上角带红点 |

克隆会话与正常会话一起显示在消息列表，不再单独占用左栏入口。「更多功能」菜单已移除；窄屏导航可横向滚动。

导出、任务、消息补全、分析与报告、WeQ 助手由工具按钮进入。数据库与密钥维护、防撤回、高级诊断、模型使用统计、帮助均位于设置。

### 设置分类

设置采用一级分类与页内二级导航，最多两层：

| 分类 | 二级内容 |
| --- | --- |
| 常规 | 窗口行为、开机启动、默认保存 |
| 个性显示 | 主题与背景、消息显示 |
| 隐私与安全 | 应用锁 |
| 账号与消息 | 账号管理、接入与监听、防撤回、QQ 空间设置 |
| 数据与存储 | 缓存与网络、媒体来源、损坏处理与容错、容错记录、维护工具 |
| 模型与识别 | 模型配置、语音转写、语音合成、图片识别、模型使用统计 |
| 服务与集成 | MCP、SSE 推送、外部 RKEY、后台服务 |
| 高级与诊断 | 账号凭据、抓包与解析工具入口 |
| 帮助与关于 | 帮助、日志设置、版本、更新提醒 |

账号凭据与普通配置分开，密钥、rKey、ClientKey 默认隐藏。只有容易误解的项目说明作用范围；不为所有设置重复标注。

空间页的齿轮按钮打开同一份空间配置。WeQ 助手工具内的齿轮按钮配置 QQ 公众号推送，返回对话不销毁聊天现场。数据库浏览、修复、抓包与解析在独立工具界面打开。

### 左栏快捷控制与工具停靠

截图、隐私模式、主题切换和锁定默认折叠在“快捷控制”中；悬停临时展开，点击可固定展开。固定模式显示图钉，移出、点击外部或窗口失焦都不会取消固定；再次点击或 Escape 返回自动折叠。账号头像保持独立可见；Web 不显示桌面专属按钮。

圆形工具按钮可自由拖动，也可拖到快捷控制上方停靠。拖动期间停靠位置持续提示，靠近时加强提示；停靠后仍可拖出，位置与停靠偏好会保留。点击展开扇环菜单，按窗口边缘调整方向；支持键盘导航和减少动态效果。

频道私聊从 QQ 频道页面右下角的局部悬浮按钮进入，不在全局工具或更多功能中重复提供。查看本地私聊后可返回频道，再次进入会保留已选会话；窄屏通过返回会话列表按钮切换列表与消息。

设置及其维护工具在主内容区打开，全局工具仍可使用。内容标签支持切换和关闭，原聊天现场不会因打开内容页而销毁。资料、消息记录、下载与克隆进度使用非模态面板或轻量浮层，不压暗背景，也不拦截面板外的操作；高风险确认、认证与媒体大图仍保留聚焦展示。

全局「任务」使用带背景遮罩的居中弹窗；关闭、重开或切换工具保留任务阅读现场，不中断后台任务。导出、消息补全与 WeQ 助手同样保留各自的居中遮罩。

群文件、群相册、群公告和聊天分析等会话附属内容在会话区域右侧显示，左侧保留聊天，不占据整屏；关闭后恢复原群资料栏。

### 顶部标题栏

内容区顶部是当前会话/页面的标题栏。聊天的标题栏里还有搜索聊天记录、导出聊天记录、添加消息、
删除列表、撤回列表，以及群聊专属的群公告、群精华、群相册、群文件、群分析、反馈 Bug 等按钮
（详见[消息页](./chat-view.md)）。

## 2. 联系人页

点左栏「联系人」进入。页面分三块：

### 顶部工具区

| 按钮 | 作用 |
| --- | --- |
| **好友通知** | 好友申请 / 被删除等通知 |
| **群通知** | 入群申请、被移出群等通知 |
| **好友 / 群聊** 切换 | 在好友列表与群聊列表之间切换 |

### 搜索与添加

窗口标题栏的搜索图标展开全局搜索，结果可按类别调整范围，详见[消息页的全局搜索](./chat-view.md#全局搜索)。列表里的 **+** 按钮展开两项：

- **创建群聊**；
- **添加好友/群聊**（快速加好友或加群）。

### 联系人资料

点击好友或群聊打开资料卡：

- 好友资料卡展示昵称、备注、QID、分组、状态、所在地、教育经历、生日、亲密度、成为好友时间、
  特权 / 互动标识等；底部有「发消息」与「聊天分析」按钮。
- 群资料卡展示群公告、群简介、群备注、创建时间、群容量、入群问题等。

## 3. 账号头像弹层（左下角）

左栏底部是当前账号的大头像。点头像弹出账号面板：

- **顶部**：当前账号头像 + 昵称 + `UIN` 号 + 「在线」状态；
- **用户名**：账号内部标识；
- **编辑资料**：修改本账号在 WeQ 里的资料；
- **添加联系人**：加好友 / 加群。

面板下方还有几枚功能按钮：

| 按钮 | 作用 |
| --- | --- |
| 🌙 / ☀️ | 切换深色 / 浅色主题（从「跟随系统」点一下会固定到具体模式） |
| 🔒 | **立即上锁**（应用锁开启且验证器/系统认证可用时） |
| 👁 | **隐私模式**开关 |
| 📷 | **截图当前窗口**并写入剪贴板（桌面版） |
| 🗄 | **切换其它账号** |
| ⏻ | **退出账号**，回到 Bootstrap 首页 |

### 切换账号

点开「其它账号」列出所有已保存的账号配置：

- 点某个账号即可切换。切换过程中显示载入页，**不会出现旧账号的残留会话**（WeQ 会先清空
  React Query 的账号级缓存再打开新账号）；
- 右键账号项可以**删除该账号配置**（只删 WeQ 侧保存的密钥与数据目录，不动 QQ 本体数据）；
- 当前账号不会出现在可切换列表里；同一个 QQ 号若同时存在在线账号与静态账号两条记录，
  两者都能互相切过去。

### 退出账号

点「退出」会显式停掉账号监听（QQ 登录实例监听、数据库监听），清空账号级缓存，返回首页。

## 4. 隐私模式

隐私模式是一个全局视觉开关：开启后头像、昵称、会话预览、消息气泡等敏感元素会被整屏模糊，
搜索结果、资料、签名、空间、收藏和导出目标也会遮罩，悬停不再自动揭示；查看明文需关闭隐私模式。适合截图 / 录屏时遮挡隐私。状态会持久化，从 `html[data-privacy]` 根属性
驱动。

因为遮罩是 DOM 上的滤镜，桌面版的「截图当前窗口」会如实截到糊后的效果 —— 截图与隐私模式天然
联动。

## 5. 主题

主题在[设置 → 个性显示](./settings.md)里完整配置（浅色 / 深色 / 跟随系统、主题色、界面背景、
组件风格）。左下角头像弹层里的月亮 / 太阳按钮是快捷切换，点一下会把主题**固定**为具体模式。
