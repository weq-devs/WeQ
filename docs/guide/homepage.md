# 主界面与账号

进入账号后，左侧导航选择内容，右侧浏览或操作。当前分支的界面与已发布版本可能不同。

## 内容与工具

左栏提供消息、联系人、QQ 空间、QQ 频道、QQ 邮箱、收藏和个性装扮；底部的「菜单」统一收纳任务、助手、工具与应用控制。克隆会话与普通会话共用消息列表。

- **标题栏搜索**默认勾选当前可见分类，联系人、群聊与消息跟随消息列表的真实 / 虚拟 / 频道显示范围；空间合并自己与他人的已浏览内容，助手会话独立保留，详情见[全局搜索](chat-view.md#全局搜索)。
- **菜单**上部显示任务或 WeQ 助手，右上角按钮切换两者，标题旁的展开按钮打开完整遮罩弹窗。中下部依次为「分析」「导出」「查看」「合成」，后两项分别打开导出查看器与合成聊天记录；底部依次为设置、锁定、切换账号、截图和深浅色切换。全局导出与分析仍可自选内容与对象，会话菜单或消息多选的入口继续沿用指定范围。
- **漫游拉取**从会话顶部的消息管理或会话右键进入；已有任务也可在任务工具查看。
- **维护与诊断**位于设置，不放在全局工具条。分类见[设置总览](settings.md)。
- 从设置进入数据库管理、存储占用等维护工具时，左栏继续高亮「设置」；关闭工具后返回对应设置页。

设置和个性装扮使用主内容整页；报告、群文件、群相册以及抓包等诊断页面统一不显示额外的顶部页签，使用内容自身的标题和关闭入口。会话附属内容在右侧查看，关闭后恢复群资料栏；会话设置在按钮附近打开非模态小窗格。聊天记录搜索、记录查看和本地消息编辑使用可拖动、可缩放的应用内浮窗，双击标题区恢复默认位置与大小，不创建系统窗口。商城表情已并入个性装扮页签。

## 竖向工作菜单

点击左下角菜单打开竖向面板，点击外部或 Escape 收起；没有悬停展开、固定或拖动停靠。切换任务与助手会记住上次选择，上部内容独立滚动，下部两排按钮固定。

左栏内容入口和菜单使用统一的无边框按钮，悬停、当前页与菜单展开状态分别显示对应底色；键盘操作仍有清晰的焦点提示。消息与邮件数字、联系人通知和菜单提醒保留独立角标。

非全屏任务列表每项最多显示两个常用操作图标，其余收进「更多操作」菜单，无需展开完整面板即可暂停、继续、取消、保存或查看结果。桌面端已保存的导出结果可直接打开或在文件夹中显示，已完成的单文件闪传可直接打开，多文件闪传只打开下载目录；克隆完成后可直接查看克隆体。删除缓存、移除记录、再次保存及完整性报告等次要操作从更多菜单进入。Web 保留导出结果的「下载到浏览器」，不显示打开服务器本地文件的入口。

菜单角标中的数字表示当前颜色的来源数量，超过 99 显示「99+」：每个在途任务、助手当前会话回答中各贡献一个蓝点来源；每个尚未查看的已结束任务（成功、失败或取消）、助手当前会话尚未查看的回答结果（成功或失败）、新版本各贡献一个红点来源。同一入口优先显示蓝色计数，没有在途来源时才显示红色计数；查看当前任务列表会清除已结束任务的红点，查看对应助手会话结果会清除该会话红点，蓝点不受影响。列表刷新或再次打开面板不会恢复已读提醒；新任务或新一轮回答结束后再次提醒，隐藏面板或窗口不算查看。右上角切换按钮只提示另一侧的任务或助手状态，版本更新仍从菜单、设置按钮标到「关于 WeQ → 版本与更新」，不会因查看任务或助手结果而清除。暂停或仍有缺口的任务不算结束，完成记录移除后不再贡献提醒。桌面专属的锁定与窗口截图不会在 Web 控制栏中显示。

任务和助手结果的已读标识按账号及配置保存在当前设备本地，重启 WeQ 后仍生效；新结果或重新运行不沿用旧结果的已读状态。任务列表暂时为空或只返回部分任务时不会删除缺席任务的已读标识；最近查看的任务标识最多保留 4096 项。本地只记录结果标识，不额外保存助手对话原文；若浏览器禁用存储或配额用尽，仍可在本窗口消除提醒，但可能无法跨重启记忆。

资源扫描与清理、数据库维护、备份恢复步骤、模型和更新下载、相册上传、逐条转发、收藏表情导入，以及单文件媒体／表情／装扮等快捷保存，不会在发起时自动展开任务列表。自动定时导出同样在后台运行；漫游拉取只在整次提交时打开列表，不随扫描或子任务反复展开。这些任务仍保留任务记录、进度与结果角标，可从菜单手动查看；普通手动导出、批量资源导出、克隆与闪传保持原有展开行为。

光标停留在截图按钮上满 1 秒时，菜单暂时隐藏，只保留原位的半透明截图按钮；移开光标恢复菜单。此时点击截图，图片不包含菜单和截图按钮。停留不满 1 秒时沿用原截图行为，菜单和截图按钮均保留在图片中。

## 消息与联系人

会话列表顶行提供搜索、多选、真实/虚拟范围和添加；“+”先打开菜单，选择后再创建克隆。好友与群列表同样支持搜索和多选，快捷键见[消息页](chat-view.md)。

左栏「消息」入口显示未读消息总数，免打扰会话不计入汇总；超过 99 条显示 `99+`，全部已读后红点消失。「设置 → 基础功能 → 阅读与未读 → 在消息图标上显示红点」可关闭该角标，默认开启，全局保存；不影响会话旁的未读数和已读状态。在消息页再次点击消息图标，会定位到当前列表顺序中最上面一条普通未读会话（置顶优先）；没有普通未读时，改为定位有未读消息的免打扰会话。群助手仅在开启「群助手显示总消息数」且汇总数大于零时参与定位。关闭消息图标红点不影响此操作，点击汇总红点也仍可定位。定位自动清除列表筛选，但不打开会话或标记已读；窄屏下会先返回会话列表。

通过 WeQ 提交消息时，会立即更新会话列表的预览、时间和排序，预览同时显示「发送中」；连续提交时，尚未开始发送的消息显示「排队中」。收到正常回执后移除状态文字，失败或疑似未送达时显示对应提示，不必等待 QQ 写入会话摘要。已确认并保存到本地缓存的消息重启后仍能恢复；QQ 同步到同一条或更新的消息后优先显示 QQ 摘要。此更新不写 QQ 数据库，也不增加未读数。

消息确认发送失败后，新提交的消息会自动越过失败及此前排队的消息开始发送，后续新消息仍逐条等待回执。失败前已经排队的消息不会自动补发，可点击「排队中」立即发送；失败消息可点击「发送失败」重试。如果前驱消息正在发送或重试，新消息仍正常排队等待。

跨设备导入的历史会话如果没有 QQ 已读位置，首次打开账号时不会把全部历史当成未读。WeQ 单独保存本地阅读基线，后续由实时监听确认的新消息才累加；漫游补齐和旧消息导入不增加计数，已有的明确提醒仍保留。未读与阅读进度在重启后保留，并按账号及数据目录隔离；离线目录的阅读位置只保存在 WeQ，不修改原始数据库。

真实聊天会话的右键菜单按状态显示一个标记操作：有未读时显示「标为已读」，全部已读时显示「标为未读」；多选右键菜单只要选区有未读就显示「标为已读」。多选后也可通过底部工具栏批量标为已读或未读，一次最多 4096 个会话。一次将 10 个及以上会话标为未读时会弹窗确认，取消不修改状态；标为已读不弹此确认框。撤销入口仅保留在操作后的提示横幅和 macOS 系统「编辑 → 撤销」（Cmd+Z），不在会话菜单或工具栏另放按钮；输入框内仍优先撤销文字编辑。

macOS「编辑」菜单在业务上下文显示「撤销标为已读」或「撤销标为未读」；文本编辑、网页及开发者工具使用原生撤销／重做，具体名称和可用性由当前编辑历史决定，重做使用 Shift+Cmd+Z。会话标记仍只撤销最近一次操作，不支持重做；输入框或弹窗不会误撤销底层会话标记，切换账号后不沿用旧账号的标记记录。

手动标为已读、未读及撤销会写入可写账号的 QQ 本地数据库，同时保存 WeQ 阅读状态；静态只读目录只保存 WeQ 状态。撤销核对阅读水位后恢复本次改动，并合并期间新增的提醒，不覆盖后来变化的阅读位置。手动标记跨重启保存，撤销记录仅在当前打开的账号会话内有效。

「设置 → 基础功能 → 阅读与未读 → 未读提醒 → 向 QQ 服务器上报已读位置」默认开启，自动阅读和手动标记均可上报；已有配置保留明确保存的选择，缺少的字段使用开启的默认值。两类设置不一致时界面会注明，关闭再开启才统一启用。手动上报仅包括标为已读及撤销中推进已读水位的操作；QQ 已读上报不能倒退水位，手动未读和向未读恢复的撤销不能恢复其他端已清除的提醒。

QQ 中收进群助手的群会在「群助手」内部显示，可按群名或群号搜索。内部支持右键与多选，与主列表共享选区；主列表全选包含助手内部会话，并在总数旁注明数量。内部优先显示已置顶的群，通过右键菜单置顶或取消，不再显示直接置顶按钮；手动调整仅按账号保存在当前 WeQ 客户端，不修改 QQ 的置顶或通知设置。从全局搜索、资料卡等入口打开这些群时仍可正常阅读聊天，不会把群移到主会话列表。

联系人页可切换好友、群聊及好友/群通知。直接进入、尚未打开好友或群聊时，右侧默认显示「群交集」。好友与群聊标签分别保留选中的详情，切换其他页面后返回仍停留在原对象和好友分区，不再意外回到群交集；也可主动点击「群交集」返回关系图。好友与群聊详情顶部统一提供「查看消息」与「预览消息」，预览在当前详情内显示，可通过「返回资料」回到原分区或群资料。群内个人名片也支持只读私聊预览；这些预览均不切换主聊天、不发送、不编辑、不标已读。

联系人详情占满右侧区域：顶部横向显示身份与常用操作，好友正文分为个人资料、兴趣照片和好友关系；群聊正文展示公告、群资料、相册/文件/精华入口及成员列表。群资料同时显示与群聊排序一致的活跃度和群内好友数，复用「好友/群信息缓存」，未取得数据时显示「未知」，打开资料不会自动在线更新。宽屏双栏、窄屏单栏，顶部「群交集」可返回保留现场的关系图。群成员复用分页加载与全群关键词搜索，点击成员打开对应群的名片，成员加载失败时可重新加载；共同关系未读到时显示「未知」。聊天、搜索等其他入口仍使用紧凑名片。

群资料的「扩展资料」单独展示服务端 grade、活跃成员数、冻结状态及已返回的头像元数据。打开具体群资料后按需读取，五分钟内复用账号缓存，可手动刷新；离线或读取失败保留已有缓存。未返回的字段显示未知，不把 grade 换算为星级，也不为活跃成员数附加未经确认的统计周期。该读取不更新群名／备注，不修改 QQ 原库，也不触发全量群查询；桌面、Web 和 Remote 共用。

群交集中的「群友圈子」「群聊网络」单击头像即可在旁边打开对应的个人或群聊名片，不再额外展示右上角的信息卡；拖动头像仍用于调整图谱位置，不会打开名片。

群交集首页的「更新成员」和图谱中的刷新按钮复用联系人刷新任务，点击后先弹窗确认，只在线更新全部群的完整成员名单，不更新好友信息、群资料或其他联系人指标。进度、取消和继续操作统一显示在任务列表；QQ 不在线时任务暂停，个别群失败时保留其旧名单并继续其余群，可仅重试失败项。任务等待群交集基础数据重算成功后才标为完成，更新期间保留当前结果；页面漏收通知或离开后返回时会补读状态和新结果，不重复拉取名单或强制重算。完整名单按账号保存在本机缓存，缺少快照的群回退本地群资料库；平时打开页面不自动发起全量在线更新。

个人详情内可切换「资料」「个性主页」「互动标识」「互动画像」，直接在正文显示，不再打开叠加的资料弹窗。个性装扮与互动标识仍需有效 QQ 号及在线能力，互动画像遵循原有独立开关；缺少必要身份时相应分区不可选。互动标识可点开单个标识的等级小窗，画像仍标明启发式推断与样本数量。

好友、群友名片右上角的展开按钮跳转对应的联系人详情，群名片则跳转群聊详情并切换左栏分类；原名片随跳转收起。目录外的群友或群也可临时查看详情，不会被自动添加为好友或写入群目录。小名片不再显示个性主页、互动标识、互动画像入口；私聊顶栏的互动画像入口也改为直达联系人页对应分区。

好友通知与群通知可点击申请人头像打开资料名片，已处理通知、退群通知和在线新申请同样支持。群通知中的群名也可点击打开对应群名片，不受当前聊天选中哪个群影响；仅有 QQ 号时按 QQ 号查询资料。通知日期时间按北京时间显示到秒，群通知的处理时间同样显示到秒；在线申请接口未返回时间时不补造时间。

好友／群通知的阅读记录按账号及数据来源保存在电脑端，桌面端、连接同一电脑的 Web 与 Remote 共用。查看后会同步清除其他在线端的红点，断线重连会补读；升级时合并各端已有的已读记录。阅读记录与申请是否处理相互独立，真正新增的通知仍会提醒。

已退群成员、群公告发布者、群分析中的发言排行和入群批次人物、收藏列表及详情的来源作者也支持点击头像查看名片。有明确群归属时使用所属群；缺少有效 UID 或 QQ 号时仅展示头像。收藏多选时头像参与原有选择操作，不打开名片；导出的分析图片不包含头像按钮。

贴表情名单、红包详情中的发送者与领取者、群收款名单、动态消息卡片发布者、合并转发发送者、关键词规则中的已选成员，以及好友／成员分析中的人物头像也可点击查看名片。选人搜索结果仍用于选择成员，动态卡片其余区域仍执行原有跳转；分析图片导出不含名片按钮。合并转发只按记录携带的 UID／QQ 号查询资料，不据此确认作者身份，也不套用外层会话的群信息。

好友和群聊列表顶部同排提供「分组依据」「排序依据」和升降序按钮，选择按账号保存，组内使用所选排序；两类列表均支持「不分组」，平铺后同一对象只显示一次。列表默认宽度为 240px，已有手动设置保留。缺少有效数据的对象始终排在最后，未知不等于零。

分组、排序控件固定在列表顶部；滚动浏览时，当前分组标题吸附在控件下方，进入下一组时自动替换，仍可点击折叠或展开。

| 列表 | 排序依据 | 分组依据 |
| --- | --- | --- |
| 好友 | 备注、昵称、年龄、生日、亲密度、获赞数、QQ 等级、添加时间、共同好友数、共同群聊数、签名更新时间 | 不分组、QQ 分组、出生年份、星座、性别、所在地、亲密关系、添加方向、职业 |
| 群聊 | 备注、群名、人数、活跃度、创建时间、群内好友数 | 不分组、消息提醒方式、我的身份、群容量 |

备注为空时使用昵称或群名；昵称、群名为空时不会把兜底 QQ 号或群号当作有效名称。年龄缺失时用有效完整生日按北京时间推算周岁，列表与名片同等显示，无法确认时显示 `?? 岁`。年龄排序优先按完整出生日期精确排列；没有有效缓存星座且月日不全时，若出生年份等于「今年 − 年龄 − 1」则放在该年最后，否则放在该年最前（含年龄未知或与年份不一致），仅用于排序，不补写生日。没有可用生日时回退资料年龄，不按年龄来源分档。生日先比较月日，同一天再按年龄排序，次级排序跟随升降序；所在地在境内按省、境外按国家分类。群活跃度使用 QQ 活跃度分值，群容量使用人数上限，不是当前人数。

月日不完整但有有效本地星座缓存时，会结合已有出生年、部分月日及按北京时间当前周岁解释的资料年龄推断生日范围。摩羯座保留年初与年末两段；例如截至 2026 年 11 月 11 日，「2010 年、16 岁、摩羯座」可收窄至该年 1 月 1～19 日。年龄排序使用推断范围最早出生日期，生日排序使用年度月日最早边界，在同一列表的范围入口显示，不另分组、不重复联系人；同一入口范围行在准确日期行前，升降序不切换边界。没有有效缓存星座、月日已经完整或资料冲突时，保留原排序。

星座分组与好友、群友资料优先使用完整月日计算的星座，缺月日时才用缓存。出生年份分组优先使用原始年份；仅在星座补全得到唯一年份时加入对应年份组，资料与排序摘要注明「推断」。推断出多个可能年份时仍归入原有「出生年份未知」。月日缺失时，生日摘要仅显示可用年份与星座，不显示缺失提示；点击可展开「推断生日」范围或冲突原因，目录摘要悬停也可查看。排序边界不作为真实生日显示，也不回写 QQ 数据库。仅有年龄或仅有完整月日的原有处理不变，不新增生日提醒。

好友与群友资料显示本地已缓存的职业、血型和生肖；生肖不用于反推出生年份。职业显示 QQ 职业目录中的名称（例如「学生」），血型显示「A型」「B型」「O型」「AB型」或「其他」；未识别的编号仍显示为「职业（编号 N）」「血型（编号 N）」，未填写的字段不显示。职业可通过联系人搜索框按名称检索、按职业分组，未缓存者归「职业未知」。这些操作不触发在线资料刷新。

本地签名旁显示对应的更新时间，使用北京时间并精确到秒；没有签名或有效时间时不显示时间。目录的「签名更新时间」默认最新在前，切换升降序时未知值均沉底。签名更新时间不是整个资料的刷新时间或最后活跃时间。

群资料中的自定义标签可点击展开当前缓存记录的设置者与设置时间，支持键盘及触屏；同名但来源不同的标签分别保留。设置者优先显示本地备注、群名片和昵称，缺少资料时显示 UID，可继续打开名片。这里只展示当前缓存来源，不表示标签修改历史。

联系人详情的「互动标识」先显示本地已有的标识，再使用原有在线接口更新。更新失败保留本地内容，成功后使用在线结果，包括明确的空结果；本地记录不推测等级、天数或点亮状态，无法确认名称时显示种类编号，图标失败显示占位。机器人及非好友的入口条件不变，查询按账号与数据源隔离。

亲密关系只作为分组依据，不额外显示一个「亲密关系」特殊分组；「特别关心」特殊分组仅在 QQ 分组和亲密关系两种模式显示。按亲密关系分类时，仅使用当前展示的情侣、死党、闺蜜或基友关系；预设选项、搭子关系和亲密度分值不作为依据。头像右下角仍保留关系标志。只有 QQ 分组模式可以编辑或拖拽真实 QQ 分组，其他模式只影响展示。

联系人列表顶部入口、悬停提示与弹窗标题统一为「更新好友/群信息缓存」。弹窗在选项前提示「选择好友/群信息缓存的更新范围」，通过分段选择控件提供「超 24h 未更新 / 全部 / 不更新」，按账号保留上次选择；「不更新」只刷新列表，不创建缓存任务，此时确认操作为「仅刷新列表」，其余范围为「更新」。时间逐个好友或群维护，超 24h 范围仅处理各自相关缓存超过 24 小时或尚未取得的对象，不使用全局最近刷新时间。切换排序与分组时分别检查本次切换依据的好友/群信息缓存依赖；存在相关缓存超过 7 天或尚未建立的对象时，使用同一弹窗询问，不自动重建，也不因为另一控件需要缓存就重复提示。

已有好友/群信息缓存或群成员名单任务正在运行、暂停时，手动点击更新入口直接打开现有任务，不再弹窗确认；此时仅切换到缓存未完成的分组或排序依据，只应用选择，不弹窗也不跳转任务页面。

更新会在任务列表创建「更新好友/群信息缓存」任务，好友与群聊并行处理，可取消、离线后继续或仅重试失败项。任务详情只显示一个可滚动日志框，保留最近 200 条记录；更新期间保留已有内容，停留在底部时跟随最新日志，向上翻阅时保持当前位置。更新不先清空旧值，成功后逐项替换，失败保留旧结果并记录状态；关闭账号停止任务，已完成缓存保留，重启不自动续作。

用户信息更新范围包含当前好友及完整会话列表中的用户，非好友、临时会话和隐藏／已删除会话也会尝试获取等级、获赞和共同关系，但非好友不查询好友线索（添加时间、添加方向）。群聊只更新当前群目录中的群，不获取已退出或不在其中的群的信息；这些历史群在分组、排序时仍可使用已有本地数据。更新按联系人 UID 或群号去重，不受列表分页、当前搜索及分组影响。缺少 QQ 号时仍查询可按 UID 获取的指标，其余指标记录未完成原因；单项失败继续尝试其他指标，部分成功不判整个对象失败，未取得字段在日志中列明并保留旧缓存；全部请求失败的对象仍记录失败，可单独重试。群内好友数仍只计算当前好友，不将非好友或临时联系人计入。此范围适用于「更新好友/群信息缓存」，不改变单独的群成员名单刷新任务范围。

共同群聊数只采用在线共同群查询结果；群内好友数使用有效成员与完整好友名册的交集，成员缓存不完整时在线补齐后计算。资料卡等日常查询的结果共用同一缓存，相关好友或群成员变化会定向校准；无关资料变化不触发全体在线查询，也不因重复读到同值而重置其他对象的缓存时间。离线使用已有缓存。

「特别关心」名单读取在线 QQ 好友名册的整体特别关心状态，不再使用 QQ 空间名单。刷新联系人或修改特别关心后会重新读取；需要 QQ 在线且已启用完整功能。QQ 刚上线或重连时先等待在线凭据就绪，再自动读取，准备期间保留已有名单。下方「特关我的人数」仍由空间接口提供，读取失败时显示暂不可用，不影响好友名单。

频道私聊从 QQ 频道页内的局部悬浮按钮进入，不另占全局导航；窄屏可在列表与消息之间切换。

## 合成聊天记录

工具菜单打开独立合成工作窗。左栏「合成记录」可新建或续编，修改自动保存；旧草稿与历史记录也在此查看。需要另一份版本时使用「创建副本」。保存失败保留内容，切换或关闭前会再次尝试。

新建记录在实际编辑标题或消息内容后才出现在左栏，仅打开窗口或展开消息编辑器不会生成空记录。拖动消息旁的排序手柄可调整顺序，落点线标示插入位置；聚焦手柄后也可用上下方向键移动消息，排序结果自动保存。

消息右键或多选栏的「添加到素材库」只收集快照，不改变当前合成。在工作窗将素材拖到消息之间插入，空白处追加；拖入另一份记录默认嵌套，也可展开插入。自身或循环嵌套会被阻止。

插入内容是独立副本，不随源记录改变。装扮、商城和预览在发起它们的合成窗口内打开。

每条消息旁可按北京时间修改消息日期与时间（精确到秒），嵌套记录中的消息同样支持。
修改同步用于预览、草稿及发送的合成结果，不改写来源聊天记录。

旧版文本素材会在读取时兼容迁移；重复拖入同一素材会生成独立节点，不复用编辑身份。
损坏、循环或超深记录会单独提示，不清空当前合成，也不删除源记录。外来文件或链接拖放不会让编辑窗口跳转。

## 切换与退出

打开左下角菜单，点击底部中间的账号头像切换账号或退出。锁定、截图与主题切换是旁边独立的按钮。

- 切换时清除旧账号查询与内存现场；同一 QQ 号的在线与静态配置可分别选择。
- 删除账号配置只删除 WeQ 侧配置，不删除 QQ 本体数据；当前配置须先退出。
- 退出会停止该账号的监听并返回账号选择页；未保存的编辑按各页面提示处理。

## 隐私与主题

「设置 → 常规 → 隐私」中的隐私模式遮罩身份、私人内容和凭据，包括聊天、资料、空间、收藏、搜索和导出目标中的敏感字段；保留群人数、时间、seq、等级、个性装扮、统计、按钮与任务状态，关系图保留匿名节点与连线。敏感字段的原生悬浮提示会临时隐藏，桌面截图会包含遮罩。它只是视觉保护，不加密 DOM、数据库或导出文件，也不静音或改变复制内容；第三方网页和未建模的原始数据仍需自行检查。

浅色、深色、跟随系统、自定义主题色和界面背景在「设置 → 常规 → 主题与背景」配置。菜单底部的主题按钮是快捷切换，会固定为明或暗模式。
