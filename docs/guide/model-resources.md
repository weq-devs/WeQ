# 模型设置

模型设置位于 **设置 → AI 功能**：

- **API 配置**：管理 API 服务商与语音合成服务，继续使用原有配置及密钥。
- **API 用量**：按时间、功能与服务商／模型查看当前账号及应用全局请求和已知 token；每份账本最多保留 5000 条，旧记录缺少的服务商信息不猜补。详见[设置](settings.md#ai-功能)。
- **意图感知**：管理当前账号的分析开关、引擎、上文及缓存；同页管理全局意图模型。资源可选择自动、自研 QWeQ-NineBird-v1 或 Laya；自研模型沿用安装包或已有目录，Laya 支持在线下载。
- **互动画像**：独立配置开关、统计与推断采样，可仅做本地统计，或分别选择本地资源／API 模型；不跟随意图感知设置。
- **推荐回复**：独立选择 API 模型，设置回复建议、自己发送后推荐及推荐上文；不提供本地生成模型。
- **好友克隆**：右上角「添加」打开原有好友选择与训练流程，尚无克隆体时也可添加；选择已有克隆体可复用原有配置编辑器，聊天模型与生成参数、提示、发言意愿、语音和记忆保存到该克隆体，不新建平行配置。
- **语音识别**：管理语音识别模型，沿用原有下载与资源目录。
- **图片识别**：独立管理 OCR 与筛图模型，区分本地资源与 QQ 在线 OCR，不重复复制已下载文件。

旧版直接打开语音、图片识别、模型配置或用量统计的入口继续有效。切换设置分类不会自动下载模型，也不会更改已保存的服务商或密钥。

API／TTS 配置和厂商模板读取失败时会显示原因，可点刷新图标重试；已有配置仍可查看。
模型列表未读到时，已保存的模型引用仍保留，不会仅因读取故障就判定为不可用。模板重试成功不会覆盖正在编辑的 API 草稿。

API 页按 LLM / TTS 分块，LLM 可保存或明确清空默认模型。各消费入口只有显式选择「默认：具体模型」才继承，旧空值、禁用或具体引用不自动改变。调用时解析当前默认及能力；模型删除或不匹配时保留引用并报错，不静默改选。克隆检索索引绑定训练模型，默认变化导致向量空间不同后需重新训练；导出 bot 固定导出时的实际引用。默认模型随 API 配置备份，旧备份缺字段时保留本机值。

## 共享资源与迁移

语音转写、图片灯箱、导出、MCP 与意图感知引用同一份全局 `modelResources` 配置，功能本身的账号开关和 API 引用仍按原范围保存。QQ 在线 OCR 单独标注，不登记为本地模型。

本地语音、文字识别与筛图模型下载完成即可使用，页面仅保留下载和删除，不再提供「设为当前／取消选用」。旧版本已下载但未选用的完整模型在启动时也会自动启用，无需重新下载。关闭设置页后下载仍会完成并自动启用，失败不改变原有可用模型；删除后自动使用同用途的其他完整模型（如果有），不会跨用途替换。模型可用不会开启自动语音转写等独立功能开关。

图片识别与导出预筛选在使用时也会检查已下载模型，自动补齐旧版遗漏的引用，无需重复下载或重启。导出预检与实际识别共用后台的可用状态；本机缺少推理引擎时会显示具体原因，不会误报为模型未下载。

意图感知可以使用本地模型或 API；生成式推荐回复只使用独立的 `suggestionProviderRef` API 引用，两者可以选不同服务商与模型。旧配置使用 API 引擎时，首次读取把原 API 引用复制为推荐回复初始值，之后分别保存；旧本地引擎配置保留规则候选，不会因历史 API 引用而自动联网生成回复。API 不可用时按回退开关和统一列表提供候选；回退不使用本地模型生成，也不计入 API 用量。

意图感知、推荐回复和互动画像各有独立启用开关。会话中的意图感知开关只控制消息意图分析，不再隐藏互动画像。旧版总开关迁移仍保留原有效状态，不会自动开启之前关闭的功能。

旧画像的「跟随意图感知」首次读取时固化为当时的 API 引用或本地资源选择，之后互不改写。画像直接从聊天记录取样；本地模型和本地统计模式会只读复用采样中对方消息已有的有效意图情绪结果，包括本地或 API 分析结果。本地模型仅补算缺失情绪并独立推断 MBTI，本地统计不新增模型调用；API 画像仍独立推断。关闭意图感知不影响复用；清空或切换意图分析不删除已完成画像，下次重算使用当时仍有效的缓存。画像模型不可用、样本不足或仅做统计时，仍展示互动统计和已有情绪结果；完全没有有效情绪依据时，好感度显示「未分析」，不填默认分数或情绪走势。

读取旧配置时自动补入语音、识别与筛图的资源引用；未指定意图资源时保留原有的自研优先、Laya 兜底策略。旧 `voiceTranscribe.modelId`、`ocr.modelId` 与 `ocr.filterModelId` 仍作为兼容字段读写，写入时同步到共享引用，不会丢弃 TTS 服务商或 API 密钥。迁移不下载、不移动、不删除模型文件。

意图与画像的本地资源分别选择，相同模型文件与 worker 可复用，不同资源按需启动各自的 worker；空闲五分钟后释放 worker。切换意图资源会清空当前账号的分析缓存，不中断画像正在使用的资源；其它账号的旧缓存仍可手动「清空并重算」。模型下载期间不可切换意图资源，删除语音或 OCR 资源时同步解除对应选用。

## 可调参数

设置只开放有业务意义且有界的参数；协议字段、语料分类权重及必要安全限制不作为任意输入开放。

各页优先显示「功能与模型」，上文数量、补齐范围、批次、生成参数、时效及缓存等按用途直接分区展示，不折叠。切换页面保留未保存输入，并停止非活动页面无必要的读取与订阅；按参数名搜索会定位，不会保存或启动模型。意图资源仅在本地模式展示，仍按全局资源共用；不适用的模型配置直接隐藏。

字段的含义、默认值、范围和零值语义在对应输入项下说明；联网与隐私提示在相关模型选择附近，分组共用说明留在分组内，页面标题不再堆叠大段介绍。

| 分组 | 参数 | 默认 | 范围 |
| --- | --- | --- | --- |
| 意图感知 | 单条上文 | 4 条 | 0–100 |
| 意图感知 | 自动补齐范围 | 60 条 | 20–1000 |
| 意图感知 | 每次 API 请求目标数 | 12 条 | 1–50 |
| 意图感知 | 模型温度 | 0.2 | 0–2 |
| 意图感知 | 上文相邻间隔／追溯跨度 | 8／15 分钟 | 1–120／1–1440 |
| 请求与缓存 | 单会话分析缓存 | 2000 条 | 100–10000 |
| 请求与缓存 | API 超时／失败冷却 | 30／30 秒 | 5–120／0–300 |
| 推荐回复 | 上文／同消息缓存 | 30 条／90 秒 | 0–100／0–600 |
| 推荐回复 | 最近推荐过期时间 | 1 分钟 | -1–5256000；-1 永不过期、0 立即过期 |
| 推荐回复 | 候选数量／目标字数／模型温度 | 3 条／40 字／0.7 | 1–5／5–200／0–2 |
| 互动画像 | 统计范围／推断采样上限 | 800／120 条 | 50–5000／10–1000 |
| 互动画像 | 最少推断样本 | 8 条 | 1–1000，不能超过采样上限 |
| 互动画像 | 会话切分间隔／趋势天数／话题上限 | 30 分钟／14 天／10 项 | 1–240／1–90／1–30 |
| 互动画像 | 推断温度／情绪衰减时长 | 0.3／14 天 | 0–2／1–90 |

画像采样上限不能超过统计范围，最少样本始终按可用对方文本数计算。画像的请求超时、失败冷却、缓存版本与模型选择独立保存，修改意图设置不会重置画像失败冷却或使在途画像作废。

推荐目标字数是生成提示而非强制截断；回退候选从统一列表随机无重复抽取，不超过候选数量上限，不会为了凑数发起额外请求。

数字与回退文本修改后自动保存：停止输入 600 毫秒、失焦或数字框内回车时提交有效值，保存期间仍可继续编辑，失败保留输入供重试。恢复默认统一使用卡片或二级页右上角的图标，先确认后立即应用；页面恢复覆盖当前引擎下隐藏的参数，保留提供方与凭据。旧配置缺省时沿用表中默认值。模型选择按服务商分组，只显示用途匹配的模型；已保存但失效的选择仍显示，不会静默改选或清除密钥。

好友克隆的生成参数默认保持原行为：历史 8 条、参考问答 5 组、记忆 4 条、表达风格上限 4 条、温度随发言意愿调整、输出 Token 使用模型默认。可以分别调整上限；历史设为 0 不会误传完整历史，召回设为 0 不额外请求无用向量。聊天模型可以单独改选，训练检索／视觉模型仍绑定原训练产物，避免新旧向量混用。新建训练仍使用原克隆创建入口。
