# WeQ 使用手册

WeQ 是一个**完全自主**的 NTQQ 本地数据库解密、解析与导出工具：不重启 QQ、不预先登录，
自动根据 QQ 在线情况选择取密钥方案，然后把聊天记录还原成高仿 QQ 的界面供你离线浏览、
分析、导出。

本手册按「从进入软件到用遍每一项功能」的顺序组织。每一节都是独立页面，可以直接从下面
的目录跳转。

> [!tip]
>
> 不确定从哪看起？先读[快速上手](./getting-started.md) 把账号打开，再回到本页按需查阅。

## 界面地图

WeQ 打开账号后是「左侧竖排导航 + 右侧内容区」的两栏布局。左栏自上而下：

| 图标 | 名称 | 说明 |
| --- | --- | --- |
| 💬 | **消息** | 最近会话列表 + 聊天窗口 |
| 👤 | **联系人** | 好友 / 群组 / 通知 |
| ⭐ | **QQ 空间** | 内嵌空间（网页版改为新标签打开） |
| # | **QQ 频道** | 内嵌频道（网页版改为新标签打开） |
| ⬇ | **导出** | 导出中心 |
| 🤖 | **AgentLab** | 克隆与分析智能体 |
| 💾 | **缓存** | 本地资源页 |
| 📊 | **年度报告** | 年度 / 历史报告 |
| ⊕ | **更多** | 个性装扮、我的收藏、商城表情、妙妙工具、数据库修复、频道私聊、空间相册、帮助 |
| ⚙ | **设置** | 12 个设置分区 |

左栏底部是**当前账号头像**：点开可以切换 / 退出账号、上锁、切换主题、隐私模式、截图。

> [!note]
>
> 同一账号可以同时存在「在线账号」和「静态（离线）账号」两条配置记录，WeQ 按配置 ID
> 而不是 QQ 号来区分它们。
