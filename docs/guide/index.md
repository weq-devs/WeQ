# WeQ 使用手册

WeQ 是一个**完全自主**的 NTQQ 本地数据库解密、解析与导出工具：不重启 QQ、不预先登录，
自动根据 QQ 在线情况选择取密钥方案，然后把聊天记录还原成高仿 QQ 的界面供你离线浏览、
分析、导出。

本页的八个分组与左侧栏**顺序一致**，也大致对应软件自己的左栏（消息、联系人、空间 / 频道、
邮箱、收藏、装扮、菜单）。装好软件之后，按你正要做的事找那一组即可。

::: tip 不确定该看哪一篇？

- 打不开账号 / 拿不到密钥 → [快速上手](getting-started.md)、[维护与诊断工具](wonderful-tools.md)
- 想找某个功能在哪 → 下面的分类表，或直接搜（右上角）
- 想导出 / 备份 / 迁移数据 → [统一导出](export.md)、[设置总览](settings.md)
- 只想算个 hash / 密钥 → [工具箱](/tools/)

:::

::: info 同一账号的两条配置

同一账号可以同时存在「在线账号」和「静态（离线）账号」两条配置记录，WeQ 按配置 ID
而不是 QQ 号来区分它们。

:::
