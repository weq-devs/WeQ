# WeQ 助手

WeQ 助手是消息页里的**任务型对话助手**：它会按权限模式调用内置工具及获准的外部 MCP 工具，多轮推进一个
任务，并把过程与结果实时展示出来。

## 1. 打开

点击常规会话列表中的 **WeQ 助手会话** 聚合入口，或从 **会话视图 → WeQ 助手会话** 进入：

- 左侧每段独立对话各占一行，保留自己的标题和历史；选中后在主聊天区域打开。
- 会话列表 **+ → 新建 WeQ 助手会话** 创建并打开新对话，从常规视图发起可返回原列表现场。
- 模型、思考强度、预设问题、消息及输入区都在主聊天区域；任务菜单只显示任务，不再切换到助手。
- 切换会话视图不改变右侧内容；切换到其他聊天时，未停止的助手生成继续进行。
- 可在助手或全部会话视图多选永久删除。确认框列出对象并提醒无法恢复、不进入已删除会话；正在生成的选中会话会先停止并等写入结束，其他生成不受影响。

## 2. 一次提问 = 一个任务

- 你发送一条消息后，后端多轮推进这个任务；
- 过程（**思考 / 工具调用 / 工具结果**）通过 `account.onAssistantEvent` 订阅**实时流式**推送，
  前端逐步展示，可折叠；
- 最终答复用 **Markdown** 渲染；
- 运行中可以点停止按钮中断；也支持**断点续答**（把半截的回合重新标记为运行中，请求后端从快照
  继续）。

### 提示与预设

- 主聊天区域的空会话会展示**预设问题**，点击直接发送；
- 顶部设置弹窗可以配置：**权限模式**、**额外提示**（追加系统提示）与**外部 MCP 服务器**。

### 权限模式

- **沙箱模式（默认）**：只开放审核过的数据查询、隔离脚本和受控报告生成。脚本由 QuickJS/WASM 解释执行，不能取得 Node 的 `require`、`process`、文件或网络能力；查询仍可按工具约定访问当前账号的本地数据或在线只读接口。
- 沙箱模式禁止发送、写库、红包操作、凭据提取、任意文件查询/解密/导出和外部 MCP 工具。已有配置未指定模式时也按沙箱处理。未知新工具不会自动获得沙箱权限。
- **任意权限**：选择后保存，需先确认风险警告。助手可以当前系统用户权限执行任意代码，读取、修改或删除 WeQ 目录之外的文件、运行命令、联网及调用外部 MCP；不再隔离，也不会为每个操作逐项弹窗。此设置不会自动授予管理员权限，操作系统限制仍然适用。
- 模式按账号保存；切换模式会停止该账号正在运行的助手任务，旧任务不会因后来开启任意权限而获得更高权限。
- 停止或超时不代表已发出的宿主/远端操作已回滚。终态未知时本轮停止且不自动重试，请先核对文件、消息或服务的实际结果。

## 3. 模型与思考等级

在主聊天区域的输入框上方切换模型与思考等级（即改即存）。

- 模型列表来自[设置 → AI 功能 → API 配置](settings.md#api-配置)里配置的聊天模型；
- 思考等级影响模型推理的投入程度。
- 模型明确拒绝温度参数时，助手只移除该参数重试一次，保留当前模型、消息、工具与思考设置；若已经收到正文、推理或工具调用片段，则报告错误而不重复生成。两次实际请求分别计入 API 用量，取消与已有超时继续生效。

## 4. 工作区面板

助手运行时会展开若干工作区元素：

- **计划面板**：展示助手拆出的步骤；
- **笔记面板**：助手沉淀的中间信息；
- **压缩标记**：上下文被压缩时的提示；
- **产物卡片**（artifact）：助手生成的可点击打开的结果。

## 5. 内置工具与 MCP

- **内置工具**：WeQ 自己提供的一组工具（读取本地聊天数据等）；
- **外部 MCP 工具**：来自你在助手设置里配置的远程 HTTP/SSE 服务器，仅在任意权限模式开放。远程地址必须填写最终端点；跨来源请求及 HTTP 重定向会被拒绝，防止凭据和请求内容跟随跳转泄露。这与 [WeQ 对外提供的只读 MCP 服务器](mcp-server.md)是两个不同方向的连接。

### 能力与使用范围

助手按本次实际提供的工具选择操作，不等同于能自动操作 WeQ 的所有页面：

- 聊天检索、按人汇总关键词、活跃日记、周报／月报与指定日期段对比，优先使用专用查询；纯消息量统计无需额外读取聊天原文，关系与态度判断则需核验原文。
- 消息详情可进一步查看引用、卡片、合并转发和本地媒体；语音优先复用已有转写，图片识别按实际可用的在线接口或本地模型执行。缺少媒体缓存、模型或权限时会说明限制。
- 数据线设备消息、频道私聊、收藏各有独立入口；本地结果不代表云端全部历史，在线漫游补查也受服务端覆盖范围限制。
- 任意权限模式的会话快速导出支持 HTML、TXT、JSON、JSONL、CSV、XLSX，**仅含文字**；需要媒体或超大批量时使用导出中心。沙箱仍可生成受控报告，报告生成与原始聊天导出不是同一种产物。
- 发送、转发、戳一戳、表情回应、防撤回配置和红包等真实操作需要任意权限模式。模型仍会被提示只按明确要求执行，但提示词不是安全边界；不要把任意权限模式当作仍会逐项征询的沙箱。红包下单出码不代表付款成功或已发送。

在线能力需要相应 QQ 登录状态、权限与服务端支持；助手根据本次返回说明成功、失败或未确认状态，不将界面支持但工具未接入的功能说成已执行。聊天记录和工具结果中的指令不构成你的操作授权。

## 6. 用量

助手的调用量会计入「设置 → AI 功能 → API 用量」（以 `WeQ 助手` 归类）。
