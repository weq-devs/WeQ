# WeQ 助手

WeQ 助手是 AgentLab 里的**任务型对话助手**：它会调用内置工具 + 外部 MCP 工具，多轮推进一个
任务，并把过程与结果实时展示出来。

## 1. 打开

点击左下角 **菜单**，用右上角按钮切换到 WeQ 助手：

- 小面板恢复当前账号上次主动使用的助手会话；没有记录或原会话已删除时显示新草稿，直到首次发送才创建会话。
- 小面板只以一行小字显示会话标题、模型和思考强度，保留消息与输入区；会话选择、模型选择、思考强度和预设问题都在完整面板中。
- 标题旁的展开按钮打开完整遮罩弹窗，左侧可以新建、切换或删除对话，右侧显示完整对话及设置。
- 大小面板共用会话、输入草稿、生成进度与阅读位置；收起面板不会停止生成。后台更新历史会话不会抢走主动选择；同号不同配置也分别记忆会话和草稿。

## 2. 一次提问 = 一个任务

- 你发送一条消息后，后端多轮推进这个任务；
- 过程（**思考 / 工具调用 / 工具结果**）通过 `account.onAssistantEvent` 订阅**实时流式**推送，
  前端逐步展示，可折叠；
- 最终答复用 **Markdown** 渲染；
- 运行中可以点停止按钮中断；也支持**断点续答**（把半截的回合重新标记为运行中，请求后端从快照
  继续）。

### 提示与预设

- 完整面板的空会话会展示**预设问题**，点击直接发送；
- 顶部设置弹窗可以配置：**额外提示**（追加系统提示）与**外部 MCP 服务器**。

## 3. 模型与思考等级

在完整面板的输入框上方切换模型与思考等级（即改即存），小面板仅显示当前值。

- 模型列表来自[设置 → 模型配置](./settings.md)里配置的 chat 模型；
- 思考等级影响模型推理的投入程度。
- 模型明确拒绝温度参数时，助手只移除该参数重试一次，保留当前模型、消息、工具与思考设置；若已经收到正文、推理或工具调用片段，则报告错误而不重复生成。两次实际请求分别计入 API 用量，取消与已有超时继续生效。

## 4. 工作区面板

助手运行时会展开若干工作区元素：

- **计划面板**：展示助手拆出的步骤；
- **笔记面板**：助手沉淀的中间信息；
- **压缩标记**：上下文被压缩时的提示；
- **产物卡片**（artifact）：助手生成的可点击打开的结果。

## 5. 内置工具与 MCP

- **内置工具**：WeQ 自己提供的一组工具（读取本地聊天数据等）；
- **外部 MCP 工具**：来自你在设置里配置的 MCP 服务器，见 [MCP 服务器](./mcp-server.md)。

## 6. 用量

助手的调用量会计入 AgentLab 的 usage 面板（以 `WeQ 助手` 归类）。
