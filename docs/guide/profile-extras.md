# 个人资料扩展

自己的「QQ 资料与状态」、联系人资料、群成员名片和个性主页均提供以下只读内容。桌面、Web 和 Remote 使用同一组入口。

- **历史签名**：点击签名旁的入口查看历史正文、时间和附带位置，使用「加载更多」向前浏览。当前签名为空时仍可打开历史。
- **QQ 能量值**：资料区单独显示能量值和能量等级，与 QQ 太阳／月亮等级无关。零值正常显示，未返回的数值不补零。
- **标签相册**：查看标签及照片，点击标签展开相册；照片可以放大预览、切换、缩放，读取更多照片时保留已显示内容。原来的文字兴趣标签和精选图片不受影响。
- **匿问我答**：浏览问题、回答、时间及返回的互动数量。自己的列表可切换「全部／已回答」，查看他人时只读取已回答内容。

原有本地资料立即展示，扩展内容需要当前账号在线读取。能量值在资料可见时读取，其他列表在打开时读取；关闭后不会自动拉取完整历史。已浏览结果在当前查询缓存中保留五分钟，不另建历史数据库。

没有数据、暂不可读取和读取失败分别显示。后续页失败时保留已加载内容，可以单独重试；列表是否结束以服务器标记为准，少于一页不一定表示已经结束。切换账号、数据源或目标后不会沿用上一人的详情。此处不会提问、回答、点赞或修改 QQ 资料。
