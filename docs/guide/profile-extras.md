# 个人资料扩展

自己的「QQ 资料与状态」、联系人资料、群成员名片和个性主页均提供以下扩展内容。桌面、Web 和 Remote 使用同一组入口。

- **历史签名**：点击签名旁的入口查看正文、时间和附带位置，使用「加载更多」向前浏览。支持点赞、取消、展开点赞人、评论和回复；自己的评论及本人签名下的评论可以删除。发送失败保留输入。当前签名为空时仍可打开历史。
- **QQ 能量值**：资料区只显示能量值，不显示能量等级，与 QQ 太阳／月亮等级无关。零值正常显示，未返回的数值不补零。
- **详细资料**：点击查看公司、个人说明和邮箱，个人说明保留换行；未返回与明确未填写分别显示，支持刷新，读取失败时保留已显示内容。这些资料不等于自己给好友添加的备注信息。
- **教育经历**：点击查看多条学校记录，包括院系、学历、入学和毕业年份，不再局限于本地缓存的一行学校。自己的未公开经历会明确标记，查看他人时不展示隐藏条目；可手动刷新，失败时保留已读内容。
- **标签相册**：查看标签、点赞摘要和照片，点击标签展开相册；照片可以放大预览、切换、缩放。在自己的标签相册中可多选照片上传，逐张显示结果并重试失败项。原来的文字兴趣标签和精选图片不受影响。
- **匿问我答**：浏览问题、回答和时间，点击互动区展开点赞人和评论，支持加载更多评论。自己的列表可切换「全部／已回答」，查看他人时读取已回答内容。

原有本地资料立即展示，扩展内容需要当前账号在线读取。能量值在资料可见时读取，其他列表在打开时读取；关闭后不会自动拉取完整历史。已浏览结果在当前查询缓存中保留五分钟，不另建历史数据库。

没有数据、暂不可读取和读取失败分别显示。后续页失败时保留已加载内容，可以单独重试；列表是否结束以服务器标记为准。切换账号、数据源或目标后关闭上一人的详情。点赞摘要使用“张三、李四等 28 人点赞”等形式，人数采用返回的总数。

照片可一次选择最多 100 张，每张 20 MB 以内。上传成功后刷新相册；显示“已上传，等待相册更新”时可使用“刷新相册”，该操作只更新照片列表。队列保留每张照片的结果，重试只处理尚未完成的项。

## 自己的资料展示设置

在联系人中打开自己的资料页，点击顶部“资料展示设置”按钮进入设置模式。已有可控信息旁会出现分段选择：基础资料为“所有人／仅好友／不可见”，标签相册与匿问我答为“展示／隐藏”。学校与完整教育经历共用同一个展示设置；单条教育经历自身的公开状态不随此设置改写。

选择后立即保存该项，独立读回一致才显示“已保存”。保存期间仅禁用当前项，其他项仍可调整；失败或未确认时显示原因，可以重新读取核对。未知、未返回和读取失败不会默认显示为公开或关闭。

点击“完成资料展示设置”只收起分段控件，不改变已保存设置。切换账号或联系人后模式关闭；他人的资料页没有此入口。离线时仍可看本地资料，不能修改展示范围。
