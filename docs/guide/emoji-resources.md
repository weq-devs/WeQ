# 表情与装扮资源

这一页讲本地资源页里的五类表情浏览器，以及「更多功能 → 商城表情」和「个性装扮」。

## 1. 系统表情

本地资源 → **系统表情**。

QQ NT 把内置动态表情放在 `nt_data/Emoji/BaseEmojiSyastems/…`。WeQ 会报告每个表情**带有哪些
格式**（PNG / APNG / Lottie），以网格展示：

- 默认预览用 APNG（`<img>`），没有就退回静态 PNG；
- 滚动到底自动加载下一页；
- 点击一个表情打开灯箱，**有几个格式就渲染几个**：PNG / APNG 走 `<img>`，Lottie 走 lottie-web，
  各占一块面板；
- QQ 目录缺失时（新装、清了缓存、静态账号）工具栏有 **补全** 按钮，从官方 CDN 拉取；聊天渲染
  本来也会逐个回填。

## 2. 商城表情（磁盘）

本地资源 → **商城表情**。

QQ 把下载的商城贴纸放在 `nt_data/Emoji/marketface/<itemId>/<hash>`，其中 GIF 是 50 步 XOR
加密、PNG 明文。WeQ 按 hash 分组（一个贴纸可能同时有 gif 和 png）：

- 网格展示，缩略图优先 GIF，滚动分页；
- 点击打开灯箱，并排显示所有可用格式；
- 图片字节走 `weq-media://mface` 协议，不经过 tRPC。

## 3. 商城表情包（在线）

本地资源 → **商城表情包**。

与上面直接读磁盘不同，这里读 `emoji.db` 的包清单，再对每个包**在线**拉 `android.json` 补全：

- **列表**：一包一张大卡片（封面 + 名称 + 介绍 + 来源徽章：免费 / 付费 / SVIP / VIP）；
- **详情**：顶部信息条（来源 / 介绍 / 密钥 + 解密原理）+ 表情网格；
- 图片走 CDN 加密流 + QQTEA 解密（packId 自动恢复密钥）；
- **密钥计算器**（独立弹窗）：
  - **时间戳 → 密钥**：本地按 `md5(秒级时间戳)[:16]` 派生（离线，纯演示原理）；
  - **pack_id → 密钥**：在线查询 native `getMarketFaceKey`，查到后可跳转到该表情包详情。

## 4. 自定义表情

本地资源 → **自定义表情**。两个来源页签：

| 页签 | 目录 |
| --- | --- |
| **搜到的表情** | `emoji-recv/<YYYY-MM>/{Ori,Thumb}` |
| **我的表情** | `personal_emoji/{Ori,Thumb}` |

后端把每个 hash 的**原图**（jpg/gif/png，扩展名不可靠）与**缩略图**合并成一条。WeQ 每个 hash
一张卡：

- 卡片显示缩略图（加载失败时退回原图），并标注存在哪些文件（ori / thumb）；
- 点击打开灯箱，并排渲染所有可用文件（原图全尺寸）；
- 支持按关键字搜索。

## 5. 关联表情

本地资源 → **关联表情**。

QQ 在 `nt_data/Emoji/emoji-related/emoji` 维护「关键词 → 表情集」：`words.json` 列出关键词，
每个有表情的关键词对应一个 `md5(关键词)` 目录，里面是明文 gif。

WeQ 只展示**目录存在**的关键词，每个关键词一张卡（第一张 gif 当封面），点击打开灯箱展示该关键
词的全部 gif。

## 6. 更多功能 → 商城表情浏览器

左栏「更多功能」里的 **商城表情** 打开一个两栏灯箱（不依赖本地缓存）：

- **左栏**：搜索框 + 来源筛选 chips（免费 / 付费 / VIP / SVIP）+ 无限滚动的包列表；
- **右栏**：点包后展示该包全部表情的解密动图网格；
- 数据走 `account.marketEmoji.searchCatalog` / `getPackDetail`，图片指向
  `weq-media://mface?...&enc=tea`（密钥后端自动恢复）。

## 7. 个性装扮

左栏「更多功能」里的 **个性装扮** 打开装扮灯箱。顶部一行是类别切换 + 搜索框 + 作用范围，下面
直接是卡片网格。

### 四个类别

| 类别 | 来源 | 说明 |
| --- | --- | --- |
| **聊天气泡** | 商城 | 消息气泡皮肤 |
| **聊天字体** | 商城 | 聊天字体 |
| **头像挂件** | 商城 | 头像外圈挂件 |
| **聊天背景** | 本地 | 背景图 / 视频 + 浮屏挂件 |

前三类走商城，第四类完全是本地的（因此搜索框、「已装」筛选、范围控件在它上面会隐藏）。

### 浏览 / 安装 / 搜索

- **排行榜**：离线即可浏览，本地有离线 bundle（QQ 自带那批资源），所以安装按钮**不按在线
  状态禁用**；
- **搜索**：**必须有在线 QQ 实例**（商城搜索接口要用在线实例取凭证）；离线时给出明确提示，
  清空关键词即可离线浏览排行榜；
- **已装**：列出清单里的款 + 你在 QQ 里正在用的那款（可一键装上，让 WeQ 观感与手机 QQ 对上）；
- 点 **使用** 会安装并立即生效；点已激活的那款无操作。

### 作用范围

| 范围 | 说明 |
| --- | --- |
| **仅自己** | 只渲染我发出的消息（与手机 QQ 一致） |
| **所有人** | 连对方的消息也套上我的气泡和字体 |

### 聊天背景与浮屏挂件

- 背景可选：不使用 / QQ 同款（手机 QQ 设置的那张）/ 自定义（本地图片或视频，主进程开系统文件
  框拷贝进账号目录）；
- **清晰度**滑块：拖动实时预览，松手才落盘；默认压了一层磨砂，拖到最右接近原图；
- **浮屏挂件**：叠在背景上循环播放的动画，点一次选中、再点一次取消。
