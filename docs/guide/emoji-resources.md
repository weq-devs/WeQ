# 表情与装扮资源

## 商城表情

从左栏 **个性装扮 → 商城表情** 页签进入内容页，不需要先打开旧本地资源浏览器。

- 使用装扮页顶部搜索框输入表情包名称，回车搜索，清空恢复目录；目录搜索离线可用。可按免费、付费、VIP、SVIP 筛选。
- 选择表情包查看名称、介绍及解密图片；离线目录不代表图片已经下载或在线商城完整历史。
- 批量下载保留原有任务与保存流程；单张预览失败不视为已取得资源。
- 商城目录、QQ 已下载贴纸和个人自定义表情是不同来源，不混算数量。
- 目录与其他装扮页一样使用卡片网格，卡片展示首张表情预览；接近可视区域时才加载，失败时保留占位。点击查看整包，返回后保留目录位置。
- 页面跟随装扮页的深浅模式、主题色与界面背景。

## 自定义与聊天表情

聊天中的系统表情和贴纸由消息渲染器显示，点击可查看可用预览。QQ 资源目录缺失时，联网补全仍受当前凭据和资源可用性限制。

导出个人表情从统一工具选择[导出表情包](export.md#11-导出表情包)，区分“我的表情”和“收到的表情”、原图与缩略图。缓存占用与清理由 **设置 → 数据与存储 → 维护工具** 管理；当前没有独立的本地媒体一级导航。

需要研究缓存格式时，参见[表情数据库](../database/emoji.md)和[商城表情解密](../principles/mface-decrypt.md)，不要把磁盘布局当使用步骤。

## 个性装扮

左栏 **个性装扮** 打开主内容整页。类别为聊天气泡、聊天字体、头像挂件、聊天背景和商城表情。

- 排行榜可使用本地离线资源浏览；在线搜索需要 QQ 实例提供凭据。
- “已装”显示本地安装及可确认的 QQ 当前装扮；点击 **使用** 安装并生效，失败会提示。
- 作用范围可选仅自己或所有人；改变的是 WeQ 渲染，不代表修改他人的 QQ 设置。
- 聊天背景可关闭、使用 QQ 同款或选择本地图片/视频；清晰度调整在松手后保存，浮屏挂件可单独切换。
- 本地背景不使用商城搜索，相关筛选在该类别隐藏。聊天中的逐条装扮渲染另受[消息显示设置](settings.md#个性显示)控制。
