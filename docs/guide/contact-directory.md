# 联系人排序与分组

好友和群聊列表顶部的「分组依据」「排序依据」分别控制分组与组内顺序，箭头切换升降序。
原有默认选项不变，偏好按账号、数据源及列表分别保存；桌面、Web 和 Remote 使用相同规则。

## 好友与联系人

- **最近联系时间**：按本地有效私聊消息的最后时间排列，不使用草稿或资料更新时间，发送中、失败发送和系统提示不推进时间。
- **QQ 能量值**：使用 QQ 返回的 score，与 QQ 等级、原有亲密度分别显示，真实 0 参与排序。
- **AI 好感度**：只读取本次宿主运行中已完成的画像缓存，不发起批量分析。未分析或缓存失效时排在末尾；改变画像配置后旧分数不再参与排序。
- **关系／类型**：依次显示我自己、我的设备、机器人、当前好友、非好友、关系待确认。非好友不代表已经删除好友。
- **添加来源**：QQ 群来源统一归入「QQ 群」，不按具体群或群来源文案拆组；其他来源按好友线索文案分组。有来源群时仍可打开具体群名片，不根据验证消息猜测来源。
- **学校**：合并本地学校及可见教育经历，同名学校合组。一人可出现在多个学校组，但同校多段经历不会重复。多选、批量操作与导出按身份去重。

## 群聊

- **最近消息时间**与**我最近发言时间**分别按本地有效群消息及本人消息统计，不以群成员名片的最后发言时间代替。
- **我的入群时间**来自本人群成员记录，不以群创建时间或第一条本地消息代替。
- **冻结状态**按明确返回值分为正常、已冻结、其他状态码和未知；未知不视为正常。
- **grade**按服务端原值分组，数值升序，0 保留，未知置后；不解释为星级或成员等级。

历史群及入群状态待确认的群仍保留原分区，不自动发起当前群资料刷新。

## 缓存与读取

切换依据先使用已有本地资料与缓存。能量值、学校、添加来源和群扩展缺失或过期时，沿用「更新好友／群信息缓存」提示与任务；可选择不更新。成功的详情读取也会补充目录缓存。

消息时间按小批分页逐步补齐，首次可先显示已确认发送的消息摘要和本次运行已有结果；未完成与确认没有本地记录分别显示。切走列表、隐藏窗口或进入多选后停止继续读取，多选期间目录不因异步数据重新排列。

时间以北京时间显示到秒。缺失值始终置后，读取失败保留旧成功值，并可查看更新状态；这些时间和统计只反映当前来源的本地记录，不代表完整的 QQ 历史。

设备传输与克隆内容不作为本次私聊时间、QQ 能量值或 AI 好感度排序的数据来源；这些对象仍保留在目录，并显示对应指标不适用。
