# 我的名片与资料页

点击桌面顶栏头像，或移动 Web 顶部个人入口，打开“我的名片”。名片展示当前账号的个人资料与状态，不提供编辑控件。

## 查看与编辑资料

展开名片进入本人资料页，直接点击可编辑字段内容，可修改昵称、性别、生日、所在地、邮箱、职业、家乡、公司、个人说明和在线状态，不再需要展开独立编辑区域或点击额外编辑按钮。个性签名和学校的内容分别打开「个性签名」「教育经历」对话框；从本人名片或资料页打开「个性签名」时，顶部均显示默认留空、占位提示为「新签名」的输入框和勾号保存控件，保存成功后清空输入，下方保留历史记录；学校暂不提供编辑。点击本人头像统一打开「历史头像」，在对话框内点击「更换头像」选择新图片。

编辑后点击保存，或点击取消放弃该项草稿。保存结果按现有 QQ 读取链路确认；未确认成功时保留输入，不自动重新提交。切换账号或数据来源后，不沿用上一账号的编辑草稿。QQ 号、QID、等级、特权等只读信息不显示编辑按钮。

支持调整展示范围的字段，在编辑态显示分段选择控件，与内容共用保存和取消。年龄、星座、标签相册、匿问我答等只支持修改展示范围的项目，也从对应内容旁进入编辑。选择范围不会立即提交；内容与范围全部确认成功后退出编辑，部分保存失败时保留草稿，重试只提交尚未成功的部分。范围读取失败不影响独立保存资料内容。

账号登录和管理仍在设置中；资料和状态编辑不再定位到设置里的旧资料区域。

只有 QQ、QID、UID 支持点击复制；其他字段按关联对话框、编辑、纯文本的顺序提供交互，不可编辑或暂时离线的资料不会改为复制按钮。

## 历史头像

点击本人名片或资料页的头像，打开「历史头像」对话框。页面先显示首批头像，再逐页读取其余记录；关闭页面或切到后台时暂停继续读取。

- 每个头像显示“最早使用”和“最后使用”时间，均为北京时间。
- 默认按最后使用时间从新到旧排列；可切换最早使用时间，也可切换升降序。
- 读取中显示已加载数量；读到服务端终点后显示完整数量。分页边界重复返回的头像只显示一次。
- 点击头像可放大预览，支持前后切换。旧头像的可用尺寸可能较小。
- 点击「更换头像」选择并提交新图片，更换后自动刷新头像与历史列表；暂不可更换或正在提交时仅禁用此按钮，不影响打开历史头像与预览已加载图片。
- 读取失败保留已加载头像，并可重试。没有时间的头像显示“未知”，排序时放在末尾。

历史头像列表仅查询本人，不包含设置次数，也不提供恢复、设置或删除历史头像操作。
