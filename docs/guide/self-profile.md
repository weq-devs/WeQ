# 我的名片与资料页

点击桌面顶栏头像，或移动 Web 顶部个人入口，打开“我的名片”。名片展示当前账号的个人资料与状态，不提供编辑控件。

## 查看与编辑资料

名片中的“查看资料”进入本人资料页。在资料页点击字段右侧的铅笔按钮，可编辑昵称、性别、签名、生日、当前地区、邮箱、职业、家乡、学校和在线状态；头像旁的铅笔用于更换头像。

编辑后点击保存，或点击取消放弃该项草稿。保存结果按现有 QQ 读取链路确认；未确认成功时保留输入，不自动重新提交。切换账号或数据来源后，不沿用上一账号的编辑草稿。QQ 号、QID、等级、特权等只读信息不显示编辑按钮。

账号登录和管理仍在设置中；资料和状态编辑不再定位到设置里的旧资料区域。

## 历史头像

点击名片或本人资料页中的“历史头像”，查看当前账号的历史头像。页面先显示首批头像，再逐页读取其余记录；关闭页面或切到后台时暂停继续读取。

- 每个头像显示“最早使用”和“最后使用”时间，均为北京时间。
- 默认按最后使用时间从新到旧排列；可切换最早使用时间，也可切换升降序。
- 读取中显示已加载数量；读到服务端终点后显示完整数量。分页边界重复返回的头像只显示一次。
- 点击头像可放大预览，支持前后切换。旧头像的可用尺寸可能较小。
- 读取失败保留已加载头像，并可重试。没有时间的头像显示“未知”，排序时放在末尾。

历史头像列表仅查询本人，不包含设置次数，也不提供恢复、设置或删除历史头像操作。
