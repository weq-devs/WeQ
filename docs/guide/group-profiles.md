# 群名片与群资料

点击群头像或群标题打开快速名片。有本地备注时以备注为主标题，同时显示原群名；群号可复制（复制后提示「已复制」），入群状态与角色根据已有资料显示。点群名或底部的「完整群资料」进入完整资料页。

名片按「谁 → 什么关系 → 能做什么 → 有多少人」排列：身份区（备注/群名、关系与角色、群号、成员数）→ 创建时间与群内好友数（与完整资料页同一套数据行）→ 群简介 → 标签 → 成员预览 → 操作。简介先显示三行，点击展开查看原文，正文可以选择复制。成员头像最多八位，优先展示已取得候选中的好友，窄屏分两行显示；点击头像打开带当前群上下文的个人名片，关闭后返回群名片。群内好友数使用已有成功缓存，没有缓存不占位，也不显示「未知」。

群名片没有展示内容自定义设置。公告正文、入群问题、群等级、活跃度和活跃成员数在完整群资料中查看，不随名片提前加载。

快速名片与联系人名片使用同一个浮层容器、同一套数据行与同一套操作行；群资料页与联系人资料页使用同一个「目录 + 内容」容器和同构页头（标题 + 关闭）。

## 完整群资料

通过名片里的群名、「完整群资料」或聊天侧栏的群资料入口进入。宽屏显示侧边目录，窄屏显示可横向滚动的章节条：

- 概览：基本资料、成员预览和群待办。
- 详细资料：完整简介、名称、备注、群号、创建时间、成员数/容量、入群问题、群地点，以及标签来源、已有群等级与活跃成员数。头像编号、头像版本和冻结原因代码收在默认折叠的「技术详情」中。
- 成员：搜索、分页浏览、个人名片、已退群成员和等级排行。
- 公告、相册、文件、精华、打卡：使用原有内容与操作，进入对应章节才读取。
- 群管理：按当前账号实际能力提供已有群设置和编辑操作。
- 资料历史：浏览本机保存的资料版本。

切换章节保留同一群的浏览状态；未打开的章节不提前读取，离开后暂停刷新。切换账号、数据源或群不会沿用上一对象的数据。离线或局部读取失败时保留已有内容，需要时可重试。照片、文件和成员查询仍取决于对应来源是否可用，不因没有返回内容就推断已经退群。

群等级（grade）保留服务端原值，不转换成未经验证的星级；活跃成员数不假定为今日或七日统计。没有可信缓存的值直接不显示，不写「未知」占位。
