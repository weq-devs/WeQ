# 群名片与群资料

点击群头像或群标题打开快速名片。名片标题始终显示真实群名，备注作为独立属性展示，不替代标题。头像可点击放大，右上角的展开按钮进入完整群资料页；群主和管理员可点击标题直接修改群名，其他人的群名标题可用于进入完整资料页。

身份区显示群头像、群名、入群状态与角色，已知冻结状态紧随身份展示；下方按备注、群号独立成行。备注可原行编辑，群号点击复制并短暂提示「已复制」。正文分为「群资料」「成员」：

- 群资料：简介、标签、创建时间。简介先显示三行，仅实际超出三行时提供展开／收起，正文可以选择复制；没有资料时不留空分区。
- 成员：依次显示已有群容量、群成员数、群内好友数，不显示成员头像预览，也不单列「与我的关系」。好友数使用已有成功缓存，真实零值保留，没有可信数量时显示「查看」，不冒充零人。

点击群成员数或群内好友数，在数值旁打开对应名单，空间不足时自动避让。名单在打开后才分页读取，支持搜索、继续加载和失败重试；群内好友使用当前完整好友目录筛选群成员，不限于预览候选。点击名单中的头像和姓名打开带当前群上下文的个人名片，关闭个人名片后仍保留名单，关闭名单返回原群名片。本地合成群只显示其自身成员，不读取真实 QQ 成员接口。

底部只保留可用的「查看消息」「预览消息」，完整资料入口统一放在右上角。

群名片没有展示内容自定义设置。公告正文、入群问题、群等级、活跃度和活跃成员数在完整群资料中查看，不随名片提前加载。

快速名片与联系人名片使用同一个浮层容器、同一套数据行与同一套操作行；群资料页与联系人资料页使用同一个「目录 + 内容」容器和同构页头（标题 + 关闭）。

## 完整群资料

通过名片右上角的展开按钮或聊天侧栏的群资料入口进入。宽屏显示侧边目录，窄屏显示可横向滚动的章节条：

- 概览：基本资料、成员预览和群待办。
- 详细资料：完整简介、名称、备注、群号、创建时间、成员数/容量、入群问题、群地点，以及标签来源、已有群等级与活跃成员数。头像编号、头像版本和冻结原因代码收在默认折叠的「技术详情」中。
- 成员：搜索、分页浏览、个人名片、已退群成员和等级排行。
- 公告、相册、文件、精华、打卡：使用原有内容与操作，进入对应章节才读取。
- 群管理：按当前账号实际能力提供已有群设置和编辑操作。
- 资料历史：浏览本机保存的资料版本。

切换章节保留同一群的浏览状态；未打开的章节不提前读取，离开后暂停刷新。切换账号、数据源或群不会沿用上一对象的数据。离线或局部读取失败时保留已有内容，需要时可重试。照片、文件和成员查询仍取决于对应来源是否可用，不因没有返回内容就推断已经退群。

群等级（grade）保留服务端原值，不转换成未经验证的星级；活跃成员数不假定为今日或七日统计。没有可信缓存的值直接不显示，不写「未知」占位。
