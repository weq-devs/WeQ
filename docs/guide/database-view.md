# 本地资源页

左栏点 **缓存**（本地缓存资源中心）进入。布局是「左侧竖向资源分类 + 右侧内容区」。分类栏可以
收起（把空间让给右侧数据表近全屏查看）。

> [!note]
>
> 静态（离线）账号导入的只是一份数据库快照，`nt_data` 那些资源属于本机在线账号，因此静态账号
> 只保留「本地数据库」一项。

## 2. 本地数据库

「本地数据库」分类是一个类似 SQLiteStudio 的数据库浏览器。

### 左栏

- **数据库选择器**：下拉切换账号下的数据库文件（显示文件名与大小）；
- **对象树**：表 / 视图（不含触发器），可搜索过滤；对象树与最外层资源列都可以折叠。

### 右栏

选中一个表 / 视图后，右侧有 **数据 / SQL** 两个子页签。

#### 数据页签

- 以数据表格展示行，支持翻页；
- 顶部有 **编辑模式** 开关：打开后解锁**行内编辑**与手写写入；
- 二进制字段可以打开 **Blob 查看器**（hex）或 **Protobuf 树**查看。

#### SQL 页签

- 一个主题化等宽编辑器 + **执行**按钮；
- `SELECT` / `WITH` / `PRAGMA` / `EXPLAIN` 返回**列 + 行**结果表（服务端上限 1000 行，触顶会
  提示截断）；
- `INSERT` / `UPDATE` / `DELETE` / DDL 返回受影响行数；
- 写入直接作用于 QQ 的**实际数据库**，所以任何非只读语句**必须先在「编辑模式」下**才会发送，
  只读时会在客户端直接拦下；
- 选中某张表时，编辑器上方会列出**该表的索引**，点一个会把它的 `CREATE INDEX` DDL 载入编辑器。

> [!warning]
>
> 数据库页的写入会直接改 QQ 本地数据库。动手前建议先在[妙妙工具 → 数据库修复](./wonderful-tools.md)
> 里做一次备份，或确认自己清楚在改什么。

## 3. 整体分析

分类栏顶部有 **📊 整体分析**（静态账号不显示）：全屏覆盖层，逐个扫描每棵资源树并画图。

- 一次只扫一棵树，带进度条 + 逐类卡片，扫完一棵填一块；
- 扫完后给出跨分类图表：分类排名条、按月份条、源文件 / 缩略图占比等；
- 所有颜色取设置里的主题色。

## 4. 清理释放

分类栏顶部还有 **🗑 清理释放**（静态账号不显示）：全屏覆盖层，**可释放磁盘空间**。

流程：打开后先扫描每个可删除目标的大小，然后提供五个预设：

| 预设 | 说明 |
| --- | --- |
| 完全安全清理 | 只清最安全的部分 |
| 清理原图 | 删除原图缓存 |
| 清理缩略 | 删除缩略图缓存 |
| 清理 File 目录 | 删除 File 目录 |
| 全部清理 | 需要手动输入「确认清理」 |

也支持**自定义**勾选。选定模式后进入确认步骤，列出将被删除的内容与总量；含风险的模式会点亮
红色按钮。执行后所有资源浏览器与整体分析会重新扫描磁盘。

> [!important]
>
> 「下载文件」列表**不是**清理目标，任何模式都不会删掉你已下载的文件。
