# 本地资源页

从 **设置 → 数据库与资源 → 资源目录管理 → 资源浏览** 进入。布局是「左侧竖向资源分类 + 右侧内容区」。同一设置正文还有「占用概览」和「资源清理」，不再分别打开三个工具窗口。
分类栏可以收起（把空间让给右侧内容区）。

> [!note]
>
> 静态（离线）账号导入的只是一份数据库快照，`nt_data` 那些资源属于本机在线账号，因此静态账号
> 的「本地缓存」入口会禁用。需要查看数据库时用同一页的「数据库管理」。

## 1. 资源分类

分类按类型分组：

| 分组 | 分类 | 内容 |
| --- | --- | --- |
| **表情** | 系统表情 | 内置表情资源 |
| | 商城表情 | 商城下载的贴纸 |
| | 商城表情包 | 我已添加的表情包（在线解密） |
| | 自定义表情 | 收到的 / 我的表情 |
| | 关联表情 | 关键词联想表情 |
| **头像** | 头像资源 | `nt_data` 头像缓存 |
| **图片与视频** | 图片资源 | 聊天图片缓存 |
| | 视频资源 | 聊天视频缓存 |
| | 图片墙资源 | 群相册 / 图片墙缓存 |
| **文件** | File 目录 | `nt_data` 的 File 目录 |
| | 下载文件 | 下载到本地的文件 |
| **语音** | 语音资源 | 聊天语音缓存 |
| **空间** | QQ 空间缓存 | 空间浏览缓存 |

各类资源浏览器支持浏览、按月份 / 平铺查看、下载、删除等操作；表情类详见
[表情与装扮资源](./emoji-resources.md)。

## 2. 数据库管理

从 **设置 → 数据库与资源 → 数据库管理** 直接查看数据库浏览器，不需要再打开一层工具窗口。选库、对象树、数据表格、SQL 和编辑模式铺满设置正文，不再放在独立边框和固定高度的内嵌区域中；设置侧栏始终保留，表列表与数据区各自滚动。

工具栏「导出」复用公共明文导出面板，默认勾选正在浏览的库。可以在同一账号、同一配置来源内扩选；单库保存为文件，多库保存为整包，仍沿用全局保存偏好、快速模式风险确认和后台任务。取消面板后保留原来的库、表、SQL 草稿与编辑模式；切换账号或数据源后不沿用旧导出目标。原选库不再存在时会明确提示，不自动扩大为全部库。

### 左栏

- **数据库选择器**：下拉切换账号下的数据库文件（显示文件名与大小）；
- **对象树**：表 / 视图（不含触发器），表列表可以收起。

### 右栏

选中一个表 / 视图后，右侧有 **数据 / SQL** 两个子页签。

#### 数据页签

- 以数据表格展示行，支持翻页；
- 顶部有 **编辑模式** 开关：打开后解锁**行内编辑**与手写写入；
- 二进制字段可以打开 **Blob 查看器**（hex）或 **Protobuf 树**查看。

#### SQL 页签

- 一个主题化等宽编辑器 + **执行**按钮；
- `SELECT` / `WITH` / `PRAGMA` / `EXPLAIN` 返回**列 + 行**结果表（服务端上限 1000 行，触顶会
  提示截断）；
- `INSERT` / `UPDATE` / `DELETE` / DDL 返回受影响行数；
- 写入直接作用于 QQ 的**实际数据库**，所以任何非只读语句**必须先在「编辑模式」下**才会发送，
  只读时会在客户端直接拦下；
- 选中某张表时，编辑器上方会列出**该表的索引**，点一个会把它的 `CREATE INDEX` DDL 载入编辑器。

> [!warning]
>
> 数据库页的写入会直接改 QQ 本地数据库。动手前建议先从「数据库与资源 → 损坏与修复」打开修复工具并备份，
> 或确认自己清楚在改什么。

## 3. 整体分析

在资源目录管理的 **占用概览** 查看。页面统一调度资源分析和清理目标扫描，切换到清理视图不会另起一轮扫描；可以显式重新扫描或在错误后重试。

- 一次只扫一棵树，带进度条 + 逐类卡片，扫完一棵填一块；
- 扫完后给出跨分类图表：分类排名条、按月份条、源文件 / 缩略图占比等；
- 所有颜色取设置里的主题色。

总量只累加图片、视频、语音、表情、头像、图片墙、QQ 空间与文件八类顶层统计。表情下的商城表情、收到的表情、我的表情和关联表情是清理子目标，不再次加入概览总量。显示的是逻辑文件大小，不代表卷实际分配空间或可用空间变化。

## 4. 清理释放

在同一正文切换到 **资源清理**（静态账号不可用），使用同一轮扫描取得的白名单目标。

流程：打开后先扫描每个可删除目标的大小，然后提供五个预设：

| 预设 | 说明 |
| --- | --- |
| 完全安全清理 | 只清最安全的部分 |
| 清理原图 | 删除原图缓存 |
| 清理缩略 | 删除缩略图缓存 |
| 清理 File 目录 | 删除 File 目录 |
| 全部清理 | 需要手动输入「确认清理」 |

也支持**自定义**勾选，支持变体的目标可以选择全部、仅原图或仅缩略。选定模式后在原视图进入确认步骤，列出目标、后端解析的实际目录、变体与预计逻辑清理量；含风险的模式会标明风险，全部清理仍需确认短语。执行结果逐项列出逻辑删除量与失败计数，再统一刷新统计和资源数据。切换视图保留已访问的分类和筛选；换账号或数据源不沿用旧来源的清理选择。

> [!important]
>
> 「下载文件」列表**不是**批量清理目标，清理不会按下载记录遍历用户保存位置。系统表情资源与表情包元数据也不在批量清理目录内。确认页所列的 QQ 缓存目录仍会按选择处理，请勿将需要保留的个人原件放在其中。
