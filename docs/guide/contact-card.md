# 联系人名片与资料页

消息头像、群成员、联系人和空间中的人员入口使用同一份名片显示配置。打开后先显示已有本地资料，再补全已开启的在线内容；点击昵称进入完整资料页，点击头像查看大图。

## 名片显示配置

在 **设置 → 基础功能 → 联系人名片** 调整显示内容。开关、顺序及默认值共用一份全局设置，桌面和 Web 不分别维护。拖动条目或使用上下箭头调整顺序；右侧示例即时更新，可通过页面的恢复默认入口重置。

头像、昵称、备注、QQ 号和好友关系固定保留；机器人、企业身份及适用的群内身份状态同样固定。群等级、入群和最后发言时间可分别配置。在线状态包含自定义状态；学校附带已有学历；共同关系、关系标签、好友添加信息和我的备注资料分别按组配置。

**QQ 能量值独立、默认关闭，只显示数值，不显示能量等级。** QQ 等级是另一项资料，不受此规则影响。

隐藏内容也会停止仅为该项进行的自动查询。多个字段共用一次返回时复用结果，不重复读取；关闭名片显示不会移除资料页中的完整能力。编辑、展开、复制、查看等动作不再另设开关。

## 点击内容查看

- 号码点击复制；备注文字进入备注编辑。长文字仍可选中复制，拖选不触发导航。
- 签名点击展开原文；学校进入教育经历；标签进入相册。在线标签包括没有照片的标签，空相册显示“暂无照片”；接口不可用时使用本地标签，点击进入相册总览。
- 当前 QQ 秀点击进入历史展柜，更多资料中也保留展柜入口；历史扫描只在打开展柜后开始。
- 共同群数量打开名单，群头像和名称共用一个群资料入口。共同好友数仅作计数展示。
- 群昵称和头衔点击后读取编辑能力，可以编辑时直接进入原行表单，保存和取消仍需明确操作；空字段也可填写。

已有会话提供“查看消息”和可用的预览；未找到会话时显示“发起会话”，尚未确定时不误报不存在。空间预览和本群发言在点击后读取，不随开名片提前加载。

## 完整资料页

顶部保留身份和消息操作，左侧目录切换概览、详细资料、签名历史、标签相册、匿问我答、关系与互动、群内资料、个性主页、互动画像及资料历史。窄屏通过目录菜单切换。只显示适用于当前对象的章节。

教育、历史签名、标签相册和问答在页内浏览，继续支持原有分页、照片预览、点赞和评论。进入章节后才读取相关详情；同一对象切换章节保留已浏览内容和位置，切换账号或联系人不混用旧结果。

本人与他人使用相同的只读名片。自己的基本资料、状态、历史头像和对外资料展示设置在本人资料页的“编辑资料”中操作；自己的群昵称、头衔仍可在有群上下文的名片中编辑。
