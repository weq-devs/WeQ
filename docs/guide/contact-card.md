# 联系人名片与资料页

消息头像、群成员、联系人和空间中的人员入口使用同一份名片显示配置。打开后先显示已有本地资料，再补全已开启的在线内容；点击昵称进入完整资料页，点击头像查看大图。

## 名片显示配置

在 **设置 → 基础功能 → 联系人名片** 调整显示内容。开关、顺序及默认值共用一份全局设置，桌面和 Web 不分别维护。

设置页与其它设置同一套结构：页面标题下是「展示字段」「字段顺序」「群内资料字段」「预览」几张卡片。「展示字段」里每个字段一行开关，卡头右侧显示「已显示 N / 总数」，并支持「全部显示 / 全部隐藏」；「字段顺序」用拖动把手或上移/下移按钮调整，把手获得焦点后可用方向键；页头的「恢复本页默认」一次还原开关与顺序。

「预览」渲染的是**我自己的真实名片**（读取当前登录账号的资料），不再使用虚构示例联系人；账号资料还没读到时显示骨架和一句说明。窄屏下预览排在设置之后，先看到开关。

头像、昵称、备注、QQ 号和好友关系固定保留；机器人、企业身份及适用的群内身份状态同样固定。群等级、入群和最后发言时间可分别配置。在线状态包含自定义状态；学校附带已有学历；共同关系、关系标签和好友添加信息分别按组配置。

当前状态位于顶部昵称旁，沿用好友聊天顶栏的状态展示；QID 开启时与 QQ 号并列。QQ 等级归入基本信息，生日和群内资料的文字标签不额外添加装饰图标。

公司、个人说明和邮箱直接展示在「基本信息」中，默认开启，已保存的字段开关继续保留；个人说明完整保留换行，邮箱可点击复制，不再需要打开名片的「详细资料」。可见分区之间统一使用分割线，空分区不留标题或分割线；群名紧接标题，以「群内资料（群名）」展示。

备注与基本信息之间同样用分割线分隔；好友尚无备注时，「添加备注」放在同一备注行。此处仅展示和编辑普通备注名，不提供好友扩展备注资料（公司、电话、描述）的展示或编辑入口。

**QQ 能量值独立、默认关闭，只显示数值，不显示能量等级。** QQ 等级是另一项资料，不受此规则影响。

隐藏内容也会停止仅为该项进行的自动查询。多个字段共用一次返回时复用结果，不重复读取；关闭名片显示不会移除资料页中的完整能力。编辑、展开、复制、查看等动作不再另设开关。

## 点击内容查看

- 号码点击复制，成功提示短暂显示后淡出；好友备注、群备注点击后直接在原行编辑，不再另开备注弹窗，留空保存可清空备注。长文字仍可选中复制，拖选不触发导航。
- 点击签名正文进入签名历史，超过三行时另提供独立的展开和收起；学校进入教育经历；标签进入相册。在线标签包括没有照片的标签，空相册显示“暂无照片”；接口不可用时使用本地标签，点击进入相册总览。
- 当前 QQ 秀点击进入历史展柜；历史扫描只在打开展柜后开始。
- 共同群数量打开名单，群头像和名称共用一个群资料入口。共同好友数仅作计数展示。
- 群昵称和头衔点击后读取编辑能力，可以编辑时直接进入原行表单，保存和取消仍需明确操作；有权限的空字段可填写，没有值又无编辑权限的字段不显示。
- 好友分组点击后在原行下拉选择并保存；群主和管理员的群名片另提供可原行编辑的「群名称」，顶部群名仍用于打开完整资料。上述入口与完整资料页共用，离线时不可提交，保存失败保留输入以便重试。

名片不再显示「更多资料」区域；匿问我答、资料历史等内容仍可从完整资料页查看。底部操作按钮统一高度，图标与文字横向排列。

已有会话提供“查看消息”和可用的预览；未找到会话时显示“发起会话”，尚未确定时不误报不存在。空间预览和本群发言在点击后读取，不随开名片提前加载。

## 完整资料页

顶部保留身份和消息操作，左侧目录切换概览、详细资料、签名历史、匿问我答、关系与互动、群内资料、个性主页、互动画像及资料历史。窄屏目录折叠成横向章节条。只显示适用于当前对象的章节。

教育、历史签名和问答在页内浏览，继续支持原有分页、点赞和评论。点击概览或名片中的标签，在标签旁展开该标签的相册，以紧凑四列照片展示，不打开遮罩或全部标签聚合页；照片仍可放大预览，自己的标签相册可上传照片。进入章节或展开相册后才读取相关详情；同一对象切换章节保留已浏览内容和位置，切换账号或联系人不混用旧结果。

本人与他人使用相同的只读名片。自己的基本资料、状态、历史头像和对外资料展示设置在本人资料页的“编辑资料”中操作；自己的群昵称、头衔仍可在有群上下文的名片中编辑。
