# 联系人名片与资料页

名片和资料页中，昵称与群名使用相同的点击规则：可编辑时进入原位编辑，否则复制当前显示的昵称或群名，成功后短暂提示「已复制」。他人昵称不会跳去修改备注；暂时离线无法编辑时仍可复制名称。QQ、QID、UID 等只读文字和号码直接点击复制，有关联对话框的字段点击打开对应对话框；拖动选择文字不会触发操作，不额外显示复制或编辑图标。

消息头像、群成员、联系人和空间中的人员入口使用同一份名片显示配置。打开后先显示已有本地资料，再补全已开启的在线内容；点击右上角放大按钮进入完整资料页，点击头像查看大图。

## 名片显示配置

在 **设置 → 基础功能 → 联系人名片** 调整显示内容。开关、顺序及默认值共用一份全局设置，桌面和 Web 不分别维护。

设置页分为「名片资料」和「群内资料字段」两组，每个字段的显示开关与拖拽把手在同一行。拖动左侧把手调整顺序，把手获得焦点后也可用方向键；右侧开关控制是否显示。页面保留「全部显示 / 全部隐藏」及显示数量，页头的「恢复本页默认」一次还原开关与顺序。

改动自动保存。点击应用顶部头像即可查看自己的真实名片，设置页不再重复展示底部预览。

头像、昵称、备注、QQ 号和好友关系固定保留；机器人、企业身份及适用的群内身份状态同样固定。群等级、入群和最后发言时间可分别配置。在线状态包含自定义状态；学校附带已有学历；共同关系、关系标签和好友添加信息分别按组配置。

当前状态位于顶部昵称旁，沿用好友聊天顶栏的状态展示。名片与完整资料页共用身份布局，身份正文按「备注、QQ、QID、UID、个性签名」依次分行，QID、UID 和签名遵循已保存的显示开关，没有值的可选字段不占空行；号码点击即可复制。签名更新时间开启时附在签名行内，不再独占一行。完整资料页的四页正文不受名片内容开关限制。

浮层名片在身份区之后依次展示适用的「群内资料、个人资料、与我的关系、个性展示、QQ 账号、机器人信息」。群内资料仅在有群上下文时显示；个人资料包含性别、生日、所在地、学校、职业、公司、邮箱和个人说明，职业和公司分别成行；与我的关系包含共同好友、共同群、亲密度、关系标签、互动标识和好友添加信息，共同好友和共同群分别成行；个性展示包含标签、精选照片和 QQ 秀；QQ 账号包含等级、累计获赞、已开通特权和能量值，沿用与其他资料一致的行格式。分区内保留用户保存的字段顺序，空分区不留标题或分割线。

公司、个人说明和邮箱默认开启，已保存的字段开关继续保留；个人说明完整保留换行，邮箱直接展示，不需要打开名片的「详细资料」。身份正文与后续分区、各可见分区之间统一使用分割线；群名紧接标题，以「群内资料（群名）」展示。好友尚无备注时，「添加备注」放在身份正文的备注行。此处仅展示和编辑普通备注名，不提供好友扩展备注资料（公司、电话、描述）的展示或编辑入口。

**QQ 能量值独立、默认关闭，只显示数值，不显示能量等级。** QQ 等级是另一项资料，不受此规则影响。

隐藏内容也会停止仅为该项进行的自动查询。多个字段共用一次返回时复用结果，不重复读取；关闭名片显示不会移除资料页中的完整能力。编辑、展开、复制、查看等动作不再另设开关。

## 点击内容查看

- 群成员仍在禁言中且当前账号具有管理权限时，点击「禁言截止」时间可确认解除禁言；头像右键菜单也提供独立的「解除禁言」，原「设置禁言」时长菜单保持不变。操作需要 QQ 在线，提交后自动读回并更新成员资料。
- 点击「入群时间」定位到该时间之后最早的一条本地群消息；点击「最后群发言」定位该成员在记录时间发送的消息。名片会在定位成功后关闭；本地没有对应消息时提示未找到，不跳到其他成员的发言。
- QQ、QID、UID 点击复制，成功提示短暂显示后淡出；好友备注、群备注点击后直接在原行编辑，不再另开备注弹窗，留空保存可清空备注。长文字仍可选中复制，拖选不触发导航。
- 点击签名正文在点击处旁打开无遮罩的签名历史对话框，保留当前名片，超过三行时另提供独立的展开和收起；学校进入教育经历；标签进入相册。在线标签包括没有照片的标签，空相册显示“暂无照片”；接口不可用时使用本地标签，点击进入相册总览。
- 当前 QQ 秀点击进入历史展柜；历史扫描只在打开展柜后开始。
- 共同群数量打开名单，群头像和名称共用一个群资料入口。共同好友数仅作计数展示。
- 群昵称和头衔点击后读取编辑能力，可以编辑时直接进入原行表单，保存和取消仍需明确操作；有权限的空字段可填写，没有值又无编辑权限的字段不显示。
- 好友分组点击后在原行下拉选择并保存；群主和管理员可直接点击群名片或完整群资料页的群名标题原地编辑，头像旁可更换群头像，无权编辑或暂时离线时点击群名复制。本人昵称在完整资料页支持点击编辑，名片及暂不可编辑时点击复制。名片右上角展开按钮进入完整资料页。编辑共用已有保存操作，离线时不可提交，保存失败保留输入以便重试。

名片不再显示「更多资料」区域；匿问我答、资料历史等内容仍可从完整资料页查看。底部操作按钮统一高度，图标与文字横向排列。

已有会话提供「打开会话」和可用的「预览消息」；未找到会话时显示「发起会话」，尚未确定时显示「打开会话」。适用的「本群发言」「查看空间」「聊天分析」全部直接显示在操作区，窄屏自动换行，不再收进「更多」。本群发言在点击后读取，不随开名片提前加载。底部不再提供空间预览和资料卡点赞；「累计获赞」数值仍可点击打开点赞面板。

## 完整资料页

顶部左侧使用与名片相同的身份区，右侧操作一行一个按钮；资料页可用宽度不足时，操作整组移到身份区下方，像名片一样横向排列、自动换行并铺满每行。较长的身份内容可在页头内滚动。左侧目录按「个人资料、与我的关系、群内资料、个性展示」组织，窄屏使用横向章节条，页内不再重复章节名称。个人资料合并原概览和详细资料；互动画像归入与我的关系，匿问我答归入个性展示。群内资料仅对有群资料或有效 UID 的对象提供。

群内资料顶部可选择联系人所在群，按需加载更多群聊；从群中进入时默认显示来源群。本群发言、聊天分析及「查看群名片」入口统一放在群选择器旁，窄屏自动换行；群名片在按钮旁打开，不离开当前资料页。切换群聊只更新本页，群昵称、头衔及操作均作用于所选群，不切换外部聊天。来源群不在当前所在群列表时仍保留已有资料。

历史不再汇总为页面或折叠区：某个项目实际保存过不同内容时，在该项目旁显示历史图标，点击后在旁侧无遮罩弹窗中查看该项目的历史值和观察时间，支持继续分页。重复读取、其他字段变化、只返回部分字段，以及单次本地与云端资料不一致，不会直接让项目出现历史按钮。索引按当前联系人渐进读取，按钮可在索引完成后补齐；群内项目按所选群和成员隔离。签名正文点击打开签名历史，学校内容点击打开教育经历；点击 QQ 秀可在旁侧打开展柜，本人历史头像保留在资料页的头像入口。资料页不再显示「技术详情」，UID 仅在身份区开启该字段时显示。

不再单独展示「教育经历」区块，点击学校值在旁侧弹窗查看教育经历；共同群数量同样在旁侧无遮罩弹窗打开名单。关系页的互动标识与互动画像是同级常驻分区，以分割线和较大标题区分，标识使用紧凑排列，画像不再折叠。个性展示先显示独立的 QQ 秀，再显示标签和照片；QQ 秀与项目名垂直居中、内容左对齐，装扮仅展示真实素材，不重复头像或 QQ 秀。

## 完整群资料

群资料页没有目录或分页。上半部分与联系人资料页使用相同的身份区、操作区布局，操作区只保留打开会话和预览消息。宽屏下方的完整资料与成员列表沿用页头的列宽、间距和内边距，上下两栏严格对齐并独立滚动；窄屏依次显示身份、操作、资料与成员。已有资料先显示，成员按需分页，不等待全群成员加载。

群名始终使用真实群名，备注独立展示和编辑；入群状态、角色及冻结等异常集中在身份区。完整资料包含简介、标签和可信来源、创建时间、群地点、入群问题、我的入群时间、成员与容量、群内好友、等级及活跃情况。成员数定位到页内成员搜索，好友数在旁侧打开名单。有真实变化的字段在对应行提供历史入口，不设独立资料历史或技术详情。

成员列表复用聊天侧栏的搜索、分页、成员行、角色与头衔徽标、名片及更多菜单。成员编辑与管理保留在成员处。公告、待办、相册、文件、精华和打卡继续从会话侧栏的已有入口打开，不在资料页重复放置功能按钮；原有群内容定位链接仍可打开对应浮窗或资源窗口。预览返回后保留资料、搜索和滚动现场。

## 会话设置

会话右上角、联系人及群完整资料页右上角共用同一个设置按钮；资料页按钮位于关闭叉左侧，原地打开紧凑设置窗格，关闭或查看当前资料后保留原页面。窗格名称旁可进入对应完整资料。

- 群会话偏好包含置顶、四种消息接收方式及我的群昵称／专属头衔；群管理包含加群方式、问题与答案、只读群分类及分类标签管理。退出群聊在「其他操作」中独立显示。群备注、群名和头像只在身份区编辑，会话右键快捷备注仍保留。
- 好友会话偏好保留置顶、消息免打扰、特别关心及独立的空间权限分组；备注和好友分组不重复放入窗格。
- 意图感知分别显示会话是否跟随应用设置和实际生效状态；防撤回分别显示保护／通知选择与真实读取到的触发器安装状态。选择已保存不等于已核实安装完成。
- 群关键词按词设置发言人成员范围，成员搜索只读取目标群，保存状态与失败重试明确展示；快速关闭前仍会保存未回车的关键词。

问答在页内展开浏览；教育、签名、共同群及项目历史的弹窗自动避让窗口边缘，支持点外、Esc 或关闭按钮收起。标签在旁边展开对应相册，以紧凑四列照片展示，照片可放大预览，自己的标签相册可上传。只有打开当前页或相关详情后才读取所需内容，离开后暂停读取；同一对象切换章节保留已浏览内容和位置，切换账号或联系人不混用旧结果。

本人与他人使用相同的只读名片。自己的基本资料、状态和对外资料展示设置在个人资料中的「编辑资料与展示设置」展开区操作；自己的群昵称、头衔仍可在有群上下文的名片中编辑。
