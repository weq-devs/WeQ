# 消息页

消息页是 WeQ 的主场：左侧是最近会话列表，右侧是聊天窗口。这一页把私聊、群聊和所有消息操作
讲清楚。

## 1. 会话列表

全局搜索位于窗口标题栏 WeQ 图标与用户头像之间，默认只显示图标，悬停临时展开，点击可固定展开或收起；不会因当前内容页改变搜索语义。创建群聊、添加好友仍属于内容侧的操作，不进入全局工具条。

### 会话行

每个会话显示头像、名称、最后一条消息预览与时间。状态标记：

| 标记 | 含义 |
| --- | --- |
| 📌 置顶 | 会话被置顶 |
| 🔕 免打扰 | 消息免打扰（灰色徽标 + 划掉铃铛） |
| 🚫 屏蔽 | 屏蔽此人 |
| ✏️ 草稿 | 这个会话存有未发送的草稿 |
| 🤖 bot | 机器人会话 |
| @ | 群里 @ 过我（有专门的未读提示） |
| 幸运字符 | 群会话上会显示幸运字符徽标 |

### 列表中的特殊入口

- **隐藏会话** —— 会话列表最上方出现「隐藏会话 N 个」行，点击展开（不显示内部预览与时间）；
- **删除会话 / 服务号 / 公众号** —— 归在同一个合并面板里，通过 `MergedKind` 分类展示
  （`service` / `official` / `hidden` / `deleted`）。

### 数据线会话

「我的手机 / 我的电脑」这类数据线会话按单聊解析：头像使用对应的设备图标，PC 端发出的消息算
「我发的」，手机 / 平板发来的算对端。

## 2. 聊天窗口

点会话进入聊天。标题栏显示会话名、机器人徽标、幸运字符、私聊在线状态，以及一串操作按钮：

| 按钮 | 仅群聊 | 作用 |
| --- | --- | --- |
| 🔍 | | 搜索聊天记录 |
| ⬇ | | 导出该会话的聊天记录 |
| ➕ | | 添加消息（[消息编辑](./message-edit.md)） |
| 🗑 | | 删除列表 |
| ↺ | | 撤回列表 |
| 📄 | ✔ | 群公告 |
| ✨ | ✔ | 群精华 |
| 🖼 | ✔ | 群相册 |
| 📁 | ✔ | 群文件 |
| 📊 | ✔ | 群分析 |
| 🐞 | ✔ | 反馈 Bug（仅项目交流群，且 QQ 在线时可用） |

### 消息气泡

WeQ 高仿 QQ 渲染，支持几乎全部消息类型：

- 文本、@ 提及、链接预览卡片；
- 图片、视频、语音、文件、在线文件 / 文件夹；
- QQ 表情、商城表情、贴表情（表情回应）、emoji 互动；
- 回复引用、合并转发（`multiMsg`）、卡片（Ark）、Markdown、机器人内联键盘；
- 钱包 / 红包 / 转账、通话、位置共享、QQ 动态、闪传、名片、灰条提示（撤回 / 戳一戳 / 群操作
  等）。

**装扮**：每条消息会按数据库里记录的「气泡 / 字体 / 挂件」逐条渲染（可在设置 → 个性显示里关
掉）。**撤回标记**：被防撤回拦截的消息内容保持完整，气泡上带撤回标签。**贴表情**会渲染在气泡
下方；鼠标悬停到某一枚表情上，会在鼠标旁弹出「谁贴了这个表情」的面板（头像 + 昵称 + QQ 号，
自己那行高亮，滚到底自动续传下一页）。这份名单是在线的 QQ 实时查的（见
[docs/develop/send-message.md](../develop/send-message.md) 的 0x9083_1），所以账号离线时面板
会显示「需要 QQ 在线」而不是空名单。

### 输入区

- 纯文本输入，回车发送；
- 表情按钮打开表情面板；
- 群聊里输入 `@` 弹出成员浮层，选中后插入 @名字；
- 可以粘贴文本；
- 草稿自动保存到当前会话。

### 提及与复制

在群输入框键入 `@` 可展开成员列表，继续输入名称或 QQ 号筛选；支持方向键、Enter / Tab 选中、Escape 收起。列表可滚动加载，搜索同时查询尚未加载的群成员；群主和管理员可选择全体成员，实际发送权限及剩余次数由 QQ 决定，界面不编造额度。

从 WeQ 复制含提及的消息或选中的正文时，剪贴板同时保留普通文字和提及身份。粘贴到输入框后，依据 UID（缺少时才用 QQ 号）查当前账号的名称，不照搬原作者的备注，不按同名文字猜人。未查到成员时显示唯一 ID，仍保留真实提及。外部应用若只提供纯文本，无法可靠恢复目标，按普通文字处理。

### 相同消息 +1

私聊、群聊在最近两条消息的实际元素内容相同时，在最新消息旁显示 `+1`。只比较当前最新窗口，不跨过灰条、撤回或失败消息；同名但不同 UID 的提及不视为相同目标，同一个 UID 的不同备注不影响判断。

点击后发送相同元素，不覆盖输入框或清除草稿。普通/超级/随机表情、商城贴纸、图片等保留各自发送形态，提及按当前账号重新解析名称。没有有效身份、媒体资源或发送适配器时明确失败，不将媒体或提及悄悄降级成占位文字；红包等交易/系统内容不参与等价重发。

## 3. 消息操作

### 右键菜单

在消息气泡上右键（移动端长按）弹出菜单：

| 菜单项 | 作用 |
| --- | --- |
| **复制** | 复制消息文本 |
| **修改** | 打开原始元素编辑器（见[消息编辑](./message-edit.md)） |
| **装扮** | 查看这条消息用到的字体 / 气泡 / 挂件 ID 与预览图，可单项另存或打包另存全部 |
| **下载** | 下载媒体（图片等） |
| **删除** | QQ 式删除：消息仍留在聊天里（半透明覆盖），可恢复 |

「装扮」卡片里的单项另存会优先给原生文件：字体是 `.ttf`，静态气泡 / 挂件是 `.png`；
多帧动画打包成 `.zip`。「另存全部」会把这条消息用到的资源按 `font/`、`bubble/`、
`widget/` 收进一个 zip，并附一份 `manifest.json`。资源还没有缓存时会提示先联网加载。

### 合并转发窗口

点击合并转发的消息会打开一个**可拖动、可堆叠**的小窗口，逐层展示转发内容；嵌套转发会继续叠
新窗口，可以一直往下钻。窗口复用与主聊天相同的渲染器，样式一致。

### 媒体查看

- 图片点击进入大图灯箱；
- 视频点击进入视频灯箱；
- 商城表情进入专属灯箱；
- 闪传卡片可打开闪传查看器 / 分享窗口。

## 4. 搜索

### 全局搜索

顶部搜索框输入关键字会弹出分类结果下拉，覆盖七个类别：

| 类别 | 内容 |
| --- | --- |
| 会话 | 会话名匹配 |
| 好友 | 好友资料匹配 |
| 群友 | 群成员匹配 |
| 聊天记录 | 消息正文匹配 |
| 文件 | 文件名匹配 |
| 克隆消息 | 当前账号克隆私聊、克隆群聊的本地对话正文 |
| 助手对话 | 当前账号助手各会话的本地正文 |

范围复选框默认全选，可独立勾选类别；全部取消时不执行查询。切换范围不会改变关键词，也不会随当前页面自动改成局部搜索。查询失败会显示重试按钮，不把失败当作无结果。

目前这里的「全部」是已接入的上述七类；空间、收藏等内容的全局检索仍在接入中，不代表已经搜索这些内容或在线拉取完整历史。

克隆和助手结果标明本地对话来源，不冒充真实 QQ 消息。点击结果定位具体记录：克隆在独立消息列表中打开，助手在悬浮工具中打开；记录已删除时明确提示。旧版单桶对话以只读方式查看，不作为新会话草稿。窄屏可在会话列表和消息区之间切换，返回时保留该会话。

点某类的「更多」打开大号分页弹窗，可无限滚动加载更多结果。

### 聊天记录搜索

- 标题栏的 🔍 进入**当前会话内**的聊天记录搜索（左侧会话列表隐藏，结果占满宽度，跳转始终
  指向当前会话）；
- 全局「聊天记录」类结果则打开左右分栏的聊天记录弹窗：左边是命中的会话，右边是该会话里命中
  的消息，点击可跳到原消息。

搜索结果渲染时复用主聊天的消息渲染器，看到的和聊天里一致。

会话内搜索的「时间范围」和「跳转日期」位于搜索框下方，复用导出页的消息密度日历。日期按北京时间计算，颜色由当天消息数量分级；范围可正选或反选，跳转只允许有消息的日期。

「设置 → 个性显示」里的消息序号与发送时间为两个独立开关，默认关闭。打开后与昵称同排，时间精确到秒；戳一戳等系统消息不显示序号。

### 发送与多选

- WeQ 发送中的消息在气泡旁显示圈圈，收到正常回执后直接隐藏；只有失败或疑似未送达时才在下方显示提示，不显示“已发送”标签。
- 尚未同步入库的 WeQ 消息也可右键复制、多选和使用已满足条件的引用 / 协议操作；依赖本地数据库行的修改、删除在同步入库后可用。
- 右键「多选」后，点击或 Ctrl/⌘+点击切换单条，Shift 从锚点选择连续区间，Ctrl/⌘+Shift 追加区间。Ctrl/⌘+A 选择当前已加载的全部消息，不设选择数量上限；切会话或 Esc 退出。
- 「复制纯文本」或 Ctrl/⌘+C 按时间线顺序复制所选内容，包含发送者昵称、精确到秒的北京时间和正文，保留正文换行；仍保留「复制 JSON」。输入框 / 编辑器中的原有快捷键不被接管。
- 窄屏多选操作以图标呈现，仍提供可访问名称和提示。

主页头像与其它头像共用本地优先缓存；回到主页、重新聚焦窗口或从后台恢复可见时复核头像。CDN 直连模式按浏览器 reload 策略读取，不给上游 URL 添加随机参数；失败可在下次聚焦时重试。

### 系统消息与已读

- 撤回灰条按当前账号的 UID / QQ 号识别“你”，不依赖群成员昵称是否已缓存；不按同名判断为同一个人。系统消息时间与正文同排，仍不显示 seq。
- 系统消息不能贴表情或撤回。自己的贴表情可在消息右键菜单中逐枚撤回，也可点击自己已贴的回应；其它人的回应仅查看名单。
- 在最新消息窗口的最底端（允许 2px 舍入误差）点击、滚动、滑动或操作键盘，以及在该位置发送消息，会请求标记当前会话为已读。高频操作合并，保留原先进入会话时先记录未读跳转位置再标已读的流程；新增交互不会把历史窗口、后台页面或已切走的会话误当作当前底部。

## 5. 缺失消息

聊天时间线里偶尔会出现一条「占位条」——代表 QQ **从未把这段时间的消息同步到本机**。

- 点击占位条按 seq 窗口从 QQ 服务端拉取，已确认的记录直接融入主时间线，并标注来源；
- 每个 SSO 小窗至多检查 30 个 seq，未补齐的区间保留续查入口；
- 拉取需要 QQ 在线：未在线或处于完全离线模式时会提示无法拉取；
- 私聊旧编号等无法确认 NT 序号的记录只独立展示，不猜测其时间线位置。
- 会话顶部可打开批量补全：会话显示与选择无数量上限，扫描后手动开始；不设请求次数预算，仍可暂停、取消和续作。任务连续显示，请求记录使用会话友好名称。

## 6. 会话设置

点聊天标题栏进入会话详情面板，可以：

| 操作 | 说明 |
| --- | --- |
| 设为置顶 | 固定到会话列表顶部 |
| 消息免打扰 | 不再提醒 |
| 屏蔽此人 | 仅私聊 |
| 消息通知设置 | 消息预览、提示音等 |
| 删除聊天记录 | **仅清空本地显示**，不清数据库 |

群聊还有群资料面板（群成员、群公告、群设置等）。

## 7. 群聊专属面板

| 面板 | 内容 |
| --- | --- |
| **群公告** | 当前公告 + 历史公告列表，含发布者、时间、已读数、配图 |
| **群精华** | 被设为精华的消息，可跳转到原消息 |
| **群相册** | 群相册列表与媒体（详见[空间与相册](./album-qzone.md)） |
| **群文件** | 群文件目录树，可下载 |
| **群分析** | 群画像（详见[聊天分析](./analytics.md)） |
| **反馈 Bug** | 仅项目交流群，把日志与说明以闪传发到群，或以图文卡片发 issue/PR 链接 |
