# 消息页

消息页是 WeQ 的主场：左侧是最近会话列表，右侧是聊天窗口。这一页把私聊、群聊和所有消息操作
讲清楚。

## 1. 会话列表

全局搜索位于窗口标题栏 WeQ 图标与用户头像之间，默认只显示图标，悬停临时展开，点击可固定展开或收起；不会因当前内容页改变搜索语义。创建群聊、添加好友仍属于内容侧的操作，不进入全局工具条。

桌面左栏底部的工具吸附入口、快捷控制与设置使用统一样式，设置位于快捷控制下方、账号头像上方，打开设置或维护工具时保持高亮，并保留新版本提醒。工具拖离吸附位置后恢复圆形悬浮按钮，运行任务数量继续显示；窄屏设置入口仍位于导航栏。

列表读取全部最近会话，不设总长度上限，滚动时仅渲染可见行。顶行提供搜索、多选、显示范围和添加。搜索展开时占满该行；会话多选保留顶行，在列表底部显示独立操作栏，提供已选数量、全选当前结果、导出、拉取漫游消息和退出。混入不支持的对象时仍可点击操作，弹窗列出相应数量和名称；确认后仅处理支持的会话，取消则保持原选区。全选包含当前结果中的群助手内部会话，不重复计入群助手入口，已选总数旁注明其中的群助手会话数。范围可选真实、虚拟或两者，虚拟会话只增加来源标记，切换保留真实聊天现场。联系人顶行另有刷新，位于好友/群通知上方。所有位置进入多选都不会自动展开全局浮动工具栏，仍可手动打开。

### 会话行

会话分页在后台静默进行，已有会话不会因翻页重新显示加载占位。全选会等待当前范围的全部分页读取完成，再提交完整选区；补齐期间显示「正在补齐全选」，不会把已加载的前几页冒充全部结果。读取失败会明确提示并保留原选区，可重试。

每个会话显示头像、名称、最后一条消息预览与时间。状态标记：

会话右键菜单提供多选、置顶或取消置顶、分析、导出和拉取漫游消息，目标是右键选中的会话；置顶不再提供独立按钮或详情开关。对已多选集合中的会话右键，可批量导出或拉取，不先切换当前聊天。分析针对单个好友或群，群成员头像右键另有「分析此成员」。

| 标记 | 含义 |
| --- | --- |
| 📌 置顶 | 会话被置顶 |
| 🔕 免打扰 | 消息免打扰（灰色徽标 + 划掉铃铛） |
| 🚫 屏蔽 | 屏蔽此人 |
| ✏️ 草稿 | 这个会话存有未发送的草稿 |
| 🤖 bot | 机器人会话 |
| @ | 群里 @ 过我（有专门的未读提示） |
| 幸运字符 | 群会话上会显示幸运字符徽标 |

### 列表中的特殊入口

- **隐藏会话** —— 会话列表最上方出现「隐藏会话 N 个」行，点击展开（不显示内部预览与时间）；
- **删除会话 / 服务号 / 公众号**：各自通过聚合入口查看。
- **群助手**：收纳 QQ 设置为群助手的群；内部搜索与置顶见[主界面](homepage.md#消息与联系人)。

### 数据线会话

「我的手机 / 我的电脑」这类数据线会话按单聊解析：头像使用对应的设备图标，PC 端发出的消息算
「我发的」，手机 / 平板发来的算对端。

## 2. 聊天窗口

点会话进入聊天。标题栏显示会话名、机器人徽标、幸运字符、私聊在线状态，以及一串操作按钮：

点击会话标题可打开对应的好友或群名片，也可用键盘聚焦标题后按 Enter 或空格打开。
群名片使用无背景遮罩的非模态浮窗，点击外部、按 Escape 或点击关闭按钮可收起。

| 按钮 | 仅群聊 | 作用 |
| --- | --- | --- |
| 🔍 | | 搜索聊天记录 |
| 消息管理 | | 拉取漫游消息、撤回列表、删除列表；分隔后是添加本地消息 |
| 群资料 | ✔ | 窄屏打开右侧群资料；桌面使用右栏收放把手 |
| 会话设置 | | 打开当前会话设置 |
| 🐞 | ✔ | 反馈 Bug（仅项目交流群，且 QQ 在线时可用） |

「消息管理」只整合入口，选择后仍打开原有范围配置、列表或本地消息编辑器；漫游运行进度显示在该按钮旁。群公告在右侧资料栏预览，点击可查看完整公告；精华、相册、文件在同栏并排展示，打开后沿用现有查看界面。窄屏通过顶部的群资料按钮打开侧栏，关闭资源查看后返回资料栏。

聊天记录搜索、更多搜索结果及消息管理中的记录查看/编辑使用应用内浮窗，可拖动标题区和调整右下角大小，不压暗聊天背景。切换当前聊天不会将已打开的搜索目标改成新会话；选择结果跳转仍按原有规则处理。任务和进度从对应入口附近的小窗格查看，不再占据屏幕中央。

日历、用户资料、互动标识等轻量小窗可点击外部收起；嵌套时只收起最上层，工具浮窗和侧栏继续保留。克隆、建群及相关设置有未保存修改时会先确认，保存中不会关闭。好友克隆的进度统一在「任务 → 好友克隆」查看，收起进度不停止后台任务，完成后可打开克隆体或移除任务记录；任务按账号隔离，仅保留在本次应用会话内。

### 消息气泡

WeQ 高仿 QQ 渲染，支持几乎全部消息类型：

- 文本、@ 提及、链接预览卡片；
- 图片、视频、语音、文件、在线文件 / 文件夹；
- QQ 表情、商城表情、贴表情（表情回应）、emoji 互动；
- 回复引用、合并转发（`multiMsg`）、卡片（Ark）、Markdown、机器人内联键盘；
- 钱包 / 红包 / 转账、通话、位置共享、QQ 动态、闪传、名片、灰条提示（撤回 / 戳一戳 / 群操作
  等）。

**装扮**：每条消息会按数据库里记录的「气泡 / 字体 / 挂件」逐条渲染（可在设置 → 个性显示里关
掉）。**撤回标记**：被防撤回拦截的消息内容保持完整，气泡上带撤回标签。**贴表情**会渲染在气泡
下方；鼠标悬停到某一枚表情上，会在鼠标旁弹出「谁贴了这个表情」的面板（头像 + 昵称 + QQ 号，
自己那行高亮，滚到底自动续传下一页）。这份名单是在线的 QQ 实时查的（见
[docs/develop/send-message.md](../develop/send-message.md) 的 0x9083_1），所以账号离线时面板
会显示「需要 QQ 在线」而不是空名单。

### 输入区

- 纯文本输入，回车发送；
- 表情按钮打开表情面板；
- 群聊里输入 `@` 弹出成员浮层，选中后插入 @名字；
- 可以粘贴文本；
- 草稿自动保存到当前会话。

### 提及与复制

在群输入框键入 `@` 可展开成员列表，继续输入名称或 QQ 号筛选；支持方向键、Enter / Tab 选中、Escape 收起。列表可滚动加载，搜索同时查询尚未加载的群成员；群主和管理员可选择全体成员，实际发送权限及剩余次数由 QQ 决定，界面不编造额度。

成员选择列表仍可显示群名片或好友备注，但插入和发出的提及文字只使用昵称，不使用备注或群名片；缺少昵称时使用 QQ 号或 UID，发送前也会重新处理旧草稿里的提及。

从 WeQ 复制含提及的消息或选中的正文时，剪贴板同时保留普通文字和提及身份。粘贴到输入框后，依据 UID（缺少时才用 QQ 号）查昵称，不照搬原作者的备注，不按同名文字猜人。未查到成员时显示唯一 ID，仍保留真实提及。外部应用若只提供纯文本，无法可靠恢复目标，按普通文字处理。

### 相同消息 +1

私聊、群聊在最近两条消息的实际元素内容相同时，在最新消息旁显示 `+1`。只比较当前最新窗口，不跨过灰条、撤回或失败消息；同名但不同 UID 的提及不视为相同目标，同一个 UID 的不同备注不影响判断。

点击后发送相同元素，不覆盖输入框或清除草稿。普通/超级/随机表情、商城贴纸、图片等保留各自发送形态，提及按当前账号重新解析昵称。没有有效身份、媒体资源或发送适配器时明确失败，不将媒体或提及悄悄降级成占位文字；红包等交易/系统内容不参与等价重发。

私聊、群聊的消息右键菜单也提供 `+1`，可直接重发单条消息，不要求连续重复，也可用于历史消息。灰条、红包等不支持等价重发的内容，以及撤回、删除和发送中或失败的消息不显示此项；当前不可发送或正在发送时按钮禁用。

## 3. 消息操作

### 右键菜单

在消息气泡上右键（移动端长按）弹出菜单：

| 菜单项 | 作用 |
| --- | --- |
| **复制** | 复制消息文本 |
| **转发** | 选择目标后发送；多选可逐条转发 |
| **+1** | 在当前会话发送一条相同消息，仅可等价重发的消息显示 |
| **撤回** | 私聊或群聊中撤回自己的消息；群主管理员还可撤回其他成员的消息 |
| **添加到素材库** | 保存独立合成素材，不改变当前聊天 |
| **修改** | 打开原始元素编辑器（见[消息编辑](./message-edit.md)） |
| **装扮** | 查看这条消息用到的字体 / 气泡 / 挂件 ID 与预览图，可单项另存或打包另存全部 |
| **下载** | 下载媒体（图片等） |
| **删除** | QQ 式删除：消息仍留在聊天里（半透明覆盖），可恢复 |

撤回需要 QQ 在线及完整的消息定位信息。私聊中，NT 序号已确认且定位完整的缓存消息也可撤回，无需等待 QQ 本地库同步。普通用户的消息超过 2 分钟、漫游记录缺少可靠定位或私聊消息定位不全时，会保留禁用的「撤回」菜单并显示原因。对方的私聊消息和系统灰条不提供撤回入口；最终是否允许撤回由 QQ 服务端判定。

「装扮」卡片里的单项另存会优先给原生文件：字体是 `.ttf`，静态气泡 / 挂件是 `.png`；
多帧动画打包成 `.zip`。「另存全部」会把这条消息用到的资源按 `font/`、`bubble/`、
`widget/` 收进一个 zip，并附一份 `manifest.json`。资源还没有缓存时会提示先联网加载。

图片的复制操作复制图片本体；Web 需要支持图片剪贴板的安全环境，失败会提示。逐条转发等待上一条确认后继续，可设置间隔、抖动、尝试次数和失败策略；停止不撤回已发送消息，未知回执后的重试仍可能重复。

群内名片支持查看私聊和只读预览。点击「预览私聊」后直接在名片内显示聊天内容，不再打开额外浮窗，可通过「返回资料」回到名片资料。预览不切换主聊天、不发送、不编辑、不标已读；首次显示最新消息，向上加载保持位置。可确认目标身份的空间分享卡片进入对应说说、相册或主页，未知内部协议不猜测。

### 合并转发窗口

点击合并转发的消息会打开一个**可拖动、可堆叠**的小窗口，逐层展示转发内容；嵌套转发会继续叠
新窗口，可以一直往下钻。窗口复用与主聊天相同的渲染器，样式一致。

### 媒体查看

- 图片点击进入大图灯箱；
- 视频点击进入视频灯箱；
- 商城表情进入专属灯箱；
- 闪传卡片可打开闪传查看器 / 分享窗口。

## 4. 搜索

### 全局搜索

顶部搜索框输入关键字会弹出分类结果下拉，当前接入以下来源：

| 类别 | 内容 |
| --- | --- |
| 会话 | 会话名匹配 |
| 好友 | 好友资料匹配 |
| 群友 | 群成员匹配 |
| 聊天记录 | 消息正文匹配 |
| 文件 | 文件名匹配 |
| 收藏 | 当前账号本地库、已采集历史与已浏览摘要；包含已缓存的文本、语音转写和图文正文 |
| 克隆消息 | 当前账号克隆私聊、克隆群聊的本地对话正文 |
| 助手对话 | 当前账号助手各会话的本地正文 |
| 个人空间 | 自己的已浏览说说正文、详情、相册名称与描述 |
| 他人空间 | 当前账号已浏览的他人说说正文、详情、相册名称与描述 |
| 群相册 | 已浏览群相册的名称与描述 |
| 群文件 | 已浏览目录中的文件名与上传者 |
| 邮件 | 已浏览列表的主题、摘要和地址；已读邮件的正文与附件名 |
| 频道私聊 | 本地频道私聊库的正文，按会话分页读取，不只搜索最新一页 |
| 商城表情 | 随应用提供的离线目录名称与介绍，不代表实时商城全部内容 |

默认勾选会话、好友、群友、聊天记录、文件、收藏、个人空间、他人空间、群相册、群文件、邮件和频道私聊。个人空间与他人空间可分别开关，各自包含说说与相册，结果也区分作者范围。克隆消息、助手对话和商城表情默认不勾选，仍可手动加入；「全部」也包含这三个可选类别。账号范围包含收到的消息和参与会话的资料，不是只搜索自己发送的消息，不查询其它已登录账号；他人空间也仅指当前账号已浏览缓存的内容，不会自动联网补取。

名称完全匹配优先于前缀、包含匹配；空间等缓存来源的标题匹配优先于仅正文匹配。同档文件与缓存内容优先较新的记录，聊天记录分组再按命中数排序。会话、好友和群友在分页前排序，同分使用稳定身份确定顺序。聊天记录与文件仍在有界候选池内排名，不代表任意历史命中都已参加排序。下拉先显示有命中的类别，名称相关度相同按会话、好友、聊天记录、文件、收藏等常用顺序排列，失败、加载中和空结果靠后；生成对话与商城在范围列表末尾。

可独立勾选类别；全部取消时不执行查询。切换范围不会改变关键词，也不会随当前页面自动改成局部搜索。查询失败会显示重试按钮，不把失败当作无结果。

这里的「全部」表示上述已接入类别，不代表完整云端历史。空间、相册、群文件和邮件采用当前账号的已观察文本索引，类别旁显示「已缓存内容」、记录数及是否有回收或截断；本版本浏览接口取得的内容才会进入该索引，不扫描所有旧导出目录或原始缓存。关闭账号会保存索引，同号不同数据来源互相隔离。索引最多保留约 16 MiB / 两万条，回收会明确标注；旧格式或无法保存时仍可使用当前内存内容，并提示缓存尚未保存。

搜索不会自动登录邮箱、联网补读空间或下载媒体。收藏也不补取尚未缓存的正文。点击命中是明确的打开操作，按真实身份进入对应说说、相册、目录文件、邮件、频道消息窗口或个性装扮里的商城表情包；原查看器需要在线权限时仍需连接，已删除或不可访问时明确报错，不改开同名或第一条内容。邮箱仍遵循原生读信与已读规则，未保存的写信内容会先确认。各个慢来源独立显示失败与重试，某一来源出错不会清除其它来源的有效命中。

克隆和助手结果标明本地对话来源，不冒充真实 QQ 消息。点击结果定位具体记录：克隆复用会话列表，助手在工具中打开；记录已删除时明确提示。旧版单桶对话只读，不作为新草稿。

点某类的「更多」打开大号分页弹窗，可无限滚动加载更多结果。

更多结果换词或清空后立即废弃旧请求；查询失败可重试，分页失败保留已取得结果。同名文件按来源会话与消息分别保留，不按文件名合并。聊天记录排名和文件检索使用有限候选池；超过上限时显示「当前候选」而非完整总数，本轮候选读完也不表示全部历史已查完。

翻页期间来源变化时，重叠命中只显示一次，后续游标仍按服务端原始返回条数前进。界面会提示结果可能已更新并提供刷新入口，不把去重后已载入数量伪称为完整最新结果。

点击命中后，标题栏搜索图标旁会出现返回箭头，可恢复原查询与类别。下拉结果保留滚动和命中焦点；从“更多”进入内容时还会保留在更多页调整的关键词、已载入结果及分页位置，返回不自动重读第一页。需要最新结果时使用更多页的重新搜索按钮。修改全局关键词、改变类别或切换账号后，旧返回现场失效；现场仅保存在当前窗口内存中，不写入历史文件。

### 聊天记录搜索

- 聊天标题栏的搜索打开**当前会话内**的记录浮窗，跳转绑定打开时的目标，不随后来切换聊天改变；
- 全局「聊天记录」类结果则打开左右分栏的聊天记录弹窗：左边是命中的会话，右边是该会话里命中
  的消息，点击可跳到原消息。

搜索结果渲染时复用主聊天的消息渲染器，看到的和聊天里一致。

会话内搜索的「时间范围」和「跳转日期」位于搜索框下方，复用导出页的消息密度日历。日期按北京时间计算，颜色由当天消息数量分级；范围可正选或反选，跳转只允许有消息的日期。

「设置 → 个性显示」里的消息序号与发送时间为两个独立开关，默认关闭。打开后与昵称同排，时间精确到秒；戳一戳等系统消息不显示序号。

### 发送与多选

- WeQ 发送中的消息在气泡旁显示圈圈，收到正常回执后直接隐藏；只有失败或疑似未送达时才在下方显示提示，不显示“已发送”标签。
- 文本、表情、图片、语音、视频和卡片等常规消息拿到有效序号后，会保存到当前账号的 WeQ 消息缓存，重启后仍可读取；不向 QQ 原始数据库伪造插入记录。后续 QQ 同步或漫游返回同一条消息时会合并显示，本地保存失败会提示，请勿因此重复发送。
- 引用回复会携带原消息摘要；私聊引用指针先转换为会话序号再跳转，不再把发送方的 client sequence 当作时间线序号。原消息未同步或编号存在歧义时会明确提示找不到。
- 提交后立即清空本次内容并保留输入焦点，可以继续写下一条；等待回执期间不会重复发送。失败不自动回填，也不自动移除失败消息。自己的“发送失败”、撤回或“可能未送达”标志可点击一次切换为“重新编辑”，再次点击才带入输入框；已有草稿时先确认替换，取消会保留原内容。这只恢复编辑，不自动重发；失败草稿仅保留在当前账号窗口内，不保证重启恢复。
- 尚未同步入库的 WeQ 消息也可右键复制、多选和使用已满足条件的引用 / 协议操作；依赖本地数据库行的修改、删除在同步入库后可用。
- 右键「多选」后，点击或 Ctrl/⌘+点击切换单条，Shift 从锚点选择连续区间，Ctrl/⌘+Shift 追加区间。Ctrl/⌘+A 选择当前已加载的全部消息，不设选择数量上限；切会话或 Esc 退出。
- 逐条转发支持固定间隔或按文本长度发送。按文本长度时，每条发送前等待：纯文本默认每字 1000 毫秒；含图片、表情、文件、卡片或合并转发等非文本的整条消息默认 5000 毫秒，不再累计其中的文字耗时。两个时间均可按毫秒调整；配置窗显示所选目标的预估等待总时长及随机抖动范围，不含上传、网络与重试耗时。开始后配置窗关闭，右下角常驻横幅显示进度并可停止后续发送；完成后可点击目标名称打开对应对话，已发出的消息不会因停止而撤回。
- 多选操作栏的「复制」可选择纯文本、富文本或 JSON；Ctrl/⌘+C 按时间线顺序复制昵称、北京时间和正文，Ctrl/⌘+Shift+C 复制富文本并保留引用块和提及身份。输入框原有快捷键不被接管。「转发」统一选择合并转发或逐条转发。
- 在会话空白处按住鼠标左键拖动可框选消息，只按消息整行与选框的竖直交集命中，不要求横向碰到气泡；靠近上下边缘可自动滚动。Ctrl/⌘ 或 Shift 起拖追加原有选择，普通起拖替换选择，不影响气泡内的文字选择。多选栏「分析」「导出」固定使用所选本地消息，不重复选择范围；漫游缓存与尚未入库的发送消息暂不支持这两种精确处理。
- 窄屏多选操作以图标呈现，仍提供可访问名称和提示。

通用多选还支持 Ctrl/Command+Shift+A 清空、方向键/Home/End 移动焦点、Shift 扩展范围、Space 切换焦点项及 Escape 退出。全选只包含当前候选，不会自动读取整库或虚构未加载的服务器内容。会话和联系人多选栏在当前结果全部选中后，再次点击全选按钮可取消当前结果的选择，保留筛选外的已选项，且不退出多选模式。

主页头像与其它头像共用本地优先缓存；回到主页、重新聚焦窗口或从后台恢复可见时复核头像。CDN 直连模式按浏览器 reload 策略读取，不给上游 URL 添加随机参数；失败可在下次聚焦时重试。

### 系统消息与已读

- 浏览历史时，自己或对方的新消息会显示在右下角提示中；悬停提示可选择「预览新消息」或「定位到底部」，键盘聚焦和触屏也可使用。预览复用私聊预览的消息列表，可向上加载更早记录，关闭后保留主时间线的阅读位置；只有定位到底部才回到最新消息并按原规则请求已读。
- 撤回灰条按当前账号的 UID / QQ 号识别“你”，不依赖群成员昵称是否已缓存；不按同名判断为同一个人。系统消息时间与正文同排，仍不显示 seq。
- 系统消息不能贴表情或撤回。自己的贴表情可在消息右键菜单中逐枚撤回，也可点击自己已贴的回应；其它人的回应仅查看名单。
- 在最新消息窗口的最底端（允许 2px 舍入误差）点击、滚动、滑动或操作键盘，以及在该位置发送消息，会请求标记当前会话为已读。高频操作合并，保留原先进入会话时先记录未读跳转位置再标已读的流程；新增交互不会把历史窗口、后台页面或已切走的会话误当作当前底部。
- 已读请求按固定消息水位即时更新当前会话红点，再单独核对该会话的未读结果，不等待全会话扫描；较早发出的扫描不会让红点重新出现，之后到达的新消息仍正常计数。写入失败时重新核对状态。

## 5. 缺失消息

聊天时间线的缺口占位表示本地已观察锚点之间存在候选 seq 空窗；它不能证明远端一定有消息，或 QQ 从未同步过该区间。

- 点击占位条按 seq 窗口从 QQ 服务端拉取，已确认的记录直接融入主时间线，并标注来源；
- 每个 SSO 小窗至多检查 30 个 seq，未补齐的区间保留续查入口；
- 拉取需要 QQ 在线：未在线或处于完全离线模式时会提示无法拉取；
- 私聊旧编号等无法确认 NT 序号的记录只独立展示，不猜测其时间线位置。
- 会话顶部的「消息管理 → 拉取漫游消息」或会话右键打开漫游拉取，目标固定为该会话，不再重复选择；会话多选底部操作栏或右键可批量带入，弹窗展示固定的已选会话名单，可展开核对，后续选区变化不修改已打开的目标。关闭配置保留会话选区。扫描后手动开始，不设请求次数预算，仍可暂停、取消和续作。切换会话或关闭配置不取消后台拉取；工具栏的「任务 → 漫游拉取」可查看和控制已有任务，请求记录使用会话友好名称。

## 6. 会话设置

聊天标题栏的 **会话设置** 管理当前会话的防撤回保护和通知；群聊另有群关键词范围。防撤回仍依赖全局总开关，关键词按成员身份过滤，不因打开面板自动执行清理或修改 QQ 设置。

会话设置在按钮附近打开与任务列表同款的非模态小窗格，点击外部或关闭按钮即可收起。群相册、群精华、群文件等会话附属内容保留自身标题与关闭按钮，不再额外显示顶部页签。

在群聊中打开群公告、精华、相册或文件侧栏时，常规会话列表与宽度拖拽条暂时隐藏，为聊天和资源查看留出空间。关闭侧栏后恢复原列表宽度与筛选内容，聊天草稿保持不变。

「会话设置 → QQ 设置」可以修改好友或群备注、置顶、消息接收方式，以及好友分组。群消息接收保留正常提醒、接收但不提醒、收进群助手、屏蔽四档；进入群助手或屏蔽前会确认。群设置还可以修改自己的群昵称、群名和群头像，群成员名片内的「群名片与头衔」用于指定成员。专属头衔仅群主可编辑，管理员和普通成员只读显示；提交前会再次检查当前账号的群主身份，最终权限与结果仍由 QQ 服务端判定。

会话中的推荐群聊／群名片消息可点击打开群资料，再通过「查看群聊消息」进入对应群会话。已收录的群显示本地群资料；未收录的群只展示分享消息中的群名、头像与群号，不推断人数或成员关系，也不会自动加群。缺少明确群号的分享仍保留原有消息展示。

群消息右键菜单中的「设为精华／取消精华」绑定原消息的群号、序号和 random，缺少可靠定位时不可操作。以上操作需要当前账号 QQ 在线且在线能力就绪；「已受理」不表示本机缓存或其他设备已经同步，结果未确认时应先核对 QQ，不要直接重复提交。

群公告发布／删除、设置／取消群待办及群文件夹管理仅向群主和管理员开放，普通成员仍可完成待办、上传文件，以及管理自己上传的群文件。文件归属在提交前从群文件目录核对，不能管理他人上传的文件；最终操作仍受 QQ 服务端权限限制。

群聊还有群资料面板（群成员、群公告、群设置等）。

## 8. 同步已读状态到 QQ

在「设置 → 账号接入与消息」开启「同步已读状态到 QQ」后，WeQ 会在本地标记已读后向 QQ
上报这次阅读的位置，可能清除手机等其他端的未读提醒。开关默认关闭，保存后立即生效。
需要同账号 QQ 在线、在线功能开启且已有可用会话；离线数据账号不上报。

设置页仅保留同步开关与功能说明，不展示逐次上报状态。上报失败不影响本地阅读，缺少可靠消息位置时跳过；
收到上报应答不等于其他端已经同步。关闭开关停止后续上报与未发出的重试，已发出的请求无法撤销。
开启开关不会批量补报过去读过的会话。

手动标为已读、未读和撤销会写入可写 QQ 本地数据库（静态只读目录只保存 WeQ 状态），默认不向服务端上报。下方独立的「手动标记时上报已读位置」默认关闭，开启后仅对手动已读及撤销中推进已读水位的操作生效，与自动阅读同步开关互不依赖。现有已读回执不能倒退服务端水位，因此标为未读或撤销已上报的阅读不能保证恢复手机等其他端的未读提醒。
