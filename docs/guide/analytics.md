# 聊天分析与年度报告

WeQ 有两套分析：**即时聊天分析**（针对单个群 / 单个好友 / 单个群成员）和**年度报告**（把一整
年的数据排成一份可翻阅、可导出的报告）。

悬浮工具的「分析与报告」可以统一选择报告类型、对象和时间：年度报告选择年份或历史以来；好友、群聊和群成员分析支持全部本地历史或指定日期。指定日期包含起止两天，按北京时间统计。群成员需先选群，再选该群成员，不沿用其它群的选择。

正在查看好友或群聊时，工具栏默认带入当前对象；其它页面默认年度报告。会话右键的 **分析** 带入右键选中的对象，不要求先打开会话；群成员头像右键的 **分析此成员** 和资料卡分析入口会带入该成员及所属群，均使用相同配置与报告流程。

确认后在主区域打开独立结果标签，原内容和草稿仍在下层；普通导航不会销毁报告，可从标签返回，显式关闭才移除。工具里继续修改对象或时间不会改写已经生成的结果。同年份年度报告可以并存，页码和字体互不覆盖。工具草稿与结果按当前账号隔离，切号后不使用旧确认响应。

私聊对象合并好友名册和本地消息中的非好友会话；群对象合并当前群列表、资料缓存和历史消息。成员对象包含缓存名册（含退群记录）及该群本地发言人，并标明来源。只有 QQ 号的旧成员可按真实号码分析；缺少姓名时显示号码或 UID，不把历史名册冒称当前成员关系。旧记录中的 UID 与号码对应冲突时不自动扩大 UID 分析范围。

## 一、聊天分析

### 1. 群聊分析

从工具栏或群会话右键选择分析，确认对象与时间后生成**全群画像**。三路数据各拉各的，任一失败
只标出那一路的错误：

| 统计 | 内容 |
| --- | --- |
| 群画像 | 排行、活跃时段、每日热力图与词云 |
| 入群批次 | 当前缓存成员中相近时间入群的批次，不是历史完整名册 |
| 会话力图 | 根据发言时序估计互动关系，不等同真实社交关系证明 |

各来源独立加载与重试，不因一路失败清空全部结果。

### 2. 私聊分析

从工具栏或好友会话右键选择分析，确认对象与时间后生成。内容：

- 时段柱状图（谁在什么时候聊）；
- 贡献热力图；
- 消息类型环形图（文本 / 图片 / 语音 / 视频 / 表情 / 其他）；
- 词云；
- 聊天时长等指标。

### 3. 群成员分析

从**群资料卡**里某位成员的资料页底部「聊天分析」打开。只针对「**这个人在这个群里**」的发言，
因此同时需要群身份与成员 UID 或可确认的 QQ 号。内容是成员维度的活跃时段、消息量、词云等。

### 4. 保存为图片

好友、群聊和成员报告提供「保存为图片」，使用本次统计数据生成长图，不需要截图当前窗口。

有图片导出桥接时，长图保留本次所选时间口径；没有该桥接的 Web 等环境明确禁用图片保存并显示能力提示。群资料与成员资料来自当前本地缓存，不应把指定日期的发言统计当作历史成员名册。

## 二、年度报告

从悬浮工具的 **分析与报告** 选择「年度报告」和时间，生成后直接进入报告。

年度区间、每日和作息统计、空间日期均按北京时间计算，不随设备或服务器时区改变。日均消息量按覆盖的自然日计算，包含起点当天和今天；往年按完整自然年计算。可选年份取自本地消息的实际发送时间，不要求 QQ 日字段完整。

宽内容区保留演示画布；窄屏或较短的内容区自动改用阅读布局，正文保持可读字号，长页可滚动，翻页控件位于底部。滚轮、触摸与 PageDown 在阅读布局中滚动当前页，不自动翻页。全年绿墙可横向滚动查看日期，好友榜在窄屏下改为竖排，长姓名可换行。

### 1. 年份与范围

在统一工具中选年后直接进入结果，不再重复选年。“历史以来”使用本地可分析历史，年份可用性与具体页面数据仍取决于当前账号记录。

### 2. 报告页面

报告是一叠可以上下翻的整屏页面，带**景深翻页动画**（已翻过的页往上退进暗处，没到的页从下方
抬起）。完整页面列表：

| 页面 | 标题 | 内容 |
| --- | --- | --- |
| overview | 年度总览 | 这一年发出 / 收到多少条 |
| dress | 你最喜欢的装扮 | 用过的气泡、字体与挂件 |
| spark | 私聊火花 | 最忙的一天与最长火花（按会话 × 日期） |
| friends | 好友榜 | 把同一天的私聊归到每个好友，排出好友榜 |
| openers | 谁先开口 | 按 5 小时静默间隔切分私聊，数每段聊天由谁先开口 |
| rhythm | 我的作息 | 把发出的消息按星期与小时归桶 |
| voice | 我的话 | 逐条解码你发出的语音并分词（最慢的一页） |
| home | 我的主场 | 各群发言量 + 说得最多的群的正文 |
| at | @ 与被 @ | 你 @ 过谁、谁在人群里喊过你 |
| poke | 戳一戳 | 戳一戳与被戳的那些一下 |
| echo | 复读 | 那些被大家接住的同一句话 |
| months | 陪你走过 12 个月 | 把私聊按月分桶，排出每个月的聊天第一名 |
| mate | 还没加好友的同路人 | 扫群成员与好友名册，算跨群兴趣重合度 |
| qzone | QQ 空间回忆 | 从你的 QQ 空间逐页拉取说说（**需要 QQ 在线**） |
| end | 这一年，辛苦了 | 收尾 |

### 3. 阅读体验

- 工具确认的年份固定在本份结果里，重新配置会生成独立结果；顶部可进入 / 退出全屏；
- 页面加载时会显示「主进程此刻卡在哪一步」的人话提示，而不是只转一个圈；
- 报告应用专属字体与装扮（气泡 / 挂件）渲染。

### 4. 导出报告

在报告末页（end）可以导出为：

| 格式 | 说明 |
| --- | --- |
| **长图** | 拼成一张分享图 |
| **HTML** | 离线可打开 |
| **PDF** | A4 逐页排版 |
