# 聊天分析与年度报告

WeQ 有两套分析：**即时聊天分析**（针对单个群 / 单个好友 / 单个群成员）和**年度报告**（把一整
年的数据排成一份可翻阅、可导出的报告）。

## 一、聊天分析

### 1. 群聊分析

在群聊标题栏点 📊 打开。点进来就是**全群画像**，不用先过一层菜单。三路数据各拉各的，任一失败
只标出那一路的错误：

| 数据 | 内容 |
| --- | --- |
| `getGroupStatsReport` | 排行 / 活跃时段 / 每日热力图 / 词云，**一次扫描**全算完 |
| `getGroupJoinBatches` | 入群批次（3 小时内挤进 ≥ max(3, 群人数÷20) 人算一批） |
| `getGroupConversationGraph` | 真小团体：按 5 分钟间隔切会话、算两两拉力并画**关系力图** |

首屏加载用 skeleton + shimmer，数据到了原地替换。

### 2. 私聊分析

从好友资料卡底部的「聊天分析」按钮打开。内容：

- 时段柱状图（谁在什么时候聊）；
- 贡献热力图；
- 消息类型环形图（文本 / 图片 / 语音 / 视频 / 表情 / 其他）；
- 词云；
- 聊天时长等指标。

### 3. 群成员分析

从**群资料卡**里某位成员的资料页底部「聊天分析」打开。只针对「**这个人在这个群里**」的发言，
因此同时需要群号与 uid。内容是成员维度的活跃时段、消息量、词云等。

### 4. 保存为图片

群聊分析 / 成员分析支持「保存为图片」：数据交给主进程，由它在一个**从不显示的窗口**里用同一个
组件把卡片重新渲染（840px 长图口径）并拍下来 —— 屏幕上全程零变化。私聊 / 成员分析同样有一键
导出图片按钮。

## 二、年度报告

左栏点 **年度报告**。

### 1. 入口海报

报告入口是一块海报，不是表单：

- 巨型年份占据画面中轴，年份用**横向刻度轨**选择：选中的那一年放大、其余缩到边缘；
- 轨道上只列「真的能生成报告」的年份 —— 即**发出过至少一条消息**的年份，左小右大，
  「**历史以来**」单独钉在最右端；
- 底部是一个下沉式的进入按钮，进报告后第一步就是一次向下滚动。

若某年有消息记录但**没有一条是自己发出的**，页面会被全部摘掉并给出提示。

### 2. 报告页面

报告是一叠可以上下翻的整屏页面，带**景深翻页动画**（已翻过的页往上退进暗处，没到的页从下方
抬起）。完整页面列表：

| 页面 | 标题 | 内容 |
| --- | --- | --- |
| overview | 年度总览 | 这一年发出 / 收到多少条 |
| dress | 你最喜欢的装扮 | 用过的气泡、字体与挂件 |
| spark | 私聊火花 | 最忙的一天与最长火花（按会话 × 日期） |
| friends | 好友榜 | 把同一天的私聊归到每个好友，排出好友榜 |
| openers | 谁先开口 | 按 5 小时静默间隔切分私聊，数每段聊天由谁先开口 |
| rhythm | 我的作息 | 把发出的消息按星期与小时归桶 |
| voice | 我的话 | 逐条解码你发出的语音并分词（最慢的一页） |
| home | 我的主场 | 各群发言量 + 说得最多的群的正文 |
| at | @ 与被 @ | 你 @ 过谁、谁在人群里喊过你 |
| poke | 戳一戳 | 戳一戳与被戳的那些一下 |
| echo | 复读 | 那些被大家接住的同一句话 |
| months | 陪你走过 12 个月 | 把私聊按月分桶，排出每个月的聊天第一名 |
| mate | 还没加好友的同路人 | 扫群成员与好友名册，算跨群兴趣重合度 |
| qzone | QQ 空间回忆 | 从你的 QQ 空间逐页拉取说说（**需要 QQ 在线**） |
| end | 这一年，辛苦了 | 收尾 |

### 3. 阅读体验

- 顶部工具栏可切换年份、刷新、进入 / 退出全屏；
- 页面加载时会显示「主进程此刻卡在哪一步」的人话提示，而不是只转一个圈；
- 报告应用专属字体与装扮（气泡 / 挂件）渲染。

### 4. 导出报告

在报告末页（end）可以导出为：

| 格式 | 说明 |
| --- | --- |
| **长图** | 拼成一张分享图 |
| **HTML** | 离线可打开 |
| **PDF** | A4 逐页排版 |
