# QQ 邮箱

打开账号后，从左侧导航进入 **QQ邮箱**。邮箱使用当前账号的 QQ 本机登录态，优先通过 QQ 客户端的邮箱专用授权码连接，不要求开启 IMAP/SMTP，也不需要输入邮箱授权码。首次连接需要对应 QQ 已登录；需要客户端确认或额外安全验证时，按错误提示处理后重试。

## 查看邮件

- 左侧切换收件箱、星标、已发送、草稿及自定义文件夹；列表支持分页和未读筛选。
- 搜索框查询邮箱中的邮件，不只是当前已加载的一页。
- 选择邮件后读取正文，并调用邮箱服务端的标为已读接口，成功后更新邮件已读状态和左侧导航未读角标；已读提交失败会显示错误，不会仅在本地显示已读。标记已读/未读或移至已删除后也会同步角标，不依赖开启新邮件提醒。仅刷新列表不会逐封读取未读正文。
- 会话邮件先列出子邮件，再选择具体邮件阅读；锁定或不可访问的邮件不会被伪装成空正文。
- 列表支持 Ctrl／⌘ 点击切换单封勾选、Shift 点击连续范围、Ctrl／⌘＋Shift 点击追加范围；复选框也支持范围选择。普通点击打开的邮件可作为范围起点，修饰键多选不会读取正文或标为已读。选择仅限当前页，翻页、切换文件夹或修改搜索与未读筛选时清空；列表刷新后移除已不在当前页的选择。
- 工具栏可标记已读/未读、设置星标或移至已删除。当前页面不提供永久删除。

正文在隔离区域中显示，脚本、表单和嵌套页面不可运行。图片默认隐藏；点击 **显示图片** 后才加载。邮箱内嵌图片由主进程代理，邮箱票据不会放进页面图片地址。外部链接交给系统浏览器打开。

## 写信与草稿

**写邮件** 打开独立写信区，支持抄送/密送、富文本与纯文本、回复、回复全部和转发。邮箱地址可用逗号、分号或换行分隔。

**保存草稿** 会把内容写入服务端草稿箱；不会自动发送。未保存内容仅保留在当前账号界面内，切号或退出前请保存。关闭写信或离开账号时会对未保存内容作提示。

点击 **发送** 才提交邮件。接口接受不代表收件人已经收到或阅读。如果连接在提交期间中断，界面会显示 **结果未知** 并暂时禁止重发。先检查已发送或草稿箱，确认结果后再选择是否恢复编辑，避免重复邮件。

## 导出邮件

勾选列表中的邮件（或打开一封邮件），使用工具栏「导出所选邮件」。旁侧保存菜单复用公共保存偏好；任务创建后可在当前任务列表查看进度、取消及保存结果。

每封邮件单独保存 `message.json` 基本信息、`body.html` 静态正文和附件，`index.json` 汇总结果。会话邮件展开导出子邮件，重复邮件只处理一次。导出读取不会额外提交标为已读操作。

正文移除脚本、表单、外部图片及主动链接，图片位置保留提示，不自动联网加载。附件保留文件内容与名称（存储文件名避让重名和路径字符），失效或下载失败会记录在元数据与任务缺失清单中。部分成功不等于完整归档。切换账号／数据源会终止旧来源任务，不发布迟到结果。

## 附件保存

附件通过本机文件选择器加入。普通附件和超大附件使用邮箱自己的上传服务，按片扫描、加密协商和上传；当前客户端单文件上限为 2 GB，超过 50 MB 自动使用超大附件。上传完成前不能发送。传输中可取消。

阅读区的附件保存沿用公共保存偏好，旁侧菜单可本次另存或先下载、稍后保存。系统位置选择取消后保留当前邮件与附件；已创建的任务在导出任务列表中查看进度、取消、保存或定位结果。Web 的服务器保存与浏览器下载是两个独立动作，浏览器下载位置由浏览器控制。

下载会检查大小、受信任跳转和磁盘空间，不自动执行文件，也不覆盖已有同名文件；默认目录自动避让重名，显式选择的目标已存在时请另选名称。附件保留原文件名和类型，无扩展名文件不额外补写后缀。没有硬链接支持的文件系统需要额外临时空间。过期、删除或未通过安全检查的附件会显示失败状态。

Web 宿主没有本机文件选择器时，不能从服务器磁盘任意挑文件；桌面端使用原生选择器。

## 新邮件提醒

在 **设置 → 空间与邮箱 → QQ 邮箱** 中配置 **显示未读邮件数** 和 **新邮件提醒**，两个开关分别按账号保存。未读数默认显示，关闭后仅隐藏左侧导航角标，不改变邮件状态或提醒偏好。

开启 **新邮件提醒** 或 **显示未读邮件数** 后，启动 WeQ 并打开该账号时就会在后台连接邮箱，无需先进入邮箱页面；刚获取 QQ 凭据时也会立即尝试连接。QQ 暂时离线时使用有界间隔重试，不高频换票据。仅开启未读数不会触发新邮件通知。

前台使用未读数和应用内提示，后台系统通知只显示通用“收到新邮件”文案，不显示发件人和主题。点击系统通知会核对账号，再打开邮件。系统通知是否能显示还取决于操作系统权限。

首次同步只建立基线，不把已有邮件全部弹成新消息。提醒结合 WebSocket 增量和服务端建议的轮询间隔，并对重复邮件去重。界面隐私模式同样遮罩邮箱内容。

## 账号与隐私

邮箱 Cookie、clientkey、p_skey 和 sid 仅在主进程内存中使用，不交给前端、不写入账号配置或日志。切号或关闭账号时停止请求与连接并清除票据、附件令牌和界面查询缓存；断开邮箱也会清除当前邮件视图和邮箱票据。

提醒偏好会持久化；浏览取得的主题、摘要、已读正文和附件名还会进入当前账号的[全局搜索文本索引](chat-view.md#全局搜索)，受缓存上限约束。清除登录票据不等于删除这些已观察文本；该索引不保存登录凭据，也不是完整离线邮箱。

邮件目前按需在线读取，不是独立的离线邮箱归档数据库。QQ 邮箱私有接口可能随腾讯更新变化；遇到错误应保留业务码反馈，不应提供 Cookie、sid 或邮箱授权码。
