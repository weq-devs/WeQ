# QQ 在线操作

这些入口会真实修改 QQ 侧的数据，不是 WeQ 的本地显示设置。需要当前配置具备 QQ 在线能力；同号在线配置与静态配置仍按配置 ID 区分。

## 入口

| 位置 | 操作 |
| --- | --- |
| 窗口标题栏头像 → QQ 资料与状态 | 昵称、签名、性别、头像、基础／扩展／自定义在线状态；手动查询服务端状态 |
| 好友资料／成员资料／个性主页 → 赞资料卡图标 | 选择本次次数并提交资料卡点赞；本人、机器人或缺少真实 UID 时不提供入口 |
| 会话设置 → 会话偏好 | 好友／群备注、置顶、免打扰、已有好友分组；自己的群名片及头衔文本 |
| 群文件侧栏 → 工具栏／行菜单 | 文件和文件夹选择、保存、重命名及删除，文件移动，文件夹新建，本机文件拖入上传，数量与空间 |
| 群资料侧栏 → 群公告 | 独立公告摘要，点击标题进入公告管理：发布、附图、置顶、需要确认、新成员公告、弹窗提醒、群名片引导及删除 |
| 群资料侧栏 → 群待办 | 直接查看列表、完成待办；群主／管理员取消待办 |
| 群资料侧栏 → 打卡 | 今日打卡，按北京时间日期查看打卡名单及翻页；打开页面本身不打卡 |
| 群相册 → 打开相册 | 图片上传；具备媒体定位的项目可删除、点赞／取消赞及发送评论 |
| QQ 空间说说下方 | 点赞、取消赞、文字／带图评论 |
| 自定义表情资源页 → QQ 收藏表情管理 | 从服务器读取收藏、添加图片、改备注、调整顺序及删除 |
| 好友通知／群通知卡片内 | 对收到且仍待处理的好友、可疑好友、加群及过滤申请直接同意／拒绝；退群通知与自己发出的申请不提供审批按钮 |
| 会话设置 → 群管理（仅群聊） | 群名、群头像、加群方式、分类标签、退群；打卡名单及 @全体剩余次数 |
| 群消息右键菜单 | 设置／取消精华，设为群待办 |
| 群资料侧栏 → 精华 | 查看精华；有权限且消息定位齐全时可取消精华，取消按钮与消息跳转分开 |
| 群消息头像或群资料侧栏成员头像右键 | 修改自己的群名片，群主／管理员可修改低职权成员的名片；仅群主可编辑专属头衔 |
| 私聊输入框工具栏的键盘图标 | 开启／关闭“正在输入”广播，默认关闭，每十秒最多发送一次 |
| 群聊输入框输入 @ | 候选首项为“全体成员”，右侧显示本账号及群剩余额度；权限、额度或在线状态未核实时不可选 |
| 机器人消息内联键盘 | 链接继续走外部链接；定位与机器人信息齐全的回调按钮可在确认后提交 |
| 联系人 → 群聊 → 加入群聊，或左栏添加菜单 → 申请加入 QQ 群 | 读取分享链接对应的群资料与验证问题，填写回答并申请加入 |

## 加群与状态

群聊的“全体成员”候选不依赖成员列表是否已经加载到自己。打开候选时按当前账号与配置读取权限和额度，不顺带查询打卡，也不新增持续轮询。只有群主／管理员、远端允许且个人／群额度均大于零时可选；离线、读取失败和权限未知会明确显示，未知额度不写成零。选择只插入提及 token，不发送消息；实际发送仍以 QQ 服务端结果为准，其他设备的即时额度变化不由该菜单实时推送。

群资料、群公告和群待办在同一侧栏分区竖排，长内容在各区内部滚动；内容少时按实际高度收缩，下方保留群成员列表，不需要在公告与待办页签之间切换。

消息菜单、精华列表和消息角标共用精华操作的受理回执。成功受理后立即同步显示并短时回读，失败或结果未确认时保留原记录，不自动重发写请求。回读逐渐退避，最多持续一分钟；离线、页面隐藏或切换到其他页面后不继续轮询。超过时限仍未同步会明确提示，并恢复显示读取结果。只有本地记录、缺少原消息 `random` 时，不猜测定位参数，取消按钮会说明缺口。

通用加群需要有效的 QQ 群分享链接，不提供任意群号生成鉴权串的功能。鉴权串只保留在主进程；读取的目标短时有效，过期或目标变化后需要重新读取。验证问题显示“无法获取”不等于该群没有问题；多问题表单尚未证实，当前提交的是单个回答字符串。

申请被受理不等于已经入群。非明确回包可能涉及官方安全验证，会显示结果未确认，需先在 QQ 核对。接口不会绕过入群问题、管理员审核或安全验证。

群打卡使用现有的 `0xEB7_1` 写入链路，收到空回执仅显示“已受理”，随后刷新当日记录；读取失败与写入失败分开提示。离线验证已覆盖按钮、账号绑定、服务调用及编码，真实服务端是否接受仍需在目标群核验。

标题栏状态来自本地缓存；资料编辑器的服务端状态按钮是独立查询。预设扩展状态使用各自的 `extStatus`，自定义状态使用本机经典表情的 QSid，不能互换成 Unicode 编号。

状态编辑器按基础、扩展、自定义状态排列。扩展状态选择后会显示对应图标和文字预览，点击保存才提交；自定义状态的表情位于文字输入框左侧。

资料保存收到回执后即可继续编辑其他字段，不必等待后台列表刷新。编辑器会在随后 15 秒内每秒回读本地资料与状态，并同步刷新标题栏；回读不覆盖尚未提交的草稿。超过这段时间仍未更新时，可使用重新读取按钮核对 QQ 缓存，勿因同步延迟反复提交。

## 备注与名片

资料卡点赞默认每次 1 赞，编辑器允许选择 1–20 次后提交。这个范围是本次批量请求的输入边界，
不是“每日还剩 20 次”。每日额度与会员差异由 QQ 服务端判定，当前不展示未经核实的剩余额度。
打开或关闭编辑器不发送请求；发送在途不可重复提交，也不自动重试。

受理后会刷新该人的累计获赞统计，不在本地直接加数。累计获赞可能同时受到其他人操作影响，
不能单靠数字变化证明本次请求的准确生效次数。未知回执显示待核对，次数限制或业务拒绝保留实际错误；
核对 QQ 后再决定是否继续操作。本入口已做离线验证，真实每日额度与多端生效仍待验收。

好友备注保存或清空后，按当前账号和数据源回读资料，更新会话标题、联系人姓名与预览。
群名片只更新对应群的成员和预览，不改变其他群的名称；迟到的旧补全不会盖回新值。
群备注作为聊天标题、会话列表与群聊列表的显示名称，资料中的真实群名保留，仍可按真实群名、
备注或群号搜索；清空群备注后恢复显示真实群名。

读回最多四次。QQ 本地缓存尚未同步时保留明确提示，不自动重发写入；刷新失败与远端写入失败
分开处理。切换账号或来源后，旧操作不会把资料回填到新来源。

## 置顶同步

真实好友和群聊的列表右键置顶／取消会提交 QQ 请求，会话偏好里的开关使用同一链路。
操作后有界读回本机置顶表；未同步或读取失败会明确提示，不写 QQ 数据库来伪造生效。
置顶组按 QQ 的置顶时间排列，不再被列表组件重新按最后消息时间覆盖；同秒或缺少置顶时间时回退到消息时间。
克隆与聚合入口的置顶仍属于 WeQ 本地设置，不宣称跨设备同步。

## 消息接收策略

群消息接收编辑器从服务端读取正常提醒、接收但不提醒、群助手与屏蔽四档策略。
保存后最多进行四次读回，不重复发送写请求。服务端已更新而 QQ 本地缓存仍是旧值时，
编辑器显示服务端值，并提示“服务端与本机消息策略尚未同步”；这不代表其他设备已完成同步。
手动重新读取仍可重试，切换账号、数据源或会话后不继续旧操作的回读。

好友免打扰目前没有已确认的权威读回，保持未知状态；本地会话的提醒级别不能用来推断
它已开启或关闭。设置请求的未确认回执不会被显示成已生效。

## 群文件管理器

群文件使用同一张列表浏览和操作，不再另开“文件操作／操作目标”表单。列表展示名称、大小、上传者与
北京时间，可按名称、大小或最近修改排序；搜索只筛选当前目录。窄面板把次要信息放在名称下方，保留完整名称与保存菜单。
单击选择，Shift 连选，Ctrl／Command 追加选择，也可使用复选框。工具栏与右键菜单作用于所选项目；
文件夹通过名称、双击或 Enter 打开，面包屑可逐层返回。搜索直接定位到未知祖先路径的目录时，
显示“定位目录”，返回入口回到全部文件，不猜测其父目录。

重命名与新建在列表上方编辑，移动时浏览并选择目标目录。普通成员只能管理自己上传的文件；
文件夹的新建、重命名和删除需要群主或管理员，文件夹暂不支持移动。提交前重新读取目录并检查
同名冲突，不会静默替换已有项目；其他设备在检查后产生的变化仍以 QQ 实际回执为准。

在桌面端拖入本机文件，或将文件拖到某个文件夹，会先进入待上传列表，允许修改名称和移除，确认后
才上传并发布群文件消息。同一路径、同一目标不会重复排队，待上传列表最多 100 项。
Web 无法取得本机路径时可使用文件选择入口，不会把浏览器临时地址当成服务器文件路径。
群内文件拖到目录同样先准备移动，确认提交；跨账号、跨来源或跨群的内部拖拽会被拒绝。

批量操作逐项执行并保留已受理、待核对和未执行结果。停止只停止后续项目，不撤销已经提交的请求；
未知回执后不继续批次，也不自动重发。保存所选文件与文件夹复用公共保存偏好和后台任务，
保留已知的相对目录结构；取消位置选择不清空选择、不创建任务。离开目录前会保护未提交的编辑和上传列表。

## 确认、结果与权限

联系人图标、好友通知和群通知入口在有未查看的新通知时显示红点；打开对应列表后即清除该类提示，不要求先处理申请。查看记录按账号与数据源分别保存在本机，下次新通知到达后再次提示。

- 删除文件、文件夹、公告、相册媒体、收藏表情，以及退群、处理申请、发布公告等操作有明确确认。
- 群公告与加群设置需管理权限；其他操作的最终权限由 QQ 服务端判定。
- “已受理，等待 QQ 同步”不是已经跨端验证；“结果未确认”不是未发送。超时或失败后先核对，不自动重发写请求。
- 读图、取票、取相册详情等异步阶段会复核账号及运行时；切号或同号换数据源后不会把旧草稿应用到新配置。
- 群文件上传会按现有文件发送链路上传并发布群文件消息；若上传与发布未能得到明确结果，界面保持未确认，不制造成功记录。
- 原始 QQ 数据库不会被这些入口直接改写来模拟成功，列表刷新等待实际读取结果。

生日、地区、学校等资料、好友分组的新建／删除、群相册视频上传及登录设备主动查询仍不属于已确认支持范围。群头衔有效期不在本批需求中。

源码具备入口与离线测试不代表已发布，也不代替具体账号、权限和群设置下的真实 QQ 验收。
