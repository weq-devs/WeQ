# AgentLab（克隆 / 群聊）

左栏点 **AgentLab** 进入。AgentLab 把「用你的聊天记录训练一个分身」这件事做成一整套工作台：
建克隆体、和克隆体聊天、把多个克隆体拉到同一个群聊里。

> [!tip]
>
> 使用前请先在[设置 → 模型配置](./settings.md)里配好模型提供方，否则克隆与群聊都缺可用的
> 聊天 / 向量 / 视觉模型。

## 1. 工作台首页

AgentLab 首页是克隆体列表，底部/右上角有：

- **新建克隆**（好友克隆）；
- **新建群聊**（克隆体群聊）；
- 克隆任务列表（可点开进度灯箱，也可隐藏到后台继续构建）；
- 使用量面板（usage）；
- 模型与人格设置入口。

顶部的「WEQ 助手」入口打开任务型助手（见 [WeQ 助手](./assistant.md)）。

## 2. 好友克隆

点 **新建克隆** 打开两步弹窗：

### 第 1 步：选好友

带头像 / 昵称的列表，可搜索。

### 第 2 步：配置

| 配置项 | 说明 |
| --- | --- |
| **聊天模型** | 必选 |
| **向量模型** | 可选（用于语义检索语料） |
| **视觉模型** | 选「分析表情」时才需要，用来解读表情包 |
| **语料来源** | `group` = 私聊为主、不足时群补采风格；`private` = 纯私聊、不回退 |
| **名称** | 克隆体显示名 |
| **额外提示** | 追加给模型的人设说明 |

点「开始克隆」后，构建在**模块级任务 store** 里后台进行：

- 关掉进度灯箱任务不会中断；
- 可以切出 AgentLab 再回来，任务态仍在；
- 构建完成后自动刷新克隆体列表。

### 克隆体人格

克隆体由后端从聊天记录里抽取人设：消息统计、风格摘要、语音占比、关系摘要、Top 词项，以及
更深的卡片信息（语气、性格、口头禅、标点习惯、称呼、话题等）。

点克隆体打开**人格设置**可以查看 / 调整这些内容，以及是否允许群聊。

## 3. 和克隆体聊天

点克隆体即开启一段新会话：

- 左侧是会话列表，可切换历史会话、新建会话、删除会话；
- 克隆体的回复以流式逐段揭示，气泡渲染复用 `ChatBubble`（头像 / 名字 / 表情 / 语音）；
- 输入框支持自动增高、@ 等；
- 每次「打开克隆体」会生成一个不重复的挂载 key，避免草稿状态串台。

## 4. 克隆体群聊

点 **新建群聊**，选择若干克隆体 + 「我」同处一室。

- 发一条消息 → 后端让「被 @ 或全部」克隆体各自回复；
- 每条回复经 `account.onGroupChatEvent` **流式**推来，按发送者分气泡**逐条揭示**；
- **@ 选择**：输入 `@` 弹出成员浮层，选中插入 @名字；发送时按文本里出现的 @名字 推出
  `mentions`；
- 群聊里可以增删成员、清空会话。

## 5. 使用量

AgentLab 内置 usage 面板，用图表展示各克隆体 / 助手的调用量、token、活跃时段等（KPI 卡、
条形图、折线图、环形图、雷达图）。所有颜色取自主题色。
