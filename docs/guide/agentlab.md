# AgentLab（克隆 / 群聊）

好友克隆与克隆体群聊已并入「消息」的虚拟会话列表。通过会话列表「+」创建好友克隆或
克隆体群聊，点击已有虚拟会话进入聊天；不再依赖独立的 AgentLab 左栏入口。

> [!tip]
>
> 使用前请先在[设置 → AI 功能 → API 配置](./settings.md#api-配置)里配好模型提供方，否则克隆与群聊都缺可用的
> 聊天 / 向量 / 视觉模型。

## 1. 入口与管理

- 消息列表「+」提供新建好友克隆与克隆体群聊；真实 / 虚拟范围可筛选对应会话。
- 打开克隆体会话后点击「设置」，管理模型、人格、语音，或更新画像与删除克隆体；全局设置不再单设克隆页。
- 克隆进度在「菜单 → 任务 → 当前任务」查看，收起面板不会停止后台构建。
- 模型提供方与调用量分别在「AI 功能 → API 配置」和「API 用量」。
- 任务型助手从「菜单」切换到 [WeQ 助手](./assistant.md)，不是克隆体群聊。

## 2. 好友克隆

从消息列表「+ → 新建好友克隆」打开两步弹窗：

### 第 1 步：选好友（可多选）

带头像 / 昵称的列表，可搜索，点一行即勾选。选中多位好友后点「下一步」，会为每位好友各起一个克隆任务；会话列表的「添加会话 → 新建好友克隆」也能带已选好友直接进来。

### 第 2 步：配置

| 配置项 | 说明 |
| --- | --- |
| **聊天模型** | 必选 |
| **向量模型** | 可选（用于语义检索语料） |
| **视觉模型** | 选「分析表情」时才需要，用来解读表情包 |
| **语料来源** | `group` = 私聊为主、不足时群补采风格；`private` = 纯私聊、不回退 |
| **名称** | 克隆体显示名（多选时禁用，各自沿用好友昵称） |
| **额外提示** | 追加给模型的人设说明 |

点「开始克隆」后，构建在**模块级任务 store** 里后台进行：

- 关掉进度灯箱任务不会中断；
- 可以切换页面再回来，任务态仍在；克隆任务按账号隔离，仅保留在本次应用会话内；
- 构建完成后自动刷新消息会话列表与新建群聊中的克隆体选项，即使已切到其他页面也会更新。

### 克隆体人格

在克隆体会话的「设置」内点击「更新画像」，确认后使用最新聊天记录重新训练；同一处也可删除克隆体。
会话头部「样本 xx 条」后显示最近一次画像更新时间（北京时间），保存模型或提示等配置不会改变该时间。
更新沿用该克隆体当前模型与原训练范围；旧版克隆未保存训练范围时仅使用私聊。
语料会发送至配置的模型服务商，任务可在后台运行，并在「菜单 → 任务 → 当前任务」查看进度。
更新保留克隆体名称、配置、历史会话、记忆及群聊关系；失败时继续使用旧画像，可再次更新。

克隆体由后端从聊天记录里抽取人设：消息统计、风格摘要、语音占比、关系摘要、Top 词项，以及
更深的卡片信息（语气、性格、口头禅、标点习惯、称呼、话题等）。

点克隆体打开**人格设置**可以查看 / 调整这些内容，以及是否允许群聊。

## 3. 和克隆体聊天

打开已有克隆体会话可继续聊天，也可显式新建或切换历史会话：

- 标题栏的历史图标可切换、新建或删除会话，齿轮图标打开克隆设置；
- 右上角沿用普通会话的搜索、消息管理和设置图标；搜索可在当前会话内定位文字消息，消息管理可导出当前会话，群聊另可清空记录或删除克隆群；
- 克隆私聊与群聊共用普通会话的标题栏、消息气泡与聊天背景，跟随深浅主题、主题色和装扮；标题旁保留克隆标识，不代表真实 QQ 消息；
- 克隆体的回复以流式逐段揭示，显示带克隆角标的源好友头像，并保留表情和合成语音；私聊不重复显示昵称，群聊显示发送者；
- 输入区支持文字发送、Enter 发送与 Shift+Enter 换行，中文输入法确认候选时不发送；群聊保留 `@` 成员选择；
- 输入框上方保留常用工具栏，表情面板支持系统表情、字符表情和颜文字；红包、通话、录音、图片文件、Ark 卡片及实时位置入口保留图标但禁用，悬停说明限制，不向真实 QQ 发送；
- 消息右键或触屏长按提供复制和多选；多选与普通会话一致，由底部操作栏显示已选数量并提供复制、导出和退出，不在右上角另设多选按钮；退出后保留输入草稿，不提供真实 QQ 撤回操作；
- 新草稿首次发送后才创建持久会话；切换历史会话不会把另一会话的草稿或生成状态带入。

## 4. 克隆体群聊

点 **新建群聊**，选择若干克隆体 + 「我」同处一室；会话列表的「添加会话 → 新建克隆体群聊」也会直接打开这个多选弹窗。

- 发一条消息 → 后端让「被 @ 或全部」克隆体各自回复；
- 每条回复经 `account.onGroupChatEvent` **流式**推来，按发送者分气泡**逐条揭示**；
- **@ 选择**：输入 `@` 弹出成员浮层，选中插入 @名字；发送时按文本里出现的 @名字 推出
  `mentions`；
- 标题栏的设置图标管理群内克隆体；消息管理菜单可清空会话或删除克隆群聊，操作前仍需确认。

## 5. 导出机器人数据保护

导出的 OneBot 机器人在产物 `data/` 目录保存对话、记忆、反思和关系。私聊产生的数据按机器人账号、
克隆体和实际对端隔离；真实群聊使用独立的群作用域。共享画像与训练样本仍用于扮演，私聊记忆不会注入其他私聊或群聊。

升级前已经混合保存的旧对话、记忆、笔记和关系仍保留在原文件中，但机器人不会猜测归属或自动注入新会话。
升级后各对端的长期记忆重新积累，桌面端已有克隆会话不受此隔离策略影响。

机器人只将不存在的存储文件视为空库；JSON 损坏、结构无效或无法读取时会拒绝启动并保留原件。
请先停机器人，修复文件或从可信备份恢复，再重启；不要直接覆盖损坏原件。
保存使用同目录临时文件与原子替换，失败会报错，不把未保存的变更当作已持久化。
后台记忆或反思保存失败会记录错误，不自动重发消息。目录同步在不支持的平台上仅尽力完成，不能保证所有断电场景。

机器人同一私聊或群聊按接收顺序处理，不同会话默认最多同时处理 4 个。等待队列默认总计最多 256 条、
每个会话最多 32 条；超限消息不会受理，控制台明确告警，不会静默记成已排队。
可在导出产物 `config.json` 的 `queue` 中设置正整数 `maxConcurrentChats`、`maxQueuedMessages` 和 `maxQueuedPerChat`。
停止或重载会取消当前请求、清空等待消息并停止后续分条发送；已经提交给 OneBot 的发送不能撤销，未知结果不会自动重发。
新导出的入口收到 Ctrl+C（SIGINT）或 SIGTERM 时会等待收尾再退出；强制终止或断电不具备此保证。

非流式聊天、向量及画像提炼请求默认总期限为 180 秒，包含响应正文读取。慢模型可在提供方配置中设置
`timeoutMs`（1–2147483647 毫秒的整数）；导出时保留该值，独立机器人也可直接修改 `config.json` 的 `llmProviders[].timeoutMs`。
该字段是高级配置，当前没有新增界面控件；省略时使用默认值，修改已有提供方的其他字段不会清除已保存的期限。
超时记为失败、主动停止记为取消，两者都不代表模型服务端未执行或未计费。

机器人普通日志仅保留会话类型、实例内脱敏关联标识、状态、长度、数量和耗时，不记录原始对端、昵称、正文、
生成回复或模型错误正文。日志时间为北京时间；脱敏标识在重启或重载后更换，不作为持久身份。
确需临时排障时，可在 `config.json` 设置 `logging.debugContentUntil` 为未来 30 分钟内、明确带时区的 ISO 截止时间，
如使用 `+08:00` 标记北京时间。开启时会警告，正文及错误详情单条最多 512 字符；日志可能包含隐私，请勿分享。
到期自动关闭，系统时钟回拨也不能延长已开启窗口；停止立即关闭旧实例的调试，重载或重启不延长原截止时间。
删除该字段后重载也可关闭；过期字段按关闭处理。本改动不删除历史控制台、容器或系统日志。

## 6. 使用量

「设置 → AI 功能 → API 用量」用图表展示各克隆体 / 助手的调用量、token、活跃时段等（KPI 卡、
条形图、折线图、环形图、雷达图）。所有颜色取自主题色。
