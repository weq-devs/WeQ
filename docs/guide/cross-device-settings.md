# 跨端设置与草稿

桌面端、Web 与 Remote 连接同一台电脑时共用设置与业务数据，不需要另建云账号。
Remote 使用电脑提供的共用页面。通用设置同步只需更新电脑服务与页面；识别手机系统省流量状态另外需要包含对应桥接能力的手机安装包。

## 哪些共享

- 设置页各项统一共用电脑上的同一份值，包括深浅模式、主题色、界面背景、组件风格、界面密度、隐私模式、截图遮挡与网页通知。
- 消息气泡、字体、头像挂件、QQ 秀、消息时间、日期及序号，以及阅读交互和图片内存预算也统一共享。不提供“仅本设备”或单端覆盖选项；在任一端保存后，其他已连接界面自动重读。
- 全局搜索的来源与类型、号码查询偏好、会话日历类型、全部会话的包含隐藏／删除开关、联系人分组与排序及资料刷新范围全局共享，切换账号不更换使用偏好。新搜索模型首次将来源与类型重置为全选，此后保留显式选择，包括全部取消。
- 意图感知、推荐回复、互动画像的通用参数，邮箱红点、提醒与查询间隔，防撤回模式与通知开关，本地装扮及安装清单，年度报告页面选择，以及助手模型、提示词、思考强度与外部 MCP 同样全局共享。AI、邮箱与防撤回的通用选项在尚未打开账号时也可配置。
- 具体会话的防撤回／通知名单、群关键词、隐藏输入状态名单和 AI 启停规则仍属于对应账号与数据源；数据库容错和本机媒体关联也分别保存。群助手内部置顶、任务和助手结果已读标记、群待办历史、草稿、分析结果与画像属于业务内容，不因设置统一而合并。同号在线账号与导入备份不混用这些内容。
- 普通会话置顶与免打扰继续走 QQ 链路。选择“跟随 QQ”装扮时读取当前账号自己的 QQ 装扮，不把某个账号的 QQ 装扮变成其他账号的资料。

## 设置与运行现场

### 群消息与引用

「设置 → 基础功能 → 消息显示 → 群消息」提供「显示群消息发送者名称」「显示群成员等级」「显示群成员头衔与身份」，默认均开启。三个开关独立生效，只控制消息区域，不改变成员列表、名片、@ 候选或引用中的发送者名称；发送者名称继续使用本地名称规则，等级名称随等级开关控制。

「设置 → 基础功能 → 互动与防撤回 → 引用回复」提供「群聊引用时自动 @ 对方」（默认关闭）与「按退格键移除引用」（默认开启）。自动 @ 会插入输入框中可删除的真实提及，不提及自己，也不重复插入已有提及。输入框为空时可按退格键移除引用，私聊同样适用，引用条的关闭按钮仍保留。

以上偏好应用级共享，切号或重新打开后保留，随设置备份保存，也可通过「恢复本页默认」还原。

### 省流量模式

「设置 → 数据库与资源 → 资源加载」中的「省流量模式」卡片提供开启、关闭、跟随系统（默认）。卡片内「省流量模式下的行为」统一管理以下选项，模式关闭时仍可提前配置；这些偏好应用级共享，但每端的实时网络状态分别检测，不会因一部手机使用计费网络就把其他端的自动模式一起打开。

资源加载页先显示「加载来源」，再显示省流量设置；省流量基础模式与聊天图片档位使用分段选择。系统或 WeQ 省流量模式开启时，搜索框右侧显示省流量图标，点击可修改基础模式、临时开启／关闭，或打开完整设置。临时设置存在时图标保留，包括临时关闭期间。

临时开启可选择「直到 WeQ 退出」或自定义 1–1440 分钟（默认 30 分钟）；临时关闭还可选择「直到全部任务完成」。全部任务包含运行、排队、暂停任务和期间新增的任务，失败、取消也算结束；导出后的保存、下载、漫游、克隆及窗口本地任务同样计入。没有未完成任务时不能选择任务期限。读取失败或客户端暂时断连不视为任务完成。

临时设置由宿主本次进程共用，不改写基础偏好；切换账号、刷新页面或关闭菜单不取消，宿主 WeQ 退出后清除。到期后恢复当时的基础模式及系统状态，也可点击「恢复基础设置」提前结束；修改基础模式或恢复默认会取消临时设置。系统变化、临时到期或任务结束导致实际自动进入／退出时显示横幅，手动操作只更新菜单状态；检测失败保留最近已确认状态，不虚报退出。

| 省流量模式下的行为 | 默认值 |
| --- | --- |
| 聊天图片自动加载 | 仅小图，可选不自动加载或原图 |
| 自动加载未缓存的头像 | 开启 |
| 自动下载表情图片 | 关闭 |

自动模式读取 macOS／iOS 的低数据与高费用网络、Windows 的连接费用／后台限制、Android 的计费网络与 Data Saver，以及 Linux NetworkManager 的计费状态。普通浏览器使用可用的 Save-Data 信号；系统接口、Linux 服务或手机桥不可用时显示“无法检测”，仍可手动选择模式，不根据网速或普通 Wi-Fi 猜测。

开启后优先使用缓存和消息真实提供的小图地址，没有小图时点击加载；浏览器／手机不会因宿主已有原图就自动传输整张原图。图片小图失败不再偷偷回退原图，链接预览、装扮和屏幕外会话预取减少联网。本地历史、搜索、缓存气泡准备、消息收发与通话不暂停。

联网批量任务及达到设定阈值的应用内下载按各自开关进入策略暂停；未知大小的传输在接收达到阈值时暂停，纯本地导出继续。在任务列表可继续本次任务，或保持手动暂停。只有策略暂停的任务在开启自动继续且限制解除后自动恢复。下载保留完整文件及可验证的分段；不支持可靠 Range 续传的服务器重新传输，不拼接不同资源。已有导出检查点继续使用，不支持检查点的资源任务重新执行并复用可用缓存。交给系统浏览器的下载由系统管理。

电脑限制自身联网下载，手机／Web 还限制传到本端的内容。系统状态不是共享设置或设备覆盖；旧手机壳没有上报能力时，不会显示为已识别系统模式。手机更新检查在省流量时不取样下载安装包测速。

模型和直接媒体下载使用校验后的分段续传；安装包保留现有更新器的签名与完整性校验，恢复时可能重新下载，不承诺保留更新器已清理的中断分段。

### 其他运行现场

新消息系统通知与应用图标未读角标位于「常规 → 提醒与窗口 → 消息提醒」；应用内的消息红点、联系人未读数和群助手计数仍位于「基础功能 → 阅读与未读 → 未读显示」。移动设置入口不改变已保存的开关值。

新群消息的系统通知以群名为标题，正文显示「发送者：消息内容」；发送者优先使用本地群名片、备注和昵称，资料缺失时显示 QQ 号或 UID。隐私模式或应用锁定时仍只显示通用新消息提醒。

“跟随系统”本身是共享设置，各端按同一规则解析各自系统的深浅状态。网页通知开关也共享，但系统通知授权由各端浏览器实际授予；一端未授权不会把其他端的共享开关关掉。
当前页面、窗口实际尺寸、滚动位置及截图期间的临时遮罩是操作现场，不会因另一端操作而跳走。电脑导出目录仍指电脑上的目录，手机实际保存文件使用系统提供的位置。

首次启用时，桌面已有外观和隐私等值初始化共享设置；手机旧值与共享值不同时，直接采用共享值，不保留单端覆盖。
没有设置过的项目使用统一默认值。
电脑尚未提供初值时，手机不会把旧值自动上传；手机上的主动修改会保留，之后桌面迁移不会覆盖它。

从旧版升级时，已经明确保存的全局值优先；其余通用偏好以首次打开的当前账号初始化，缺项使用默认值，不从其他账号拼接。已安装装扮取并集，当前使用哪款仍以当前账号为准。不同账号的旧值保存在本机迁移记录中，之后切号不会重新导入。迁移写入失败时保留原件和未完成状态，可在修复后重试。

## 草稿与失败处理

聊天草稿沿用 QQ 草稿存储，输入过程仍在本机保留恢复快照。助手草稿在输入停顿后共享，合成记录继续使用原有草稿存储。
内联图片在共享保存前通过已有分段上传转存到电脑，单图支持 32 MiB；失败保留本机素材，不把手机私有素材标识或 blob 地址当作共享图片。尚未写入正文的附件栏内容仍属于当前设备的编辑现场。
没有本机未提交修改时接受新共享稿；已有输入时保留正文。保存时自动协调版本，相同内容不会重复写入，不同内容以最新读到的版本重试保存当前编辑，不需要选稿或确认覆盖。清空和删除也记录版本，重复清空直接确认。
不再生成或保存草稿副本，同时编辑同一草稿时按实际成功保存的顺序更新内容。升级后读取账号状态时自动清理旧副本及其文件，不影响正式草稿和本机恢复快照；恢复旧备份时也执行同样清理。

设置保存失败会显示“未保存”和重试入口，不会在重连时偷偷重放失败操作。草稿写入失败保留本机恢复快照。
设置统一进入共享设置备份；旧备份的主题、隐私等字段恢复为共享设置。恢复默认也更新同一份共享值，并通知其他端。
