# 跨端设置与草稿

桌面端、Web 与 Remote 连接同一台电脑时共用设置与业务数据，不需要另建云账号。
Remote 使用电脑提供的共用页面，本功能不要求更新手机原生安装包，但电脑服务与页面需要包含此实现。

## 哪些共享

- 设置页各项统一共用电脑上的同一份值，包括深浅模式、主题色、界面背景、组件风格、界面密度、隐私模式、截图遮挡与网页通知。
- 消息气泡、字体、头像挂件、QQ 秀、消息时间、日期及序号，以及阅读交互和图片内存预算也统一共享。不提供“仅本设备”或单端覆盖选项；在任一端保存后，其他已连接界面自动重读。
- 全局搜索的来源与类型、号码查询偏好、会话日历类型、全部会话的包含隐藏／删除开关、联系人分组与排序及资料刷新范围全局共享，切换账号不更换使用偏好。新搜索模型首次将来源与类型重置为全选，此后保留显式选择，包括全部取消。
- 意图感知、推荐回复、互动画像的通用参数，邮箱红点、提醒与查询间隔，防撤回模式与通知开关，本地装扮及安装清单，年度报告页面选择，以及助手模型、提示词、思考强度与外部 MCP 同样全局共享。AI、邮箱与防撤回的通用选项在尚未打开账号时也可配置。
- 具体会话的防撤回／通知名单、群关键词、隐藏输入状态名单和 AI 启停规则仍属于对应账号与数据源；数据库容错和本机媒体关联也分别保存。群助手内部置顶、任务和助手结果已读标记、群待办历史、草稿、分析结果与画像属于业务内容，不因设置统一而合并。同号在线账号与导入备份不混用这些内容。
- 普通会话置顶与免打扰继续走 QQ 链路。选择“跟随 QQ”装扮时读取当前账号自己的 QQ 装扮，不把某个账号的 QQ 装扮变成其他账号的资料。

## 设置与运行现场

新消息系统通知与应用图标未读角标位于「常规 → 提醒与窗口 → 消息提醒」；应用内的消息红点、联系人未读数和群助手计数仍位于「基础功能 → 阅读与未读 → 未读显示」。移动设置入口不改变已保存的开关值。

“跟随系统”本身是共享设置，各端按同一规则解析各自系统的深浅状态。网页通知开关也共享，但系统通知授权由各端浏览器实际授予；一端未授权不会把其他端的共享开关关掉。
当前页面、窗口实际尺寸、滚动位置及截图期间的临时遮罩是操作现场，不会因另一端操作而跳走。电脑导出目录仍指电脑上的目录，手机实际保存文件使用系统提供的位置。

首次启用时，桌面已有外观和隐私等值初始化共享设置；手机旧值与共享值不同时，直接采用共享值，不保留单端覆盖。
没有设置过的项目使用统一默认值。
电脑尚未提供初值时，手机不会把旧值自动上传；手机上的主动修改会保留，之后桌面迁移不会覆盖它。

从旧版升级时，已经明确保存的全局值优先；其余通用偏好以首次打开的当前账号初始化，缺项使用默认值，不从其他账号拼接。已安装装扮取并集，当前使用哪款仍以当前账号为准。不同账号的旧值保存在本机迁移记录中，之后切号不会重新导入。迁移写入失败时保留原件和未完成状态，可在修复后重试。

## 草稿与失败处理

聊天草稿沿用 QQ 草稿存储，输入过程仍在本机保留恢复快照。助手草稿在输入停顿后共享，合成记录继续使用原有草稿存储。
内联图片在共享保存前通过已有分段上传转存到电脑，单图支持 32 MiB；失败保留本机素材，不把手机私有素材标识或 blob 地址当作共享图片。尚未写入正文的附件栏内容仍属于当前设备的编辑现场。
没有本机未提交修改时接受新共享稿；已有输入时保留正文。保存时自动协调版本，相同内容不会重复写入，不同内容以最新读到的版本重试保存当前编辑，不需要选稿或确认覆盖。清空和删除也记录版本，重复清空直接确认。
不再生成或保存草稿副本，同时编辑同一草稿时按实际成功保存的顺序更新内容。升级后读取账号状态时自动清理旧副本及其文件，不影响正式草稿和本机恢复快照；恢复旧备份时也执行同样清理。

设置保存失败会显示“未保存”和重试入口，不会在重连时偷偷重放失败操作。草稿写入失败保留本机恢复快照。
设置统一进入共享设置备份；旧备份的主题、隐私等字段恢复为共享设置。恢复默认也更新同一份共享值，并通知其他端。
