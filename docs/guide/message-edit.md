# 消息编辑与删除

WeQ 可以像「本地聊天记录编辑器」一样，往本地数据库里新增、修改、删除消息，不修改 QQ 服务器。
发送失败占位的移除是另一条仅清理界面状态的路径，不走原库删除。

## 1. 添加消息

在私聊或群聊的标题栏点 **➕** 打开「添加消息」弹窗。它是一个单窗口多子视图的编辑器：

```
main → 选发送者 · 开关回复并选原消息 · 编辑文本/@/表情/图片 → 添加
```

流程：

1. **选择发送者** —— 从会话成员里挑一个身份来发出这条消息（自己或他人）；
2. **回复（可选）** —— 打开回复开关后选一条原消息，会作为消息的**首元素**加入，并让后端把
   msgType 翻成 9；
3. **编辑正文** —— 文本、@、QQ 表情、图片四类内容可组合；
4. 点「添加消息」写入。**文本 / @ / 表情 / 图片至少要有一项**。

头像一律由 QQ 号现拼，不使用数据库里可能过期的头像 URL。

## 2. 修改消息

在消息上右键选 **修改**，打开原始元素编辑器（`MsgElementEditor`）。

它直接编辑这条消息在数据库里的原始 `elements` 数组，能力包括：

- **嵌套编辑**：元素里嵌套的对象 / 数组可以逐层展开修改；
- **字节 hex 编辑**：二进制字段以 hex 显示并可编辑；
- **数字输入**：数字型字段用数值输入框；
- **复制 JSON**：一键复制整份元素结构。

保存后写回数据库，聊天窗口按新内容重新渲染。

> [!warning]
>
> 原始元素编辑器改动的是底层数据，请先确认自己的修改意图，再保存。

## 3. 删除与恢复

### 删除

消息可右键或多选后 **删除**。确认时可勾选 **删除后不再显示**；未勾选则消息仍留在聊天中，带半透明的已删除覆盖。

QQ 原库记录沿用「QQ 式删除」，原地改写消息行的 40011 / 40012 字段并记住原值以便恢复。
漫游缓存（包括普通漫游、原生缓存与自发协议缓存）只修改 WeQ 的本地删除标记，不写 QQ 原库或服务器。
勾选不再显示后，删除造成的中间缺口可重新拉取，只有一条的缺口也会显示入口；实际重新收到的消息恢复显示，拉取失败仍可在删除列表恢复。

多选包含可恢复的已删除消息时，底部才显示 **恢复所选已删除消息**。该操作只恢复所选的已删除条目，不操作普通消息；失败条目保留选中。

### 移除失败占位

明确发送失败、没有确认信号的本机占位可右键「移除失败消息」，也可多选清理。这会直接从聊天中
移除占位并更新会话摘要，不撤回、不重发，也不删除附件或输入框的新草稿。切回会话或刷新视图
不会把已移除占位补回来；如果之后真正同步到已发送记录，真实消息仍正常保留。发送中和已提交
待同步的条目不会作为失败占位删除。

### 删除列表

标题栏的 **🗑 删除列表** 打开集中管理视图：

- 列出该会话里被 WeQ 删除的所有消息；
- 每条用与聊天窗口**完全相同**的气泡与渲染器展示（头像、昵称、回复都一致）；
- 被 WeQ 删除的消息带「恢复」按钮，成功后取消删除与隐藏；QQ 自身已删除而没有原始类型记录的消息不可恢复。

## 4. 撤回列表

标题栏的 **↺ 撤回列表** 打开防撤回的集中视图：

- 列出防撤回触发器在同会话里拦下的所有撤回；
- 因为触发器是在**原地取消** QQ 的撤回写入，消息内容完好，所以这里能正常渲染原消息；
- 每条额外展示「谁撤回的」「什么时候撤回的」；
- **没有恢复按钮** —— 消息从来没被删除过。

> [!tip]
>
> 「删除列表」是被 WeQ 主动删除、可恢复的集合；「撤回列表」是 QQ 本来要撤回、被 WeQ 拦下的
> 集合。两者都由同一个渲染管线构建，所以在弹窗里看到的和聊天里看到的完全一致。
