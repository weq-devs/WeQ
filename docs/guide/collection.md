# 我的收藏

左栏「更多功能 → 我的收藏」打开 QQ 收藏查看器。

## 1. 加载方式

打开时**两段式加载**：

1. 先立刻画出本地 `collection.db` 的收藏（快、离线可用）；
2. 再悄悄用微云收藏器的结果替换（慢，但更权威）。

网络失败或拿不到 `p_skey` 时**保留本地结果** —— 收藏永远不会因此变成错误状态。

## 2. 界面

```
┌───────────────────────────────────────────────────────┐
│ 我的收藏   [总数]   [同步中…]                          │
│ 🔍 搜索标题 / 内容 / 来源…                             │
│ [全部][图文][链接][图片][视频][语音][文件][位置][文本][其他] │
├───────────────────────────────────────────────────────┤
│ 卡片网格（编号 / 来源 / 类型徽章 / 内容 / 收藏时间）    │
├───────────────────────────────────────────────────────┤
│              上一页   第 N / M 页   下一页              │
└───────────────────────────────────────────────────────┘
```

- 顶部显示总条数与「同步中」标记；
- 搜索框在**全部字段**里搜（作者、群名、文本、链接、视频标题、语音转写、文件名、地点等）；
- 类型 chips 带计数，只显示有内容的类型；
- 分页是**真翻页**（不是滚动加载），每页 8 条。

## 3. 各类型卡片

| 类型 | 展示方式 |
| --- | --- |
| 文本 | 纯文本（空文本显示「(空文本)」） |
| 链接 | 封面缩略图 + 标题 + 简介 + 来源，点击用浏览器打开 |
| 图片 | 图片网格（最多 6 张，超出显示 +N），点击看大图 |
| 视频 | 封面（点击看大图）+ 播放图标 + 时长 + 标题 / 大小 |
| 语音 | 时长 + 转写文字（若有） |
| 文件 | 扩展名徽章 + 文件名 + 大小 |
| 位置 | 地点名 / 地址 / 坐标，点击在**高德地图**打开 |
| 图文 | 标题 + 正文 + 图片网格 |
| 其他 | 显示原始 type |

收藏图片走磁盘缓存的头像 / 收藏图片桥（`collectionImageUrl`），点击进入共享大图灯箱。

## 4. 导出收藏

收藏也可以批量导出：在[导出中心](./export.md)的 **导出收藏** 模式里，把 QQ 收藏导出为
JSON / CSV / XLSX / TXT 表格。图片只写 CDN URL，不下载。
