## 开始使用与账号

### 1. 必须一直开着 QQ 吗？WeQ 能独立登录吗？

查看、搜索和导出本地已有记录，不需要 QQ 一直在线；加密数据库要先拿到与它匹配的密钥。发送消息、拉取漫游、读取在线资料等操作仍需要该账号的 QQ 在线，并且 QQ 在线能力已就绪。

WeQ 目前不是脱离 QQ NT、自己维持完整登录的独立客户端。扫码取得密钥，也不代表已经下载了这个账号的全部历史。打开账号的步骤见[快速上手](https://weq-devs.github.io/WeqDocs/guide/getting-started.html)。

### 2. 「在线能力受限」是什么意思？关掉「启用 QQ 在线能力」会失去什么？

「在线能力受限」表示当前 QQ 在线能力或相关数据读取尚未就绪，点开详情可查看具体原因：可能是 QQ 未登录、内存读取未授权，也可能是数据库文件读不到。只要数据库仍可读取，就可以浏览、搜索和导出本地已有记录。

在「设置 → QQ → QQ 在线能力」关闭「启用 QQ 在线能力」，依赖 QQ 会话凭据的功能会立即停用。受限详情中的「启用 QQ 在线能力」可重新开启，或点「在线能力设置」查看该页。

### 3. QQ 在线能力、QQ 代理连接和长期授权有什么区别？需要都开吗？

按你要用的功能配置即可。代理连接和同步设置位于「QQ → QQ 在线能力」，长期授权在「应用 → 长期授权」管理。

- **想发消息、拉漫游或查看在线内容**，启用「QQ 在线能力」，等当前账号显示「已就绪」。就绪后，WeQ 也会自动向 QQ 服务器上报已读位置。
- **想把本人消息和已读同步回本机 QQ，或加速实时更新**，在「QQ 在线能力」页配置「代理连接」。开启在线能力并等当前账号显示「已连接」后，可使用「同步与实时更新」中的选项。这里的已读同步会把已成功上报的位置同步回同一台电脑上的 QQ。
- **想减少读取 QQ 会话凭据或抓包时的重复管理员授权**，在运行 QQ 的电脑上启用「长期授权」，也可以在需要时临时授权。长期授权显示「已授权」后，当前 QQ 账号仍需登录并等待在线能力就绪。

代理实时更新可提前展示临时会话、本人在其他设备发送的消息及更多富媒体。私聊标题会短暂显示对方的输入或讲话状态。申请通知、好友目录、禁言状态和群精华会随对应推送刷新。

具体设置见[使用手册的设置说明](https://weq-devs.github.io/WeqDocs/guide/settings.html#qq-在线能力与启用方式)。

### 4. 为什么提示「组件版本过旧」？不更新还能用吗？

内置的 QQ 解析组件带有效期，过期后 WeQ 会停在提示框、进不了主界面，需要换用包含有效组件的版本。可使用提示框里的更新入口；由系统包管理器安装的版本，请用包管理器更新。

过期不是聊天记录损坏，也不会删除账号数据。已经保存到本机的导出文件不受影响；想长期留住记录，建议提前导出为 HTML 或 WeQ JSON/JSONL，并一起保留媒体目录。

### 5. 在 Mac 上必须关闭 SIP 吗？几种授权有什么区别？

不必为了 WeQ 关闭 SIP。需要读取 QQ 内存时，可按受限详情的引导准备并打开 QQ 调试副本；副本与原版 QQ 共用数据目录和登录态，不是另一套聊天记录。

- **完全磁盘访问权限**：解决读不到本机 QQ 数据文件的问题。这跟密钥错误是两件事，反复扫码没用。
- **QQ 调试副本**：在 SIP 开启时为 WeQ 提供一个可读的 QQ 进程，需要在副本里登录目标账号。
- **长期授权**：减少内存读取、抓包反复提权，不能代替磁盘访问授权。

按界面给出的实际原因处理。详见[数据读取授权](https://weq-devs.github.io/WeqDocs/guide/macos-data-access.html)与[QQ 调试副本](https://weq-devs.github.io/WeqDocs/guide/macos-debug-copy.html)。

### 6. 手机、TIM 或另一台电脑的备份怎样打开？同一个 QQ 能共用密钥吗？

在账号主页选「导入备份」，选中备份目录，再按扫描结果确认账号。尽量保留完整目录结构，不要把备份数据库直接替换进正在使用的电脑 QQ 目录。

明文库不需要密钥；可识别的 Android 备份会先尝试自动推导，无法取得有效密钥时再按提示处理。同一个 QQ 号在不同设备、不同备份里的密钥不一定相同，以实际验证结果为准。支持的目录结构见[快速上手](https://weq-devs.github.io/WeqDocs/guide/getting-started.html)。

## 聊天记录与媒体

### 1. 手机或 QQ 里有的聊天，为什么 WeQ 里不全？空白占位能补回来吗？

WeQ 读的是当前数据源。手机上有的记录不一定已经同步到电脑；序号之间的空白占位只说明本地观察到了缺口，本身不含原消息正文。

可以在会话顶部或会话右键菜单里「拉取漫游消息」，也可以在「设置 → 聊天 → 会话浏览」里配置查看时自动补全。能补回多少取决于服务器还保留多少记录、账号有什么权限；补不回来时，可尝试导入仍保存着这段记录的设备备份。详见[消息与缺失记录](https://weq-devs.github.io/WeqDocs/guide/chat-view.html)。

### 2. 文字能看，图片、语音、视频或附件打不开，还能找回来吗？

消息文字和媒体文件是分开存的，能看到消息不代表原文件还在。先看「设置 → 资源与数据库 → 媒体来源」里的关联资源目录和外部安卓图片缓存，再在原消息处重试。

WeQ 会尝试可用的本地与在线来源；需要本机 QQ 凭据时，让对应账号在线并启用 QQ 在线能力。拿不到本机凭据时，聊天图片还可以使用「设置 → 凭据与账号 → 凭据管理」里已配置的外部 rKey。QQ 不在线或某条地址失效，不等于所有来源都没了；但原件已被清理、在线来源又不可用的资源，无法只凭文字记录还原。

### 3. 离线备份怎样连图片一起保存？为什么有些缓存入口是灰的？

备份时要同时保留数据库和媒体目录。标准目录里的 `nt_data` 装着图片、语音、视频、文件和表情，WeQ 会优先读备份自带的媒体；只有一个 `.db` 文件，不等于把附件也备份下来了。

没有备份媒体时，仍可关联同账号的本机资源，或尝试在线补全。静态备份不是本机 QQ 的实时缓存，所以部分缓存浏览、占用和清理入口不开放，这并不影响读取备份里实际存在的媒体。数据库可在「设置 → 资源与数据库 → 数据库管理」中查看。

## 导出与任务

### 1. 怎样只导出一个会话、一段时间，或群里某个人的消息？

- **一个会话或一段时间**：会话右键选导出，再设时间范围。
- **群里某个人的发言**：进群后点顶部「搜索聊天记录」，在「发送者」里填 QQ 号或 UID（可从候选里挑，也能勾「我」），再点同一行的「导出筛选结果」；关键词、时间和消息类型可以一起设。
- **几条指定消息**：在聊天里多选后导出，任务只会用本次选中的消息。

批量会话从菜单的「导出」进入。「导出群成员名单」保存的是成员资料，不是这些人的聊天正文。更多范围说明见[统一导出](https://weq-devs.github.io/WeqDocs/guide/export.html)。

### 2. 直接阅读、长期备份、以后还想增量更新，分别该选什么格式？

- **只是想看**：HTML 适合浏览器里翻阅，TXT 适合读和检索纯文本，CSV/XLSX 适合丢进表格。
- **长期归档、之后继续补**：选 WeQ JSON、JSONL 或 JSONL（压缩），需要时一并保存媒体。增量更新只支持 WeQ JSON/JSONL。
- **想回到 WeQ 里看**：用「导出查看器」，它支持 WeQ 正式归档和旧的聊天 JSON/JSONL，不支持 HTML、TXT、CSV、XLSX。

导出包里有媒体目录时，请和正文一起保留。格式细节见[统一导出](https://weq-devs.github.io/WeqDocs/guide/export.html)。

### 3. 任务显示「执行完成」，就是保存好了、内容也齐全了吗？Web 或手机保存到哪了？

要分开看三件事：执行结果、保存状态、缺失清单。执行完成不等于每个附件都取到了；想核对覆盖情况，导出时勾上「附带完整性报告」。

桌面端保存成功后可以直接打开结果或在文件夹里显示；保存失败可对已有结果重试，旧任务或还没确定位置的用「保存结果」，不用重新生成。

Web 的保存位置在运行 WeQ 的电脑或服务器上。要拿到浏览器或手机本地，还得在任务列表里下载已生成的结果，落到哪由浏览器或系统决定。

### 4. 收起任务面板、离开页面、暂停、取消、退出，分别会发生什么？

收起任务面板不取消任务。导出、漫游拉取、模型和更新包下载、资源清理这类由宿主执行的任务会继续跑；逐条转发、群相册视频上传、资源扫描则跟着发起它的窗口走，关掉那个窗口就不再继续后续部分。

「暂停」保留可继续的进度，「取消」结束本次执行；能不能重启后续作，要看这个任务有没有提供继续入口，不能一概当成断点续传。完全退出 WeQ 会停掉本机所有任务和服务；点关闭按钮则取决于「设置 → 应用 → 启动与退出 → 关闭窗口」，默认是最小化到托盘。详见[任务管理](https://weq-devs.github.io/WeqDocs/guide/export.html)。

## 增强功能与性能

### 1. 装好 WeQ 为什么还要下载增强包？本地识别和 AI 回复是一回事吗？

安装包里不带全部模型和推理组件，用到哪项就去「设置 → 应用 → 增强包」准备哪项资源。资源就绪后可直接使用；语音自动转文字这类行为还要单独在「设置 → 聊天 → 消息显示」里打开。

本地文字识别、语音转写、意图与画像资源和生成式聊天模型不是同一套东西。推荐回复要在「设置 → AI → API 配置」里配好服务商，再到「推荐回复」里选模型；意图感知和互动画像也各有自己的开关和模型选择。

选本地模型时推理就跑在这台电脑上；选 API 模型时，相应的输入会发给你选的服务商，是否收费由服务商决定。详见[模型设置](https://weq-devs.github.io/WeqDocs/guide/model-resources.html)与[语音转文字](https://weq-devs.github.io/WeqDocs/guide/voice-transcribe.html)。

### 2. 为什么任务自己暂停了、图片只显示小图？这算失败吗？

先看任务提示和搜索框旁的省流量图标。「设置 → 资源与数据库 → 资源加载」里的省流量模式可按设置限制原图、装扮、视频封面的自动加载，以及大文件和联网批量任务。如果任务明确提示因省流量暂停，这是策略等待，不是失败。

想马上处理，可以在任务列表里继续这次任务，或临时调整省流量模式。限制解除后是否自动继续取决于已保存的偏好；手动暂停的任务不会因为网络恢复自己跑起来。详见[省流量模式](https://weq-devs.github.io/WeqDocs/guide/cross-device-settings.html)。

### 3. 开久了变卡、内存越涨越高，怎样给出有用的反馈？

先打开「设置 → 关于 → 日志与性能」，确认性能记录开着，在问题出现前后各留一段，再从性能监视导出对应时间段。反馈时带上 WeQ 与系统版本、运行了多久、出问题前做了什么。

任务管理器里的进程总内存、JS 堆和「图片预览内存预算」是三个不同指标，图片预算也不是进程内存上限。重启后占用下降只能说明这轮进程释放了内存，不能证明长期增长问题已经解决。详见[性能监视](https://weq-devs.github.io/WeqDocs/guide/performance-monitor.html)。

## QQ 与多端

### 1. 在 WeQ 发出的消息，为什么电脑 QQ 窗口没有立刻出现？已读会同步吗？

WeQ 的发送结果、QQ 本地数据库和 QQ 窗口的显示不是同一步更新。WeQ 会先保留已确认发送的消息，等 QQ 同步到同一条记录再合并显示；别因为电脑 QQ 还没出现就再发一遍。结果暂未确认时，先回会话核对，再决定要不要重试。

QQ 在线能力就绪时，WeQ 自动向 QQ 服务器上报已读位置，可能清除手机等其他端的未读提醒。其他端的界面刷新由 QQ 处理，在 WeQ 中标为未读只改本地状态。详见[消息与已读](https://weq-devs.github.io/WeqDocs/guide/chat-view.html)。

### 2. 防撤回能找回以前已经撤回的内容吗？关掉 WeQ 还有效吗？

防撤回保留的是本地已有的消息，不是事后恢复工具；开启之前就丢掉的正文不会因此回来，也不能阻止对方在服务器上撤回。

规则装进本机 QQ 数据库后，不依赖 WeQ 窗口一直开着；但撤回通知需要 WeQ 在运行。改过保护范围后，QQ 可能要到下次重启才用上新规则。静态 PC 备份不会再收到 QQ 写入，也就拦不到实时撤回。

启用范围、触发器和实际状态在「设置 → 聊天 → 防撤回」，已拦下的内容从「查看撤回记录」进入。详见[防撤回](https://weq-devs.github.io/WeqDocs/guide/anti-recall.html)。

### 3. WeQ Remote 是手机上的独立 QQ 吗？电脑休眠或不在同一 Wi-Fi 时还能用吗？

Remote 连的是电脑上跑着的 WeQ，不在手机上另外登录 QQ。电脑要保持唤醒、WeQ 在运行、远程服务可用；完全退出 WeQ 后，手机就读不到电脑提供的内容了。

在「设置 → 服务 → Web 与 Remote」开启远程连接后，同一局域网可直接扫码配对；不同网络可按页面引导配置 Tailscale。手机能上网不等于能访问电脑，连不上时先看电脑这边的服务和当前连接地址。详见[Web 与手机连接](https://weq-devs.github.io/WeqDocs/guide/remote-web.html)。

新配对的手机默认可访问开启 Remote 时所在的 QQ 账号。以后可在「Web 与 Remote → 已配对手机」展开该手机的「访问权限」，增删可以访问的账号。一个手机可以在已授权账号之间切换，桌面窗口继续打开各自的账号。

### 4. 为什么换账号、换手机后设置也跟着变了？哪些内容不会混在一起？

连到同一台电脑的桌面端、Web 和 Remote 共用一份应用级偏好：主题、背景、阅读习惯、通用 AI 设置等会在各端一起变化，不提供单账号或单设备覆盖。

账号凭据、会话名单与规则、草稿、分析结果仍按对应账号和数据源保存；同一个 QQ 的在线账号和导入备份也不会合成一份内容。页面、滚动位置这类操作现场不会跟着另一端跳。详见[跨端设置与草稿](https://weq-devs.github.io/WeqDocs/guide/cross-device-settings.html)。

### 5. 在 WeQ 里用气泡、字体、挂件，会改变别人或原版 QQ 看到的样子吗？

个性装扮里的「使用」只改 WeQ 本地显示，不会给 QQ 账号开通装扮，也不改变别人看到的效果。

实际发送时用不用 QQ 个性字体是另一项设置，在聊天输入区的「个性字体」面板中控制，它依赖账号真实可用的 QQ 字体信息，不等于能发出任意已下载的字体。详见[表情与装扮](https://weq-devs.github.io/WeqDocs/guide/emoji-resources.html)。

## 功能范围与反馈

### 1. 看着像 QQ，是不是所有 QQ 操作都能做？

还不能。一对一主动呼叫和群通话不是一回事，群通话尚未开放完整流程；查 QQ 号、群号不等于能主动加好友或申请入群；群临时会话也还不能发普通文件。

底层研究或早期演示不代表安装版已经提供相关功能。查找入口时，可参考[使用手册](https://weq-devs.github.io/WeqDocs/guide/)，并以所用版本的[更新记录](https://github.com/weq-devs/WeQ/blob/dev/CHANGELOG.md)和实际界面为准；尚未开放的功能不会通过重装出现。

### 2. 还是解决不了，反馈时要带什么？

到「设置 → 关于 → 反馈」，写清 WeQ 版本、QQ 版本、操作系统，以及从哪里开始、做了什么、期望和实际分别是什么。有具体报错文字就原样附上，卡顿问题可附性能记录。

日志在「设置 → 关于 → 日志与性能」查看，账号主页右上角的齿轮也能进入设置。启动异常时可直接打开日志目录。发送前请检查截图和日志里的聊天正文、账号、个人路径和凭据，不必上传整份聊天数据库。也可以直接到 [GitHub Issues](https://github.com/weq-devs/WeQ/issues) 反馈。
