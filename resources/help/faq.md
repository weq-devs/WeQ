# 常见问题

> 想系统地了解每一项功能，请先看[使用手册](../../docs/guide/index.md)；本页只回答具体问题。

## 为什么显示数据库损坏

数据库顺坏大概率是不正常的关闭或者断电导致QQ本体的数据库意外受损，**而不是WeQ的代码问题**

**v1.1.0版本之后，WeQ已支持一键备份，修复数据库**

## 为什么显示占位空消息

占位消息指的是，根据seq递增的规则发现，**数据库里面缺失了这段时间的消息**

可能是QQ不在线的时候的消息，也可能是老版本数据库迁移导致的

- 如果是最近时段的占位空消息，打开QQ客户端查看这部分内容时，会自动从服务器拉取写到数据库里面
- 如果是很久之前的空消息，服务器上大概率也没有存储了，只能知道这里曾经有消息，但是不知道是什么

**v0.4.0版本后，WeQ已支持自主拉取漫游消息记录/群聊历史消息记录**

## 什么是QQ助手组件损坏

助手组件损坏指的是native模块缺失，或者构建过期

- 尝试打开安装目录查看是否缺失native文件
- 或者更新到最新版本通常会解决问题

> [!important]
>
> v0.3.0版本之后，就不再校验客户端环境了

## QQ弹出的报错提示是什么情况

> 已过时，v0.3.7版本解决这个问题

过去QQ弹窗提醒： 不支持的功能

是WeQ在外部探测QQ的在线状态导致的副作用，weq向深链接的监听端口9210-9219发送 测试深链接 tencent:// 会导致改问题

最新版本已经修复！！

## 为什么提示找不到媒体

找不到媒体意味着本地没有存储，尝试一下方法解决

- 很老的图片： 导入安卓目录辅助寻址，手机可能存储了对应资源
- [推荐] 如果cdn服务器还可以下载，打开对应账号的QQ客户端，并允许获取rkey，完成下载
- 无法完成注入，或者MacOS 版本时，尝试导入外部rkey服务器的地址，或者自己使用onebot框架部署（例如napcat）

## 本项目的两种使用策略

WeQ 有两种使用方式，可按需选择：

- 打开QQ客户端，允许WeQ注入实现全部功能，包括很多小巧思
  - 个性装扮
  - 个性卡片/主页   字体/气泡/浮屏/挂件等等等
- 完全离线，可以正常使用绝大部分功能，包括：
  - 导出，克隆，存储消息查看

> [!tip]
>
> v0.3.7版本native重构后，已支持pt_login 接口获取pskey等凭据，可能大幅度优化小巧思在MacOS上面的体验？？

## 切换账号后为什么还看到旧账号的会话

正常不会。WeQ 在切换 / 退出时会显式清空账号级缓存再打开新账号，并强制重挂载主界面。
如果你确实看到旧数据，请退出到首页后重新进入，并把日志附给我们。

## 静态（离线）账号为什么没有缓存资源

静态账号导入的只是一份数据库快照，`nt_data` 里的头像、图片等资源属于本机在线账号，不属于
这份快照，因此「本地资源」页只保留「本地数据库」一项。

## 语音转文字在哪里开

**设置 → 语音配置 → 转录模型**：先下载模型，再点「设为当前」。选好之后聊天里的语音即可
转文字（离线识别，不走网络）。

## 导出完成后找不到文件

两种方式：

- 在**设置 → 全局设置 → 导出保存目录**里设好目录，之后导出任务可一键批量保存；
- 或在导出灯箱里打开「自动保存」，导出完成后会弹出保存路径。

没设置目录、也没开自动保存时，导出产物会先留在任务列表，需要你手动保存。

## Web 版的访问令牌丢了怎么办

令牌在服务启动时打印在终端。想固定令牌，用环境变量显式指定：

```bash
WEQ_TOKEN=$(openssl rand -hex 24) node server.mjs
```

详见 [WeQ Web 说明](../../apps/web/README.md)。
