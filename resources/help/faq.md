# 常见问题

> 想系统地了解每一项功能，请先看[使用手册](../../docs/guide/index.md)；本页只回答具体问题。

## 为什么显示数据库损坏

数据库读取失败可能与文件损坏、密钥或数据源不匹配、文件尚未就绪等情况有关。异常退出或断电也可能造成损坏，但仅凭提示无法确定原因。

请先保留原始文件并查看检查报告。确认结构损坏后，可从 **设置 → 数据与存储 → 维护工具 → 数据库修复** 尝试修复；修复会先备份，再重建可读取的内容，不能保证恢复全部记录。

## 为什么显示占位空消息

占位消息表示根据消息序号发现了本地记录缺口，不代表这段记录一定还能从服务器找回。

QQ 离线期间未同步的消息、旧版本数据迁移等情况都可能造成缺口。

- 可先在 QQ 客户端查看对应时段，确认是否能同步记录；
- 也可以使用 WeQ 的漫游或群历史拉取入口尝试补全，结果取决于服务器保留情况和账号权限；
- 较早的记录可能已无法获取，缺口本身不包含原消息正文。

## 提示 QQ 助手组件不可用怎么办

可能是原生模块缺失、加载失败或与当前平台、版本不匹配。请保留具体报错，核对安装包是否适合当前系统。

- 安装版可重新下载对应平台的完整安装包；
- 源码运行请参考[原生产物说明](../../docs/develop/native-artifacts.md)，不要混用不同平台的文件。

## 为什么提示找不到媒体

媒体可能未保存在本地、路径已变化，或在线资源已过期。可根据实际情况尝试：

- 在「设置 → 数据与存储 → 媒体来源」核对本地路径，或绑定仍保留图片的安卓缓存目录；
- 保持对应 QQ 账号在线，在允许读取 QQ 内存的情况下尝试获取下载凭证；
- 无法获取本机凭证时，可查看「设置 → 服务与集成 → 外部 RKEY」的配置说明。在线文件是否可下载仍取决于资源有效期与访问权限。

## 切换账号后为什么还看到旧账号的会话

切换账号后应只显示新账号的数据。如果仍看到旧会话，请先退出到首页再重新进入；若问题持续，
请记录切换步骤并反馈日志，分享前注意检查和遮盖个人信息。

## 静态（离线）账号为什么没有缓存资源

静态账号导入的只是一份数据库快照，`nt_data` 里的头像、图片等资源属于本机在线账号，不属于
这份快照。因此维护工具会禁用本地缓存、存储占用和清理缓存等资源入口；仍可从「数据库管理」查看快照数据库。

## 语音转文字在哪里开

**设置 → 模型与识别 → 语音识别 → 本地语音模型**：先下载模型，再点「设为当前」。模型下载完成后，
可对本机可读取的语音进行离线识别，识别过程不会将语音发送给 API 服务商。

## 导出完成后找不到文件

请先查看任务列表中的生成结果与保存状态：

- 「生成完成」不一定表示已保存到目标位置；尚未保存的结果可在任务列表中另存；
- **设置 → 常规 → 默认保存** 提供「每次询问保存位置」和「自动保存到默认文件夹」；
- 导出按钮旁的菜单可为本次操作选择保存方式，不改变全局偏好。保存失败时，请按提示核对目录，再对已有结果重试保存，无需重新生成。

Web 版的服务器保存与浏览器下载是两件事，详见[统一导出](../../docs/guide/export.md)。

## Web 版的访问令牌丢了怎么办

令牌在服务启动时打印在终端。想固定令牌，用环境变量显式指定：

```bash
WEQ_TOKEN=$(openssl rand -hex 24) node server.mjs
```

详见 [WeQ Web 说明](../../apps/web/README.md)。
